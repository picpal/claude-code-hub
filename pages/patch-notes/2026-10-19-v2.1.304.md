> 원문: [Claude Code v2.1.304 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.304)

## 변경사항

- 플러그인이 먼저 실행되어 mod의 hook 중 하나를 건너뛸 때 transcript 라인을 추가하여 이벤트와 플러그인의 이름을 표시합니다
- mod의 `tool.check` 응답에 `decider: "person"`을 추가했습니다. 이는 permission dialog 또는 호스트의 callback만 요청을 승인할 수 있으며, 아무도 물어볼 수 없는 경우 mod의 reason으로 거부됩니다
- mod의 `tool.check` 이벤트에 `e.isReadOnly`를 추가했습니다. tool call이 read-only일 때 설정됩니다
- `/auto-mode-setup`을 추가했습니다. 이는 프로젝트와 최근 세션을 읽어 auto mode에 사용자의 환경을 학습시키는 가이드 설정입니다. 이제 Bedrock, Vertex, Foundry, Claude apps gateway 및 telemetry-disabled 세션에서도 사용 가능합니다
- `/claude-api managed-agents-secure`를 추가했습니다. 이는 아무것도 변경하지 않고 Managed Agents의 agent 설정을 Anthropic의 published security guide와 비교합니다
- transcript 보기(Ctrl+O)의 compaction summary에 이전에 호출된 tool의 이름을 추가했습니다
- Pro 및 Max 플랜에서 비활성 대화를 재개할 때 5시간 usage limit의 눈에 띄는 부분을 사용하게 될 경우 경고를 추가했습니다. 어쨌든 재개하거나 새 대화를 시작하면 이전 대화를 참조할 때 Claude가 조회할 수 있습니다
- 시작 시 `ANTHROPIC_API_KEY`를 승인하거나 `/config`에서 "Use custom API key"를 전환한 후 hourly check까지 organization policy가 새로 고쳐지지 않는 문제를 수정했습니다
- Linux에서 `sandbox.filesystem.denyRead` glob에 character class가 아닌 괄호(예: `[user-id]` route 폴더)가 포함된 경우 sandboxed commands가 시작되지 않는 문제를 수정했습니다
- mounted drive 또는 최상위 폴더(`/Volumes`, `/media`, WSL의 `/mnt/c`)에서 `rm -r`을 실행할 때 `rm -rf /Applications`가 받는 safety prompt를 받지 않는 문제를 수정했습니다
- `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC`가 파일을 자르는 동안 디스크가 가득 찰 때 저장된 transcript에서 메시지를 삭제하는 문제를 수정했습니다
- plugin이 subagent를 생성하거나 완료된 것을 다시 실행하여 `--max-turns`, Stop 또는 ended input을 초과하여 headless run을 유지하는 문제를 수정했습니다
- 실패한 mod reload가 로드된 상태로 유지되는 버전의 tool과 command를 제거하고 이전 버전이 여전히 로드되고 있는지 여부에 대해 메시지가 잘못되거나 침묵하는 문제를 수정했습니다
- mod의 버튼을 클릭할 때 `key`가 없는 동일한 레이블을 가진 버튼이 변경되지 않은 상태로 다시 그려지면 버튼의 클릭이 손실되는 문제를 수정했습니다
- managed settings이 있는 머신과 Team 및 Enterprise 플랜에서 built-in `plugin-authoring` skill의 mod sharing이 secret scan에서 중단되는 문제를 수정했습니다
- 예약된 Cowork cloud 세션이 WebFetch가 승인할 사람이 없었던 URL approval을 필요로 하는 각 subagent마다 다시 5분을 기다리는 문제를 수정했습니다
- Write 결과 및 rejected edit이 작업 디렉토리 외부의 파일을 `../../…`로 표시하는 문제를 수정했습니다. 이제 `~/…` 또는 전체 경로를 표시합니다
- Cowork cloud 세션의 "/" 메뉴에서 선택할 때 claude.ai Directory plugin의 skill이 command로 실행되지 않는 문제를 수정했습니다
- 다른 계정이 터미널에 로그인되어 있을 때 Remote Control이 desktop 대화의 history를 영구적으로 보류하는 문제를 수정했습니다
- DISABLE_TELEMETRY 또는 DO_NOT_TRACK이 paid plan에서 설정된 경우 Remote Control이 Claude Desktop에서 시작되지 않는 문제를 수정했습니다
- SDK 및 desktop 세션에서 model 전환, 메시지 및 interrupt가 context usage check 뒤에서 기다리는 문제를 수정했습니다
- LLM gateway 뒤에서 `context_management: Extra inputs are not permitted` 오류를 수정했습니다. Claude Code는 이제 해당 필드 없이 요청을 다시 전송합니다
- server-managed settings를 통해 전달된 OpenTelemetry 설정이 first-run setup 중이나 /logout 후 첫 시작 시 로그인한 후 전체 세션 동안 무시되는 문제를 수정했습니다
- Claude Desktop Code tab 세션의 macOS 및 Linux에서 unsandboxed Bash command가 ~/.zshrc와 같은 shell startup 파일에서 내보낸 environment variable을 보지 못하는 문제를 수정했습니다
- 서버 오류 후 Consumer Terms notice가 하루 이상 건너뛰어지는 문제를 수정했습니다
- 네트워크 또는 서버 오류 후 `/privacy-settings`가 사용자에게 적용되지 않을 수 있는 선택지를 제공하는 문제를 수정했습니다
- turn을 중단하는 동안 Claude Code가 API가 너무 길다고 거부한 대화를 compacting할 때 "Context limit reached" 또는 "Prompt is too long" 오류가 발생하는 문제를 수정했습니다
- subagent가 작업을 완료한 직후에 message를 받거나 재개될 때 최근 작업을 잊어버리는 문제를 수정했습니다
- `claude --help` 텍스트가 `--tools`, `--resume`, `--debug`, `--json-schema`, `--disable-slash-commands`, `--system-prompt-snapshot` 및 `claude update`의 실제 동작과 일치하지 않는 문제를 수정했습니다
- HEAD가 detached되어 있거나 다른 branch에 있을 때 `claude --worktree`가 worktree와 해당 branch를 확인하지 않고 제거하여 commit을 손실할 수 있는 문제를 수정했습니다
- resumed 및 cloud 세션이 시작 시 plugin이 다시 로드될 때마다 Claude에 전체 skill list를 다시 보내는 문제를 수정했습니다
- interrupt가 idle pipe 또는 image처럼 명명된 장치에서 대기하는 Read를 종료하지 않는 문제를 수정했습니다
- `/effort status`, `/effort ultracode` 및 prompt의 effort indicator가 `CLAUDE_CODE_EFFORT_LEVEL`이 `auto` 또는 `unset`이고 level이 전송되지 않을 때 추측된 effort level을 표시하는 문제를 수정했습니다
- PreToolUse hook의 deny reason이 같은 tool call의 Agent SDK callback hook이 timeout될 때 timeout error로 대체되는 문제를 수정했습니다
- Bash 및 PowerShell이 디스크가 가득 차 있지 않은 한 세션의 tool-results 폴더로 복사할 수 없을 때 대규모 command의 출력 파일을 삭제하는 문제를 수정했습니다
- preview가 있는 multiple-choice 질문에 입력한 note가 약 100 열 미만의 terminal에서 "…"로 잘리는 문제를 수정했습니다. 이로 인해 입력한 내용이 숨겨집니다(anthropics/claude-code#82768)
- self-paced `/loop` wakeup이 1시간 최대값에 예약되어 1시간 prompt cache가 만료된 직후에 발생하여 해당 wakeup이 더 이상 대화를 uncached로 다시 읽지 않는 문제를 수정했습니다
- agent team: main 세션에서 shutdown 요청을 승인하면 더 이상 전체 CLI가 종료되지 않습니다
- skill의 `once` hook이 실행된 후 다른 skill의 동일한 hook도 제거하는 문제를 수정했습니다
- transcript mode의 `{` 및 `}`가 prompt를 일관성 없는 행에 내려놓거나 화면 밖에 내려놓는 대신 transcript의 첫 행에 내려놓는 문제를 수정했습니다
- `CLAUDE_CODE_AUTO_COMPACT_WINDOW=200k`가 조용히 100K window를 설정하는 문제를 수정했습니다. 변수는 이제 `--autocompact`처럼 `k` 및 `M` suffix를 허용하며, 값이 범위를 벗어나거나 무시될 때 경고합니다
- 마우스 버튼이 해제되기 전에 Ctrl+C를 누를 때 agents 보기가 text selection을 삭제하지 않고 복사하는 문제를 수정했습니다
- `/usage`를 개선하여 "try again in a moment" 대신 rate limit on usage data가 끝나는 시점을 표시합니다
- session에서 로드, 다시 로드 또는 로드 실패한 mod가 표시될 때의 라인을 개선했습니다
- 여러 보기가 있는 artifact를 개선했습니다. 링크를 요청할 때 Claude는 이제 각 보기의 링크를 작성하고 주소 표시줄이 보기를 전환할 때 동일하게 유지됨을 설명합니다
- cloud 세션을 개선했습니다. 새 대화의 첫 번째 turn은 더 이상 server가 `alwaysLoad: true`를 설정하지 않는 한 claude.ai에서 동기화된 plugin의 local(stdio) MCP server를 기다리지 않습니다
- server가 다른 session data를 전달하는 status update를 거부할 때 remote 세션이 상태를 복구하는 방식을 개선했습니다
- auto mode의 session 파일 크기를 개선했습니다. safety classifier의 context은 더 이상 모든 요청과 함께 저장되지 않습니다
- `claude -p` invalid-settings 경고를 개선했습니다. 로드되지 않은 파일은 로드되지 않은 항목만 나열하고, 긴 목록은 파일별로 제한됩니다
- SDK 및 headless mode에서 대규모 compacted 세션의 재개를 개선했습니다. 재개 후 첫 번째 요청이 더 빨리 전송됩니다
- 많은 subagent가 동시에 실행 중일 때 반응성 및 처리량을 개선했습니다
- 길거나 재개된 대화에서 요청을 보낼 때 메모리 사용량을 개선했습니다
- Self-hosted runner: git host가 세션의 repository에 대해 "not found"로 응답할 때 표시되는 오류를 개선했습니다. 이제 repository 이름과 요청할 사람을 표시합니다
- Windows: standard Git for Windows install을 사용하여 cmd launcher 대신 git.exe를 직접 실행하여 git command start-up을 개선했습니다
- mod의 `settings.read` hook을 변경하여 각 settings layer를 수신하고 병합된 설정을 다시 작성하므로 관리형 mod이 organization의 설정을 ceiling으로 만들 수 있으며, retention sweep이 사용하는 `cleanupPeriodDays`를 포함합니다
- `/artifacts` delete 확인을 번호가 매겨진 선택지로 변경했습니다. 1 또는 Enter는 artifact를 유지하고, 2는 삭제하고, y, n 및 Esc는 여전히 작동합니다
- 세션에서 Claude가 작성한 mod를 켜는 질문을 링크나 session id가 없는 plain text로 변경했습니다. 새 turn이 시작될 때 유지되며, 켜지면 Claude는 로드된 항목을 알려줍니다
- tool search를 custom `ANTHROPIC_BASE_URL` 뒤에서 기본적으로 켜도록 변경했습니다. gateway에서 400 또는 422는 없이 재시도됩니다
- compaction을 변경하여 그 후 Claude에 skill list를 다시 보냅니다. `/reload-skills`는 이제 새로
