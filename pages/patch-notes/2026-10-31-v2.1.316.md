> 원문: [Claude Code v2.1.316 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)

## 변경사항

- `ultrathink` 키워드를 비활성화하는 `CLAUDE_CODE_DISABLE_ULTRATHINK`를 추가했습니다
- Claude apps gateway에 pooled group budgets를 추가했습니다: 그룹의 각 멤버가 자신의 한도에 더하여 공유하는 월간 예산으로, spend limits admin API에서 `pooled_budget`으로 설정합니다
- 루프 형태로 서로를 인증하는 시스템 cross-certificates를 유지하기 위해 `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`를 추가했습니다(private CA가 하나를 필요로 하는 서버용)
- 세션의 설정을 상속하는 대신 아무것도 설정하지 않았을 때 subagents가 실행되는 effort level을 설정하는 `CLAUDE_CODE_SUBAGENT_EFFORT`를 추가했습니다
- Claude apps gateway에 `managed.policy_mode: layered`를 추가했습니다: 개발자와 일치하는 모든 policy가 적용되며, 각각 아래에 나열된 policy들을 병합하는 방식으로 작동합니다(첫 번째만 적용되지 않음)
- Claude apps gateway Bedrock upstreams의 `guardrail.input_tagging`을 추가했습니다. 이는 prompt를 Amazon Bedrock guardrail의 prompt attacks filter가 필요로 하는 input tags로 감싸며, `all_messages_and_system`은 system prompt도 태깅합니다
- 2026년 10월 30일부로 Opus 4.8의 fast mode를 폐기했습니다. 2026년 11월 30일에 제거될 예정입니다. 제거 후 Opus 4.8에 대한 fast mode 요청은 오류를 반환하며 standard Opus 4.8로 폴백되지 않습니다. 속도 향상을 유지하려면 Opus 5.5로 마이그레이션하십시오
- Claude Code가 자체적으로 종료될 때(예: credentials이 거부되거나 cloud session이 보관됨) macOS 및 Linux에서 shell commands가 실행 중인 채로 남아있는 문제를 수정했습니다
- Bash tool의 shell에서 값에 줄바꿈이 있는 bash aliases(Git Bash 제외) 및 이름이 대시로 시작하는 함수가 손상되거나 손실되는 문제를 수정했습니다
- Bash tool에서 시작된 bash scripts가 `SHELLOPTS`를 내보낼 때 첫 번째 명령 후 중지되는 문제를 수정했습니다
- 명령이 type cast, `param`, `using` 또는 attribute로 시작할 때 PowerShell hooks이 exit code 2에서 차단되지 않는 문제를 수정했습니다
- 압축된 response가 끊기거나 손상될 때 일부 network requests가 행(hang)되는 문제를 수정했습니다
- Vertex AI 및 Amazon Bedrock의 `sonnet`, `opus` 및 `haiku`이 가장 최신 모델을 계정이나 지역에서 사용할 수 없을 때 session 중에 오류를 표시하는 대신 이전 모델로 전환하지 않는 문제를 수정했습니다
- Claude apps gateway이 요청이 명명하는 모든 모델을 `availableModels`, `deniedModels` 및 `models`에 대해 확인하지 않는 문제를 수정했습니다. 차단된 모델을 명명하는 요청은 이제 해당 필드를 명명하는 400을 반환합니다
- managed settings이 Claude apps gateway를 요구하는 위치에서 `claude auth login`이 실행을 거부하는 문제를 수정했습니다. 터미널에서 이제 gateway sign-in을 표시합니다
- `--restricted` sessions이 Read allow rule이 포함할 때 작업 디렉토리 외부에서 파일을 업로드하는 문제를 수정했습니다
- 보이지 않는 문자를 포함하는 prompts이 전송하려면 두 번째 Enter가 필요한 문제를 수정했습니다. 일반 prompts은 이제 첫 Enter에서 정리된 상태로 전송되며, 명령은 여전히 검토를 기다립니다
- 부모 sub-agent의 model을 상속한 sub-agents이 background job이나 message가 이를 깨울 때 main model로 이동하는 문제를 수정했습니다
- managed `autoMode.allow` list가 `"$defaults"`를 포함하지 않을 때 host app의 `--settings`, `/permissions`에 추가된 첫 번째 rule, 또는 `/auto-mode-setup`에서 built-in exceptions을 다시 받는 문제를 수정했습니다
- auto mode가 server가 safety verdict를 반환하지 않았기 때문에 turn을 중지했을 때 cloud sessions 및 cloud scheduled tasks이 failed로 표시되지 않는 문제를 수정했습니다
- background agent가 여전히 실행 중일 때 auto mode가 turn을 중지한 이유를 `claude -p` text output이 때때로 말하지 않는 문제를 수정했습니다
- `CLAUDE_CODE_AUTO_MODE_SERVER=1`이 proxy 또는 experimental betas가 비활성화된 LLM gateway 뒤의 host application(예: Claude Desktop)에서 시작된 sessions에서 무시되는 문제를 수정했습니다
- credential-named environment variable이 `1`과 같은 switch value로 설정되었을 때 plugin MCP `headersHelper` scripts이 손상된 `CLAUDE_PLUGIN_ROOT` 및 server URL을 수신하는 문제를 수정했습니다
- SDK `register_repo_root` control request이 작업 디렉토리 외부의 디렉토리(`CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` 포함)에서 CLAUDE.md를 로드하지 않는 문제를 수정했습니다
- Artifact tool이 artifact database access rules을 `self` level에서 `?`로 표시하고, republish를 거부할 때 이러한 rules을 다시 인용하지 않는 문제를 수정했습니다
- `/model <id>`이 모델을 이 버전에서 인식하지 못하고 auto-compact가 200K context window를 가정할 때 경고를 표시하지 않는 문제를 수정했습니다
- "hold space to speak" hint가 한 session에서 세 번의 표시를 소진하고 push-to-talk이 바인드되지 않았을 때 빈 key를 표시하는 문제를 수정했습니다
- Grep 및 Glob이 timeout에서 search process가 killed되지만 exit되지 않을 때(Windows에서 확인됨) 반환되지 않는 문제를 수정했습니다
- conversation 일부가 여전히 저장 중일 때 `/clear` 또는 `/resume`이 실행되었을 때 conversation을 재개해도 그 plan이 복원되지 않는 드문 경우를 수정했습니다
- 좁은 터미널에서 first-run setup이 security notes 및 terminal-setup explanation에서 단어를 삭제하는 문제를 수정했습니다
- Enterprise survey card가 짧은 일시 중지 후 입력된 1 또는 0을 받는 문제를 수정했습니다. 입력된 답변은 이제 Enter가 필요합니다
- Self-hosted runner: Claude가 작동 중일 때 전송된 message가 Stop 후 답변되는 문제를 수정했습니다(session의 process가 교체된 후)
- Self-hosted runner: session이 새 machine으로 이동할 때 MCP server의 on/off switch가 때때로 손실되는 문제를 수정했습니다
- Windows: Bash tool이 Git Bash에서 rc file이 errexit 및 pipefail을 설정하고 winpty aliases만 정의되거나 정의되지 않을 때 aliases 및 functions을 손실하는 문제를 수정했습니다
- Claude Desktop 또는 web의 Code tab에서 시작된 `/code-review`를 개선했습니다: cloud 및 `claude remote-control` sessions이 이제 plain-text list 대신 findings card를 표시합니다
- 대규모 repositories에서 `/diff`를 개선했습니다: 각 refresh는 보통 한 번 더 적은 full-repository git command를 실행하며, git이 느릴 때 refreshes가 분산됩니다
- `/ultrareview`, cloud session 또는 cloud agent가 GitHub remote를 찾지 못했을 때 표시되는 messages를 개선했습니다: 이제 https://github.com/new에서 repository를 생성하도록 말하며, `/ultrareview`는 더 이상 `gh`이 거부하는 `gh` command를 제안하지 않습니다
- SSL certificate errors를 개선했습니다: 이제 intermediate certificate를 남기는 server 등 가능한 원인들을 명명하고, 각각의 수정 방법을 표시합니다
- auto mode를 변경했습니다: `autoMode.allow` list가 `"$defaults"`를 포함하지 않을 때 더 이상 scheduled-task prompts의 built-in rule을 제거하지 않습니다
- Team 및 Enterprise logins을 위한 server-managed settings를 변경했습니다: Anthropic의 API에서 가져온 settings가 이제 approval prompt 없이 적용되며, 검증되지 않은 stored copy는 거부됩니다
- [VSCode] chat panel에서 Claude apps gateway로 sign-in하도록 추가했습니다(terminal 불필요)
- [VSCode] `ultrathink`를 `xhigh` effort에서 실행하고 terminal처럼 chat box에 rainbow로 표시하도록 변경했습니다
- [VSCode] model setting이 `opus[1m]`과 같은 `[1m]` tag를 가질 때 missing Effort slider, Ultracode switch 및 model name을 수정했습니다
- [VSCode] settings file에 오류가 있을 때 saved `/btw` side-question history가 너무 일찍 삭제되는 문제를 수정했습니다
- [VSCode] conversation이 "Yes, and manually approve edits"로 plan이 approved된 후 reload 또는 restart 시 Auto mode에서 돌아오는 문제를 수정했습니다
- [Cloud sessions] cloud sessions에 form card를 추가했습니다. MCP server가 요청하는 form을 채우거나 거부할 수 있으므로 요청이 확인 없이 취소되지 않습니다
- [Cloud sessions] cloud 또는 Remote Control session이 messages를 최신 상태로 가져올 때 "Catching up…" line을 추가했습니다
- [Cloud sessions] network secrets을 변경했습니다: Enterprise members가 이제 자신의 cloud environments에서 network secrets을 추가 및 삭제할 수 있으며, 보기만 가능한 대신입니다
- [Cloud sessions] cloud sessions의 Changes pane을 개선했습니다: list가 남겨두는 항목에 대한 note가 이제 diff 위의 row 대신 branch name 옆의 badge입니다
- [Cloud sessions] cloud session의 Files pane에서 file search를 수정했습니다: Claude가 디렉토리를 변경한 후 folders가 ../.. paths로 표시되던 문제를 수정했습니다. 결과는 이제 project의 root에서 path를 표시합니다
- [Claude Tag] Claude가 Slack channel에서 만든 canvas를 해당 channel에서 edit 또는 append하지 않던 문제를 수정했습니다(canvas가 다른 channel 또는 DM으로도 공유된 후)
- [Claude Tag] 두 organizations가 모두 Claude를 설치했고 Slack이 reply를 다른 organization의 app으로 전달했을 때 Slack Connect thread에서 untagged replies가 답변되지 않는 문제를 수정했습니다
- [Claude Tag] cloud scheduled task의 live status checklist가 Slack에서 절반만 완료된 상태로 유지되던 문제를 수정했습니다. run이 이제 해당 run 중에 게시한 top-level messages를 edit할 수 있습니다
- [Claude Tag] Slack channel의 Respond automatically switch를 channel의 Configure page 및 Claude Tag admin settings의 "How Claude participates" choice로 변경했습니다
- [Code Review] Code Review analytics page에 findings-by-severity card를 추가했습니다: period의 총 findings, severity별로 stacked된 daily chart, 및 각 severity의 count를 표시합니다
