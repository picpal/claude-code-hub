> 원문: [Claude Code v2.1.275 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)

## 변경사항

- Claude 앱 게이트웨이 로그인에 로그인된 계정을 추가했습니다. 게이트웨이에서 이름을 지정하면 자격 증명이 저장되기 전에 확인하고, `/status`에 표시됩니다
- 현재 차례를 중단하고 대기 중인 모든 메시지를 한 번에 보내는 송신 즉시 키(ctrl+enter 또는 ctrl+x ctrl+s)를 추가했습니다. 송신된 메시지와 대기 중인 메시지는 모델이 수신할 때까지 회색으로 표시됩니다
- 구성된 `otelHeadersHelper`가 실패할 때 시작 경고를 추가했습니다. 따라서 원격 측정을 자동으로 내보내지 않는 세션을 감지할 수 있습니다
- claude.ai 계정에서 활성화된 skills 및 plugins을 터미널 세션과 동기화하도록 추가했습니다. `syncClaudeAiSkills: false` 또는 `syncClaudeAiPlugins: false`로 옵트아웃할 수 있습니다
- `/plugin install <plugin> --marketplace <source>`를 추가했습니다. 이는 플러그인 설치 전에 마켓플레이스를 추가하도록 제안합니다
- 압축 또는 재개 후 복구된 메모리 파일의 나이 참고가 요청 간에 변경되어 prompt cache를 놓치는 문제를 수정했습니다
- `--forward-subagent-text` stream-json 및 SDK 출력이 `context: fork` skill에서 생성한 subagents의 메시지와 subagent 또는 다른 forked skill에서 호출한 forked skills의 메시지를 삭제하는 문제를 수정했습니다
- 사용자 정의 `fileSuggestion` 명령을 사용하거나 `@.`/`@./`를 입력할 때 @-mention 파일 제안이 MCP resources 아래에 묻히는 문제를 수정했습니다
- 전체 화면 모드가 긴 차례의 축소된 tool row 아래에 background-task 완료 알림을 배치하는 대신, 도착한 위치에 배치하도록 수정했습니다. 이제 각 알림이 열린 행을 닫습니다
- `claude plugin marketplace update`가 fetch가 실패했고 마켓플레이스의 이름이 해당 리포지토리를 따를 때 GitHub 마켓플레이스의 로컬 복사본을 삭제하는 문제를 수정했습니다
- 플러그인 및 마켓플레이스 메시지, 로그 및 `claude plugin marketplace list`가 git, ssh 또는 마켓플레이스 URL에 저장된 암호 또는 token을 표시하는 문제를 수정했습니다
- 재개된 cloud 세션이 대기 중인 메시지가 대체된 후 transcript에 답변하지 않은 질문을 남기는 문제를 수정했습니다
- vim mode가 dot-repeated "!" 또는 빠르게 입력된 "i!" 후 커서를 한 문자 오른쪽에 배치하여 비어있지 않은 prompt를 shell mode로 전환하는 문제를 수정했습니다
- 전체 화면 모드가 큰 파일 diff를 위로 스크롤할 때 몇 초 동안 멈추거나 표시되지 않는 문제를 수정했습니다
- responses에서 가끔 `</ccmemory>` 스타일의 닫는 태그가 나타나는 문제를 수정했습니다
- 플러그인 메시지, 로그 및 VS Code 플러그인 대화상자가 일부 git 주소에 대해 잘못된 server를 표시하는 문제를 수정했습니다
- API 오류 응답을 다시 쓰는 네트워크 게이트웨이 뒤에 있는 사용자들의 경우 매 차례마다 터미널 `API Error: 400`이 나타나는 문제를 수정했습니다. 이는 beta 요청 header가 거부될 때 발생합니다
- Linux의 샌드박스 Bash 명령이 shell이 zsh일 때 실패한 명령에 대해 종료 코드 0을 보고하는 문제를 수정했습니다
- Read tool이 메모리 부족 상황에서 큰 파일의 일부를 디코딩할 수 없을 때 오류를 보고하는 대신 hanging하는 문제를 수정했습니다
- `--resume`, resume picker preview, 재개된 background agents 및 transcript view가 저장된 history에 malformed task-reminder 또는 @-file attachment entry가 포함된 세션에서 실패하는 문제를 수정했습니다
- malformed message entry를 포함하는 conversation을 재개할 때 crash가 발생하고, 그러한 conversation이 위로 스크롤된 상태에서 새 메시지를 수신할 때 전체 화면 crash가 발생하는 문제를 수정했습니다
- 저장된 transcript에 malformed message content block이 포함된 경우 세션이 재개되거나 시작되지 않는 문제를 수정했습니다
- Grep, Glob 및 @-file 제안이 20MB 출력 상한선을 초과하는 검색에서 hanging하거나 메모리가 부족한 문제, 그리고 system ripgrep이 경고 flood 후에 오류 대신 "no matches"를 보고하는 문제를 수정했습니다
- forked 또는 background 세션의 `/rewind`가 세션의 file-history backups을 완전히 복사할 수 없을 때 zero-filled 또는 truncated file을 복구하는 문제를 수정했습니다
- 전체 화면 세션이 slash-command dropdown이 열린 상태에서 빠르게 입력하거나 키를 누를 때 때때로 "Claude Code exited after an unrecoverable interface error"와 함께 종료되는 문제를 수정했습니다
- background 세션이 stdin을 통해 공급된 명령이 file descriptors를 모두 소진한 머신에서 실행될 때 crash하고 worker를 재시작하는 문제를 수정했습니다
- `~/.claude.json`이 malformed `mcpNeedsAuthNoticed` 값을 포함할 때 시작 중 crash가 발생하는 문제를 수정했습니다
- `--resume` 및 `--continue`가 시작한 built-in tool이 이후 server-side flag에 의해 꺼졌을 때 conversation의 초기 thinking을 삭제하는 문제를 수정했습니다
- 마우스로 전체 화면 `claude --resume` session picker에서 선택한 텍스트가 clipboard에 도달하지 않는 문제를 수정했습니다
- 플러그인 reload previews가 플러그인이 `--plugin-dir` 또는 `--plugin-url` archive에서 로드되었을 때 실행 중인 세션의 추출된 플러그인 파일을 대체하는 문제를 수정했습니다
- `--drain-wait-sec`을 사용하는 self-hosted runners가 SIGTERM drain 중에 완료된 차례의 최종 결과를 잃는 문제를 수정했습니다. 이제 runner는 차례가 보고될 때까지 잠시 기다립니다
- 특정 `matcher`를 가진 `SubagentStop` hooks이 agent type이 비어있는 모든 stopping subagent에 대해 발동하는 문제를 수정했습니다
- 샌드박스 Bash 명령이 `hooks/` 또는 `config/` 이름의 project directory에 쓸 수 없는 문제를 수정했습니다
- 다른 머신에서 세션이 재개되거나 scratchpad가 지워진 후 Artifact 업데이트가 "File not found"로 실패하는 문제를 수정했습니다. 이제 페이지의 마지막 게시된 버전이 복구됩니다
- `/update-config`가 file permission checks와 일치하지 않는 `Write(path)` permission rules를 `Edit(path)` rules 대신 쓰는 문제를 수정했습니다
- 번들된 claude-api skill의 live-sources table에서 4개의 dead documentation URLs (Pricing, Computer Use, Skills, CLI)를 수정했습니다
- `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` 줄을 포함하는 `--system-prompt`에 대한 prompt caching을 개선했습니다. 이제 그 위의 텍스트는 SDK의 array 형식처럼 globally cached됩니다
- Claude Desktop이 열리지 않을 때 `/desktop` 오류를 개선했습니다. 이제 이유와 다음 단계를 말합니다
- Artifact tool의 publish 및 read results를 개선했습니다. 이제 페이지를 열 수 있는 사람과 소유자의 Share 메뉴가 제공하는 것을 말합니다
- artifact publish results를 개선했습니다. 이제 전송된 tab icon을 이름으로 지정하고, 페이지에 NUL byte가 포함되어 있을 때 경고하며, stale publish 후 병합할 최신 페이지의 flaky fetch를 재시도합니다
- 붙여넣은 이미지 및 첨부 이미지를 개선했습니다. 이제 Desktop 및 VS Code를 포함하여 Claude가 permission prompt 없이 파일로 열 수 있는 위치에 저장됩니다
- Artifact tool의 guidance를 개선했습니다. 따라서 Claude는 shared artifact에 edit access를 받았을 때 별도의 복사본을 게시하는 대신 제자리에서 업데이트합니다
- plan-usage reads를 개선했습니다. 한 머신의 editor windows 및 non-interactive 세션은 이제 각각 usage endpoint를 호출하는 대신 지난 1분 내에 만든 read를 공유합니다
- `ListPlugins` tool description을 개선했습니다. 따라서 Claude는 로컬로 `/plugin`으로 설치된 plugins이 아니라 claude.ai 계정에서 활성화된 plugins을 나열한다는 것을 압니다
- 터미널이 느리거나 일시 중지되었을 때의 responsiveness를 개선했습니다. 터미널이 따라잡는 동안 출력이 더 이상 뒤떨어지지 않습니다
- synced account-skills folder의 파일에 대한 Write 및 Edit results를 개선했습니다. 이제 변경 사항이 계정에 저장되지 않으며 저장 방법을 말합니다
- Claude 앱 게이트웨이 로그인에 대한 `/logout`을 업데이트했습니다. 이제 token 취소를 광고하는 게이트웨이에서도 세션을 종료합니다
- hosted 세션이 container restart 후 질문하지 않고 대신 답변하지 않은 permission prompt를 유지하도록 변경했습니다
- Artifact tool을 변경하여 emoji favicon 대신 첫 게시 시 한 단어의 tab icon을 요청하도록 했습니다
- Chrome의 Claude를 auto mode에서 변경하여 bypass mode처럼 extension의 per-site check를 건너뛰도록 했습니다. 이는 리다이렉트 후 `browser_batch` "Permission denied"를 수정합니다
- npm 소스에서 설치된 plugins을 `npm pack --ignore-scripts` 및 integrity-verified로 fetch하도록 변경했습니다. 따라서 package의 install scripts는 더 이상 실행되지 않습니다
- scheduled 및 Run now routine runs을 변경하여 편집할 수 있는 artifact의 data를 저장하고 페이지를 다시 게시하도록 했습니다. public artifacts, first publishes 및 deletes는 여전히 요청합니다
- 마지막 세션 이후 일회성 scheduled routine이 실행되었음을 알려주는 startup notice를 제거했습니다
- [VSCode] Memory 대화상자 내에서 저장된 memory를 보고, 편집하고, 삭제하는 기능을 추가했습니다
- [VSCode] 텍스트를 입력하지 않고 첨부 이미지를 보내는 기능을 추가했습니다
- [VSCode] server list 로드가 실패했을 때 MCP servers 대화상자에 Retry link를 추가했습니다
- [VSCode] proposed-change diff tab의 각 변경 아래에 accept 및 reject 버튼을 추가했습니다. 따라서 edit을 변경별로 검토할 수 있습니다
- [VSCode] permission card가 대기하고 content가 계속 도착하는 동안 transcript이 작은 단계로 아래로 이동하는 문제를 수정했습니다
