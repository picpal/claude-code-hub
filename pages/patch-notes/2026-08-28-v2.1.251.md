## 변경사항

- `PreModelSwitch` 및 `PostModelSwitch` hook events 추가됨 (model switch를 차단, 확인 또는 주석 처리); `SessionStart` resume hooks는 이제 session staleness 및 예상 re-cache 비용을 수신합니다
- foreground subagent의 tool calls 및 results에 대한 live streaming을 Remote Control clients에 추가함 (background subagents, 기본값, 여전히 상태만 표시됨)
- `/usage`에 Spend limit bar 및 spend limits가 있는 Claude apps gateway 뒤의 개발자를 위한 `rate_limits.spend_limit` status line field 추가됨
- `/cost`에 per-session prompt-cache line (hit ratio, misses, tokens re-cached, warm/cold) 및 status line scripts를 위한 matching `prompt_cache` object 추가됨
- `claude --help`에 `attach`, `logs`, `stop`, `respawn`, `rm` 추가됨; running background session의 `--resume` 메시지는 이제 정확한 `claude attach <id>` 명령을 표시합니다
- file tools (Read, Write, Edit)가 permission check 후 working directory 내에서 swapped되는 symlink를 따르는 문제 수정됨. 이로 인해 승인된 위치 외부의 파일을 읽거나 쓸 수 있었습니다
- marketplace entry에서 선언된 plugin commands가 plugin directory 외부를 가리킬 수 있는 문제 수정됨; 이러한 경로는 이제 path-traversal 오류로 거부됩니다
- project settings가 detailed beta tracing이나 raw API body logging을 활성화할 수 있었던 문제, 그리고 lower-scope beta tracing endpoint가 managed settings나 host app에 의해 pinned된 OTLP collector를 우회할 수 있었던 문제 수정됨
- Workflow tool이 permission check가 실행되기 전에 session이 읽을 수 있는 항목 외부의 `scriptPath`를 읽는(그리고 오류에서 인용하는) 문제 수정됨
- Grep 및 Glob이 symlinked search path를 통해 도달하는 파일에 `Read(...)` deny rules을 적용하지 않는 문제 수정됨
- model이 thinking만 생성한 턴 이후 "text content blocks must be non-empty" 오류에서 conversations이 stuck되는 문제 수정됨
- fresh install에서 첫 번째 실행 시 startup default이 auto mode인 계정의 경우 auto mode 대신 default mode에서 시작하는 문제 수정됨
- Opus 5 요청이 effort가 xhigh/max이고 thinking이 꺼져 있을 때 "effort … is not supported when thinking is disabled" 오류로 실패하는 문제 수정됨; 이 경우 effort는 이제 `high`로 전송됩니다
- Claude Desktop이 다른 session에서 전달한 메시지에 답장하는 문제 수정됨: 해당 session id에 대한 `SendMessage`는 이제 "not reachable" 오류로 실패하는 대신 Claude Desktop을 통해 전달됩니다
- 많은 parallel subagents가 있는 경우 TUI lag 수정됨: 초당 progress ticks는 이제 transcript에서 쌓이는 대신 predecessor를 대체합니다
- agent teams 수정됨: teammate의 final answer가 team lead에 도달하지 않는 문제 - 이제 content-free "available" notice 대신 idle notification에 도달합니다
- background subagents가 unnamed sibling이나 parent agent (`from`은 agent type이었으므로 주소가 아님)로부터의 메시지에 답장할 수 없는 문제 수정됨
- managed-settings `disableAutoMode`가 mid-session에 도착하면 이미 실행 중인 auto-mode session을 default mode로 다시 이동하지 않는 문제 수정됨
- 현재 Opus model이 이미 1M context window를 가지고 있을 때도 표시되는 "switch to Opus 1M for 5x more context" tip 수정됨
- Claude apps gateway sessions이 stored Anthropic profile (예: Console sign-in)을 active로 취급하는 문제 수정됨: `/status`에 나열하고 gateway 401s를 재시도하지만, 요청이 사용하지 않습니다
- cloud sessions이 host가 session의 initial model을 설정하고 있을 때 Claude에 model이 변경되었다고 알리는 문제 수정됨
- organization의 정책이 Remote Control을 비활성화할 때 Remote Control이 failure를 보고하는 문제 수정됨; 이제 단일 quiet notice를 대신 표시합니다
- Remote Control에서 `/mcp reconnect`가 server가 다른 session에서 비활성화되었을 때 real remedy 대신 generic withheld-detail 오류를 표시하는 문제 수정됨
- `--input-format stream-json`: message id 없이 전송된 client-injected assistant tool calls이 첫 번째 호출로 병합되고 결과가 손실되는 문제 수정됨. 여기에는 older sessions를 resume할 때도 포함됩니다
- directory change가 session을 기존의 동일 ID transcript로 재배치할 때 session transcripts이 silently 덮어써지는 문제 수정됨
- background sessions 및 해당 subagents가 `git worktree add`로 생성한 git worktree 내에서 파일을 편집할 수 없는 문제 수정됨
- 다른 Claude Code process가 plugin marketplace를 refresh하고 있을 때 background sessions이 plugin skills 없이 가끔 시작되지 않는 문제 수정됨
- tmux over SSH에서 opened background session의 텍스트를 선택하는 문제 수정됨: 이제 OSC 52로 fallback하는 대신 foreground session처럼 tmux buffer로 복사됩니다
- SDK MCP server의 handshake acknowledgment이 손실되었을 때 SDK 및 cloud sessions이 indefinitely 행(hang)하는 문제 수정됨; 이제 wait는 70초 후 timeout되고 해당 server만 failed로 표시합니다
- self-hosted runner가 session이 force-stopped된 후 stuck session의 Bash tool processes를 실행 중인 상태로 남겨두는 문제 수정됨
- `/usage-credits` for Team 및 Enterprise members whose admin이 org의 usage-credit limit을 $0로 설정함: 이제 cap이 reached되었다고 말하는 대신 admin에게 물어보도록 제안합니다
- `--worktree --tmux` with a merge-request number on a gitlab.com origin이 GitLab ref를 직접 fetch하는 대신 doomed GitHub-style fetch를 먼저 시도하는 문제 수정됨
- `/dev/tty`를 열기하는 editors (예: `emacs -nw`, `micro`)의 경우 background sessions에서 Ctrl+G가 "Emacs quit unexpectedly"로 실패하는 문제 수정됨
- `additionalDirectories` entry containing a null byte가 startup을 crash하거나, SDK host, IDE, 또는 hook에서 나온 경우 `/add-dir` 및 later settings updates를 깨뜨리는 문제 수정됨; 이제 skipped됩니다
- MCP server menu의 copy shortcut 수정됨: 항상 success를 주장하는 대신 sign-in URL이 어떻게 복사되었는지 표시합니다
- italic text (예: session recap line)이 GNU screen 및 `screen` terminal type을 사용하는 tmux sessions에서 highlighted blocks로 렌더링되는 문제 수정됨
- `claude mcp add --header` 및 `claude mcp add-json` help text가 wrong transports를 명명하는 문제 수정됨
- `claude ultrareview` 및 `/ultrareview`가 cloud session이 시작되지 않을 때 전체 30분을 대기하는 문제 수정됨; 이제 조기에 중단하고 이유를 보고합니다
- Bash permission checks가 arithmetic expression을 integer shell variable에 할당하는 명령을 auto-approving하는 문제 수정됨 (예: `OPTIND=1/0`, `RANDOM=2+2`); 이제 approval을 prompt합니다
- backgrounded sessions (`←`, `/background`, `--bg`)이 shell에서 exported된 Vertex/Bedrock gateway (`ANTHROPIC_*_BASE_URL` + `CLAUDE_CODE_SKIP_*_AUTH`)를 잃는 문제 수정됨. 따라서 모든 요청이 실패했습니다
- `claude --bg --model fable` on Max plans이 interactive session on the same account이 여전히 Fable allowance를 가지고 있는 동안 usage credits를 요청하는 것을 멈추는 문제 수정됨
- one-time "make auto mode your default" offer이 unattended sessions (예: agent-team teammate panes)에 나타나는 문제 수정됨. 여기서 stray keypress가 읽지 않은 상태로 수락할 수 있었습니다
- managed-settings approval prompt이 settings이 변경되지 않았을 때 same Claude apps gateway에 다시 sign in한 후 re-appearing하는 문제 수정됨
- disabled `/bug` 및 `/share`가 `/feedback`이 비활성화되었다고 보고하는 문제 수정됨; tips, `/help`, 및 refusal messages은 org policy나 env var이 이를 끌 때 더 이상 `/feedback`을 제안하지 않습니다
- cloud session creation이 transient GitHub connection failure 이후 GitHub setup을 조언하는 문제 수정됨 — 메시지는 이제 retry를 대신 제안합니다
- interactive sessions 중 CPU usage 개선됨 — redundant UI re-renders를 줄입니다
- install size 개선됨: native binary은 약 5 MB 더 작습니다
- cloud sessions 개선됨: session의 network proxy가 Bash command 중에 연결을 끊으면, tool result는 이제 "connection reset" 대신 host 및 reason을 표시합니다
- `/schedule` 개선됨 — Claude Code에서 configured된 MCP servers를 cloud routines에 attach할 수 없음을 설명합니다. bare "No MCP connectors" 메시지 대신입니다
- own subagents의 메시지 framing 개선됨: Claude는 sender가 이 session 내의 worker이지, unrelated Claude session이 아님을 알립니다
- prompt placeholder 개선됨 — background subagent이나 fork transcript을 subagent panel이나 `/tasks`에서 opened 상태로 보고 있을 때 "Message @name…"을 읽도록 합니다
- MCP server names의 sanitization 개선됨 — error messages, menus, command results에서
- Amazon Bedrock session start 개선됨 `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` (예: Claude Desktop) 하에서: Bedrock model ID 또는 ARN이 주어진 session은 더 이상 inference-profile discovery를 대기하지 않습니다
- managed settings approval dialog 개선됨 — 마지막으로 승인한 이후 변경된 settings만 나열합니다
- model의 tool call이 malformed될 때 retry 개선됨: broken output은 이제 retry context에서 삭제됨. Bedrock, Vertex, Foundry에서도 포함됩니다
- `/radio`를 Bedrock, Vertex AI, Foundry, Claude Platform on AWS에서 사용할 수 있도록 변경됨. telemetry가 비활성화되었을 때도 포함됨
- Claude in Chrome이 browser actions을 항상 Claude Code의 permission checks를 통해 실행하도록 변경됨 — telemetry가 비활성화된 sessions 포함. 이전에는 Chrome extension의 자신의 prompts를 사용했습니다
- `CLAUDE_CODE_SUBAGENT_MODEL`을 변경함 — 모든 것을 override하는 대신 default subagent model을 설정합니다: agent definition의 `model:` 및 explicit per-spawn model이 이제 precedence를 갖습니다
- active model이 recognized Claude model이 아닐 때 (예: custom `ANTHROPIC_BASE_URL` 뒤의 third-party models) default commit trailer를 `Co-Authored-By: Claude Code`로 변경됨
- seat-based Enterprise subscriptions의 default model을 Opus 5로 변경됨 — 다른 premium plans과 일치합니다
- `/effort`를 변경함 — model당 default effort level을 저장합니다. 각 model은 switch할 때 자신의 setting을 유지합니다
- analytics를 변경함 — managed settings가 gateway login을 강제하거나 읽을 수 없기 때문에 sign-in 이전에 더 이상 꺼지지 않음; gateway에 signed in하거나 `DISABLE_TELEMETRY`를 통해 signed in하면 꺼진 상태로 유지됩니다
- Bedrock, Vertex, Foundry의 footer PR badge, 및 telemetry가 off일 때를 변경함 — `gh pr view` 대신 GitHub API를 직접 호출합니다 (`gh auth token`, `GH_TOKEN`, `GITHUB_TOKEN` 통해)
- Bash command output files이 created되고 commands가 sandbox에서 실행될 때 read back되는 방식을 변경함. sandboxed command는 이들을 redirect하거나 replace할 수 없습니다
- plugin/LSP install suggestions 및 auto-mode default offer을 변경함 — 당
