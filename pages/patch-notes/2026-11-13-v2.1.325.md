> 원문: [Claude Code v2.1.325 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

## 변경사항

- zstd 압축 응답 디코딩 방식의 보안 문제를 수정했습니다
- VS Code 및 유사한 통합 터미널에서 Claude가 Jupyter 노트북을 읽거나 편집한 후 노트북 셀을 다시 실행하는 방법을 설명하는 spinner tip을 추가했습니다(한 번만 표시됨)
- 조직의 정책이 요청을 차단할 때 표시되는 오류 아래에 계속 진행하는 방법을 설명하는 줄을 추가했습니다: `/rewind`를 실행하여 메시지를 변경하거나 `/clear`를 실행합니다
- sandboxed `git checkout`, `git stash` 또는 autostash pull이 `.claude`의 파일과 같은 보호된 파일을 업데이트할 수 없을 때 Claude를 위한 참고 사항을 추가했습니다
- worktree, `--separate-git-dir` checkout 및 Android `repo` checkout의 bare repository에서 `/security-review` 및 skills의 inline git 명령이 오류로 중지되는 문제를 수정했습니다
- 모델 설정이 `opusplan` 또는 `haiku`일 때 자신의 모델을 가진 subagent가 plan-mode 모델로 이동하는 문제를 수정했습니다
- 다른 모델의 subagent가 파일 읽기 및 MCP 결과를 main session의 모델로 크기 조정하는 문제를 수정했습니다
- 많은 third-party gateway 및 Foundry의 session이 모든 turn에서 context length 오류로 중지되지 않고 압축되는 문제를 수정했습니다
- Claude Code가 clean exit 없이 중지된 후 resumed session에서 최근 turn이 누락되는 경우가 있는 문제를 수정했습니다
- 작업 디렉토리가 삭제된 후 shell 명령이 launch 디렉토리에서 실행되는 문제를 수정했습니다. 이제 명령이 메시지와 함께 실패하며 다시 발행할 수 있습니다
- `plansDirectory` 폴더가 승인된 plan edit을 받을 수 없을 때 손실되는 문제를 수정했습니다. 이제 plan이 기본 plans 폴더에 저장되고 경고에 위치와 이유를 표시합니다
- 저장된 `sonnet[1m]` 모델 설정이 새 설치 시 API가 거부하는 모델 id로 다시 쓰이는 문제를 수정했습니다
- scheduled task가 회신한 후 focus view가 프롬프트에 대한 회신을 숨기는 문제를 수정했습니다
- fullscreen이 off일 때 background subagent 뷰에서 프롬프트가 누락되는 경우가 있는 문제를 수정했습니다
- 목록 및 permission prompt의 긴 옵션이 줄바꿈될 때 부분적으로 덮어쓰이고 first-run 화면이 narrow 터미널에서 줄을 잃는 문제를 수정했습니다
- permission rule에 대한 startup warning 및 "N MCP servers need authentication" notice가 view에서 스크롤되었을 때 표시된 것으로 기록되는 문제를 수정했습니다
- agent의 이름이나 작업 폴더에 제어 문자나 줄바꿈이 포함되어 있거나 이를 포함할 때 welcome header가 제어 문자를 표시하거나 줄을 넘어서 나뉘는 문제를 수정했습니다
- Claude가 오직 당신만 실행할 수 있는 명령을 시도할 때 표시되는 빨간 오류를 수정했습니다. 이제 dim 줄이 프롬프트에서 입력할 때만 실행됨을 표시합니다
- `/stats`가 Active days total을 실제보다 1일 높게 표시하는 문제를 수정했습니다
- `/insights`가 session이 분석 조건에 맞지 않을 때 report가 준비되었다고 말하고 HTML report에 두 개의 값을 escaping 없이 작성하는 문제를 수정했습니다
- `/voice`가 managed settings, `--settings`, 또는 프로젝트의 `.claude/settings.json` 또는 `.claude/settings.local.json`이 voice mode를 유지할 때 voice mode가 변경되었다고 말하는 문제를 수정했습니다. 이제 이를 유지하는 것을 표시합니다
- IDE welcome dialog가 Windows 및 Linux에서 Quick Launch에 Cmd+Esc를 표시하는 문제를 수정했습니다
- Slack app tip이 조직의 정책이 cloud session을 거부할 때 표시되는 문제를 수정했습니다
- `claude purge`가 키를 읽을 터미널이 없을 때 자동으로 hang되고 project picker 및 `-i` prompt가 stdin이 piped될 때 키보드를 무시하는 문제를 수정했습니다
- `claude plugin eval --output-dir ''`가 report를 현재 폴더에 작성하는 문제를 수정했습니다. 이제 오류와 함께 종료합니다
- `claude -p` 텍스트 출력이 터미널에서 text styling 이외의 제어 문자를 전달하는 문제를 수정했습니다. pipe 및 파일은 변경되지 않습니다
- leftover `.oauth_refresh.lock.owner.tmp.*` 파일이 config 디렉토리에 쌓이는 문제를 수정했습니다
- `/fast`가 keyless Console sign-in 아래에서 "Fast mode has been disabled by your organization"이라고 말하는 문제를 수정했습니다. Claude Code가 서버에 요청하지 않았습니다
- `/model`이 조직이 모델을 제한한다고 말하는 문제를 수정했습니다. Claude Code가 네트워크가 없는 경우 등과 같이 확인할 수 없을 때입니다
- `/login`에서 "Sign in with your Console account"가 브라우저 단계 직후에 Esc를 눌렀을 때 기존 login을 대체하는 문제를 수정했습니다
- 브라우저가 sign-in이 실패하거나 취소된 일부 경우에 sign-in success page를 표시하는 문제를 수정했습니다
- `claude auth status` 및 기타 short 명령이 Console profile에 lock을 남겨서 다음 session이 약 1분 동안 hang되는 문제를 수정했습니다
- background session이 claude.ai login에서 시작될 때 shell이 시작한 background service의 API key 또는 token을 사용(및 billing)하는 문제를 수정했습니다
- session이 background에서 다른 sign-in으로 이동하는 더 많은 경우를 수정했습니다. 이제 이러한 이동이 거부되며 작동하는 내용을 설명하는 메시지가 표시됩니다
- exit dialog의 두 번째 Enter가 background로의 이동이 거부된 후 background work를 중지하는 문제를 수정했습니다
- Amazon Bedrock의 token counting이 `allowedProviders` managed setting이 허용하지 않을 때 conversation을 Bedrock에 전송하는 문제를 수정했습니다
- AWS `credential_process` helper 및 Google Cloud default credentials가 Claude Code를 `HOME` environment variable 없이 시작할 때 실패하는 문제를 수정했습니다
- session이 subagent의 plan이 승인된 후 때때로 이전 permission mode로 돌아가는 문제를 수정했습니다
- Agent SDK `applyFlagSettings()` 호출의 한 개의 invalid value가 이전 호출의 모든 settings을 자동으로 버리는 문제를 수정했습니다. 이를 수행할 호출이 이제 오류와 함께 거부됩니다
- session이 pull request가 오직 자신의 review 또는 merge만 필요할 때 input 대기 중으로 표시되는 문제를 수정했습니다
- 인식할 수 없는 `teammateMode` settings value가 경고 없이 무시되는 문제를 수정했습니다. `claude -p`, startup warning 및 `claude doctor`가 이제 skipped entry로 나열합니다(적용되지 않음)
- `--worktree`가 새 home directory에서 처음 실행할 때 `CLAUDE_CODE_PLUGIN_SEED_DIR`의 plugin에서 `WorktreeCreate` hook을 건너뛰는 문제를 수정했습니다
- brief-mode session(예: Dispatch)이 turn이 이미 회신한 후 회신을 다시 전송하는 문제를 수정했습니다
- Claude가 plugin이 다른 URL에 나열할 때 cloud session에서 작동하는 Atlassian, Asana 또는 Sentry connector가 실패했다고 말하는 문제를 수정했습니다
- Claude Desktop 및 SDK session이 folder move 또는 pre-warmed start 후 folder의 자신의 MCP server(`.mcp.json`, local)를 host-added로 나열하거나 전혀 나열하지 않고 WebSocket을 연결하지 않는 문제를 수정했습니다
- `/mcp`가 plugin이 연결 중일 때 plugin reload가 제거한 후에도 plugin의 MCP server를 계속 나열하는 문제를 수정했습니다
- MCP server가 "needs authentication" 상태를 유지하고 `mcp_tool` hook이 skip되는 문제를 수정했습니다. 잠시 동안만 거부된 token refresh 후입니다
- MCP elicitation request가 headless mode에서 server의 연결이 tool call 중에 대체될 때 물어보지 않고 취소되는 문제를 수정했습니다
- SDK host의 MCP tool call이 tool call이 MCP server를 다시 연결한 후 "Not connected"로 답변하는 문제를 수정했습니다
- MCP task가 질문이 Esc로 닫히거나 다시 묻힌 후 stuck되는 문제를 수정했습니다. footer가 이제 입력이 필요함을 표시하고 `/tasks`에서 Enter가 질문을 다시 표시합니다
- background MCP task가 같은 server로의 다른 호출이 연결을 잃었을 때 업데이트 중지되는 문제를 수정했습니다. 나중의 호출이 다시 연결할 때입니다
- background MCP task의 질문이 당신이 아직 입력 중인 메시지를 덮는 문제를 수정했습니다. 이제 draft를 전송하거나 지울 때까지 대기하고 spinner 및 turn timer가 계속 실행됩니다
- `worktree.sparsePaths` 및 sparse plugin 및 marketplace clone이 git 2.34와 같은 older git version에서 repository의 root file을 생략하는 문제를 수정했습니다
- self-hosted runner session이 mid-session에 추가된 repository를 사용할 수 없는 문제를 수정했습니다
- Claude가 자신의 artifact 또는 해당 data를 읽기 전에 permission을 요청하는 문제를 수정했습니다
- deny 및 ask permission rule 및 Artifact tool에 대한 hook이 일부 cloud session에 적용되지 않는 문제를 수정했습니다
- Code Mode script가 worktree를 무시하고 `EnterWorktree`로 입력된 프로젝트에 `~` path를 작성하며 sign-in이 만료된 후 `/mcp`가 MCP server를 connected로 표시하는 문제를 수정했습니다
- permission dialog 또는 plan approval에서 Yes와 함께 입력된 단어가 Code Mode에서 Claude에 도달하지 않는 문제를 수정했습니다
- Claude가 Code Mode script 중에 ended session을 resume할 때 자체적으로 작업을 시작하는 문제를 수정했습니다. 이제 다음 prompt를 기다립니다
- queued message가 VS Code에서 한 turn으로 병합되거나 한 메시지에 이미지가 있을 때 OpenTelemetry `user_prompt` event가 이전 메시지의 텍스트를 생략하는 문제를 수정했습니다
- slash command의 `allowed-tools` grants가 turn 중에 또는 후에 깨어난 background agent에 적용되는 문제를 수정했습니다
- `/feedback` 및 `/bug`가 signed-in account 또는 organization이 기록한 다른 session만 업로드하도록 수정했습니다
- relative deny 및 ask permission rule(예: `Read(./.env)`)이 `cd` 후 프로젝트를 더 이상 커버하지 않는 문제를 수정했습니다. 이제 추가된 디렉토리에도 적용됩니다
