> 원문: [Claude Code v2.1.311 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.311)

## 변경사항

- `self-hosted-runner`에 `--hold-idle-file` 및 `--max-hold-min`을 추가하여 호스트가 실행 중인 프로세스를 보고할 때 유휴 세션을 유지하도록 함
- Explanatory 출력 스타일에 대한 팁을 추가하여 Claude에 설명을 요청할 때 표시됨
- CLAUDE.md 파일이 매우 긴 목록 항목을 보유할 때 시작 시 및 파일 읽기 또는 편집 후 발생하는 길어진 정지 현상을 수정
- MCP 서버가 리소스 읽기에 응답하지 않았거나 스킬이 여전히 다운로드 중일 때 Claude를 중단하는 것이 타임아웃 때까지 적용되지 않는 문제 수정
- 요청이 200K 토큰을 초과할 때 "Usage credits required for 1M context"로 중단되는 표준 컨텍스트 세션 문제 수정; Claude Code는 이제 대화를 압축하고 계속 진행
- Write 및 Edit가 실행 후 최대 5초 동안 중단되고 파일에서 수천 줄을 변경할 때 0줄 변경을 보고하는 문제 수정
- Subagent가 시작 후 연결 완료되는 서버의 MCP 도구를 사용할 수 없는 문제 수정
- 이 파일들이 세션의 이전에 편집되었을 때 자동 압축 직후 Claude가 오래된 MEMORY.md 및 CLAUDE.md 콘텐츠를 보는 문제 수정
- `claude -p` 및 SDK 세션이 트랜스크립트 메시지를 순서대로 저장하지 않거나 되돌린 메시지를 유지하는 문제 수정
- `SubagentStop` 훅이 실행될 때마다 약 일 분에 두 번 실행되는 대신 한 번 실행되도록 수정
- @ 파일 선택기가 git 무시 파일을 다시 포함하는 `.ignore`/`.rgignore` 부정 규칙을 무시하는 문제 수정
- Subagent의 격리된 worktree가 시작한 백그라운드 subagent가 여전히 작업 중인 동안 제거되는 문제 수정
- 자신의 셸에서 대기하는 자동 모드의 백그라운드 에이전트가 깨어날 때마다 새로운 주 대화 턴을 시작하는 문제 수정
- Bash 도구 설명이 작업 디렉터리가 항상 호출 간에 유지되지 않는다고 주장하는 문제 수정
- 환경 블록이 Bash 도구가 zsh를 사용할 때 fish 같은 셸 명령이 실행되지 않는 이름을 지정하는 문제 수정
- 저장소 루트 아래에서 실행될 때 `~/.claude.json`의 로컬 범위 서버를 보유하는 프로젝트 항목 대신 현재 폴더의 이름을 지정하는 `claude mcp add`, `claude mcp remove` 및 `/mcp` 문제 수정
- 실패한 연결 줄에서 오류 코드가 두 번 표시되는 `claude mcp list` 및 `claude mcp get` 문제 수정 (예: `ENOENT: ENOENT: …`)
- 네트워크 프록시가 시작 요청을 차단할 때 Remote Control 세션이 약 2분 동안 "Connecting"에 머무르는 문제 수정
- Claude가 클라우드 또는 Remote Control 세션으로 보낸 메시지가 Claude 모바일 앱에서 자신의 메시지로 표시되는 문제 수정
- Remote Control 또는 클라우드 세션으로 보낸 메시지에 첨부된 파일을 저장할 수 없을 때 (디스크가 가득 찼을 때) Claude가 원인을 알려주지 않는 문제 수정; 이제 메시지의 첫 20개 이후 첨부 파일이 생략되었음을 나타냄
- Cowork 클라우드 세션에서 WebFetch 및 WebSearch가 정지된 응답에 걸리는 문제 수정; 미완성 요청은 이제 300초 후 실패
- 턴 사이에 충돌하는 백그라운드 세션이 첨부되거나 고정되었거나 예약된 작업 또는 웨이크업이 설정된 경우 다시 시작되지 않는 문제 수정
- "background service did not respond" 오류가 비활성화된 `claude daemon restart`를 제안하는 문제 수정; 이제 `claude daemon stop --any`를 제안하고 백그라운드 세션을 종료한다고 말함
- `claude respawn <id>`가 백그라운드 세션이 ID와 일치하지 않음을 보고하기 전에 백그라운드 서비스를 시작하는 문제 수정
- 계획 모드에서 계획 모델이 세션 모델과 다를 때 `/effort`가 prompt cache miss를 경고하지 않는 문제 수정
- VS Code 확장이 설치되기 전이나 설치가 실패했을 때 `/ide`가 설치되었다고 말하는 문제 수정
- Write 도구의 파일 미리 보기가 줄의 너비가 터미널보다 클 때 행을 건너뛰고 숨겨진 줄을 잘못 계산하는 문제 수정
- 에이전트의 채팅 탭에서 ↑이 아직 전달 대기 중인 메시지를 호출하여 다시 보내면 두 번째 사본을 보내는 문제 수정
- 플러그인 또는 설정이 `agent` 이름을 지정할 때 Cowork 클라우드 세션이 재시작 후 커넥터와 대부분의 도구를 잃는 문제 수정; Cowork 클라우드 세션은 이제 해당 설정을 무시
- agent teams 세션이 `--resume`, `--continue`, `/resume` 또는 `--session-id`로 돌아올 때 빈 작업 목록을 표시하는 문제 수정 (`/clear` 또는 충돌 후 포함); `/branch`는 이제 원본 세션의 목록에 기록
- 이미지 파일을 언급하는 텍스트를 붙여넣을 때 (예: `! open /tmp/shot.png` 또는 `/review look at /tmp/shot.png`) 이미지를 첨부하고 프롬프트에서 경로를 제거하는 문제 수정
- 피드백 드래프트 카드가 프롬프트에 텍스트가 있을 때 1/2/0 및 Esc 단축키를 표시하는 문제 수정 (해당 키가 카드 대신 프롬프트에 작동)
- 인용부호 또는 괄호의 단일 백슬래시 (예: `"\"` 또는 `(\)`)가 Claude의 응답에서 사라지는 문제 수정
- agent 팀원이 `DISABLE_COMPACT`가 설정된 경우 기록을 압축하는 문제 수정
- `DISABLE_COMPACT`가 설정된 경우 되감기 메뉴가 "Summarize from here" 및 "Summarize up to here"를 제안하는 문제 수정
- 완료된 `/code-review` 또는 다른 sub-agent에서 실행되는 스킬이 클라우드 또는 백그라운드 세션이 재시작될 때 두 번째로 실행되는 문제 수정
- Google Vertex AI, Microsoft Foundry 및 Claude Platform on AWS에서 엔드포인트가 생각 진행 업데이트를 보낼 때 길어진 숨겨진 생각이 유휴로 잘리는 문제 수정
- `/ide`가 아무것도 설치되지 않았을 때 JetBrains 플러그인이 설치되었다고 말하는 문제 수정
- Claude Pro 및 Max 구독자에게 관리자에게 문의하도록 지시하는 문제 수정; 이제 메시지가 청구 설정을 가리킴
- 넓은 전체 화면 터미널에서 편집 후 표시할 것이 없을 때 diff 창이 자동으로 열리는 문제 수정
- `/mcp`가 원격 서버가 "Clear authentication" 후 실패한 것으로 표시되는 문제 수정 (서버가 로그인 없이 작동)
- `/mcp`가 Claude Code가 자격 증명을 보내지 않는 원격 서버를 "authenticated"로 표시하는 문제 수정
- 빈 `.mcp.json`이 최상위에 있을 때 `--plugin-dir` 폴더의 플러그인이 하나의 플러그인으로 로드되는 문제 수정
- `/usage`가 "What's contributing to your limits usage?" 아래에서 큰 prompt cache miss를 표시하지 않는 문제 수정
- 터미널에서 백그라운드 세션을 열 때 상태 줄 링크가 링크를 지원하는 터미널에서 일반 텍스트로 유지되는 문제 수정
- /rewind 확인이 나중 메시지가 대화에서 제거될 때 대화가 "will be forked"된다고 말하는 문제 수정
- /rewind 경고가 수동 및 Bash 편집이 코드 복원의 영향을 받지 않는다고 잘못 말하는 문제 수정
- 화면 판독기 모드에서 계획 승인이 Escape로 닫은 피드백을 보내는 문제 수정
- Claude Code가 API가 재시도하지 말도록 표시한 요청을 재시도하는 문제 수정 (무인 재시도 모드 (`CLAUDE_CODE_RETRY_WATCHDOG`)에서 몇 분 또는 무한정 동안 턴을 유지할 수 있음)
- Linux: `--plugin-dir` 폴더도 추가 디렉터리이고 `permissions.blockReadsOutsideWorkingDirectories`가 켜진 경우 샌드박스된 Bash 명령이 `bwrap: Can't create file`로 실패하는 문제 수정
- Self-hosted runner: 속도 제한 (HTTP 429 또는 종료 75인 git 래퍼)이 추가된 읽기 전용 저장소를 차단할 때 세션이 시작되지 않는 문제 수정; 이제 해당 저장소 없이 시작
- Pro 및 Max 계정의 시작 시간을 개선하여 마지막 확인으로부터 한 시간 이내의 실행에서 두 개의 네트워크 요청을 건너뜀
- `/teleport` 및 `claude --teleport`를 개선하여 압축된 클라우드 세션이 마지막 압축에서 로드될 때 경고하므로 요약한 메시지가 로컬 사본에 없음
- 백그라운드 세션의 프로세스가 종료될 때 표시되는 메시지를 개선: 더 이상 가오지 않을 재시작을 약속하지 않으며 세션을 재개하는 방법을 알려줌
- 여러 뷰가 있는 아티팩트를 개선: Claude는 이제 각 뷰를 링크의 `#name`에 라우팅하고 뷰를 전환할 때 주소 표시줄이 동일하게 유지된다고 더 이상 말하지 않음
- 타임아웃에 도달하는 셸 명령을 개선: 결과는 이제 지금까지의 출력을 표시하고 명령이 백그라운드에서 계속 실행 중이라고 함
- 압축을 개선: 모델의 응답에 요약이 없을 때 Claude Code는 이제 대화를 바꾸기 전에 일반적으로 요약을 한 번 더 요청
- Artifact 도구의 페이지와 문서 선택을 개선: 설명자 및 시각적 또는 대화형 작업은 artifact 페이지가 되고, 문서는 사람들이 편집하거나 전달하는 글쓰기용
- `claude --model opus` 같은 옵션과 해당 값만 사용하는 시작의 시작 시간을 개선
- "Connection dropped" API 오류를 개선: 먼저 살펴볼 위치 (사용 중인 프록시 또는 게이트웨이, 그렇지 않으면 VPN 또는 방화벽; Anthropic API만 해당, Bedrock, Vertex 및 Foundry는 변경
