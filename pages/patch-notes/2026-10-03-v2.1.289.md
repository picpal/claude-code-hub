> 원문: [Claude Code v2.1.289 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.289)

## 변경사항

- 복합 shell 명령어의 중첩된 부분에 대한 deny 또는 ask 규칙이 관리형 머신의 사용자 설치 mod 승인에 영향을 주지 않는 문제를 수정했습니다
- 닫히지 않은 많은 `<script>` 태그 또는 깊게 중첩된 `${` 치환이 있는 짧은 코드 블록에서 terminal이 멈추는 문제를 수정했습니다
- symlink를 통해 IDE에서 @-언급되거나, 변경되거나, 선택된 파일에 `Read` deny 규칙이 적용되지 않는 문제를 수정했습니다
- [VSCode] `claude auth status`에 대한 2.1.288 변경사항을 되돌렸습니다. 이는 로그아웃을 더 자주 발생시킬 수 있었습니다
- plugin 코드 pane에서 큰 파일이 열리는 속도를 개선했습니다. 강조 표시된 view를 최종 너비에서 한 번에 배치합니다
- 로컬 폴더 marketplace에서 설치된 plugin의 stale copy가 `plugin list`, `plugin eval` 및 `plugin update`에 표시되는 문제를 수정했습니다. symlinked `--plugin-dir`에 대한 hot reload도 수정했습니다
- 업그레이드 후 첫 번째 session에서 설치된 mod가 로드되지 않는 문제를 수정했습니다
- Background tasks 대화상자가 전체 화면으로 열려 있을 때 plugin의 prompt 위 행이 stale row를 표시하는 문제를 수정했습니다
- link가 localhost 주소, 경로의 `@`, 대문자 host 또는 `file:` 경로를 사용할 때 plugin panes이 아무것도 그리지 않는 문제를 수정했습니다
- 사용자 설치 plugin이 조직에서 관리하는 MCP server의 sign-in 도구 설명을 다시 쓸 수 있는 문제를 수정했습니다
- plugin이 terminal이 인식하지 못하는 border style의 Box를 그릴 때 시작 시 freeze 또는 강제 종료 문제를 수정했습니다
- supervised 및 background session이 plugin의 on-screen handler가 비동기식으로 throw할 때 종료되는 문제를 수정했습니다
- 높이가 없는 plugin region이 계속 증가할 때 interface error로 session이 종료되는 문제를 수정했습니다
- sandbox auto-allow가 확장된 값을 가진 environment variable prefix 뒤의 명령어를 놓칠 때 Bash deny 및 ask 규칙이 누락되는 문제를 수정했습니다 (예: `TZ="$HOME" rm -rf build`)
- sandbox auto-allow 시 명령어 앞에 bare variable assignment가 있을 때 Bash deny 또는 ask 규칙을 건너뛰는 문제를 수정했습니다
- 폴더가 marketplace manifest도 포함할 때 `claude plugin validate`이 plugin을 건너뛰는 문제를 수정했습니다
- 팀원을 위한 `agent.spawn`, plugin hook 이벤트 전체에서 하나의 agent id, `$.agent.list()`의 idle 및 waiting 상태를 추가했습니다
- mod의 `ui.render` hook이 작성한 값이 그려질 때 행을 throw했을 때 session이 "unrecoverable interface error"로 종료되는 문제를 수정했습니다. engine이 대신 자신의 행을 그립니다
- tab, stray escape 및 C1 control이 있는 텍스트, 또는 tab과 CRLF 줄 끝이 있는 짧은 텍스트가 아래 행에 겹쳐 그려지는 문제를 수정했습니다
- mod의 pane 또는 band의 우측 정렬 content가 close mark 또는 `[-]` 아래에 그려지는 문제를 수정했습니다. 이제 terminal의 edge에서 한 column 안쪽에 유지됩니다
- 그려진 상태에서 실패하는 mod의 `Client`가 자신 주변에 그린 모든 것을 지우는 문제를 수정했습니다. 이제 단독으로 실패하고 `ui.fault`를 발생시킵니다
- `claude plugin validate`이 Anthropic marketplace의 자체 plugin을 실패하고 `--json`에서 깨끗한 `plugin.json`을 나열하는 문제를 수정했습니다
- mod의 band가 그리기 실패 시 아래 card에 대해 계단 제거를 간단히 알리는 문제를 수정했습니다
- 실패한 plugin component가 failure가 메시지를 전달하지 않을 때 `Error` 또는 아무것도 이유로 표시하지 않는 문제를 수정했습니다
- mod의 작성자가 mod의 band 또는 pane이 그리기 실패할 때 보는 행을 개선했습니다. mod의 이름을 지정하고 아무것도 그려지지 않았다고 말합니다
- 닫히지 않은 많은 `<script>` 태그가 있는 짧은 코드 블록에서 발행된 artifact 페이지가 reader의 browser tab을 freeze 또는 crash하는 문제를 수정했습니다
- terminal이 mod의 Client region을 그리는 동안 throw할 때 mod의 Client region이 전체 session 동안 실패 상태로 유지되는 문제를 수정했습니다
