> 원문: [Claude Code v2.1.246 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.246)

## 변경사항

- Bash allow rules에서 subcommand 앞에 wildcard가 있는 경우(예: `Bash(git * main)`)에 대한 시작 경고를 추가했습니다. 이러한 규칙은 subcommand 앞에 삽입된 옵션과도 일치하기 때문입니다.
- `/permissions`에 Auto mode 탭을 추가하여 auto mode classifier rules를 보고 편집할 수 있도록 했습니다.
- 턴의 완료 시간을 turn 종료 기간 라인 끝에 추가했습니다. 예: `✻ Sautéed for 23s · done 6:05 PM`
- 터미널 크기를 조정한 후 fullscreen mode에서 transcript가 공백으로 표시되고 다음 키 입력까지 맨 아래로 이동하는 문제를 수정했습니다.
- diff에 매우 긴 단일 라인(예: base64 문자열)이 포함될 때 transcript가 심각하게 느려지는 문제를 수정했습니다. 이러한 라인은 이제 마커와 함께 잘린 상태로 렌더링됩니다.
- 이전 메시지에 위치할 때 fullscreen scrolling이 불안정하게 동작하는 문제를 수정했습니다. 여기에는 jump-to-bottom이 transcript 중간에서 멈추는 경우도 포함됩니다.
- Claude Code의 시작 디렉터리가 삭제되었거나 머신이 절전 모드였거나 host가 프로세스 시작이 느릴 때 background sessions이 45초 후 열리지 않는 문제를 수정했습니다.
- 다른 Claude Code 프로세스가 npm package를 다시 설치하고 있을 때 background sessions이 "Couldn't start the background service … EACCES"로 실패하는 문제를 수정했습니다.
- 첫 500자에 markdown이 없을 때 전체 메시지에 대해 markdown rendering이 비활성화되고, `+`/`N)` lists 및 setext headings에 대해서도 비활성화되는 문제를 수정했습니다.
- headless/remote sessions에서 들어오는 메시지에 의해 중단된 MCP tool calls이 명시적 interrupted error 대신 "completed with no output"으로 모델에 보고되는 문제를 수정했습니다.
- parameter의 schema가 비어있을 때(`{}`) MCP tool arguments가 실제 타입 대신 JSON strings로 전송되는 문제를 수정했습니다.
- 실행 중 중단된 명령이 중단되었다는 표시 없이 "Ran 1 shell command"로 표시되는 문제를 수정했습니다.
- dynamic workflow 중에 ← 를 누르거나 `/background`를 실행할 때 완료된 subagents를 다시 시작하는 문제를 수정했습니다. 이제 먼저 물어보고 몇 개의 subagents가 다시 시작될 것인지 알려줍니다.
- `claude agents`에서 아직 작동 중인 worker가 있는 방금 시작된 session을 열 때 "was stopped while the respawn was in flight"로 중지되는 문제를 수정했습니다.
- `claude agents`가 backgrounded named session을 두 번 나열하는 문제를 수정했습니다. 같은 conversation을 다시 backgrounding하면 이제 새 row에 번호를 매깁니다(예: `my-session (2)`).
- background-session record가 가리키는 오래된 record가 있을 때 background retention sweep이 직접 생성한 `.claude/worktrees/` 아래의 git worktrees를 제거하는 문제를 수정했습니다.
- 매우 큰 sessions에서 auto mode tool calls가 "temporarily unavailable"로 거부되는 문제를 수정했습니다. 이제 safety-check deadline이 prompt 크기에 따라 조정됩니다.
- plugin cache가 동일한 plugin에 대해 중복된 SHA 명명 디렉터리를 생성하는 문제를 수정했습니다.
- frontmatter `name`에 이미 `<plugin>:` prefix가 포함된 plugin skills이 slash menu에서 중복으로 표시되는 문제를 수정했습니다(예: `/plugin:plugin:skill`).
- 설치된 plugin에 대해 bare name으로 `claude plugin update`가 실패하는 문제를 수정했습니다(fully-qualified name만 작동했습니다).
- `plugin.json`이 UTF-8 byte-order mark(BOM)로 저장되었을 때 plugin installation이 실패하는 문제를 수정했습니다.
- `/reload-plugins`가 `skills/*/SKILL.md` 아래에서 skills을 정의하는 plugins에 대해 0개의 skills을 보고하는 문제를 수정했습니다.
- hook error messages가 해결된 plugin path 대신 literal `${CLAUDE_PLUGIN_ROOT}`을 표시하는 문제를 수정했습니다.
- `/rename`이 theme의 prompt border color(custom theme의 `promptBorder` 포함)를 기본값 cyan으로 바꾸는 문제를 수정했습니다. 이제 border는 `/color`로 다른 색상을 선택하지 않는 한 theme의 색상을 유지합니다.
- custom theme diff colors(`diffAdded`/`diffRemoved` 및 해당 dimmed variants)가 diffs 및 `/theme` preview에서 무시되는 문제를 수정했습니다.
- 알 수 없는 action name을 가진 `keybindings.json` binding이 해당 key를 조용히 비활성화하는 문제를 수정했습니다. 이제 건너뛰어 기본값 binding이 작동하고 `--debug` 아래에 경고가 로깅됩니다.
- `/stats` activity heatmap이 UTC 동쪽 시간대에서 각 날짜의 활동을 한 셀 오프로 표시하는 문제를 수정했습니다(일요일의 count가 월요일 아래 표시됨).
- 이미 forked되었거나 backgrounded된 session에서 `/fork`를 실행할 때 새 session이 빈 conversation으로 시작되는 문제를 수정했습니다.
- `/--`로 시작하는 prompts(예: Lean doc comments)가 Claude로 전송되지 않고 알 수 없는 slash command로 거부되는 문제를 수정했습니다.
- 입력된 텍스트가 실제 path와 일치하지 않을 때 `@` file picker가 열린 상태로 유지되는 문제를 수정했습니다.
- agents view로 이동했다가 돌아온 후 status line의 cost 및 duration이 0으로 재설정되는 문제를 수정했습니다.
- fullscreen mode에서 터미널 윈도우를 클릭하여 focus를 가져올 때 포인터 아래의 control로 keyboard focus가 이동하는 문제를 수정했습니다.
- completion token 또는 working directory에 null byte가 포함되어 있을 때 path completion이 실패하는 문제를 수정했습니다.
- Windows/macOS: headless sessions이 비정상적으로 종료된 sessions이 남긴 `~/.claude/sessions`의 stale entries를 정리하지 않는 문제를 수정했습니다.
- 타사 Anthropic 호환 endpoint(`ANTHROPIC_BASE_URL`)가 `id`가 없는 `tool_use` block을 스트림할 때 첫 번째 tool call에서 UI가 render error로 중지되는 문제를 수정했습니다.
- Write tool이 매우 큰 기존 파일을 덮어쓴 후 파일이 작성되었음에도 불구하고 "Out of memory"를 보고하거나 오랜 시간 동안 freezing되는 문제를 수정했습니다.
- `~/.claude/plugins/known_marketplaces.json`이 비어있거나 손상되었을 때 `claude plugin install <name>`이 오류를 보고하지 않고 조용히 종료되거나 터미널에서 hanging되는 문제를 수정했습니다.
- 저장된 history에 Anthropic API가 수용하지 않는 tool blocks이 포함되어 있을 때(일반적으로 타사 API proxy가 작성함) resumed sessions이 모든 턴에서 400으로 실패하는 문제를 수정했습니다.
- 일부 Team/Enterprise 사용자가 server-managed settings를 사용할 때 `curl -fsSL https://claude.ai/install.sh | bash`가 "Raw mode is not supported"로 실패하는 문제를 수정했습니다.
- plan mode에서 끝난 sessions이 VS Code extension에서 plan mode 외부로 재개되고, permission mode가 설정되지 않았을 때 `claude -p --continue`/`--resume`에서 permission prompt tool을 사용할 때 재개되는 문제를 수정했습니다.
- sandbox "Network request outside of sandbox" permission prompt가 대기 중일 때 `Notification` hook이 실행되지 않는 문제를 수정했습니다.
- dangling `&&` 또는 `||` operator가 있는 malformed commands에 대해 Bash permission checks가 항상 승인을 요구하도록 수정했습니다.
- `--strict-mcp-config` sessions이 로드하지 않을 `.mcp.json` servers를 승인하라는 메시지를 표시하여 background sessions이 시작 시 대기 중인 문제를 수정했습니다.
- Anthropic으로의 telemetry 및 metrics requests가 타사 gateway(`ANTHROPIC_BASE_URL`)에 대해 구성된 API key를 전달하는 문제를 수정했습니다. 이제 credential은 해당 자체 host로만 전송됩니다.
- `apiKeyHelper`가 short-lived JWTs를 반환할 때 idle 후 첫 번째 prompt에서 visible API error가 발생하는 문제를 수정했습니다. 이제 expired cached token은 전송 전에 refresh되고 401/403 auth errors는 조용히 재시도됩니다.
- fullscreen 및 Ctrl+O transcript views에서 session length와 함께 memory가 증가하는 문제를 수정했습니다. 이제 렌더링된 각 message row는 transcript 전체 tool lookups의 전체 복사본을 더 이상 유지하지 않습니다.
- 하나의 repository에서 동시에 `/ultrareview` runs 및 cloud sessions이 시작될 때(예: 여러 worktrees에서) 다른 launch의 uncommitted changes로 시작되는 경우가 있는 문제를 수정했습니다.
- background cloud sessions(예: `/autofix-pr`)에 대해 표시되는 task progress count(예: `3/5`)가 때때로 task를 누락하는 문제를 수정했습니다.
- Remote Control sessions이 두 번째 prompt까지 claude.ai 및 Claude app에서 placeholder name을 유지하는 문제를 수정했습니다. 이제 자동 생성된 title이 첫 번째 prompt 후에 나타납니다.
- `requiresUserInteraction`로 표시된 MCP tools이 여전히 해당 permission prompt에서 "Yes, and don't ask again"을 제공하는 문제를 수정했습니다. 옵션이 allow rule을 작성했으나 tool이 이를 무시했습니다.
- self-hosted runner가 work-poll response가 malformed될 때(예: intercepting proxy의 HTML page) 그 live sessions을 종료하거나 종료되는 문제를 수정했습니다. 이제 poll을 재시도합니다.
- `/cd`를 개선했습니다. 새 디렉터리의 project settings, hooks, `.mcp.json` servers(일반적인 승인 prompt 뒤에), skills, 및 agents이 이제 `--resume`이 아닌 이동 직후에 적용됩니다.
- Bash shells에서 Bash tool latency를 개선했습니다. 이제 function당 base64 subshell 없이 snapshot functions를 replay합니다.
- Subagent results를 개선했습니다. `maxTurns` limit에 도달하여 중지된 subagent는 이제 완료된 것처럼 보이지 않고 partial로 표시된 output을 반환하며 `SendMessage`를 통해 계속할 수 있다는 힌트를 제공합니다.
- Non-interactive sessions(`-p`, SDK, cloud sessions)를 개선했습니다. 이제 server error, connection loss, 또는 stall로 인해 mid-stream에서 잘린 response를 자동으로 계속 진행하며 error로 끝나지 않습니다.
- Workload identity federation sessions, `apiKeyHelper`가 시작 시 실행되는 동안 전송된 events, 및 idle 중에 login token이 만료된 후의 usage telemetry 기여도를 개선했습니다.
- `/code-review`를 변경했습니다. 이제 Claude가 Bedrock, Vertex AI, 및 Foundry에서 Claude apps gateway를 통해, 및 telemetry나 non-essential traffic이 비활성화되
