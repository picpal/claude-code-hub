> 원문: [Claude Code v2.1.284 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.284)

## 변경사항

- Claude Sonnet 5.5(`claude-sonnet-5-5`)를 추가했습니다. 이제 Anthropic API의 기본 Sonnet 모델이며 1M 컨텍스트, Mtok당 $2/$10의 가격과 $0.20/Mtok 캐시 읽기 요금을 제공합니다.
- 작업 디렉토리 외부의 읽기 전에 auto mode의 프롬프트에 "Yes, but ask again next time" 답변을 추가했습니다. 이를 통해 그 한 번의 읽기는 허용하면서도 이후 읽기에 대해서는 계속 물어볼 수 있습니다.
- `/usage`의 Claude apps gateway 지출 한도 및 상태 라인에 달러 금액을 추가했습니다(예: "$271.40 / $500.00 spent this month"). gateway가 이 버전 이상을 실행 중일 때만 표시되며, 상태 라인의 `rate_limits.spend_limit`에 `used_usd`, `limit_usd` 및 `period`가 추가됩니다.
- `effortSlider:decreaseEffort`, `increaseEffort` 및 `toggleUltracode` keybinding actions을 추가했습니다. 이를 통해 `/effort` 슬라이더의 화살표와 Tab 키를 `keybindings.json`에서 다시 바인딩할 수 있습니다.
- claude.ai 구독자를 위해 `/rate-limit-options`을 `/help`와 명령 메뉴에 추가했습니다. 이를 통해 이를 언급하는 usage-limit 알림이 찾을 수 있는 명령을 가리킵니다.
- 대화형 터미널에 `/mcp reconnect all`을 추가했습니다. 연결에 실패했거나 인증이 필요한 모든 MCP 서버를 한 번에 다시 시도할 수 있습니다.
- managed policy의 `availableModels`이 비어 있거나 `model`을 설정하거나 `enforceAvailableModels`을 설정하지 않고 Claude Code가 시작되는 모델을 누락한 경우 Claude apps gateway 시작 경고를 추가했습니다.
- Claude apps gateway `telemetry.forward_to` 대상에 `auth: { google: {} }`을 추가했습니다. 이를 통해 텔레메트리를 gateway의 Google Cloud 자격증명을 사용하여 Google Cloud의 OTLP 엔드포인트로 직접 내보낼 수 있습니다.
- Claude apps gateway와 그 identity provider 간의 인증서 클라이언트 인증(`private_key_jwt`)을 추가했습니다. 클라이언트 비밀 대신 인증서 자격증명을 발급하는 identity provider에 대응합니다.
- 손상된 응답 스트림이 "JSON Parse error" 또는 "undefined is not an object"와 같은 원본 오류를 표시하거나 응답에 "undefined"라는 단어를 작성하는 대신 다시 시도하거나 중단된 응답으로 보고되도록 수정했습니다.
- thinking 블록 종료 직후에 overload되거나 server error가 도착하여 재시도 대신 오류로 턴이 종료되는 문제를 수정했습니다.
- compacting 후에도 지속되는 "Prompt is too long" 오류를 수정했습니다. compacted request가 여전히 너무 길 경우 Claude Code는 더 이상 한 번 더 compact하여 최근 대화의 일부를 덜 유지합니다.
- 사용 불가능한 모델이 있는 세션에서 대체 모델이 없는 경우 bare "is currently unavailable" 메시지(또는 cloud 세션의 경우 "Something went wrong")를 표시하는 대신 model-unavailable 알림과 Learn more 링크를 표시하도록 수정했습니다.
- user message에 malformed `source`를 포함하는 이미지가 있을 때 Agent SDK 세션이 crash하고, malformed document block 이후 모든 후속 턴에 실패하는 문제를 수정했습니다. malformed image는 이제 설명 노트로 교체됩니다.
- resumed 세션의 MCP tool call이 서버가 연결되는 동안 "No such tool available" 오류로 실패하는 문제를 수정했습니다. 이제 호출은 서버 연결을 최대 10초까지 대기합니다.
- plan-usage endpoint가 rate-limit하거나 로그인을 거부한 후 반복되는 호출을 수정했습니다. `/usage`, `/extra-usage` 및 IDE usage 뷰는 이제 다시 요청하는 대신 back off합니다.
- `claude mcp add`가 managed 설정이 MCP 서버를 plugins로 제한할 때 성공을 보고하는 문제를 수정했습니다. 이제 로드되지 않을 서버를 저장하는 대신 거부하고 무엇을 해야 할지 표시합니다.
- `/plugin` configure 화면을 수정했습니다. 부울 옵션은 이제 자유 텍스트 대신 true/false 선택지이고, 숫자 옵션은 유효하지 않은 입력을 거부하며, ←/→는 탭 전환 대신 옵션 필드를 변경합니다.
- `ANTHROPIC_FOUNDRY_RESOURCE`가 검증되지 않은 상태로 Foundry endpoint host에 보간되는 문제를 수정했습니다. plain resource name이 아닌 값은 이제 거부됩니다.
- Claude Desktop이 Claude apps gateway 뒤에 있을 때 1M context 옵션을 제공하지 않는 문제를 수정했습니다. gateway는 이제 각 1M capable 모델을 Desktop용으로 자동으로 표시합니다.
- shell mode에서 ↓가 숨겨진 background-tasks pill을 선택하여 Backspace와 Ctrl+U가 프롬프트 편집을 중단하는 문제를 수정했습니다.
- 많은 plugins이 활성화되었을 때 Windows에서 Bash tool이 실패하는 문제를 수정했습니다. 존재하지 않는 plugin `bin/` 디렉토리는 더 이상 PATH에 추가되지 않으며, 상속된 항목은 두 번 추가되지 않습니다.
- `sparsePaths` plugin marketplaces이 older git(2.39 이전)에서 빈 상태로 복제되고 작동하는 로컬 복사본을 교체하는 문제를 수정했습니다. 이는 "marketplace.json file is no longer present"로 인해 모든 새로고침에 실패했습니다.
- transcript mode에서 `[`이 대화를 scrollback에 작성할 때 fullscreen 렌더링이 세션 위의 터미널 출력을 지우는 문제를 수정했습니다(macOS 및 Linux).
- 회신이 위로 스크롤되어 있을 때 스트리밍을 완료할 때 fullscreen 스크롤 위치가 이전 메시지 또는 맨 아래로 점프하는 문제를 수정했습니다.
- narrow 터미널에서 `/config` 및 `/plugin`과 같은 대화상자의 탭 바가 제목과 탭 라벨을 단어 중간에 끊는 문제를 수정했습니다. 맞지 않는 탭은 이제 전체 다음 라인으로 이동합니다.
- `/model` 피커가 마지막 모델로 스크롤한 후 목록 아래에 "+1 model"을 표시하는 문제를 수정했습니다. 개수는 이제 visible rows 아래의 모델만 포함합니다.
- `/keybindings`가 아무 작동도 하지 않는 footer action에 대해 Backspace와 Delete 바인딩을 생성된 `keybindings.json`에 작성하는 문제를 수정했습니다.
- rebound agent panel close key(`footer:close`)가 보고 있는 agent의 행에서 자신 대신 "x"를 입력하는 문제를 수정했습니다.
- vim mode `.`이 매우 빠르게 입력된 텍스트(예: ssh 또는 tmux를 통한)나 bracketed paste 없이 붙여넣은 텍스트를 반복하지 않고, 입력된 것이 없는 변경(`cw` 다음 Esc)을 반복한 후 프롬프트를 INSERT mode로 남겨두는 문제를 수정했습니다.
- vim mode가 마지막 라인의 `dd` 또는 프롬프트 끝의 `yy` 후 image placeholder의 열기 괄호에 커서를 남겨두어 `r` 또는 `x`가 image를 손상시키거나 삭제하는 문제를 수정했습니다.
- 터미널이 포커스를 다시 얻은 순간 누른 키가 짧은 safety delay를 다시 시작하기 전에 Remote Control enable 프롬프트에 응답하는 문제를 수정했습니다.
- workspace trust 대화상자가 renderer를 전환하거나 Claude Code가 홈 디렉토리에서 시작되었을 때 업데이트된 후 두 번째로 나타나는 문제를 수정했습니다.
- `.claude/rules`에 symlinked된 규칙이 프로젝트 외부에서 external-imports approval prompt를 표시하지 않고 건너뛰는 문제를 수정했습니다. 프로젝트 외부에서 symlinked된 `.claude` 디렉토리는 이제 동일한 승인을 요청합니다.
- marketplaces, claude.ai 및 npm의 plugins이 managed `allowManagedPermissionRulesOnly` 아래의 `allowed-tools`를 통해 자신의 tools을 pre-approving하는 문제를 수정했습니다. 공식 Anthropic source 또는 managed 설정이 보증하는 source의 plugins만 이 pre-approval을 유지합니다.
- dependency의 version range를 충족할 수 없을 때 실패한 첫 `claude plugin install`이 plugin을 활성화하고 기록하는 채로 남겨두는 문제를 수정했습니다.
- debug log가 hook도 stdout에 쓸 때 실패한 hook의 stderr을 삭제하고 출력이 없는 실패한 hook에 대해 아무것도 기록하지 않는 문제를 수정했습니다. 이제 실패한 hooks은 status code도 기록합니다.
- Elicitation 및 ElicitationResult hooks에서 반환된 `{"decision":"block"}`이 무시되는 문제를 수정했습니다. 이제 exit code 2처럼 MCP elicitation을 거부합니다.
- `SendMessage` tool 없이 시작된 세션(예: Claude Desktop)이 여전히 이를 사용하여 다른 세션에 메시지를 보내도록 지시되는 문제를 수정했습니다.
- Claude 앱에서 Remote Control 위로 전송된 사진이 queued message를 프롬프트로 다시 끌어올 편집할 때 손실되고, 캡션이 없는 사진의 경우 커서가 한 문자 이동하는 문제를 수정했습니다.
- 자동 usage-limit wait 중에 메시지를 입력하면 해당 턴이 다시 한계에 도달했을 때 그 wait이 "Continue automatically at usage limit" 설정의 제어 범위를 벗어나는 문제를 수정했습니다.
- usage-limit 경고가 이미 highest Max plan에 있는 사용자에게 `/upgrade`를 제안하는 문제를 수정했습니다. 경고와 `/upgrade` 자체는 이제 `/usage-credits`이 이용 가능할 때 이를 가리킵니다.
- Explore subagent가 Claude Code가 인식하지 못하는 모델 ID(예: proxy 뒤의 custom model)를 실행하는 세션에서 Claude API의 Opus로 전환되는 문제를 수정했습니다. Explore는 이제 그 모델을 상속합니다.
- `/loop` status 업데이트가 Claude가 reasoning에만 작성했기 때문에 self-paced mode에서 표시되지 않는 경우가 많은 문제를 수정했습니다. Claude는 이제 각 업데이트와 loop가 중지될 때의 결과를 visible text로 작성합니다.
- `/ultrareview`가 macOS 또는 Linux에서 Claude desktop 앱이 생성한 git worktree에서 시작될 때 working tree 업로드에 실패하는 문제를 수정했습니다.
- sandboxed Bash 명령이 working directory가 write-denied이고 read-denied directory를 포함할 때 Linux에서 시작에 실패하는 문제를 수정했습니다.
- artifact database write 결과가 모든 viewer
