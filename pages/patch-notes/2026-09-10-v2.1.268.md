> 원문: [Claude Code v2.1.268 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.268)

## 변경사항

- Claude 앱 게이트웨이에 추가됨: `gateway.yaml`에서 `pricing:`을 설정하면, 로그인한 Claude Code 클라이언트가 관리형 설정을 통해 동일한 요금을 받으므로 `/cost`와 원격 측정이 지출 미터와 일치합니다
- 게이트웨이에 대한 시작 경고가 추가됨: `access_control.allow_cidrs`가 비어 있을 때, 그리고 공개 주소에서 처음 요청이 도착할 때 일회성 경고가 표시됩니다
- `gatewayInternalNetworks` 관리형 설정이 추가됨: 관리자가 조직의 자체 공개 IPv4 블록에서 Claude 앱 게이트웨이에 `/login`을 허용할 수 있습니다
- `claude self-hosted-runner --remove-session-state`가 추가됨(기본값: 해제): 세션이 끝날 때 `<base-dir>/_sessions/` 아래의 각 세션별 디렉토리를 삭제합니다
- `configDirectory`가 `claude auth status --json`의 출력에 추가됨
- `--json`이 `claude plugin install`, `uninstall`, `update`, `enable` 및 `disable`에 추가되었으며, `claude plugin list --json`의 각 행에 `errorDetails`/`noteDetails`가 추가됨
- 게시된 아티팩트에 대한 브라우저 탭 아이콘이 추가됨: Claude가 각 페이지와 일치하도록 선택합니다
- 2.1.265 이후 써드파티 Anthropic 호환 엔드포인트(`ANTHROPIC_BASE_URL`)에서 모든 턴이 HTTP 400으로 실패하는 문제가 수정됨: Artifact 도구의 입력 스키마의 정규식이 해당 엔드포인트에서 거부됩니다
- WebFetch가 응답을 종료하지 않고 열어 두는 서버에서 무한정 행(hang)에 빠지는 문제가 수정됨: fetch는 이제 300초 후에 실패합니다. `CLAUDE_CODE_WEBFETCH_DEADLINE_MS`를 설정하여 기한을 무시할 수 있습니다(0으로 설정하면 해제됨)
- 다시 생성된 in-process 팀원이 신뢰하지 않은 폴더의 같은 이름 에이전트 파일에서 도구 또는 시스템 프롬프트를 선택하는 문제가 수정됨
- CPU 사용량이 계속 높아지는 문제가 수정됨: 장기 실행 유휴 세션의 바쁜 루프가 더 이상 CPU 코어를 고정하지 않으며, 세션 요약 중 빠른 터미널 포커스 보고가 CPU를 높게 유지하지 않습니다
- MCP 도구 호출 후 Claude가 때때로 "your message came through empty"라고 응답하는 문제가 수정됨
- symlink된 디렉토리(`macOS`의 `/etc`, `/tmp`, `/var`; `Linux`의 `/bin`)에 대한 거부 및 허가 요청 규칙이 실제 위치로 지정된 경로에 적용되지 않는 문제가 수정되었으며, Bash 명령이 symlink된 경로 철자로 작성된 거부 규칙을 무시하는 문제도 수정됨
- 권한 검사기가 분석할 수 없는 `env -C`, `eval` 또는 유사한 명령이 같은 줄에 있을 때 읽기 또는 편집 거부 규칙이 적용되지 않는 경우가 수정됨
- plugin 및 marketplace 오류가 git 소스 URL의 token 또는 password를 표시하는 문제가 수정됨
- `/mcp` 및 `/plugin` 서버 세부 정보, `claude mcp list`/`get` 및 MCP 로그인 오류가 MCP 구성의 `${VAR}` 자리 표시자에서 해석된 비밀을 표시하는 문제가 수정됨
- `excludeDynamicSections`를 사용하는 SDK 세션의 prompt 캐싱 및 extended thinking이 세션 중간에 끊기는 문제가 수정됨: 첫 번째 메시지는 더 이상 각 요청마다 다시 렌더링되지 않습니다
- 캐시된 모델 접근 거부가 만료되었을 때 권한이 있는 사용자가 재시작 후 또는 Desktop Code 탭에서 모델이 제한된다고 알림을 받는 문제가 수정됨
- 다른 Claude Code 프로세스가 만료된 모델 접근 항목을 새로 고칠 때 실행 중인 세션이 조용히 조직의 기본 모델로 전환되는 문제가 수정됨
- Fable 모델의 장기 context 429가 Pro 및 Team 플랜에서 1M-context 메시지 대신 사용 크레딧 동의 프롬프트를 표시하는 문제가 수정됨
- 프로필을 통한 workload identity federation(claude-code-action이 구성하는 대로): 프로필을 공유하는 프로세스가 `401 … jti reused`로 중간에 실패할 수 있는 문제가 수정됨
- MCP 서버 OAuth 로그인이 로컬 콜백 포트 범위를 바인드할 수 없을 때 "No available ports for OAuth redirect"로 실패하는 문제가 수정됨
- `/compact`로 생성된 대화 요약 및 자동 압축이 `$` 시퀀스를 포함한 텍스트를 훼손하는 문제가 수정됨
- `/compact`로 끝난 대화를 재개할 때: 복원된 파일 메모가 이제 매번 재개할 때마다 같은 순서로 로드됩니다
- SDK 프롬프트 제안, 부가 질문 및 `/rename`이 압축 전의 대화를 보내는 문제가 수정됨
- 위쪽 화살표로 이전 프롬프트를 기억한 후 편집할 때 `@` 파일 및 `/` 명령 제안이 표시되지 않는 문제가 수정됨
- `claude agents`: 자연스러운 속도로 ← 키를 다시 눌러서 에이전트 목록으로 돌아갈 때 1초 이상 일시 중지할 때까지 무시되지 않습니다
- `claude agents` 세션 삭제가 worktree를 제거할 수 없을 때 중단되는 문제가 수정됨: 메시지가 원인과 다음 단계를 명시하며, git worktree의 경우 ctrl+x를 다시 눌러서 디렉토리를 어쨌든 삭제합니다
- 배경 에이전트 및 workflow 행이 텍스트에 줄 바꿈을 포함할 때 agents 패널에서 많은 줄로 확장되는 문제가 수정됨
- 조직 관리형 설정이 MCP allowlist를 설정할 때 Slack 세션의 Claude가 Slack 도구를 잃는 문제가 수정됨
- Claude in Chrome이 navigation URL에 scheme가 있지만 구문 분석할 수 없는 호스트가 있을 때 호스트 "https"를 허용하도록 요청하는 문제가 수정됨
- 현재 작업의 레이블이 길 때 spinner가 여러 줄로 줄 바꿈되는 문제가 수정됨: 레이블 및 "Next:" 작업 줄이 이제 한 터미널 행 내에 유지됩니다
- `/bug` 및 `/feedback` 설명 필드가 터미널의 기본 커서가 활성화되어 있을 때 커서를 표시하지 않는 문제가 수정됨
- `claude remote-control`로 제공되는 Remote Control 세션이 `ListAgents`에서 세션 제목 대신 생성된 이름을 표시하는 문제가 수정됨
- `claude plugin validate`가 plugin 로더가 허용하는 디렉토리 이름이 두 개의 점으로 시작하는 plugin 경로를 거부하는 문제가 수정됨
- plugin이 확인할 수 없는 기본 monitors 파일 또는 루트 SKILL.md를 조용히 건너뛰는 문제가 수정됨
- WebFetch의 localhost 및 기타 점이 없는 호스트명 오류가 URL이 거부되는 이유를 설명하고 curl을 제안하도록 수정됨
- PermissionRequest hook이 `--print` 모드에서 실행되지 않는 문제가 수정됨
- policy-helper 경고가 headless(`-p`) 실행에서 인쇄되지 않는 문제가 수정됨
- `/resume`이 `/fork` background 세션을 자체의 `⑂` fork 이름 대신 부모의 이름으로 나열하는 문제가 수정됨
- `/remote-control` 및 기타 claude.ai-gated 명령이 로그인하지 않았을 때 Claude for Enterprise 마이그레이션 메시지를 표시하는 대신 `/login`을 제안하도록 수정됨
- `CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS`가 per-hook `timeout`이 없는 SessionEnd hook을 연장하지 않는 문제가 수정됨(여전히 1.5초 후에 취소됨)
- `/autofix-pr` 및 기타 cloud-session 명령이 GitHub 계정이 연결되지 않았을 때 Claude GitHub App을 재시도하거나 설치하라고 하는 문제가 수정됨: 이제 `/web-setup` 또는 웹 연결 페이지를 가리킵니다
- `/teleport` 및 `/remote-env`와 같은 cloud-session 명령이 조직 정책이 해제했을 때 "Unknown command"라고 답하는 대신 설명하도록 수정됨
- Bash sandbox 지침이 confinement를 과도하게 설명하는 문제가 수정됨: 파일 시스템 격리가 해제되어 있을 때 적용되지 않은 경로 목록이 없으며, strict 모드가 더 이상 명령을 절대 unsandboxed에서 실행할 수 없다고 주장하지 않습니다
- 전체 화면 모드가 개선됨: 프롬프트 줄을 추가하거나 제거할 때(Shift+Enter) 이제 전체 대화 내용을 다시 렌더링하는 대신 문자를 입력하는 것처럼 빠르게 다시 칠해집니다
- `--continue` / `--resume`이 개선됨: SessionStart hook을 기다리지 않고 대화가 즉시 표시되며, 첫 번째 메시지가 더 이상 전체 대화 내용을 다시 읽지 않습니다
- 도구가 많은 턴 중에 도구별 batch 미리 알림에 대해 대화 내용을 다시 그리지 않음으로써 응답성이 개선됨
- 프로젝트의 `.claude/workflows/` 스크립트가 있을 때 시작 시간이 개선됨: 나열할 때 더 이상 각 스크립트를 구문 분석하지 않습니다
- 자동 모드 거부가 개선됨: Claude가 수신하는 메시지가 이제 작업을 차단한 규칙의 이름을 지정하고 더 안전한 방법을 시도하고 사용자에게 물어보기 전에 관련 없는 작업을 완료하도록 Claude에게 요청합니다
- Claude in Chrome이 개선됨: 긴 페이지 읽기가 이제 파일에 저장되고 다시 읽는 대신 인라인 상태를 유지합니다
- MEMORY.md truncation 경고가 개선됨: 잘려나간 줄의 개수와 자르기가 시작되는 위치를 표시하도록 합니다
- 아티팩트에 대한 터미널 권한 프롬프트가 개선됨: 이제 요청의 질문으로 시작합니다
- 프롬프트 footer가 개선됨: editor 또는 `/diff` 선택이 이제 prompt 입력 내에 표시되며, 전체 화면 모드는 footer 대신 header에 Remote Control 상태를 표시합니다
- "Usage credits required for 1M context" 메시지가 개선됨: 사용 크레딧이 세션 중간에 켜지면 Claude Code를 재시작한 후에 적용된다고 표시합니다
- `/plugin`: plugin을 설치, 활성화 또는 비활성화
