## 변경사항

- 자체 호스팅 환경 추가: `claude self-hosted-runner`를 사용하여 자신의 머신이나 컨테이너를 Claude Code 웹, 모바일, 데스크톱 세션이 실행될 수 있는 장소로 변환할 수 있습니다(Team 및 Enterprise 플랜).
- `archive` plugin source 추가: Git이나 npm 없이 HTTPS를 통해 zip에서 plugin을 설치할 수 있으며, 선택적 SHA-256 고정을 지원합니다.
- 사용할 수 없는 paste 변경사항을 제거할 때 취소 및 확인 단계 추가
- Bedrock의 `ANTHROPIC_BEDROCK_REGION_PREFIX` env var 추가: `AWS_REGION`에서 파생된 것 대신 특정 cross-region inference profile을 선호하도록 설정할 수 있습니다.
- `crossSessionInbound` 및 `dialogExpiry` 설정 추가: 우회된 권한으로 실행되는 세션에 보낸 cross-session 메시지는 승인 대기 중이며, 다른 세션으로의 메시지는 자동 배달됩니다.
- Sandbox credential-masking 옵션 추가: 구조화된 env 값을 위한 `extract` 및 `onExtractNoMatch`, JWT 인식 masking을 위한 `decode: "jwt"` 및 `maskClaims`, AWS SigV4 re-signing을 위한 `awsPairs`/`sigv4`; 이러한 옵션은 `network.tlsTerminate`가 필요하며 사용자, managed 또는 `--settings` 설정에서만 적용됩니다.
- Cross-session `SendMessage` 추가: Claude Code 세션이 이제 `ListAgents`로 서로를 발견하여 메시지를 주고받을 수 있습니다(macOS 및 Linux).
- 긴 (>200자) 프로젝트 경로가 공유된 정규화된 접두사 아래에서 다른 프로젝트의 세션 디렉토리로 해석되는 문제 수정; 세션 목록, 이름 변경, fork, 삭제 및 `/resume`은 더 이상 프로젝트 간 이동하지 않습니다.
- `SendMessage`가 팀 동료의 inbox에 대한 쓰기가 실제로 실패했을 때 "메시지 전송됨"으로 보고하는 문제 수정; 실패한 배달은 이제 오류로 보고됩니다.
- Sandbox filesystem 거부 항목이 후행 슬래시(예: `denyRead: "~/.aws/"`)로 작성되어 Linux 및 macOS에서 조용히 우회 가능한 문제 수정
- Sandbox 위반 세부 정보가 Bash tool 결과에 절대 표시되지 않는 문제 수정; Claude는 이제 어떤 파일 또는 네트워크 접근이 거부되었는지와 그 이유를 볼 수 있습니다.
- Mid-turn에 연결되는 MCP tool이 모델에 이름이 발표되지 않고 tool 검색을 위해 지연되는 문제 수정
- 동일한 plugin이 여러 프로젝트에 설치될 때 plugin install 레코드가 조용히 손상되는 문제 수정
- 회수되거나 복원된 paste 콘텐츠가 paste가 오래되었거나 placeholder 번호가 충돌했을 때 잘못된 데이터가 첨부되거나 텍스트가 조용히 손실되는 문제 수정
- Wayland의 copy-on-select가 때때로 clipboard에 도달하지 않는 문제 수정; 두 가지 selection 쓰기가 더 이상 경합하지 않습니다.
- 긴 세션에서 피드백 설문의 transcript 공유가 조용히 실패하는 문제 수정; 실패한 공유는 이제 성공 메시지 대신 오류를 표시합니다.
- 오래된 login token으로 cold start 시 Remote Control auto-start가 "Remote credentials fetch failed"로 간헐적으로 실패하는 문제 수정
- Remote Control 및 SDK 클라이언트가 `/clear` 및 기타 output-less 명령 후 빈 "(no content)" 메시지를 표시하는 문제 수정
- 서버 세션이 만료된 후 재생성된 Remote Control 세션이 이전 로컬 대화 이력을 새 세션에 업로드하는 문제 수정
- 전체 화면 모드 개선: 반복된 compaction 간 scrollback에 최신 interval만 아닌 전체 pre-compaction 이력을 유지합니다.
- Remote Control 개선: 부착된 웹 및 모바일 클라이언트는 조용한 일시 중지 대신 compaction 진행 상황 및 post-compaction 경계를 봅니다; `/clear` reset이 부착된 클라이언트로 전파됩니다.
- Remote Control 개선: 연결 실패 시 8초 toast만 표시하는 대신 세부 정보와 재연결 바로가기가 있는 지속적인 실패 표시기를 표시합니다.
- 200-subagent-per-session spawn cap 제거; 장시간 실행되는 세션은 더 이상 새 agent를 거부하지 않습니다(concurrency 및 depth limit은 여전히 적용됨).
- Managed settings 변경: 조직의 settings가 변경되지 않았을 때 re-login 또는 org 전환 후 승인 prompt가 더 이상 다시 표시되지 않습니다.
- Feedback-survey transcript 공유 변경: 귀하의 동의 하에 마지막 요청의 model settings도 업로드합니다. — 시스템 prompt(`CLAUDE.md` 지침 포함), tool 정의 및 model 매개변수. 이전과 같이 Secrets이 redacted되며, 공유가 너무 크면 이러한 필드가 먼저 삭제됩니다.
- Bash tool 설명 변경: 항상 command output이 사용자에게 신뢰할 수 있게 표시되지 않고 모델에 표시됨을 명시합니다.
- 회수된 paste placeholder 번호 변경: input에 수락될 때 다시 번호를 지정합니다.
- Remote Control 변경: compaction 또는 `/resume` 후 새 세션이 생성될 때 dead session을 나열하지 않고 오래된 서버 세션을 archive합니다.
- [VSCode] 연결이 실패한 후 extension이 Remote Control을 연결됨으로 표시하는 문제 수정
- 사용자가 Remote Control을 껐을 때 session resume이 조용히 Remote Control을 재연결하는 문제 수정(`--resume`, SDK hosts 및 VS Code extension).
- [VSCode] 명시적으로 활성화되었을 때 세션이 `remoteControlAtStartup`을 준수하지 않는 문제 수정
