## 변경사항

- prompt 입력 시 입력한 내용에서 설치된 `aspell`, `hunspell` 또는 `ispell`을 사용하여 맞춤법이 틀린 단어에 밑줄을 긋는 선택적 `spellcheck` 설정을 추가했습니다
- 언어 서버가 세션 중간에 연결 해제되거나 다시 연결될 때 전체 prompt 캐시 무효화를 수정했습니다
- 깊이 3 이상에서 중첩된 마크다운 목록 항목이 정렬되지 않는 문제를 수정했고, 터미널 UI의 래핑된 목록 항목에 행 들여쓰기를 추가했습니다
- 일부 여러 줄 prompt에서 prompt 입력 강조(슬래시 명령어, 키워드, 멘션)가 한 글자 이상 이동하여 나타나는 문제를 수정했습니다
- 권한 prompt의 의견 필드 내에서 Shift+Tab을 누르면 필드를 닫는 대신 편집을 승인하고 세션 전체 편집 권한을 부여하는 문제를 수정했습니다
- Agent 도구가 해당 에이전트를 사용할 수 없는 세션에서 범용 기본값을 광고하는 문제를 수정했습니다. 생략된 `subagent_type`은 이제 사용 가능한 에이전트를 나열하는 명확한 오류를 표시합니다
- 노트북 또는 셀을 읽을 수 없을 때 노트북 셀 삭제/바꾸기 승인 대화상자가 기존 셀 내용을 자동으로 생략하는 문제를 수정했습니다. 이제 대화상자에서 그 이유를 표시합니다
- Claude가 응답하는 동안 실행된 슬래시 명령어가 실제 문자 대신 HTML 엔터티를 표시하는 문제를 수정했습니다
- 백그라운드 자동 업데이트 후 prompt 푸터에 "Update installed" 다시 시작 알림이 표시되지 않는 문제를 수정했습니다
- 세션을 재개하거나 다시 시작할 때 확장된 작업 목록(`ctrl+t`)이 항상 축소된 상태로 시작되고 세션에 여전히 열려 있는 작업이 있는 문제를 수정했습니다
- `/ultrareview` 또는 `/autofix-pr` 같은 클라우드 세션이 백그라운드에서 실행되는 동안 메모리 및 CPU 사용량을 개선했습니다. 이제 event stream이 매 업데이트마다 다시 스캔되고 다시 렌더링되지 않습니다
- 권한 대화상자를 개선했습니다. 텍스트 표시 및 "다시 묻지 않음" 옵션이 이제 항상 권한 부여로 적용되는 내용과 일치하며, 내용을 완전히 표시할 수 없을 때는 "다시 묻지 않음"이 숨겨집니다
- macOS/Linux 네이티브 빌드에 포함된 `grep`을 개선했습니다. 병리학적 패턴은 이제 메모리를 소모하는 대신 빠르게 실패하며, `-m N`과 `-A/-C`를 사용하면 올바른 컨텍스트를 출력합니다
- context 제한 오류를 개선하여 자동 압축이 꺼져 있을 때를 표시하고 다시 활성화할 수 있도록 `/config`를 가리킵니다
- Vim mode: 자세한 트랜스크립트 토글(`ctrl+o`) 또는 패널 닫기 시 NORMAL 모드와 커서 위치가 이제 보존됩니다
- 대화상자: 빠르게 연속으로 눌린 화살표 키와 Enter는 이제 이전에 강조된 항목 대신 탐색한 옵션을 선택합니다
- `SendMessage`는 이제 cross-session 전달에 너무 큰 메시지를 사전에 거부하는 대신 자동으로 삭제하지 않습니다
- Remote Control: `claude rc`는 이제 대화형 시작과 동일한 enterprise-gateway 가용성 검사를 적용합니다
- [VSCode] 여러 Claude 패널이 있는 창이 복원되거나 다시 로드될 때 열려 있는 Claude 탭 간에 포커스가 독립적으로 이동하는 문제를 수정했습니다
