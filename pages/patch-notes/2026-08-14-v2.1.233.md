> 원문: [Claude Code v2.1.233 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.233)

## 변경사항

- GitLab merge request URL 지원이 `--worktree` 플래그 및 `claude agents` view에 추가되었습니다 (MR은 `!N`으로 표시됨).
- Anthropic upstream에 opt-in `forward_user_identity` apps gateway 설정이 추가되었으며, gateway 뒤의 proxy가 사용자당 지출을 귀속시킬 수 있도록 로그인한 사용자의 identity를 header로 전송합니다.
- Linux에서 Bash tool 명령어에 대한 opt-in memory cgroup 지원이 추가되었습니다 (`CLAUDE_CODE_TOOL_MEMORY_LIMIT`). 따라서 폭주하는 빌드가 세션을 정지시킬 수 없습니다.
- WebFetch 세션 URL 캐시 TTL을 설정하기 위한 `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` 환경 변수가 추가되었습니다 (기본값 변경 안 함: 15분).
- Claude가 권한 프롬프트를 기다리는 동안 환경이 종료될 때 cloud 세션이 간헐적으로 손실 상태로 표시되는 문제가 수정되었습니다.
- MCP v2 연결이 고정된 timeout에서 장시간 유지된 stream을 종료하는 서버(예: serverless 호스트)에 대해 subscriptions/listen stream을 무한정 다시 여는 문제가 수정되었습니다.
- Claude Desktop 또는 VS Code에서 실행할 때 권한 프롬프트에 대해 Notification hook이 실행되지 않는 문제가 수정되었습니다.
- 샌드박싱이 활성화된 경우 Linux의 유휴 세션이 때때로 CPU 코어 1개를 100%로 유지하는 문제가 수정되었습니다.
- `/checkup` 및 `/review` 같은 번들된 skill alias가 `-p` 모드에서 또는 plugin/MCP가 로드된 상태에서 사용자 또는 프로젝트 skill이 번들된 skill을 shadow할 때 "Unknown command" 오류를 보고하는 문제가 수정되었습니다.
- argument 값이 template marker로 다시 확장되는 것을 방지하기 위해 skill/command argument 치환이 수정되었습니다.
- NT `\??\` device prefix로 작성된 Windows 경로가 UNC 경로 유효성 검사를 우회하는 문제가 수정되었으며, NTLM 자격 증명 유출 벡터가 차단되었습니다.
- `claude self-hosted-runner` 세션 시작 시간이 개선되었습니다. 세션 branch가 working tree를 다시 쓰지 않고 생성되며, 2개의 server round trip이 더 이상 agent 시작을 차단하지 않습니다.
- apps gateway 오류 전달이 개선되었습니다. Vertex, Foundry, Claude Platform on AWS upstream의 400/413 오류가 이제 upstream의 자체 메시지를 전달하며, apps gateway의 auto-compact 버그를 수정합니다.
- `claude plugin validate`가 bare `.claude/skills` directory를 확인하도록 개선되었으며, frontmatter 파싱에 실패한 SKILL.md 파일을 보고합니다.
- screen reader 모드가 개선되었습니다. `/effort` selector가 typed-number prompt를 포함한 번호 매기기 목록으로 렌더링되며, hint와 dialog 텍스트가 더 이상 잘리지 않습니다.
- print mode 진단이 개선되었습니다. Claude Code에서 인식하지 못하는 model ID에 대한 요청이 나갈 때 `[claude-code:unrecognized_model]` 줄이 stderr에 기록됩니다. `modelOverrides`로 매핑하여 제거할 수 있습니다.
- GitHub app 설정 tip이 origin remote가 gitlab.com 또는 bitbucket.org에 있는 repository에서 더 이상 나타나지 않도록 변경되었습니다. enterprise marketplace tip이 이제 비GitHub 내부 git 호스트를 포함합니다.
- 할 일/작업 추적 tool(TaskCreate/Get/Update/List, TodoWrite)이 Opus 4.8, Sonnet 5, Fable 5, Mythos 5 및 최신 model에서 더 이상 사용 가능하지 않습니다. `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`을 설정하여 복원할 수 있습니다.
- Windows: auto 모드가 일반적인 `cd <dir> && <command> > file` Bash 명령어에서 반복적으로 수동 승인을 위해 중지하는 문제가 수정되었습니다 (2.1.232 regression).
- Windows의 Cygwin 스타일 symlink 및 input redirection(`< file`)에 대한 2.1.232 Bash 권한 변경이 되돌려졌습니다. 더 좁은 버전이 나중 릴리스에서 반환될 예정입니다.
