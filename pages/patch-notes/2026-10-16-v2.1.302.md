> 원문: [Claude Code v2.1.302 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

## 변경사항

- `CLAUDE_CODE_AUTO_MODE_MODEL`을 추가하여 클라이언트 측 자동 모드 분류기가 사용하는 모델을 선택할 수 있도록 했습니다. 이는 서버 측 자동 모드의 모델을 변경하지 않습니다.
- `/config`에 `Idle compaction` 행을 추가하여 유휴 압축을 끄거나 다시 켤 수 있도록 했습니다. 유휴 압축 후 표시되는 알림은 이제 이를 끄는 방법을 안내합니다.
- `/design-sync` 및 `/design-login`에 독립형 Claude Design(claude.ai/design)이 2026년 12월 14일까지 종료될 예정이라는 알림을 추가했습니다.
- 대화 압축 중에 턴을 중지할 때 발생하는 "Prompt is too long" 오류를 수정했습니다.
- 세션 중에 Vertex 또는 Bedrock으로 전환한 후 "diagnostics: Extra inputs are not permitted" 오류로 요청이 실패하는 문제를 수정했습니다.
- Read 도구가 모든 크기의 이미지 파일이나 이미지 파일처럼 명명된 파이프 또는 디바이스를 전체적으로 메모리에 로드하는 문제를 수정했습니다. 이제 128 MB 이상의 이미지 소스는 거부됩니다.
- 게이트웨이가 `anthropic/claude-opus-4-1`과 같은 접두사로 Opus 4 또는 4.1을 명명할 때 `/autocompact` 및 `/effort`가 잘못된 모델에 저장되는 문제를 수정했습니다.
- ToolSearch를 통해 또는 압축 후 세션 중에 추가된 도구를 다시 로드할 때 prompt cache miss가 발생하는 문제를 수정했습니다.
- `claude plugin` 및 기타 하위 명령이 대기 중인 설정 또는 구성 작성이 완료되기 전에 종료되는 경우가 있어 변경사항이 손실되거나 `.tmp` 파일이 남을 수 있는 문제를 수정했습니다.
- git이 reftable ref 형식을 기본값으로 설정할 때 플러그인 마켓플레이스가 새로 고침마다 다시 복제되고, 새로 설치된 git 플러그인이 버전 "unknown"을 표시하는 문제를 수정했습니다.
- PowerShell 도구가 플러그인의 `bin/` 폴더에서 명령을 찾지 못하고, 아무것도 찾지 못한 검색(rg, grep, findstr, git grep)이 `Select-Object` 또는 다른 형식 지정 cmdlet으로 파이프될 때 오류를 보고하는 문제를 수정했습니다.
- 데스크톱 앱의 Claude가 해당 옵션을 사용할 수 없는 MCP 서버를 승인하거나 다시 연결하도록 claude.ai 설정 또는 `/mcp`를 가리키는 문제를 수정했습니다.
- Claude가 빈 편집 목록을 전송할 때 아티팩트 게시가 실패하고, 아티팩트의 새로운 버전이 이를 거부한 후 Claude가 아티팩트 업데이트를 잘못된 방식으로 재시도하는 문제를 수정했습니다.
- 대부분의 자동 모드 분류기 블록에서 OpenTelemetry `tool_decision` 이벤트에서 `classifier_category`가 누락되고, `OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT`이 낮을 때 새로운 `tool_decision` 속성이 `tool_use_id`, `tool_source` 및 `tool_parameters`를 밀어낼 수 있는 문제를 수정했습니다.
- 긴 목록을 아래로 이동하거나 섹션을 접은 후 agents 보기의 행이 비어 있는 상태로 유지되는 문제를 수정했습니다.
- 로그인하지 않은 상태일 때 `claude remote-control --help`가 사용 정보를 인쇄하고 종료하지 않는 문제를 수정했습니다.
- `/design consent` 및 `/design revoke`가 클라우드 세션에서 실패할 때 `/design-login`을 제안하는 문제를 수정했습니다. 이제 메시지가 claude.ai/design/settings를 가리킵니다.
- MCP 서버가 protocol version 2026-07-28을 협상하지만 `resultType`, `ttlMs` 또는 `cacheScope`를 생략할 때 도구를 표시하지 않거나 모든 도구 호출이 실패하는 문제를 수정했습니다.
- 프롬프트 제안이 플랜이 크레딧으로만 지불하는 모델에서 사용 크레딧을 지출하는 문제를 수정했습니다. 이제 크레딧으로 청구되는 회신 후 건너뜁니다.
- 백틱으로 작성된 URL이 래핑될 때 첫 번째 행에서만 클릭 가능하던 문제를 수정했습니다. 이제 하이퍼링크를 지원하는 터미널에서 전체 URL이 하나의 링크가 됩니다.
- `claude plugin details <name>@builtin`이 플러그인을 찾지 못할 때 기본 제공 플러그인을 표시하지 않는 `claude plugin list`를 제안하는 문제를 수정했습니다. 이제 `/plugin`을 가리킵니다.
- 링크가 시작되는 이모지가 하나의 열이 너무 넓게 래핑되어 질문 미리보기에서 이를 숨기고 표를 목록으로 변환하는 문제를 수정했습니다.
- 워크트리 격리가 git 2.56 이상에서 stray `.git` 파일이 존재하지 않는 디렉터리를 가리킬 때 워크트리 생성 또는 재개를 거부하는 문제를 수정했습니다.
- 클라우드 세션이 새 프로세스에서 재개된 후 비용 및 사용량이 0부터 다시 시작되는 문제를 수정했습니다.
- 자체 호스팅 runner: git이 reftable 형식으로 저장된 체크아웃을 재사용하는 세션에서 git fetches가 "bad object refs/heads"로 실패하는 문제를 수정했습니다.
- Windows: `--plugin-dir`로 시작된 세션을 포함하여 exFAT 또는 FAT32 드라이브의 프로젝트에 대해 모든 파일 쓰기가 거부되거나 요청되는 문제를 수정했습니다.
- 많은 플러그인을 활성화한 상태에서 시작 시간을 개선했습니다. 플러그인 명령 및 agent 파일이 로드될 때 훨씬 더 적은 파일 시스템 호출을 수행합니다. 특히 Windows에서 그렇습니다.
- 서버 측 분류기를 사용하는 자동 모드를 개선했습니다. 안전 검사에 너무 긴 대화는 이제 압축되며, 모든 확인된 도구 호출이 거부되지는 않습니다.
- 다른 폴더에서 재개된 백그라운드 세션에 LLM gateway가 없을 때 메시지를 개선했습니다. 이제 "Not logged in" 대신 이유를 안내합니다.
- 권한 모드가 없는 `claude -p` 및 Agent SDK 세션을 타사 제공자에서 `default` 모드로 시작하도록 변경했습니다. 텔레메트리는 꺼지거나 새로 설치될 때 켜집니다. `--permission-mode auto`는 자동을 유지합니다.
- Fork subagent(`subagent_type: "fork"`)를 `claude -p`, Agent SDK, 데스크톱 앱 및 VS Code에서 기본적으로 켜도록 변경했습니다. 이들은 터미널에서 이미 켜져 있습니다. `CLAUDE_CODE_FORK_SUBAGENT=0`은 이를 끕니다. `claude mcp serve`는 절대 이들을 제공하지 않습니다.
- 데스크톱 앱과 VS Code가 터미널처럼 main 대화의 subagent를 항상 백그라운드에서 실행하도록 변경했습니다. Claude가 선택하도록 하지 않습니다. `claude -p`, Agent SDK, 데스크톱 앱 및 VS Code의 subagent 자신의 Agent 호출은 이제 기본적으로 foreground에서 실행됩니다.
- `← for agents` 푸터 힌트를 세션이 열린 후 10초 후에 숨기도록 변경했습니다. 당신을 대기 중인 agent의 개수는 여전히 표시됩니다.
- Claude in Chrome 지침이 시스템 프롬프트에 있는 위치를 변경하여 새 대화가 공유 prompt cache에서 이들을 읽을 수 있도록 했습니다.
- prompt 및 agent 훅을 변경하여 한 번에 최대 12개의 하나의 이벤트만 실행되도록 했습니다. 나머지는 차례를 기다립니다.
- 조직의 정책이 `/feedback`을 끌 때 표시되는 메시지를 변경했습니다. 이제 조직 관리자 대신 GitHub issues를 가리킵니다.
- [VSCode] 회신이 스트림될 때 목록의 닫히지 않은 코드 블록 뒤의 텍스트가 일반 텍스트로 표시되었다가 코드로 변환되는 문제를 수정했습니다.
- [VSCode] 서버 URL에 쿼리 문자열이 포함되어 있을 때 패널에서 MCP 서버 로그인이 끊어진 인증 페이지를 열도록 하는 문제를 수정했습니다.
- [VSCode] `@browser` 배너가 Claude 확장이 있는 브라우저에 연결할 수 없을 때 "Browser connected"라고 표시하는 문제를 수정했습니다.
- [Cloud sessions] 조직이 동시 클라우드 세션 제한에 도달한 등 마지막 실행이 시작되지 않은 이유를 설명하는 배너를 routine의 페이지에 추가했습니다.
- [Cloud sessions] 클라우드 세션에서 최신 메시지를 제외한 모든 메시지에서 "Rewind to here"가 실패하는 문제를 수정했습니다. 자체 호스팅 runner는 Claude Code v2.1.246 이상이 필요합니다.
- [Cloud sessions] 클라우드 세션에서 GitHub가 다시 확인하는 동안 merge 충돌이 있는 pull request를 준비 완료로 전환하는 pull request 상태 표시줄 문제를 수정했습니다.
- [Cloud sessions] 클라우드 세션이 예기치 않게 중지된 후 routine 실행이 Completed로 표시되고, 시작 전에 아카이브될 때 Cancelled로 표시되는 문제를 수정했습니다. 이제 failed로 표시됩니다.
- [Cloud sessions] 세션의 GitHub 저장소가 이름을 변경하거나 이동한 후 클라우드 세션의 diff 보기에서 변경사항이 누락되거나 로드 실패하는 문제를 수정했습니다.
- [Cloud sessions] 중간에 실패한 예약된 routine 실행이 1시간 이상 후에 처음부터 다시 실행되어 동일한 보고서 게시와 같은 작업을 반복할 수 있는 문제를 수정했습니다.
- [Cloud sessions] 열린 클라우드 세션이 다른 디바이스에서 보낸 메시지를 페이지를 다시 로드하거나 다른 곳을 클릭했다가 돌아올 때까지 표시하지 않는 문제를 수정했습니다.
- [Cloud sessions] 클라우드 세션 시작 실패 시 표시되는 오류를 개선했습니다. 이제 "Something went wrong" 대신 "Connection lost" 또는 "Server error"라고 표시합니다.
- [Remote Control] Remote Control 세션에서 컴퓨터가 오프라인 상태가 된 후 subagent의 창이 무한정 회전하는 문제를 수정했습니다. 이제
