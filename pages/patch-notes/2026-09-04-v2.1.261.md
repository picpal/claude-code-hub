> 원문: [Claude Code v2.1.261 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.261)

## 변경사항

- `/status` 및 `claude doctor`에 조직 정책을 로드할 수 없는 이유(예: 프록시가 엔드포인트를 전달하지 않음)를 설명하는 "Organization policy" 줄을 추가했습니다
- `bashOutputMaxChars` 및 `taskOutputMaxChars` 설정을 추가하여 Claude가 인라인으로 받는 명령 및 백그라운드 작업 출력 양을 파일에 저장되기 전에 최대 128K 문자까지 증가시킬 수 있도록 했습니다
- 명령줄에서 전달하기에는 너무 큰 프롬프트에 대해 subagent 시스템 프롬프트를 파일에서 읽기 위해 `--append-subagent-system-prompt-file`을 추가했습니다
- 로드된 기술 중 사용되지 않는 기술을 표시하고 컨텍스트에서 비용이 얼마나 드는지 확인하여 불필요한 기술을 제거할 수 있도록 `/skill-doctor`를 추가했습니다
- 빠른 입력이나 키 반복 중에 입력한 또는 붙여넣은 문자가 가끔 순서가 바뀌거나 손실되는 문제를 수정했습니다
- 작업 디렉토리가 `/net` automount에 있을 때 `/add-dir <subdirectory>`가 잘못된 "couldn't be resolved" 오류를 출력하는 문제를 수정했습니다
- AWS 또는 AWS 자격 증명 도우미가 응답하지 않을 때 Bedrock 설정 마법사가 중단되는 문제를 수정했으며(이제 명확한 오류로 타임아웃됨), TLS 검사 프록시 뒤에서 모델 검사가 실패하는 문제도 수정했습니다
- 클라우드 세션이 `enabledPlugins`에서 관리 설정으로 강제 활성화된 경우 claude.ai에서 동기화된 플러그인을 폐기하고 실패할 수 있는 마켓플레이스 복제본으로 폴백하는 문제를 수정했습니다
- 프롬프트 입력에서 인라인 `[Image #N]` 칩 바로 앞의 문자를 삭제할 수 없는 문제를 수정했습니다
- 세션을 재개할 때 훅 출력 및 병렬 도구 호출 주변의 다른 컨텍스트가 손실되어 재개된 요청이 변경되는 문제를 수정했습니다
- Remote Control이 휴대폰, 브라우저 또는 claude.ai 앱이 터미널 세션에 연결되거나 터미널에서 모드가 변경된 후에 오래된 권한 모드를 표시하는 문제를 수정했습니다
- 휴대폰 또는 브라우저에서 연결된 디바이스에서 턴을 중지한 후 또는 `/clear` 같은 로컬 슬래시 명령 후에 Remote Control 세션이 여전히 작동 중인 것으로 표시되는(중단된 스피너 및 중지 버튼) 문제를 수정했습니다
- SDK 및 클라우드 세션이 첫 번째 프롬프트 직후, 턴이 시작되기 전에 전송된 중지 또는 인터럽트를 무시하는 문제를 수정했으며, 이제 턴이 완료될 때까지 실행되지 않고 중지됩니다
- Remote Control이 `/teleport`로 가져온 세션을 연결된 세션에 업로드하여 휴대폰 및 웹에서 원본에 추가되어 보이는 문제를 수정했습니다
- Remote Control의 인바운드 이벤트 스트림이 기본 Windows의 TLS 검사 회사 프록시 뒤에서 실패하는 문제를 수정했습니다
- Remote Control 세션이 설정에서 오는 노력일 때 claude.ai에서 기본 노력 수준을 표시하는 문제를 수정했습니다
- 자격 증명이 여전히 유효했음에도 불구하고 Google 자격 증명 확인이 느릴 때 `gcpAuthRefresh`가 시작 시 브라우저를 여는 문제를 수정했습니다
- 시작 connector 가져오기가 타임아웃되었을 때 claude.ai 커넥터가 전체 세션 동안 나타나지 않는 문제를 수정했으며, CLI가 이제 백그라운드에서 다시 시도합니다
- 백그라운드 에이전트를 재개할 수 없고 깨어나기가 타이트한 루프에서 다시 시도될 때 지속적으로 높은 CPU 사용량이 발생하는 문제를 수정했습니다
- 같은 머신에서 실행 중인 최신 버전의 Claude Code에 제한된 기능 플래그가 가끔 이전 버전에 적용되는 문제를 수정했습니다
- 사용량 엔드포인트가 속도 제한되거나 시작 직후에 열렸을 때 `/usage` 및 VS Code 사용량 패널이 모델별 주간 한도 행을 삭제하는 문제를 수정했습니다
- `claude -p --resume <file>`이 트랜스크립트에 기록된 잘못된 형식의 세션 ID를 채택하는 문제를 수정했으며, 이제 새로운 세션 ID로 대신 재개합니다
- 백그라운드 워크플로우 또는 에이전트가 실행 중일 때 터미널 진행률 표시기(iTerm2, Ghostty, ConEmu)가 세션을 완료로 표시하는 문제를 수정했습니다
- 컨테이너가 행과 열 방향 사이를 전환한 후 상자가 잘못된 높이로 렌더링될 수 있는 드문 레이아웃 오류를 수정했습니다
- 신뢰할 수 있는 프록시가 `X-Forwarded-For`에 포트를 추가할 때 Claude 앱 게이트웨이 클라이언트 IP를 수정했으며, 액세스 목록이 설정되면 읽을 수 없는 항목이 이제 403을 받습니다
- Claude 앱 게이트웨이가 터미널 CLI가 protobuf를 사용할 때도 Claude Desktop에 OpenTelemetry를 JSON으로 내보내도록 지시하여 protobuf 전용 수집기가 Desktop의 데이터를 거부하는 문제를 수정했습니다
- Desktop 및 웹이 세션이 아티팩트 업데이트를 감시할 때 세션을 바쁜 것으로 표시하는 문제를 수정했습니다
- Chrome의 Claude `file_upload`가 Claude Desktop 앱에서 실행된 로컬 Cowork 세션에서 "paths: expected array, received undefined" 오류로 실패하는 문제를 수정했습니다
- 다른 머신의 오프라인 Remote Control 세션에 `SendMessage`를 전송할 때 배달된 것으로 읽히는 문제를 수정했으며, 이제 결과가 해당 머신이 다시 연결될 때까지 배달이 대기열에 있음을 나타냅니다
- 백그라운드 Bash 명령에서 실행된 CLI의 플러그인 설치 힌트를 수정했습니다. 이제 감지되며 원본 `<claude-code-hint>` 태그가 더 이상 대화로 유출되지 않습니다
- 인프로세스 에이전트 팀 팀원이 두 번째 턴에서 첫 번째 턴 도구 및 기술 공지사항을 다시 전송하여 요청 접두사가 변경되고 프롬프트 캐시가 누락되는 문제를 수정했습니다
- Claude Code가 모델을 인식할 때 `/model` 선택기 및 VS Code 모델 필을 개선하여 원본 Bedrock, Vertex AI 또는 LLM 게이트웨이 ID 대신 모델의 이름을 표시합니다
- `GOOGLE_APPLICATION_CREDENTIALS`가 설정된 경우 Google Vertex AI에서의 시작을 개선했습니다. API 클라이언트 생성이 더 이상 Google Cloud 프로젝트 검색을 다시 실행하거나 추가 `gcloud` 프로세스를 생성하지 않습니다
- 스트리밍 성능을 개선했습니다. 이미 렌더링된 블록은 더 이상 각 업데이트에서 레이아웃으로 다시 확인되지 않습니다
- 위험한 `rm` 안전 프롬프트를 개선하여 위치 매개변수에 대한 `rm -rf` 및 이중 인용된 `sh -c` 스크립트 내부의 명령도 포착합니다
- API가 응답 헤더를 보내지 않을 때의 처리를 개선했습니다. 재시도가 이제 다른 3분 대신 최대 `API_TIMEOUT_MS`(기본값 10분)를 기다리며, 메시지는 변경할 사항을 표시합니다
- Claude 앱 게이트웨이 403을 관리 설정 로드(시작 또는 `/login` 후)에서 변경하여 새로 로그인하라고 조언하는 대신 Claude Code가 조직에 대해 활성화되지 않았을 수 있다고 표시합니다
- `forceLoginMethod: "gateway"`로 관리 설정을 고정하는 머신을 변경하여 남은 API 키 또는 claude.ai 로그인을 무시하고 `/login`을 요청합니다. Bedrock, Vertex AI 및 Foundry 세션은 영향을 받지 않습니다
- 자동 모드를 변경하여 공개 다이어그램 렌더러의 URL에 콘텐츠를 패킹하는 링크를 해당 사이트로의 업로드로 처리합니다. 명시적으로 요청하지 않으면 더 이상 자동 승인되지 않습니다
- 프롬프트의 단어 편집 키를 Bash와 일치하도록 변경했습니다. Ctrl+W는 공백으로 뒤로 삭제하고, Alt+F 및 Alt+D는 단어 끝에서 중지하며, 구두점이 단어를 구분합니다. `keybindingFlavor`는 더 이상 영향을 주지 않습니다
- `/context` 토큰 계산을 변경하여 토큰 계산 API를 사용할 수 없을 때 추가 소형 모델 요청 대신 로컬 추정값을 사용합니다
- [VSCode] 출력 스타일 메뉴에 "Build a custom style" 연습을 추가했으며, 사용자 정의 출력 스타일 파일을 작성하고 즉시 나열합니다
- [VSCode] MCP 서버 대화 상자에 서버 추가 양식 및 제거 작업을 추가했으므로 IDE를 떠나지 않고 MCP 서버를 추가 및 제거할 수 있습니다
- [VSCode] 터미널, 다른 VS Code 창 또는 Claude Desktop에서 열린 세션에 대한 세션 목록에 속이 빈 원형을 추가했으므로 더 이상 닫혀있는 것처럼 보이지 않습니다
- [VSCode] 권한 및 질문 프롬프트에 접기 버튼을 추가했으므로 프롬프트를 해제하지 않고도 뒤의 대화를 읽을 수 있습니다. 프롬프트 옆의 공간이 이제 대화를 스크롤합니다
- [VSCode] 세션 목록의 우클릭 메뉴에 "Archive session"을 추가하고 보관 해제에 자체 아이콘을 제공했습니다
- [VSCode] 클라우드 세션이 종료될 때 중단된 질문을 거절한 것으로 처리하는 웹에서 Claude Code에서 텔레포트된 세션을 수정했습니다
- [VSCode] 창이 복원된 탭에 대해 세션 탭의 이름 변경 상자가 빈 상태로 열리는 문제를 수정했으며, 이제 현재 이름으로 시작됩니다
- [VSCode] 세션 목록 패널이 로드될 때마다 축소된 섹션이 잠깐 전개되는 문제를 수정했습니다
