> 원문: [Claude Code v2.1.278 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)

## 변경사항

- Claude API 및 Enterprise 사용자와 Bedrock, Vertex, Foundry 및 gateway에서 auto mode를 변경하여 server-side classifier를 기본값으로 설정했습니다. 이는 classifier 오버헤드에 대한 비용을 청구하지 않습니다 (Bedrock, Vertex, Foundry 및 gateway에서 `CLAUDE_CODE_AUTO_MODE_SERVER=0`으로 비활성화 가능). 청구 대상 fallback에 대해 경고를 표시합니다. https://code.claude.com/docs/en/auto-mode-classifier-billing를 참조하세요
- `/status`에 `Auto mode server` 행을 추가했습니다. 이 행은 현재 세션의 auto mode classifier가 server에서 실행되는지 여부를 나타냅니다
