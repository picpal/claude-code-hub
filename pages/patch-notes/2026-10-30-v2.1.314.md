> 원문: [Claude Code v2.1.314 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)

## 변경사항

- Added `permissions.blockWritesOutsideWorkingDirectories`: Write, Edit 및 NotebookEdit이 모든 permission 모드에서 working directories 외부의 경로를 거부합니다
- Claude apps gateway upstreams에 선택적 `groups` 목록이 추가되었습니다: 나열된 IdP 그룹의 개발자만 해당 upstream으로 전송되며, failover 시에도 적용됩니다
- Claude apps gateway Bedrock upstreams에 `guardrail_trace`가 추가되었습니다: 일치한 텍스트 없이 요청에서 어떤 Amazon Bedrock guardrail 필터가 작동했는지 기록합니다
- VS Code 및 Claude Desktop의 Code 탭에 idle compaction이 추가되었습니다: 유휴 상태인 200K 이상의 token 대화가 요약되며, prompt cache가 만료된 경우 다음 메시지에서 요약을 사용합니다
- 조직의 관리자가 모델의 effort를 제한할 때 "Invalid effort level" 오류로 인해 차례마다 세션이 실패하는 문제를 수정했습니다: Claude Code는 이제 effort를 낮추고 재시도하며 사용 중인 수준을 알려줍니다
- `claude -p` 시작 실패 시 코드 0으로 종료되고 출력이 없는 문제를 수정했습니다: 이제 오류를 출력하고 1로 종료됩니다
- 많은 이미지가 있는 Bedrock 세션이 차례마다 실패하고 `/compact`에서 "400 Input is too long." 오류가 발생하는 대신 이전 이미지를 제거하고 compacting하는 문제를 수정했습니다
- 기본 Sonnet, Opus 또는 Haiku 모델에 대한 배포가 없는 리소스가 있을 때 Microsoft Foundry 세션이 실패하는 문제를 수정했습니다: Claude Code는 이제 해당 family의 이전 모델로 대체합니다
- tool search의 `tool_reference` 블록을 허용하지 않는 gateway 뒤에서 반복된 거부된 요청이 발생하는 문제를 수정했습니다: 요청이 tool search 없이 다시 한 번 전송되며, 세션이 이를 기억합니다
- 시스템 인증서 저장소에 선행 인증서와 cross-signed된 갱신된 루트 인증서가 있을 때 TLS 연결이 `UNABLE_TO_GET_ISSUER_CERT`로 실패하는 문제를 수정했습니다
- 저장된 sign-in이 작동을 중지한 후 sign-in 없이도 작동하는 MCP 서버가 "needs authentication"을 표시하는 문제를 수정했습니다: 이제 sign out 상태로 사용됩니다
- 예를 들어 macOS keychain이 SSH를 통해 잠겨 있을 때 MCP sign-in이 제거되지 않은 경우 `claude mcp logout`이 성공을 보고하는 문제를 수정했습니다
- 여러 세션이 Anthropic profile login을 공유하고 credentials lock이 busy할 때 추가 sign-in 갱신이 발생하는 문제를 수정했습니다
- `claude ultrareview` 및 `claude remote-control`이 터미널이 있는 CI 작업에서 workspace trust 질문을 하는 문제를 수정했습니다: `CI`가 설정되면 이제 신뢰할 수 없는 폴더를 즉시 거부합니다
- Claude Desktop 세션에서 관리자의 TLS trust 설정이 managed settings에 적용되지 않는 문제를 수정했습니다
- broken manifest가 있거나 다운로드에 실패한 `--plugin-dir` 또는 `--plugin-url` 플러그인 중 하나가 있을 때 managed plugin settings이 있는 머신에서 모델 전환이 거부되는 문제를 수정했습니다
- managed settings이 모델을 고정할 때 매 시작마다 Bedrock 및 Vertex 모델 업그레이드 제안이 다시 나타나는 문제를 수정했습니다
- `forceRemoteSettingsRefresh`가 remote managed settings에만 설정되어 저장된 복사본이 만료된 후 더 이상 적용되지 않아 서버에 연결할 수 없을 때 policy 없이 세션이 시작되는 문제를 수정했습니다
- "Continue automatically at usage limit"이 작업이 waits 사이에서 재시작될 때 (a /goal check-in, a background 또는 scheduled task) 당신의 프롬프트 없이 3회 이상 계속되는 문제를 수정했습니다
- Ultracode로 시작한 background 및 cloud 세션이 꺼진 후 다음 시작 시 다시 켜지는 문제를 수정했습니다
- Claude가 parsing할 수 없는 tool call을 포기한 후 마지막 broken reply와 its retry prompts가 대화에 남아있는 문제를 수정했습니다
- 매우 큰 출력을 가진 PreCompact hook이 compaction을 실패하거나 반복하는 문제를 수정했습니다: 각 hook의 출력은 이제 10,000자로 제한됩니다
- background diff refresh가 repository의 index lock을 잠깐 유지하여 같은 순간에 실행되는 git 명령이 "Unable to create '.git/index.lock': File exists"로 실패하는 문제를 수정했습니다
- markdown 테이블이 streaming 중 반 입력된 행에서 grid와 stacked 레이아웃 사이를 점프하고, 긴 테이블이 raw pipes로 대체되는 문제를 수정했습니다
- 세션이 slash 명령만 실행했을 때 /resume picker가 CLAUDE.md 또는 CLAUDE.local.md의 텍스트를 세션의 제목으로 표시하는 문제를 수정했습니다
- `/btw`가 subagent의 open transcript에서 질문을 받을 때 main conversation에서 답변하는 문제를 수정했습니다
- SSH를 통해 Linux 머신에 이미지를 붙여넣는 것이 조용히 아무것도 하지 않는 문제를 수정했습니다: 프롬프트는 이제 파일을 복사하고 그 경로를 붙여넣도록 말합니다
- `claude remote-control` 세션이 session service가 잠깐 느릴 때 시작하지 못하는 문제를 수정했습니다: worker의 등록은 이제 증가하는 waits로 재시도됩니다
- Remote Control을 통한 8초 이상 걸리는 모델 전환이 최종 결과 대신 "still pending" 오류를 받는 문제를 수정했습니다
- `sandbox.excludedCommands` 설정 설명이 나열된 명령이 항상 sandbox 외부에서 실행된다고 말하는 문제를 수정했습니다: 이제 호출의 모든 명령이 entry와 일치해야 한다고 말합니다
- auto mode, deny rule 또는 PreToolUse hook이 차단했거나 그렇지 않으면 실행되지 않은 shell 및 MCP 호출이 collapsed tool group에서 실행된 것처럼 읽히는 문제를 수정했습니다
- `claude -p --resume` 또는 `--continue`로 입장한 worktree에 sandbox 보호가 적용되지 않는 문제를 수정했습니다
- Bash와 일치하는 hook이 Monitor tool로 시작된 shell 명령에서 실행되지 않는 문제를 수정했습니다: 이러한 hook은 block하거나 물어볼 수 있지만, approve하거나 rewrite할 수 없습니다
- `--setting-sources`로 제외된 설정 파일이 여전히 auto mode rules 및 saved permission consents와 같은 일부 설정을 제공하는 문제를 수정했습니다
- auto mode가 호출을 blocked로 보고하고 `/permissions`에 나열할 때 safety check이 no verdict를 제공하는 문제를 수정했습니다
- Claude apps gateway Vertex upstream이 Google token endpoint가 연결을 수락하고 절대 답변하지 않을 때 몇 분 동안 hanging되는 문제를 수정했습니다
- Claude apps gateway의 deprecated Claude Desktop 키에 대한 시작 warning이 키의 end date 이후 "stops being accepted"라고 말하는 문제를 수정했습니다
- `/upgrade`가 App Store 또는 Google Play를 통해 청구되는 plans에 대해 브라우저를 열고 새 login을 시작하는 문제를 수정했습니다: 이제 plan을 변경할 수 있는 위치를 알려줍니다
- `--resume` 및 거부 후 다른 모델로의 전환을 되감기할 때 Claude Code가 인식하지 못하는 모델 이름의 세션을 다른 모델로 이동하는 문제를 수정했습니다
- gateway 또는 cloud provider가 Claude Code의 beta 헤더 중 하나를 이름으로 거부할 때 요청이 실패하는 문제를 수정했습니다: 요청은 이제 이것 없이 다시 전송됩니다
- dot로 철자된 모델 ID가 LLM gateway 뒤에 있을 때 (예: `claude-opus-4.8`) 잘못된 context window, output limit, effort, thinking mode 및 cost를 가진 이전 모델로 취급되는 문제를 수정했습니다
- Remote Control 클라이언트가 /compact 후 stray "Compacted (ctrl+o to see full summary)" 행을 표시하는 문제를 수정했습니다
- cloud sessions tip 및 Remote Control idle notice가 조직의 policy가 해당 기능을 끌 때 표시되는 문제를 수정했습니다
- resumed claude.ai cloud 세션이 이전 worker가 새 chat의 파일을 받은 직후 중지했을 때 아무도 요청하지 않은 model call을 만드는 문제를 수정했습니다
- Cowork cloud 세션의 WebFetch가 PDF의 텍스트를 100,000자 이후로 조용히 삭제하는 문제를 수정했습니다: 이제 얼마나 많은 텍스트를 읽지 못했는지와 어디서 읽을 수 있는지 알려줍니다
- Claude가 cloud 세션 또는 IDE에서 Esc 또는 Stop으로 명령을 중지한 후 명령이 거부되었다고만 알려지는 문제를 수정했습니다: 이제 명령이 실행되었을 수도 있다고 듣습니다
- code block이 quote를 열 때 code block의 맨 위 blank lines가 사라지는 문제를 수정했습니다
- transcript view (Ctrl+O)에서 일부 `⎿` 행 위에 blank line이 나타나는 문제를 수정했습니다
- vim mode `dw`, `dW`, `yw` 및 `yW`가 라인의 끝을 넘어가고, `w` 및 `W`를 empty lines에서 멈추도록 만들었습니다
- agent panel에서 x 및 Enter가 다른 agent가 시작하거나 완료될 때 잘못된 agent에 작용하는 문제를 수정했습니다
- pasted text 및 dragged-in files가 "Other" 행에 focus가 없으면 Claude의 질문 dialog에서 손실되는 문제를 수정했습니다
- 프롬프트 footer의 행이 선택되면 pasted text가 손실되는 문제를 수정했습니다
- vim mode `p`가 character selection에서 yanked text가 whole lines인지 여부를 무시하는 문제를 수정했습니다
- vim mode `aw` 및 `iw`가 라인의 끝에서 line break를 취하는 문제를 수정했습니다
- ↓가 ? help menu, command list 또는 paste hint에 의해 숨겨진 footer items를 선택하는 문제를 수정했습니다
- Esc가 `/btw`와 같은 명령의 panel에서 open transcript를 가진 subagent를 also interrupting하는 문제를 수정했습니다
- fullscreen mode에서 welcome header가 다른 모델에서 실행되는 subagent 또는 teammate를 볼 때 세션의 모델을 표시하는 문제를 수정했습니다
- scroll up된 상태에서 rewind menu의 "Restore conversation"을 선택한 후 fullscreen transcript가 mid-conversation에 남아있는 문제를 수정했습니다
- 삭제된 세션이 거의 비어있는 entry로 resume list에 다시 나타날 수 있는 드문 경우를 수정했습니다
- `<bash-stdout>` 또는 `<local-command-stdout>`과 같은
