> 원문: [Claude Code v2.1.301 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)

## 변경사항

- `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`를 추가하여 무인 재시도 모드(`CLAUDE_CODE_RETRY_WATCHDOG`)가 너무 멀리 리셋되는 사용량 한도에서 대기하는 대신 요청을 종료하도록 함
- `claude-api` skill에 OpenTelemetry 추적 지침을 추가하였으며, `ant` CLI를 사용하여 추적 대상 설정을 포함함
- vim 모드에 `%` motion을 추가함: 일치하는 괄호로 이동하며, d/c/y와 함께 사용 가능
- mod의 `Input`에 `rows`를 추가함: 터미널에서 여러 줄의 텍스트 필드이며, Enter로 제출하고 Shift+Enter 또는 Enter 앞의 백슬래시로 새 줄을 시작할 수 있음
- OpenTelemetry `tool_decision` events에 `classifier_verdict`와 `permission_mode`를 추가하여 자동 모드 classifier 결정과 permission rules를 구분할 수 있게 함
- `OTEL_LOG_TOOL_DETAILS=1`일 때 OpenTelemetry `tool_decision` events에 `classifier_category`를 추가하여 classifier 블록이 일치한 기본 제공 규칙의 이름을 지정함
- 최신 Fable 모델을 조직에서 사용할 수 없을 때 `WorktreeCreate` hook으로 만든 worktree를 제거할 때 묻지 않고 종료하는 문제 수정
- 최신 Fable 모델을 조직에서 사용할 수 없을 때 Anthropic API에서 `fable`(및 `best`) 모델 alias 오류 발생 문제 수정: Claude Code는 이전 Fable 모델에서 한 번 재시도함
- 디스크가 가득 차서 로그인이 새로 고쳐지지 않을 때 오해의 소지가 있는 "Please run /login" 오류 수정: 오류가 이제 디스크를 지정하고 파일을 삭제하라고 안내함
- 검색 프로그램이 결과를 반환하기 전에 예기치 않게 실패했을 때 Grep과 Glob이 일치하는 항목이 없다고 보고하는 문제 수정: 검색이 실패했다고 알리는 오류를 반환하도록 함
- task 텍스트에 사용자 권한이 없음을 알리는 harness note를 읽은 후 workflow agents가 step을 건너뛰고 실행이 여전히 성공으로 보고되는 문제 수정
- PreToolUse hook이 Edit 또는 Write를 포함할 때 artifact 업데이트가 거부되는 문제 수정: Claude는 이제 파일을 편집한 후 publish 호출에서 변경하는 대신 다시 발행함
- 매우 많거나 매우 긴 argument 이름을 가진 skills과 commands가 호출될 때 수 초 동안 정지하는 문제 수정: 이제 처음 64개의 이름(각각 최대 64자)만 채워짐
- skills, commands, hooks가 arguments로 많은 placeholders를 채울 때 매우 많은 양의 메모리를 사용하는 문제 수정
- RHEL 8의 MATE Terminal과 같이 0.53보다 오래된 VTE 기반 터미널에서 folder trust 프롬프트를 덮는 `>0q`와 같은 stray characters와 exit 시 shell 프롬프트 앞의 `>4m` 수정
- 일부 iTerm2 버전에서 시작 시 프롬프트에 stray `GOK` 텍스트가 나타나는 문제 수정
- provider가 Bedrock이 아닐 때 이름에 `application-inference-profile`을 포함하는 모델로 전환하면 `awsAuthRefresh` 명령을 실행하고 모델 전환 hooks를 지연하는 문제 수정
- 짧은 명령(예: `claude auth status` 또는 `claude plugin list`)이 token refresh 도중에 종료된 후 sign-in 새로 고침 timeouts 및 예기치 않은 sign-outs 발생 문제 수정
- permission check 중에 전송된 메시지로 인해 tool call이 끊겼을 때 모델에 사용자가 거부한 것으로 보고되는 문제 수정
- 더 작은 context window를 가진 모델로 전환할 때 먼저 묻지 않고 이전 모델에서 요약 작업에 사용 credit을 소비할 수 있는 경우 수정
- 요청한 모델과 다른 모델의 이름을 지정하는 응답을 제공하는 LLM gateway 뒤에서 대화가 선택하지 않은 모델에서 반복적으로 압축되는 문제 수정
- Escape 후 vim 모드에서 INSERT가 유지되는 경우가 있던 문제 수정
- vim 모드에서 Esc가 입력된 AskUserQuestion 답변을 폐기하는 문제 수정: 자유 텍스트 필드는 이제 vim NORMAL 모드를 지원하며, Esc는 NORMAL에서만 취소됨
- Read tool이 .xlsm, .parquet, .epub, .heic 같은 binary files를 텍스트로 읽는 문제 수정
- 헤더 행만 있는 Markdown 테이블이 터미널이 너무 넓을 때 아무것도 그려지지 않는 문제 수정(plan 승인 카드의 계획 포함)
- /claude-api skill이 Claude Platform on AWS에서 CMEK external-key endpoints를 사용할 수 없다고 표시하는 문제 수정
- `/rewind` 사용 후 모델에 skills이 더 이상 나열되지 않는 문제 수정
- 재개된 세션에서 compaction 행이 로드되지 않은 history에 대해 ctrl+o를 제공하는 문제 수정: 이제 이전 메시지가 저장된 위치를 표시하며, fullscreen에서도 표시됨
- 응답 중단 직후에 "new task? /clear to save tokens" hint가 다시 나타나는 문제 수정
- plugin 또는 skill hook의 `ask` 결정에 대한 permission 프롬프트가 hook의 출처인 plugin 또는 skill을 표시하지 않는 문제 수정
- 일부 git 검사가 timeout되거나 실패했을 때 `/diff`가 reftable repositories에서 conflicted cherry-pick 또는 revert를 감지하지 못하는 문제 수정
- 같은 세션에서 Bash `cd` 후 workflow scripts를 읽거나 편집하거나 다시 실행할 때 permission을 요청하거나 거부되는 문제 수정
- dark ANSI theme과 16-color terminals에서 dim text 수정: 채워진 상자 안의 faint, 선택 및 검색 highlights 아래 faint 아님, 목록 설명을 다른 보조 텍스트처럼 dimmed
- mod의 `$.model.fork`가 새 Claude Code 프로세스의 첫 번째 응답이 완료되기 전에(`claude -p` 실행 및 cloud sessions 포함) 호출될 때 `nothing-to-fork`를 반환하는 문제 수정
- Fullscreen 모드: `/compact`와 auto-compact가 보이는 transcript를 다시 구축하는 동안 UI가 잠시 정지하는 문제 수정
- Self-hosted runner: 관리 settings이 MCP servers를 제한할 때 Slack에서 시작된 세션이 repository를 찾거나 첨부할 수 없는 문제 수정: `deniedMcpServers`를 사용하여 해당 tools를 비활성화함
- Self-hosted runner: 관련 없는 setup 또는 세션 실패가 git의 missing-ref wording을 인용할 때 세션이 삭제된 source branch를 가진 것으로 보고되고 재시도되지 않는 문제 수정
- Self-hosted runner: 세션이 끝나는 세션의 실패하거나 거부된 session release 재시도를 약속하는 로그 수정: 반복된 실패는 이제 개수를 표시함
- Windows: 중지된 background PowerShell 명령이 output file에서 closing `[killed]` 줄을 놓치는 문제 수정
- 더 작은 context window를 가진 모델로 전환하는 것을 개선함: 새 모델에 맞지 않는 대화는 이제 먼저 이전 모델에서 요약됨
- 오래 실행되는 subagent가 작동하는 동안 rendering performance 개선: 진행 상황 trail은 모든 render에서 완전히 재처리되지 않고 incremental하게 업데이트됨
- Artifacts 개선: Claude가 작성한 페이지는 이제 sticky header 위의 band를 칠하므로 scrolled text가 mobile apps에서 그곳에 표시되지 않음
- Mods 개선: VS Code 및 desktop과 mobile apps에서 질문 dialog 위에 그려진 tree는 이제 Markdown 및 최대 48개 행을 포함할 수 있음: 터미널은 12개의 plain 행을 유지함
- mod hook의 `.catch` handler가 hook을 throw하거나 timeout할 때만 실행되도록 변경함: hook의 자체 호출 아래에서 raised되는 events는 이제 해당 hook을 건너뜀
- mod의 `$.env.set`이 변수가 설정되거나 설정 해제되면 `{}`로 resolve되거나 write가 이루어지지 않을 때 `{ deny }`로 why를 알려주도록 변경함
- [VSCode] Claude의 응답에 LaTeX math rendering을 추가함(`$$` 및 multi-line `\[ … \]` 블록, inline `$…$` 및 `\(…\)` math 포함)
- [VSCode] VS Code 및 JetBrains panels에서 Pro 및 Max plans의 usage-limit 배너에 "Get more usage" 링크를 추가함
- [VSCode] crash되거나 freeze되는 대화가 모든 reload에서 다시 열리는 문제 수정
- [VSCode] 긴 thinking 중에 chat panel이 느려지는 문제 수정: 이제 모든 update에서 전체 thinking 텍스트를 다시 파싱하지 않음
- [VSCode] 일부 language servers의 rule code(예: MD013) 대신 "[object Object]"를 표시하는 diagnostics 수정
- [VSCode] dictation이 제공되지 않는(non-claude.ai sign-ins, remote windows) 곳에서 microphone permission을 확인하기 위해 native dictation audio module이 로드되는 문제 수정
