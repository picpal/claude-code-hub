> 원문: [Claude Code v2.1.247 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)

## 변경사항

- `SendFeedback` tool을 추가했습니다: 세션에서 문제가 발생하면 Claude가 검토하여 `/feedback`에서 전송할 수 있는 피드백 보고서를 작성할 수 있습니다 (`feedbackDrafts` 설정으로 비활성화 가능).
- `spinnerTipsOverride`에 `{id, text, cooldownSessions, priority}` 항목, `tipsFile`, `label`을 추가했으므로 조직에서 기본 제공 팁과 함께 자체 팁을 순환할 수 있습니다.
- Bash 권한 프롬프트에 대한 팁을 추가하여 auto mode를 가리키며, "예, auto mode로 전환" 옵션을 한 번의 키 입력으로 선택할 수 있습니다.
- `/claude-api cost-optimize`를 추가하여 기존 프로젝트의 Claude API 지출을 프로파일링하고 비용 요소(caching, token hygiene, batch, effort, model choice)를 한 번에 하나씩 측정된 변경으로 작업할 수 있습니다.
- Admin API 범위(조직 구성원, 초대, workspace, API key, rate limit 보고서, workload identity federation, CMEK)로 `/claude-api` skill을 업데이트했습니다.
- history search, `/config`, `/mcp`, `/skills`, background task, `/model`에서 빠른 화살표 키 + Enter 시퀀스가 탐색한 행 위의 행에 작용하는 문제를 수정했습니다.
- sub-agent가 첫 번째 호출 model 404에서 중단되는 문제를 수정했습니다: 이제 세션의 fallback model chain을 사용하며, 부모에게 반환된 오류에는 오류 유형, 상태, request id, model이 포함됩니다.
- hook 또는 background agent가 수십 MB의 오류 출력을 인쇄하여 대화를 오버플로우하고 세션을 "Prompt is too long"에서 wedge할 수 있는 문제를 수정했습니다.
- kitty-protocol terminal의 non-Latin (예: Cyrillic) 키보드 레이아웃에서 Ctrl 키보드 단축키가 실행되지 않는 문제를 수정했습니다.
- escape 접두사 직후 읽기에서 분할되어 도착한 mouse report로 인해 `<35;150;7M`과 같은 텍스트가 프롬프트에 삽입되는 문제를 수정했습니다.
- Bash sandbox의 after-command cleanup이 sandbox의 쓰기 가능 영역 외부로 다시 포인팅될 때 dotfile로 관리되는 `~/.claude/settings.json` symlink (nix/home-manager, stow)를 삭제하는 문제를 수정했습니다.
- `/terminal-setup`이 Zed `keymap.json`을 병합하지 않고 전체를 덮어쓰는 문제를 수정했습니다.
- `/rename`이 세션 레지스트리를 업데이트할 수 없을 때 자동으로 확인하는 문제를 수정했습니다: 이제 다른 세션이 여전히 이전 이름을 표시할 수 있음을 나타냅니다.
- `/compact` 및 `--agent`로 시작된 세션의 "Summarize from here"이 대화의 고유한 system prompt 대신 기본값으로 요약하는 문제를 수정했습니다.
- terminal host process가 중단된 후 background session이 `claude agents`에서 "opening…"을 무한정 표시하는 문제를 수정했습니다: 이제 행이 몇 초 내에 이유와 함께 실패하며, Enter로 다시 시작할 수 있습니다.
- hook의 또는 background task의 출력 파일을 쓸 수 없을 때 unbounded memory growth가 발생하는 문제를 수정했습니다: 파일에 이제 출력이 손실된 위치가 기록됩니다.
- SSH를 통한 `/install-github-app` 문제를 수정했습니다: copy 단축키가 항상 성공을 주장하는 대신 sign-in URL이 복사된 방법을 나타내며, 브라우저를 열 수 없을 때 URL이 즉시 표시됩니다.
- foreground에서 전달된 shell command가 background session에서 완료될 때 내부 오류를 기록하거나 오도하는 `[exited with code -1]` 줄을 표시하는 문제를 수정했습니다.
- version 없는 marketplace plugin의 live cache directory가 second-scope 설치 시 삭제되고 다시 생성되어 실행 중인 세션을 중단할 수 있는 문제를 수정했습니다.
- `/remote-control`로 시작된 Remote Control session이 연결된 클라이언트에 working-tree diff를 보고하지 않는 문제를 수정했습니다.
- self-hosted runner session이 Claude Code를 시작하기 전에 `running`을 보고하여 Claude desktop app에서 "Claude is waiting for your input" 알림을 조기에 트리거할 수 있는 문제를 수정했습니다.
- first-run setup이 관리 설정에서 Claude apps gateway sign-in을 구성하고 Anthropic endpoint에 연결할 수 없을 때 "Unable to connect to Anthropic services"로 종료되는 문제를 수정했습니다.
- cloud session (Claude Code on the web, desktop 및 mobile app)이 메시지 전송 직후 mode를 전환할 때 이전 permission mode를 표시하는 경우가 있는 문제를 수정했습니다.
- cloud session이 background agent, shell 또는 monitor가 여전히 실행 중인 동안 turn 사이에 session의 container가 재시작될 때 침묵하는 문제를 수정했습니다 — 재개된 session이 이제 손실된 작업을 보고합니다.
- Plugin marketplace hardening을 개선했습니다: control 또는 invisible character가 포함된 이름은 거부되며, marketplace에서 제공한 `/plugin` 및 `claude plugin` 출력의 텍스트는 escape-safe입니다.
- Bedrock, Vertex, Foundry session 및 telemetry가 비활성화된 모든 session을 개선했습니다 (그리고 이들과 함께): Claude는 구성된 MCP server가 연결에 실패했을 때 알림을 받으므로, tool이 존재하지 않는다고 결론짓는 대신 제공됩니다.
- Sonnet 5의 기본 auto-compact window를 전체 1M context로 변경했으므로 1M window의 session은 이제 약 934K token 대신 약 967K token에서 auto-compact됩니다.
- cross-session peer message를 기본적으로 축소하도록 변경하여 `Message from @<sender>: <first line>` 미리보기로 한 줄로 표시됩니다; Ctrl+O가 전체 본문을 확장합니다.
- 렌더링된 markdown의 terminal hyperlink를 변경했습니다: network 또는 automounter path를 가리키는 link 대상, control character를 포함하거나, invisible character로 시작하는 link는 이제 일반 텍스트로 렌더링됩니다.
- prompt-footer PR badge를 변경하여 마지막 check가 1분 미만일 때 terminal refocus 시 GitHub re-check를 건너뜁니다.
- analytics를 변경하여 로그인 후뿐만 아니라 startup부터 비활성화 상태로 유지되도록 했으며, 관리 설정이 gateway login을 강제하거나 custom OAuth deployment가 구성되었을 때입니다.
- Claude apps gateway sign-in 요청을 변경하여 Claude Code를 식별하도록 했습니다 (`surface=claude_code` device-authorization parameter 및 `claude-code/<version>` User-Agent).
- organization sign-in enforcement를 변경하여 host에서 제공한 또는 per-user Windows registry 설정이 존재하더라도 관리자의 관리 설정을 읽을 수 없을 때 시작 시 종료되도록 했습니다.
