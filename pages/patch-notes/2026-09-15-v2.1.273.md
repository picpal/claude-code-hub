> 원문: [Claude Code v2.1.273 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.273)

## 변경사항

- LLM gateway를 위해 `x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction` 및 `x-claude-code-context-compacted` request header를 추가했습니다. `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`로 옵트인할 수 있습니다.
- MCP server가 세션 중간에 연결 해제되고 자동 재연결이 실패할 때 `/mcp`를 가리키는 알림을 추가했습니다.
- `claude --remote-control` 또는 Claude 앱의 `/remote-control`로 시작한 세션을 포크할 수 있도록 추가했습니다. 포크는 컴퓨터에서 백그라운드 세션으로 실행됩니다.
- permission checker가 완전히 분석할 수 없는 Bash 명령을 `permissions.blockReadsOutsideWorkingDirectories` 아래의 프롬프트를 건너뛰도록 수정했습니다. 그리고 bypass mode에서 위험한 `rm`을 숨기는 subshell도 수정했습니다.
- claude.ai에서 동기화된 skill이 조직에서 Skills를 비활성화한 후에도 계속 사용 가능하던 문제를 수정했습니다. 이제 복구 가능한 휴지통으로 이동됩니다.
- MDM 또는 `managed-settings.json`을 통해 설정된 `allowManagedMcpServersOnly`, `deniedMcpServers` 및 `disableClaudeAiConnectors`가 server-managed settings도 있을 때 무시되던 문제를 수정했습니다.
- Bedrock, Vertex, Foundry의 401/403 오류 및 Claude 앱 gateway 403을 수정했습니다. `/login`을 실행하라는 메시지가 이제 갱신할 credential을 명명하거나 gateway administrator를 가리킵니다.
- `/login`, `/upgrade` 및 `/extra-usage`가 대화에서 이전 thinking을 버리던 문제를 수정했습니다. 이로 인해 다음 request에서 전체 prompt-cache 재작성이 강제되었습니다.
- cloud 또는 Remote Control 세션에서 Artifact tool이 채팅에 첨부한 파일을 업로드할 때 auto mode가 승인을 위해 중단되던 문제를 수정했습니다.
- 장시간 실행되는 세션이 repository의 `.git` 디렉토리가 제거되거나 이동된 후 stub `.git/info/exclude`를 다시 생성하던 문제를 수정했습니다.
- main prompt가 이미 shell mode인 상태에서 시작 시 입력된 `!`를 버리던 문제를 수정했습니다. 이제 `! grep …`과 같은 부정 명령을 입력할 수 있습니다.
- macOS에서 Read가 드래그된 스크린샷이나 시스템이 다른 경로 아래에서 보고하는 파일을 거부하던 문제를 수정했습니다. "symlink resolution changed after permission was checked" 오류가 발생했습니다.
- `permissions.blockReadsOutsideWorkingDirectories` 수정: repository의 설정에서 선택한 memory 디렉토리가 더 이상 prompt에 로드되지 않습니다. 또한 회상되지, 색인되지, memory 추출에 사용되지 않습니다.
- sub-agent 및 background agent가 스트림된 최종 응답이 token usage를 생략하거나 model id를 포함하지 않을 때 실패로 보고되고 결과가 전달되지 않던 문제를 수정했습니다.
- context meter 및 auto-compact가 advisor-tool turn을 대략 2배의 실제 context size로 계산하던 문제를 수정했습니다. 이로 인해 auto-compact가 약 절반의 실제 window에서 작동했습니다.
- `/tui`가 이미 작업을 완료했고 agents panel에 더 이상 표시되지 않는 agent-team teammate 때문에 재시작을 거부하던 문제를 수정했습니다.
- `.claude/scheduled_tasks.json`이 새로운 worktree와 같은 다른 폴더에 복사된 후 저장된 scheduled task가 잘못된 세션에서 실행되던 문제를 수정했습니다.
- SDK 및 `--output-format stream-json` 출력이 subagent가 background로 이동한 후 남은 메시지와 최종 report를 버리던 문제를 수정했습니다 (예: `CLAUDE_AUTO_BACKGROUND_TASKS`로 인해).
- `/install-github-app`이 SAML single sign-on 차단을 "admin permissions required"로 보고하던 문제를 수정했습니다.
- Remote Control client가 Claude Desktop, VS Code 또는 JetBrains 세션에 첨부되어 있을 때 세션의 context window 사용량을 요청하면 거부되던 문제를 수정했습니다.
- spinner가 "Running PreCompact hooks…"와 같은 compaction 상태 줄에서 두 배의 줄임표("……")를 표시하던 문제를 수정했습니다.
- Artifact 읽기 또는 게시 후 frontend-design plugin을 제안하는 거짓 양성 spinner tip을 수정했습니다.
- permission checker가 분석할 수 없는 Bash 줄에서 Read 및 Edit 거부 규칙을 확인한 2.1.268 변경을 되돌렸습니다 (`eval`, `env -C`). `time -p make build`와 같은 명령이 거부되지 않고 다시 prompt됩니다.
- 긴 세션의 응답성을 개선했습니다: hook progress 및 sub-agent activity가 더 이상 모든 업데이트에서 전체 대화를 재처리하지 않습니다.
- Artifact tool의 오류를 개선했습니다. publish에 artifact가 제공하지 않는 파일 유형이 포함될 때: Claude는 제공되는 유형과 대신 할 작업을 알려주고, terminal은 한 줄의 plain line을 표시합니다.
- Artifact tool의 page read를 개선했습니다. artifact service가 page에 대해 보유한 capabilities 및 database rule을 명시합니다. 이는 artifact를 게시할 수 있는 모든 사람을 위한 것입니다.
- artifact database write를 개선했습니다: 이제 update가 전체 document를 다시 작성하는 대신 단일 field를 제거할 수 있습니다.
- artifact publishing을 개선했습니다: claude.ai에 도달한 후 연결이 끊어지는 publish는 이제 실패하거나 중복 버전을 생성하는 대신 안전하게 다시 전송됩니다.
- cloud-session GitHub 오류를 개선했습니다. IP allow list, suspended app installation 또는 SAML single sign-on에 대해 일반 install hint 대신 원인을 표시합니다.
- `/autofix-pr`를 개선했습니다: `gh pr view`가 실패할 때 일반 exit-code line 대신 gh의 자체 오류(sign-in, SAML, rate limit)를 표시합니다.
- `/autofix-pr`를 개선했습니다. GitHub webhook delivery를 PR에 대해 설정할 수 없는 이유를 표시합니다 (예: linked GitHub account 없음). 일반 warning 대신 표시됩니다.
- `/web-setup` 오류를 개선했습니다: 거부된 GitHub token은 이제 가능한 원인을 나열하고 fix를 제시합니다. 연결 실패는 구성된 proxy 또는 TLS certificate 문제를 명명합니다.
- in-session SSL certificate 및 proxy connection 오류를 개선했습니다. 오류 코드와 fix 방법을 명명합니다. 예를 들어 신뢰할 수 없는 corporate CA의 경우 `NODE_EXTRA_CA_CERTS`입니다.
- cloud session을 생성할 수 없을 때의 오류를 개선했습니다. Claude login이 만료되거나 취소된 경우 `/login`을 실행하라고 표시합니다.
- MCP server의 sign-in이 세션 중간에 만료되었을 때 표시되는 오류를 개선했습니다. 재인증 방법을 표시합니다 (`/mcp`).
- Bedrock, Vertex 및 Foundry에서 auto mode를 변경했습니다. 이제 기본적으로 local classifier를 사용합니다. 플랫폼의 server-side classifier를 사용하려면 `CLAUDE_CODE_AUTO_MODE_SERVER=1`을 설정하세요.
- `OTEL_LOG_TOOL_DETAILS=1`을 변경했습니다. 이제 cost 및 token metrics의 real agent, skill, plugin 및 MCP server 이름도 포함합니다.
- Claude 계정으로 sign-in을 변경했습니다. 이제 claude.ai plugin에 대한 액세스도 요청합니다.
- `/bug` 및 `/feedback` report를 변경했습니다. 마지막 API request에서 model-behavior params만 포함합니다 (model, system prompt, tools). request metadata 및 `CLAUDE_CODE_EXTRA_BODY` field는 생략합니다.
- [VSCode] product feedback이 비활성화된 조직의 경우 "Report a problem"이 여전히 나타나고 `/bug` / `/feedback`이 report form을 여는 문제를 수정했습니다.
- [VSCode] Windows에서 완료된 turn 후 "Claude Code process exited with code 4294967295" 빨강 배너가 나타나던 문제를 수정했습니다.
- Windows: `--add-dir`로 mapped network drive가 추가되었을 때 UNC path에 대한 network-path permission check를 개선했습니다.
- [Claude Code on the web] admin이 organization connector를 제거하고 다시 추가한 후 routine이 organization connector에 대한 액세스를 잃고 이전 connector를 계속 호출하던 문제를 수정했습니다.
- [Claude Code on the web] organization settings에서 self-hosted environment를 생성할 때 가끔 server error가 발생하고 반 생성된 environment가 남아있던 문제를 수정했습니다.
- [Claude Code on the web] admin "Share cloud sessions" 설정을 Claude Code page 아래에서 Data and privacy로 이동했습니다. Data and privacy admin도 이를 관리할 수 있습니다.
- [Claude Code on the web] "Discard unsaved changes?" 확인을 New routine page 또는 Edit routine dialog가 입력한 routine name, prompt 또는 edit를 버리기 전에 추가했습니다.
- [Claude Code on the web] Mac 및 Windows에서 cloud environment 없는 새 사용자가 본 전체 페이지 desktop-app download screen을 제거했습니다. 이제 바로 setup으로 이동합니다.
- [Claude Code on the web] routine detail page를 개선했습니다: breadcrumb의 menu 및 rename, 상단의 on/off switch 및 Run now, routine settings 옆의 run history입니다.
- [Claude Tag] Enterprise Grid가 연결 해제되었지만 workspace 중 하나가 계속 연결되어 있을 때 앱 재설치 후 몇 분 뒤 Claude가 침묵하던 문제를 수정했습니다.
- [Claude Tag] organization-shared private Slack channel에서 설정된 scheduled task가 조용히 게시되지 않던 문제를 수정했습니다. 이제 생성된 thread에서 계속 실행됩니다.
- [Claude Tag] Claude가 mid-task 상태일 때 오래된 Slack thread에서 응답하면 가끔 scratch에서 다시 시작하고 아직 push하지 않은 작업을 잃던 문제를 수정했습니다.
- [Claude Tag] account token이 갱신된 직후 Claude가 가끔 "couldn't find a Claude Code environment" 부정확한 알림이 있는 메시지를 버리던 문제를 수정했습니다.
- [Claude Tag] AWS connection이 Budgets, Savings Plans, WAF Classic, Import/Export와 같은 region-less endpoint를 거부하던 문제를 수정했습니다. Global Accelerator request는 이제 올바르게 sign됩니다.
- [Claude Tag] AWS connection 실패를 개선했습니다: request에 sign할 수 없을 때 (예: region이 없는 hostname), Claude는 bare error 대신 원인과 fix 방법을 알립니다.
- [Claude Tag] OAuth client-credentials 및 JWT-bearer connection이 소문자 token type을 반환하는 provider와 실패하던 문제를 수정했습니다. request는 이제 표준 Bearer scheme을 전송합니다.
- [Claude Tag] Enterprise Grid shared channel, Claude를 아직 사용하지 않은 channel, legacy private channel에서 channel manager 추가가 거부되던 문제를 수정했습니다.
- [Claude Tag] Claude를 변경했습니다. 이제 관련 public channel을 자동으로 감시합니다. 예: conversation
