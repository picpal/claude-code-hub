> 원문: [Claude Code v2.1.265 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.265)

## 변경사항

- telemetry Claude Desktop 및 Cowork가 Claude apps gateway를 통해 보내는 데이터에 `user.email` 및 `user.groups`를 추가했습니다 (terminal sessions과 일치하도록)
- `--plugin-dir`을 plugin 폴더로 지정할 수 있도록 지원을 추가했습니다: manifest가 있는 각 하위 폴더가 로드되고, 실행 중인 동안 추가되거나 제거된 plugin들이 선택됩니다
- tool 결과로 저장된 디스크에 1 GB 제한을 추가했습니다. 저장된 파일이 잘렸을 때 대화 내 미리보기에 해당 내용을 표시합니다
- foreground로 spawned된 subagent 재개 시 tool list 및 system prompt prefix 변경으로 해당 agent의 prompt-cache 재사용이 중단되는 문제를 수정했습니다
- agent teammates 및 resumed subagents가 이후 turns에서 SubagentStart hook context 및 preloaded skills을 prompt prefix 외부로 이동하여 prompt-cache 재사용이 중단되는 문제를 수정했습니다
- tool이 실행 중인 동안 이전 process가 중단된 후 재개하는 경우: 마지막 prompt는 더 이상 다시 작성되지 않으며, interrupted tool call이 유지되고 interrupted로 표시됩니다
- `/model opusplan[1m]`이 "Model not found"로 거부되는 문제를 수정했습니다
- permission prompts 및 messages의 syntax-highlighted code가 Ruby `?`, Erlang `$`, 또는 Perl `$` sigil 다음의 문자를 생략하는 경우가 있는 문제를 수정했습니다
- fullscreen transcript가 slash-command 또는 @-file suggestion list가 열리거나 닫힐 때마다 한 행씩 이동하는 문제를 수정했습니다
- plugin 경로에 backslash가 포함되어 macOS 및 Linux에서 symlink containment check를 우회하는 문제를 수정했습니다
- 이름이 두 개의 점으로 시작하는 plugin directories가 plugin root 외부로 잘못 거부되는 문제를 수정했습니다
- VS Code 및 SDK sessions가 session 종료 시 token을 새로 고치는 동안 가끔 재 로그인이 필요한 문제를 수정했습니다
- Remote Control sessions가 reply의 마지막 message 이전에 end-of-turn signal을 보내는 문제를 수정했습니다. 이로 인해 reply의 마지막 부분이 도착하기 전에 Claude app에서 reply가 완료된 것으로 표시될 수 있습니다
- background (`--bg`) sessions가 idle timeout 직전에 message가 도착할 때 가끔 mid-turn에 retired되는 문제를 수정했습니다
- Claude Code 자신의 git status 및 diff probes가 working tree 내부의 nested repository에 의해 구성된 clean filters를 실행하는 문제를 수정했습니다
- advisor tool 및 해당 instructions이 request의 model에서 request마다 재결정되는 문제를 수정했습니다. 이제 decision이 한 번만 수행되고 변경될 때 conversation에서 announced됩니다
- artifact publish가 connector가 expose하지 않는 connector tool names를 허용하는 문제를 수정했습니다. 선언된 tools 중 어떤 것도 존재하지 않으면 publish가 거부되고, 일부만 없으면 경고합니다
- `/add-dir <subdirectory>`가 managed settings가 skills을 plugins로만 lock할 때 subdirectory의 agents 로드를 거부하고 agents만 lock될 때 agents를 promised하는 문제를 수정했습니다
- tmux 내부에서처럼 second key가 1초 이상 늦게 도착할 때 two-key keyboard shortcuts이 조용히 취소되는 문제를 수정했습니다. 이제 3초를 기다리고 timeout될 때 공지를 표시합니다
- forked skills (`context: fork`)가 kickoff prompt를 streaming하지 않고, `--forward-subagent-text`를 사용할 때 text turns를 stream-json의 progress events로 streaming하지 않는 문제를 수정했습니다
- plugin의 default component folder를 OS가 확인할 수 없는 경우 (예: symlink loop)가 조용히 skipped되는 문제를 수정했습니다. 이제 `/plugin`에서 error code와 함께 reported됩니다
- Claude apps gateway의 OTLP telemetry relay가 malformed 또는 너무 큰 payloads로 거부한 후 30초 동안 collector로의 모든 forwarding을 일시 중지하는 문제를 수정했습니다
- `/plugin` Discover/Browse 및 `claude plugin list --json --available`이 metadata가 `plugin.json`에만 존재하는 marketplace plugins에 대해 설명 또는 display name을 표시하지 않는 문제를 수정했습니다
- `/login`이 managed settings로 설정된 Claude apps gateway에 signed in한 session에서 재실행할 때 "no gateway URL is configured"를 표시하는 문제를 수정했습니다
- `/model`이 settings file을 쓸 수 없을 때 model이 "saved as your default"라고 주장하는 문제를 수정했습니다. 이제 save가 failed되었고 그 이유를 나타냅니다
- `/clear`가 Remote Control에서 SessionStart hooks 및 open terminal dialogs를 완료하기 전에 기다리는 문제를 수정했습니다
- `/config` dialog가 tabs 간 전환 시 높이가 변하는 문제를 수정했습니다
- container가 재시작된 후 workflow run을 재개하는 문제를 수정했습니다. run journal이 누락된 resume는 모든 agent를 재실행하는 대신 명확한 error로 실패합니다
- `claude-api` skill의 error-code reference를 수정했습니다: model access failures는 404를 반환하고 unavailable beta headers는 403이 아닌 400을 반환합니다
- non-interactive sessions (`-p`를 stream-json input, Agent SDK, cloud sessions와 함께)이 각 새 user message에서 shell working directory를 reset하는 문제를 수정했습니다. 이제 `cd`가 turns 전체에서 지속됩니다
- legacy HTTP+SSE transport만 사용하도록 구성된 `http` MCP servers가 연결되지 않는 문제를 수정했습니다. Claude Code는 이제 MCP spec에서 설명한 대로 SSE로 fallback합니다
- claude.ai에 연결되어 있음에도 불구하고 일부 claude.ai connectors가 cloud sessions에서 authentication이 필요한 것으로 표시되는 문제를 수정했습니다 (unsupported request에 HTTP 401로 답하는 servers)
- connector approval 또는 sign-in link가 당신을 기다리는 동안 remote sessions가 sandbox container를 살아있게 유지하는 문제를 수정했습니다
- resumed sessions가 "background task didn't finish" notices에서 long model-facing recovery instructions을 표시하는 대신 short status line을 표시하도록 수정했습니다
- Windows: AppContainer 또는 restricted-token sandbox 내부에서 실행할 때 Read, Write 및 Edit이 모든 file을 거부하는 문제를 수정했습니다 ("symlink resolution changed after permission was checked")
- `--worktree` startup을 큰 repositories에서 개선했습니다: 새 worktree는 이제 parallel로 checked out됩니다 (git 2.32+)
- `/workflows` agent detail을 개선했습니다: tool calls이 running, failed 또는 done으로 표시되고, subagent의 task list이 있을 때 표시되며, Enter는 listed calls를 inputs 및 results와 함께 unfolds합니다
- mid-prompt에 입력된 slash commands를 개선했습니다: matches는 이제 single suggestion 대신 list에 표시되고 (Tab은 fullscreen 외부에서 열기), plugin skill은 이제 bare name으로 발견됩니다
- sign-in이 필요한 remote MCP servers를 개선했습니다: Claude Code는 당신이 실제로 authenticate할 때까지 더 이상 OAuth client를 등록하지 않습니다
- 많은 files를 읽는 long sessions 재개 시간을 개선했습니다
- size limits를 초과하는 image를 decode할 수 없을 때 표시된 error를 개선했습니다: 이제 limit만 인용하는 대신 원인과 해결 방법을 나타냅니다
- Artifact tool의 다른 사용자가 작성한 artifact 읽기를 개선했습니다: summary는 이제 page를 untrusted content로 취급하고 embedded instructions를 relay하는 대신 flags합니다
- `.claude` folder permission option을 실제로 허용하는 내용을 나타내도록 업데이트했습니다: session에 대해 project의 `.claude` folder (또는 `~/.claude`)의 files를 편집합니다
- `forceLoginMethod: "gateway"`처럼 managed settings에서 `forceLoginGatewayUrl`을 가진 machines을 startup부터 Claude apps gateway sessions이 되도록 변경했습니다. leftover claude.ai login 또는 API key는 사용되지 않습니다
- image processing을 runtime의 built-in image support를 사용하도록 변경했습니다. CLI는 더 이상 native image module을 temp directory에 추출하지 않습니다
- plugin display metadata를 Installed tab 및 `claude plugin details`에서 `plugin.json`보다 marketplace entry를 우선시하도록 변경했습니다 (`plugin.json`의 gaps를 채웁니다)
- Claude apps gateway sessions을 gateway의 relay를 통해가 아닌 collector로 OpenTelemetry를 직접 export하도록 변경했습니다. gateway의 managed settings에서 `OTEL_EXPORTER_OTLP_ENDPOINT`에 이름을 지정합니다. named collector가 없는 sessions은 여전히 relay를 사용합니다
- [VSCode] sessions가 일정 기간 동안 inactive된 경우 자동 archiving을 추가했습니다 (새 "Archive inactive sessions" setting, 기본값 14일)
- [VSCode] conversation이 10분 이상 opened되어 있었을 때 Reload Window 또는 restart 후 sidebar chat이 blank로 돌아오는 문제를 수정했습니다
- [VSCode] timeline dot이 "Remote Control is active" message의 text 아래에 앉는 문제를 수정했습니다
