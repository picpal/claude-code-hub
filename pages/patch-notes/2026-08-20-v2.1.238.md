## 변경사항

- `keybindingFlavor` 설정이 추가되었습니다: `"readline"`으로 설정하면 프롬프트에서 Ctrl+W가 Bash처럼 이전 공백까지 삭제됩니다. 기본값(`"classic"`)은 변경되지 않습니다.
- 플러그인 마켓플레이스: URL 마켓플레이스 또는 카탈로그 항목의 `headersHelper`는 카탈로그 및 같은 출처 아카이브 페치를 위한 HTTP 헤더(예: 단기 토큰)를 발급하는 명령을 실행합니다.
- 카탈로그 항목의 `headersHelper`는 해당 플러그인을 설치하거나 업데이트할 때만 실행되며, 해당 명령이 표시된 후 실행됩니다. `claude plugin install/update`는 `[y/N]`을 묻습니다(또는 `-y` 전달).
- `claude self-hosted-runner --defer-shutdown-max-min <minutes>`이 추가되었습니다: SIGTERM 수신 시 연결된 세션에 대한 서빙을 계속하고, 그 이후의 남은 항목을 주차한 후 종료합니다.
- 모든 연결에서 새로 발급된 `Proxy-Authorization` 헤더를 요구하는 이그레스 프록시를 위해 `claude self-hosted-runner --proxy-authorization-command` / `--proxy-authorization-file`이 추가되었습니다.
- 긴 대화형 세션에서의 무제한 메모리 증가가 수정되었습니다: 서브에이전트 도구 결과는 이제 최근 디스플레이 윈도우를 떠나면 해제됩니다.
- 사용자 정의, 프로젝트, 플러그인 출력 스타일이 세션 중간에 기본 음성으로 돌아가는 문제가 수정되었습니다.
- `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true`가 계정이 사용량 한계에 가까워지면(초과하지는 않음) 프롬프트 제안이 켜진 상태로 유지되지 않는 문제가 수정되었습니다.
- Worktree 격리 Bash 거부가 명령에 리다이렉트가 없을 때 리다이렉트를 제거하라고 표시하는 문제가 수정되었습니다.
- Self-hosted runner가 느리거나 손실된 폴 요청 후 서버에 의해 가끔 제거되어 건강한 세션을 다른 runner에게 넘기는 문제가 수정되었습니다.
- MCP 유도 대화가 4,096자 이상의 URL에 대해 아무것도 표시하지 않고, 권한 프롬프트가 프로젝트 경로가 터미널 너비에 맞지 않을 때 "다시 묻지 않기" 옵션을 삭제하는 문제가 수정되었습니다.
- Bash 명령이 종료, 타임아웃 또는 중단될 때 남은 `/tmp/claude-*-cwd` 파일이 수정되었습니다.
- 키 입력이 대량으로 도착할 때(느린 SSH/mosh 링크) Backspace가 Ctrl+H로 전송되는 터미널에서 누르고 있는 Backspace가 무시되는 문제가 수정되었습니다.
- 일시 중단된(Ctrl+Z) 세션을 종료할 때 때때로 터미널이 괄호로 묶인 붙여넣기 모드에 남고 커서가 숨겨지는 문제가 수정되었습니다.
- Stdio MCP 서버가 `initialize` 이전에 `server/discover` 요청을 수신하여 지연 서버가 모든 세션 열기마다 백엔드를 시작하도록 강제하는 문제가 수정되었습니다.
- 프록시의 연결 거부가 프록시 이름을 지정하는 대신 일반 네트워크 오류로 보고되는 문제가 수정되었습니다.
- `/model` 및 `/effort` 캐시 미스 경고가 프롬프트 캐시가 이미 만료되었을 때 나타나는 문제가 수정되었습니다.
- 원격 컨트롤 작업 패널에서 작업별 Stop이 CLI 호스팅 세션에서 아무것도 수행하지 않는 문제가 수정되었습니다.
- 원격 세션이 유효한 역할 없이 사용자 메시지를 전달할 때 종료되는 문제가 수정되었습니다.
- `claude remote-control`로 시작된 원격 컨트롤 세션이 런칭 셸에서 세션 범위 환경 변수를 상속받는 문제가 수정되었습니다.
- 프로세스가 충돌한 원격 컨트롤 세션이 `claude remote-control`을 다시 시작할 때까지 사용 불가능하게 유지되는 문제가 수정되었습니다. 이제 다음에 메시지할 때 재사용할 수 있습니다.
- Claude가 턴 중간일 때 웹 또는 Desktop에서 전송한 원격 컨트롤 메시지가 턴이 끝난 후 트랜스크립트에서 사라지는 문제가 수정되었습니다.
- 휴대폰 또는 웹에서 만든 원격 컨트롤 모델 선택이 터미널에 표시된 모델을 업데이트하지 않는 문제가 수정되었습니다.
- 짧은 네트워크 지연으로 인해 로그인 갱신이 지연될 때 원격 컨트롤이 "login expired"로 연결 해제되는 문제가 수정되었습니다. 이제 재시도하고 연결 상태를 유지합니다.
- 원격 컨트롤이 로그아웃 시 재연결 실패를 보고하는 문제가 수정되었습니다. 로그아웃은 이제 명확한 메시지와 함께 세션을 종료합니다.
- `ListAgents`/`SendMessage`가 `claude remote-control`(서버 모드) 또는 Desktop/IDE 호스트에서 실행되는 세션에서 "Remote Control is not connected"를 보고하는 문제가 수정되었습니다. 이제 원격 컨트롤 피어를 나열하고 도달할 수 있습니다.
- `ListAgents` 및 `SendMessage`가 에이전트 보기가 다음 백그라운드 세션을 위해 사전 준비한 유휴 워커를 노출하는 문제가 수정되었습니다. 이제 작업이 이를 청구할 때만 나타납니다.
- 교차 세션 메시징: 인바운드 메시지를 거부하는 이 머신의 세션으로 전송하는 것(예: `crossSessionInbound: "refuse"`)은 이제 조용한 성공 대신 발신자에게 "refused"를 보고합니다.
- 교차 세션 메시징: 메시지를 삭제하는 세션(속도 제한 또는 전체 큐)은 이제 메시지가 조용히 사라지는 대신 세션에 알립니다.
- 시작 개선: macOS에서 단순한 `claude`가 더 빨리 시작됩니다.
- 셸 조건부의 zsh 특정 구문에 대한 Bash 도구 권한 확인이 개선되었습니다.
- 원격 컨트롤 연결 복원력 개선: 네트워크 엣지, VPN 또는 프록시의 짧은 HTTP 403 거부가 최대 3분 동안 허용되며, 블록이 계속되면 거부 당사자가 명명됩니다.
- 시작 응답성 개선: 자동 업데이트 확인은 이제 시작 경쟁 대신 시작 후 약 10초 후에 실행됩니다.
- Managed Agents Aug 19 릴리스를 위해 번들된 `claude-api` 스킬이 업데이트되었습니다: 웹 검색/페치 도메인 설정 및 self-hosted 샌드박스의 메모리 저장소입니다.
- fullscreen에서 Ctrl+L 및 Cmd+K가 변경되었습니다: 더블 프레스 `/clear` 단축키는 제거되었으며, 1행 nvim 터미널은 더 이상 자동 `/clear` 루프를 트리거하지 않습니다.
- `claude mcp list` 및 `claude mcp get`이 변경되어 비활성화된 서버를 상태 확인을 위해 연결하는 대신 `⊘ Disabled`로 표시합니다.
- 프로젝트 `.mcp.json`의 MCP `headersHelper` 및 프로젝트 또는 `--add-dir` 에이전트 파일의 인라인 MCP 서버는 이제 해당 폴더의 신뢰 대화가 수락되었을 것을 요구합니다(`claude -p` 아래도 포함).
- 프로젝트 `.mcp.json`, 플러그인 또는 에이전트 파일의 MCP `headersHelper`는 상속된 자격 증명 env vars 없이 실행됩니다. 사용자, 관리 및 claude.ai 범위 헬퍼는 이제 Claude 설정 디렉토리에서 실행됩니다.
