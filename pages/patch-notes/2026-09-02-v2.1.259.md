> 원문: [Claude Code v2.1.259 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.259)

## 변경사항

- `managedMcpServers` 관리형 설정을 추가하였습니다: 조직은 모든 사용자에게 HTTP/SSE MCP 서버를 제공할 수 있습니다(`.mcp.json`과 동일한 항목 형식); 실행할 명령을 지정하는 항목은 건너뜁니다
- 무인 headless 호스트를 위해 `--permission-prompts none`을 추가하였습니다: 프롬프트를 표시할 모든 작업은 자동으로 거부되며, 활성 권한 모드(자동 모드 포함)는 계속 결정합니다
- `glab mr create/merge/close/reopen/note/update`을 인식하도록 추가하였습니다. GitLab merge request가 축소된 도구 요약에서 `MR !N`으로 표시되고 footer MR 배지를 새로고침합니다
- `claude plugin validate`에 `--json`을 추가하여 기계가 읽을 수 있는 유효성 검사 보고서를 제공합니다
- 동시 세션이 서로의 `~/.claude.json` 변경사항을 자동으로 되돌리는 문제를 수정하였습니다. workspace trust가 더 이상 재설정되지 않으며, 많은 세션을 동시에 실행할 때 MCP/프로젝트 상태가 손실되지 않습니다
- thinking이 한 번 거부된 후 이후의 모든 차례에서 다시 거부되는 대화 문제를 수정하였습니다
- Bash `Read()` 거부 규칙이 옵션 값으로 제공된 파일(`--ignore-revs-file=.env`, `-f.env`, `@file`), `git diff`/`git grep` 파일 피연산자 또는 `cd DIR && cat FILE` 복합 명령을 포함하지 않는 문제를 수정하였습니다; `grep -r`/`cp -r`이 거부된 파일을 포함하는 디렉터리에서 실행되면 이제 요청합니다
- telemetry가 비활성화된 세션에서 OAuth token이 새로고침될 때 prompt cache가 무효화되는 문제를 수정하였습니다
- fullscreen 모드에서 수백 개의 도구 호출이 있는 긴 차례 이후 빈 대화가 표시되는 문제를 수정하였습니다
- auto 모드가 명령 또는 스킬의 frontmatter `model:`에서 지정한 모델이 지원하지 않는 경우 해당 모델에서 차례를 실행하는 문제를 수정하였습니다; 이제 차례는 세션 모델을 유지합니다
- `CLAUDE_CODE_MAX_CONTEXT_TOKENS`이 Claude Code가 인식하지 못하는 모델 버전의 Vertex 스타일 모델 ID(`@YYYYMMDD` 접미사)에 대해 무시되는 문제를 수정하였습니다
- 실행 중인 shell 명령의 live output preview가 이전 줄이 줄바꿈되었을 때 최신 줄을 숨기는 문제를 수정하였습니다
- claude.ai 사용자에게 모든 실행 시마다 실행되는 background GitHub 연결 확인 문제를 수정하였습니다; 이제 결과가 실행 전체에서 기억됩니다
- 저장된 세션에 payload가 없는 첨부 항목이 포함되어 있을 때 `--resume`이 실패하고 `--continue`가 빈 대화를 여는 문제를 수정하였습니다
- 대화형 세션에서 custom 명령 및 스킬의 frontmatter `model:`이 무시되는 문제를 수정하였습니다
- Artifact 게시가 이전 버전에서 계속된 대화에서 "unexpected parameter `note`" 오류로 한 번 실패하는 문제를 수정하였습니다
- 관리형 `forceRemoteSettingsRefresh`가 MDM 또는 관리형 설정 파일로 구성된 정책 helper가 이미 실행되었을 때 startup에서 무시되는 문제를 수정하였습니다
- worktree isolation이 `git rev-parse`가 "not a git repository" 이외의 메시지로 실패하는 머신에서 hook이 생성한 worktree를 거부하는 문제를 수정하였습니다
- cloud 세션의 OpenTelemetry metrics 및 events에서 `user.email`, `organization.id` 및 `user.account_uuid` 속성이 누락되는 문제를 수정하였습니다
- startup에서 도구가 나열되는 동안 연결이 끊어진 MCP 서버가 오류를 보고하는 대신 도구가 없는 연결된 상태로 표시되는 문제를 수정하였습니다
- file edit 권한 대화가 표시 기호 없이 변경된 줄이 잘려 표시되는 문제를 수정하였습니다
- 일시적인 git probe 실패 후 알려진 repo 항등성을 삭제하는 repository detection 문제를 수정하였습니다
- 관리형 설정 파일, drop-in, MDM plist 또는 HKLM 값을 파싱할 수 없을 때 관리형 설정이 자동으로 unenforced가 되는 문제를 수정하였습니다: Claude Code는 이제 시작을 거부하고 원본을 지정합니다
- remote-control 세션에서 Stop이 background agents 및 workflows를 실제로 중단하지 않는 문제를 수정하였습니다: killed 작업은 이제 프로세스가 종료될 때까지 표시되고 재중단할 수 있습니다
- 이전의 stopped 실행이 여전히 종료되는 동안 workflow 실행을 재개하여 agents의 중복 복사본을 실행할 수 있는 문제를 수정하였습니다
- 후행 슬래시 또는 dangling `?`/`#`이 있는 github.com의 marketplace repo URL이 사용 불가능한 `.git` clone URL을 생성하는 문제를 수정하였습니다
- Stop hook을 차단하면 블록 이후의 차례가 해당 차례의 모델의 reasoning을 손실하고 일부 모델에서 prompt cache를 놓치는 문제를 수정하였습니다
- browser에서 호스팅된 MCP 서버의 페이지가 사라진 후 원격(claude.ai) 세션이 차례를 시작하는 데 60초가 걸리는 문제를 수정하였습니다
- worktree isolation 세션이 기본 checkout에 도달할 수 없는 일반적인 Bash 루프, xargs 파이프라인 및 launcher 래핑 명령을 거부하는 문제를 수정하였습니다
- 텍스트 측정을 재사용하여 긴 응답에 대한 terminal resize 및 first-render 성능을 개선하였습니다
- `/workflows` agent detail을 개선하였습니다: JSON 결과는 구문 색상과 실제 줄바꿈으로 pretty-print되며, 긴 결과는 expand toggle 뒤로 접힙니다
- headless/SDK 세션 시작을 개선하였습니다: MCP 서버가 연결을 마칠 때 첫 번째 차례가 최대 50ms 더 빨리 시작됩니다
- `/install-github-app`을 개선하여 GitHub 전용임을 설명하고, GitLab 저장소 내에서 실행될 때 GitLab CI/CD 문서를 가리킵니다
- nested background subagent 결과를 부모 subagent의 transcript에 저장하도록 개선하였습니다. 재개된 subagent는 결과를 유지하고 공유된 transcript는 delivery를 표시합니다
- `allowedMcpServers`를 사용자가 추가하는 서버만 제어하도록 변경하였습니다: 이전에 allowlist에서 필터링한 리터럴 `managed-mcp.json` 서버는 이제 업그레이드 시 로드됩니다; `deniedMcpServers`를 사용하여 비활성화할 수 있습니다
- [VSCode] 세션 목록 sidebar에 Active quick filter 및 status filter menu(Needs input, Working, Completed)를 추가하였습니다
- connector-tool 권한 프롬프트가 세션이 일시 중지된 상태에서 승인된 후 원격 및 예약된 세션이 아무 작업도 수행하지 않는 문제를 수정하였습니다
