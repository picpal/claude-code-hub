> 원문: [Claude Code v2.1.312 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)

## 변경사항

- Claude apps gateway에 `oidc.user_id_claim`을 추가하여 `sub` 이외의 id_token claim(예: Microsoft Entra ID의 `oid`)으로 사용자를 식별할 수 있도록 함
- 전체 화면 모드에서 클릭하여 전송 기능 추가: 대기 중인 메시지 아래의 "지금 전송" 힌트를 클릭하면 키를 누르는 것처럼 즉시 메시지를 전송함
- VS Code 확장 프로그램에서 로그인한 후 관리 설정 및 조직 정책이 세션의 나머지 부분에서 가져와지지 않는 문제 수정
- Claude가 매우 큰 CLAUDE.md, rules 파일 또는 @-포함 파일을 하위 디렉토리에서 시작 부분만 본 후 덮어쓰는 문제 수정; Write에서 이제 Claude에 전체를 읽거나 제자리에서 편집하도록 요청함
- Bash `cd`로 git 저장소 내부로 더 깊게 이동한 후 디렉토리별 및 `paths:` skills를 찾을 수 없는 문제 수정
- 터미널에서 세션을 재개한 후 첫 응답이 다음에 세션을 재개할 때 누락될 수 있는 드문 경우 수정
- 잘못된 이름의 command가 모든 command의 로드를 중지하여 `claude -p`에 출력이 없을 수 있는 문제 수정
- 이전 세션 파일의 정리가 동시에 실행될 때 Read tool이 "pdftoppm failed: Could not write image" 오류와 함께 PDF 페이지에서 실패하는 경우가 있는 문제 수정
- spinner, OpenTelemetry `effort` 값 및 transcripts가 model이 적용하기 전에 task 중에 새로 선택한 effort level의 이름을 지정하던 문제 수정; 현재 적용 중인 level을 표시하도록 변경됨
- `/model` 및 `/effort` cache 경고가 다시 읽기가 다음 메시지를 기다린다고 표시하던 문제 수정; Claude가 작업 중에 변경하면 더 빨리 트리거될 수 있음
- 마지막 메시지에서 당신이 기다리는 항목만 문장 중간에 언급했을 때 일부 세션이 당신이 기다리는 것으로 표시되던 문제 수정
- Ctrl+C로 지우고 종료하기 직전에 agent view가 다음 실행에서 입력 텍스트를 복원하던 문제 수정
- 빈 `!` 입력에서 Ctrl+D로 종료한 후 agent view가 shell 모드로 다시 열리던 문제 수정
- vim 모드 `d`, `c` 및 `y`가 남은 줄보다 큰 `gj` 또는 `gk` count를 사용하여 텍스트를 삭제하거나 복사하던 문제 수정; Vim과 같이 이제는 커서만 이동함
- `/verify`가 `/help` 및 `/` command 메뉴에서 Claude를 위한 긴 설명 대신 짧은 설명을 표시하던 문제 수정
- prompt의 effort indicator 개선: task 중에 변경하면 다음 메시지를 기다릴 수 있다고 표시하고, 더 이상 적용되지 않으면 note가 지워짐
- Cloud 세션의 WebFetch 오류 개선: resolve되지 않는 호스트는 이제 허용된 네트워크 도메인 외부에 있을 수 있다고 설명되어 Claude가 호스트를 이름으로 지정하도록 함
- Bedrock, Vertex, Foundry 및 Mantle을 변경하여 Claude Code가 인식하지 못하는 model 이름(예: custom deployment 이름 및 inference profile ARN)에 대해 짧은 system prompt를 사용하도록 함(Sonnet 또는 Haiku 앞에 있는 경우에도); 전체 prompt를 유지하려면 `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0`을 설정함
- 플래그가 지정된 메시지 후 자동 model 전환을 변경하여 Claude Code가 인식하지 못하는 model 이름(예: custom deployment 이름)도 포함하도록 함; `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1`을 설정하여 이를 끌 수 있음
- usage limit 메시지를 변경하여 5시간 window를 "session limit" 대신 "5-hour limit"이라고 부르도록 함
- CLI에서 시작된 cloud 세션이 서버에서 이름 및 branch 이름을 가져오도록 변경됨
- prompt 및 agent hooks를 변경하여 세션당 sub-agents 포함 최대 24개, event의 timeout보다 더 오래 기다린 최대 12개까지만 실행되도록 함; 1초 미만의 `timeout`은 이제 1초로 계산됨
- subagent의 `autoCompactWindow`를 변경하여 `CLAUDE_CODE_AUTO_COMPACT_WINDOW`로 설정된 window를 낮추도록 함(이전에는 효과가 없었음); 여전히 해당 window를 높이지는 않음
- OpenTelemetry `mcp_server.name`을 변경하여 official Anthropic marketplace의 plugin으로 선언된 fixed-URL remote MCP servers의 실제 이름을 보고하도록 함(`custom` 대신)
- Claude Code를 변경하여 `claude_code.safety_event` OpenTelemetry event 전송을 중지하도록 함
- [VSCode] 시작 시 조직의 설정을 로드하거나 거부할 수 없을 때 세션이 bare exit code에서 종료되는 문제 수정; 탭이 이제 이유를 표시하고 Retry 또는 Sign in again 옵션을 제공함
- [VSCode] usage limit 재설정을 변경하여 시계 시간("Resets at 3:10 PM")을 표시하고 "5-hour limit"이라고 표시하도록 함
- [Cloud sessions] cloud에서 실행되는 routine을 생성하거나 편집할 때 model picker에 effort level 추가됨
- [Cloud sessions] cloud 환경 설정의 setup script box에 색상, 줄 번호 및 Copy 버튼이 있는 Bash editor 추가됨
- [Cloud sessions] Claude가 cloud 세션에 repository를 추가할 때 표시되는 단계 개선: 열면 raw JSON 대신 발생한 사항의 짧은 table을 표시함
- [Cloud sessions] cloud 세션에서 실패한 전송 후 변경되지 않은 메시지를 다시 보낼 때 두 번 실행되는 경우가 있는 문제 수정
- [Cloud sessions] 실패한 cloud 환경 생성이 error를 toast로만 열린 dialog 외부에 표시하던 문제 수정; 이제 dialog 내부에 표시됨
- [Cloud sessions] Routines 페이지의 routine 메뉴에서 Edit이 edit dialog를 열지 않고 routine의 페이지로 이동하던 문제 수정
- [Remote Control] 보관되지 않은 Remote Control 세션이 컴퓨터가 재연결될 때까지 작업 중인 것으로 표시되던 문제 수정; 이제 idle로 표시됨
- [Claude Tag] Claude Tag의 Slack retry notice를 변경하여 generic API error 대신 사용 중인 model을 이름으로 지정하거나 rate limits가 도달했다고 표시하도록 함
- [Claude Tag] Claude Tag channel의 on/off switch 및 agent settings가 이전 private Slack channel이 public으로 전환되고 새 ID를 받을 때 workspace 기본값으로 폴백되던 문제 수정
- [Claude Tag] environment의 network access가 None으로 설정된 channels에서 Claude in Slack이 응답하지 않던 문제 수정
- [Claude Tag] 다른 thread에서 응답할 때 Claude in Slack이 동일한 channel의 다른 thread에서 파일을 잘못된 thread에 게시하던 경우가 있는 문제 수정
- [Code Review] GitHub이 push event를 늦게 전달했을 때 Code Review가 outdated commit을 검토하거나 아무것도 검토하지 않던 문제 수정; 이제 pull request의 현재 commit을 검토함
