## 변경사항

- 만료된 로그인 토큰으로 세션이 시작될 때 사용자의 구독 계층 없이 기능 플래그가 평가되어 Max 플랜 사용자에게 Fable에 대해 사용 크레딧을 활성화하도록 잘못 권유하는 문제를 수정했습니다
- GitHub 호스팅 러너에서 `allowed_non_write_users`를 사용할 때 `claude-code-action`에서 모든 Bash 명령이 실패하는 문제를 수정했습니다
- `/tui`가 첫 메시지 이전으로 되돌려진 대화를 다시 불러오는 문제를 수정했습니다
- slash-command 메뉴 개선: 파란색이 이제 선택된 행만 표시하고, 일치하는 문자는 색상이 변경되지 않고 굵게 표시되며, emoji 또는 악센트가 있는 이름은 글리프를 유지합니다
- 성능 개선: 파일 없음 제안 및 at-mention 크기 확인에서 더 적은 event-loop stall 발생
