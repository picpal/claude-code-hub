> 원문: [Claude Code v2.1.318 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

## 변경사항

- Claude Code가 세션에서 작성한 mod를 켜도록 요청할 때 답변 기록을 추가했습니다
- Claude apps gateway의 `mantle` upstream에 `assume_role`을 추가했습니다. 다른 AWS 계정의 역할 및 개발자별 AWS 비용 귀속을 위해 사용됩니다
- mod의 `$.model.fork`에 `effort` 옵션을 추가했습니다. 빠른 부작업이 세션에서 사용하는 노력과 관계없이 `low`에서 실행될 수 있으며, 결과는 전송된 노력을 보고합니다
- `claude auth status`에 저장된 claude.ai 로그인이 종료되는 날짜(`loginExpiresAt`)를 추가했고, `claude -p` JSON 결과에도 추가했습니다(`credential_expires_at`)
- `claude -p` 텍스트 출력에 한 줄짜리 stderr 경고를 추가했습니다. 저장된 claude.ai 로그인이 종료되기 10일 전부터 표시됩니다
- `--continue`가 잘못된 tool call의 재시도가 다 끝난 후 이전 대화를 잃는 경우를 수정했습니다(2.1.314에서의 회귀)
- macOS 세션에서 많은 Bash 명령어가 실행 중일 때 메모리가 증가하면서 중단되는 문제를 수정했습니다
- 메시지 전송 직후에 입력한 키나 느린 프롬프트가 나타나기 전에 입력한 키로 권한 프롬프트가 답변되는 문제를 수정했습니다
- `/logout`, `claude auth logout` 및 `claude mcp remove`가 성공을 보고하고, 공유된 네트워크 홈 디렉터리에서 config 파일을 업데이트할 수 없을 때 신뢰, 동의 또는 MCP 설정의 변경 사항이 아무 경고 없이 손실되는 문제를 수정했습니다
- 다른 터미널이나 호스트가 같은 홈에서 같은 계정 및 조직에 다시 로그인할 때 job이 `Not logged in`으로 종료되는 문제를 수정했습니다
- `claude mcp add` 및 `remove`가 lock 없이 config를 작성하는 문제를 수정했습니다. 이제 lock을 기다리거나 exit 1을 표시하지만, 다른 job의 저장이 여전히 저장된 server를 대체할 수 있습니다
- `claude plugin` 명령어가 느린 token 새로고침이 저장되기 전에 종료되어 다음 실행에서 로그아웃될 수 있는 문제를 수정했습니다
- `claude plugin validate`가 `claude plugin marketplace add`가 거부하는 커스텀 이름의 marketplace 파일을 통과시키는 문제를 수정했습니다
- version probe에서 종료되는 stdio MCP server가 시작할 때마다 다시 probe되는 문제를 수정했습니다. 자신의 이유로 3초 이내에 죽는 server는 7일 동안 legacy handshake에 고정됩니다
- 같은 머신의 다른 로그인이 저장한 `allowedProviders` 목록으로 인해 세션이 시작 시에 거부되는 문제를 수정했습니다
- idle compaction이 대화를 요약이 아닌 답변으로 대체하는 문제를 수정했습니다
- "Now using usage credits" 알림이 background subagent 실행 중에 약 30초마다 다시 나타나는 문제를 수정했습니다
- 실패하거나 Claude만 호출할 수 있는 custom slash command가 `claude -p` 및 SDK 세션에서 아무 것도 출력하지 않는 문제를 수정했습니다
- `claude -p` 및 Agent SDK 세션이 API 오류로 인해 mod가 `turn.step`을 hook했을 때 응답이 중단되어도 성공을 보고하는 문제를 수정했습니다
- model 변경 직후에 전송된 메시지가 headless 세션에서 Stop 후에도 계속 실행되는 문제를 수정했습니다. 이제 Stop이 대기 중인 메시지처럼 취소하거나 중지합니다
- idle non-interactive 세션이 종료될 때 삭제된 세션 transcript가 마지막 프롬프트로 다시 생성되는 문제를 수정했습니다
- `claude remote-control` host, background daemon 및 self-hosted runner가 업데이트 또는 버전 정리 후 여전히 실행 중인 프로세스의 binary를 제거한 후 새 세션을 시작하지 못하는 문제(`spawn ENOENT`)를 수정했습니다
- 다른 사용자가 소유한 실행 중인 Claude Code 프로세스(예: `sudo claude`로 인한 것)가 버전 정리에 의해 dead로 취급되어 binary가 삭제될 수 있는 문제를 수정했습니다
- `/remote-control`이 연결 실패 후 세션을 사용 가능으로 표시하는 문제를 수정했습니다
- `/design revoke`가 404로 요청이 실패했을 때 성공을 보고하는 문제를 수정했습니다
- self-hosted runner 또는 cloud 세션 재시작 후 승인된 shell 명령어가 요청받은 폴더가 아닌 세션의 시작 폴더에서 실행되는 문제를 수정했습니다. 해당 폴더에 들어갈 수 없으면 실행되지 않습니다
- cloud 세션 재시작 후 승인된 connector tool을 사용할 수 없을 때 Claude가 이를 알지 못하는 문제를 수정했습니다
- 서비스가 여러 분 동안 업로드를 거부할 때 cloud 세션이 turn 중간에 중지되는 문제를 수정했습니다
- `Setup` hook이 `CLAUDE_ENV_FILE`에 작성한 변수가 일부 cloud 세션의 Bash tool에 도달하지 않는 문제를 수정했습니다
- iPhone 앱이 tool call에서 응답이 중단되거나 거부된 이미지 또는 문서가 제거된 후 cloud 세션의 turn이 완료된 것으로 표시되지만 계속 실행되는 문제를 수정했습니다
- 재시작된 세션이 API 오류로 인해 실패한 메시지를 뒤에서 대기 중인 새 메시지보다 먼저 다시 전송하는 문제를 수정했습니다
- 재시작이 Claude가 큰 이미지를 읽은 직후이거나 tool call을 재시도한 직후에 발생할 때 재시작된 세션이 중단된 turn을 손실하는 문제를 수정했습니다
- `NODE_EXTRA_CA_CERTS` 파일이 비어 있거나 PEM이 아니거나 손상된 certificate로 시작할 때 모든 연결이 실패하는 문제를 수정했습니다. 이제 읽을 수 있는 certificate가 사용되며 stderr에 경고가 표시됩니다
- 사용량 제한 후 재개될 때 workflow가 완료된 agent를 다시 실행하는 문제를 수정했습니다
- cloud 세션에서 `/mcp`가 model이 사용할 수 없는 tool을 계산하는 문제를 수정했습니다. 서버의 행은 이제 사용 가능한 tool의 개수를 표시합니다
- Claude가 PushNotification 호출에서 status 필드를 생략했을 때 중복 알림이 발생하는 문제를 수정했습니다
- 20개 이상의 이미지가 포함된 요청에서 너무 큰 이미지의 오류가 항상 제한이 2000px라고 표시하는 문제를 수정했습니다. 이제 API의 제한을 표시합니다
- background shell 상세 정보의 runtime이 대화 상자가 열려 있을 동안 업데이트되지 않는 문제를 수정했습니다
- mod의 `turn.step` hook이 headless 실행에서 중단된 답변을 성공으로 완료하도록 만드는 문제를 수정했습니다
- retention cleanup이 `claude -p`만 실행하는 홈을 `~/.claude.json` backup 없이 남기는 문제를 수정했습니다. 이제 마지막 good backup을 삭제하기 전에 fresh backup을 수행합니다
- 네트워크 홈 디렉터리에 데이터 공간이 없지만 여전히 새 파일을 수락할 때 저장된 로그인이 빈 파일로 대체되는 문제를 수정했습니다
- `forceLoginOrgUUID`가 있는 머신에서 `setup-token`의 token이 시작 시 거부되는 문제를 수정했습니다. token이 허용된 조직에 속할 때입니다
- non-interactive 시작이 유효하지 않은 JSON이 아닌 `~/.claude.json`을 기본값으로 대체하는 문제를 수정했습니다. 이제 시작이 실패하고, 파일을 복원하는 방법을 말하며, 그대로 둡니다(anthropics/claude-code#87551)
- backup이 없는 빈 `~/.claude.json`이 손상된 것으로 보고되는 문제를 수정했습니다. Claude Code는 이제 파일이 없을 때처럼 시작됩니다
- 손상되었거나 누락된 `~/.claude.json`에 대해 인쇄된 복원 명령어가 빈 또는 잘린 backup의 이름을 지정하거나 read-only 파일에서 실패하는 문제를 수정했습니다
- 저장된 claude.ai 로그인이 시간 제한에 도달했을 때의 로그인 실패를 수정했습니다. 이제 이를 표시하고, `claude -p`에서 `claude auth login` 및 `claude setup-token`의 이름을 지정합니다
- 공유된 네트워크 홈 디렉터리에서의 저장으로부터 `~/.claude.json`, 설정 파일 및 저장된 로그인이 어떻게 survive되는지 개선했습니다. 삭제되거나 잠시 비워지거나 거의 비어있거나 이전 복사본으로 대체되는 빈도가 줄어들었습니다
- 네트워크 파일 시스템의 세션이 configuration 파일이 잘못되어 누락된 것으로 보고될 때 다시 확인하도록 개선했습니다. 따라서 MCP server와 신뢰할 수 있는 폴더 없이 시작되는 세션이 줄어듭니다
- MCP tool 오류가 개선되었습니다. tool이 로드되기 전에 만들어진 호출은 이제 해당 input schema를 반환합니다
- Bash tool이 macOS의 built-in `/bin/bash`를 실행할 때 git commit 및 pull request 생성의 신뢰성을 개선했습니다
- 사용량 제한 메뉴의 "Ask your admin for more usage"를 개선하여 요청을 한 단계에서 전송하도록 했습니다
- remote 세션이 일시 중지 또는 절전 후 재연결하는 속도를 개선했습니다
- You should know toast를 개선하여 터미널에서만 작동하는 "press 2" 대신 "try again"이라고 하도록 했습니다
- auto-update 신뢰성을 개선했습니다. release를 검증하는 동안의 짧은 네트워크 실패가 이제 다음 확인을 기다리지 않고 바로 재시도됩니다
- unattended 실행(`claude -p`, SDK apps)이 `~/.claude.json`의 아무것도 변경되지 않았을 때 매번 다시 작성하는 것을 중지하도록 개선했습니다
- Claude Code를 IDE 터미널에서 시작할 때 더 이상 IDE extension을 설치하거나 업데이트하지 않도록 변경했습니다. 외부 터미널에서 `/ide`를 사용하거나 editor의 extensions 보기를 사용하세요
- "Switch models when a message is flagged"가 "Ask each time"으로 설정되어 있을 때 subagent가 model을 전환하는 대신 중지하도록 변경했습니다
- background subagent가 모든 제공자에서 3분 후에 shell 명령어를 background로 이동하도록 변경했습니다. 이는 prompt cache가
