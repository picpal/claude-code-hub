> 원문: [Claude Code v2.1.282 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)

## 변경사항

- `maxProseWidth` 설정이 추가되었습니다. 이는 넓은 터미널에서 Claude의 prose 너비를 제한하면서 table과 code block은 전체 너비를 유지합니다.
- 시작 공지, `/status` 및 `claude doctor` 항목이 추가되었습니다. 프로젝트의 설정 파일에서 무시되었거나 telemetry를 비활성화한 telemetry 변수들을 나열합니다.
- `allowClaudeInChromeWithManagedMcp` managed 설정이 추가되었습니다. 이는 `claude --chrome`이 exclusive `managed-mcp.json`과 함께 실행되도록 합니다. Chrome이 차단될 때 표시되는 오류는 이제 이를 명시합니다.
- Claude apps gateway에 `store.readiness_grace_seconds`가 추가되었습니다. 이는 `/readyz`가 database failover 같은 짧은 Postgres 중단을 통해 ready 상태를 유지할 수 있도록 합니다.
- fullscreen 모드에서 `/feedback` drafts 목록에 scrollbar가 추가되었습니다. 마우스가 목록 위에 있을 때 나타납니다.
- API가 복호화할 수 없는 web search 결과를 포함하는 대화 기록에서 모든 요청이 400 오류로 실패하는 문제가 수정되었습니다(예: third-party gateway를 통해 답변된 turn).
- 계속되거나 재개된 세션(`--continue`, `--resume`)이 변경된 형태로 이전 메시지를 다시 전송하는 더 많은 경우가 수정되었습니다. 이는 Claude의 이전 reasoning을 API가 버리게 할 수 있었습니다.
- Claude가 작업 중일 때 `/model`, `/rename`, `/artifacts` 또는 다른 immediate slash command를 사용할 때 이전 extended thinking이 버려지는 문제가 수정되었습니다.
- 계속되거나 재개된 대화가 이전 대화에서 제공된 built-in tool을 제외한 `--tools` 목록과 함께 재시작될 때 이전 extended thinking을 잃는 문제가 수정되었습니다.
- "Invalid `data` in `redacted_thinking` block" API 오류가 매 turn마다 발생하는 문제가 수정되었습니다. Claude Code는 이제 대화의 thinking block을 버리고 한 번 재시도합니다.
- summarization 요청이 거부될 때 compaction이 실패하는 문제가 수정되었습니다. 이제 fallback model에서 재시도합니다.
- thinking이 꺼져 있고 effort가 high보다 높은 세션에서 safety 관련 model switch 후 실패한 turn("Effort 'xhigh' isn't available with thinking turned off")이 수정되었습니다.
- SDK-hosted 세션(예: Claude Desktop)에서 답변되지 않은 Fable usage-credits 프롬프트가 model을 전환하는 문제가 수정되었습니다. 이제 turn이 대신 끝나고, Remote Control client는 model-switch 공지를 보게 됩니다.
- 계획에 아직 활성화되지 않은 usage credit이 필요할 때 `/model`이 full Fable model id를 사용하면서 API 오류에서 멈추는 문제가 수정되었습니다. 이제 usage-credits 프롬프트를 엽니다.
- 다른 프로세스가 mid-refresh 중에 닫히거나 종료된 후 요청이 "another Claude Code process is refreshing it" login 오류로 최대 1분 동안 실패하는 문제가 수정되었습니다.
- 다른 Claude Code 창이 sign-in을 새로고침하는 동안 시작된 세션(여러 VS Code 창에서 일반적)이 organization policy fetch를 재시도하지 않는 문제가 수정되었습니다.
- CLAUDE.md 및 rules가 시작 시 `..` 또는 `/.vol` 스타일 kernel 경로를 통해 macOS의 `/Network`에 도달하는 repository symlink를 통해 읽혀지거나, macOS의 `/home`에 대한 rules link가 나열되는 문제가 수정되었습니다.
- mid-pattern `:*`이 있는 Bash permission rules가 설정 파일에서 건너뛰어지는 문제가 수정되었습니다. `--allowedTools`는 이를 준수했습니다. 이제 모든 소스에서 작동하며, 일치하는 방식에 대해 시작 경고가 표시됩니다.
- remote session의 worker가 재시작될 때 복원된 permission 프롬프트에서 승인된 command가 두 번 실행되는 문제가 수정되었습니다.
- managed 설정이 `disableClaudeAiConnectors` 또는 `allowManagedPermissionRulesOnly` 같은 boolean lock key에 대해 잘못된 값을 무시하는 문제가 수정되었습니다. 이제 lock이 적용되고 시작 시 key를 명시합니다.
- managed `permissions`, `autoMode`, `worktree` 및 `attribution` 설정이 하나의 nested value가 유효하지 않을 때 완전히 무시되는 문제가 수정되었습니다. 이제 block의 나머지 부분은 여전히 적용됩니다.
- repository, user 및 `--add-dir` skills, command 및 skills-directory plugin manifest가 managed `allowManagedPermissionRulesOnly` 아래의 `allowed-tools`를 통해 자신의 tool을 사전 승인하는 문제가 수정되었습니다.
- Amazon Bedrock 및 Bedrock Mantle의 safeguard block message가 request ID를 표시하지 않는 문제가 수정되었습니다. block message는 이제 message ID도 표시합니다.
- Vertex AI: Claude Code가 아직 인식하지 못하는 새로 출시된 모델 같은 model에 대해 web search가 제공되지 않는 문제가 수정되었습니다.
- Bash 및 PowerShell이 전체 disk quota를 "Exit code 1" 뒤에 숨기고 temp에 큰 output 파일을 남기는 문제가 수정되었습니다.
- tool input validation error가 같은 call의 다른 parameter도 유효하지 않을 때만 unknown, missing 또는 mistyped parameter만 명시하는 문제가 수정되었습니다. 이제 이들도 나열됩니다.
- terminal의 bracketed paste mode가 mid-session 중에 재설정된 후 pasted multi-line text가 줄 단위로 제출되는 문제가 수정되었습니다.
- `SessionStart` hook이 있는 프로젝트에서 시작 시 prompt의 예제 텍스트가 flashing되고 사라지는 문제가 수정되었습니다.
- fullscreen 모드로 시작할 때 첫 번째 frame 전에 blank screen이 flashing되는 문제가 수정되었습니다.
- terminal보다 짧지만 여전히 더 긴 screen에서 prompt line을 삭제하는 동안 shell command가 output을 stream할 때처럼 screen이 더 짧아진 후 non-fullscreen renderer에서 garbled, misplaced row가 나타나는 문제가 수정되었습니다.
- redrawn line의 CJK character 또는 emoji가 다음 행으로 wrapped될 때 diff의 마지막 column에 stale character가 남는 문제가 수정되었습니다.
- prompt가 tab을 포함할 때 history에서 recall된 prompt의 cursor가 끝 앞에 landing되는 문제가 수정되었습니다.
- send-now hint가 ctrl+enter를 newline으로 전송하는 terminal(Windows Terminal 1.25 이전)에서 ctrl+x ctrl+s를 표시하는 문제가 수정되었습니다.
- `claude remote-control --debug`가 "Unknown argument: --debug"로 실패하는 문제가 수정되었습니다. 비록 Remote Control의 자체 eligibility error는 `--debug`로 실행하도록 말했습니다.
- `/install-github-app`이 "cancelled"라고 말한 다음에도 branch를 push하고 API key secret을 저장하는 문제가 수정되었습니다. 이제 종료하면 remaining step을 중지하고 이미 완료된 것을 보고합니다.
- Bedrock, Vertex 및 다른 third-party provider에서 /feedback, /bug 및 /share가 저장 중에 취소한 후에도 report file을 저장하는 문제가 수정되었습니다.
- plugin uninstall이 성공을 보고하고 plugin의 설정 파일이 여전히 이를 활성화했거나 읽을 수 없을 때 plugin의 저장된 옵션을 삭제하는 문제가 수정되었습니다. 이제 중지되고 file을 명시합니다.
- plugin uninstall이 제거 후 설치된 plugin의 목록을 읽을 수 없을 때 plugin의 저장된 옵션과 secret을 삭제하는 문제가 수정되었습니다. 이제 이들이 유지되고 uninstall이 이를 말합니다.
- `/` 직후 `/skills`에 입력된 key가 skill 목록을 이동시키는 대신 search box에 도달하는 문제가 수정되었습니다.
- terminal cursor가 입력 중에 `/skills` search box에서 skill 목록으로 점프하는 문제가 수정되었습니다. 이는 caret을 숨길 수 있고 IME input을 잘못된 위치에 놓을 수 있었습니다.
- `/skills` 및 `/mcp` 같은 scrollbar가 있는 list가 fullscreen 외부 모드에서 두 개 열이 더 좁게 표시되는 문제가 수정되었습니다. 여기서 scrollbar는 절대 나타날 수 없습니다.
- agent panel footer가 긴 rebound key로 두 줄에 wrap되고 "Esc to collapse" hint가 rebound collapse key를 무시하는 문제가 수정되었습니다.
- `/tasks` dialog footer에서 doubled ` · ` separator가 `keybindings.json`에서 stop-all-agents shortcut이 unbound될 때 나타나는 문제가 수정되었습니다.
- Claude가 version에 60자보다 긴 label을 지정했을 때 artifact publish가 실패하는 문제가 수정되었습니다. 이제 label이 shortened됩니다.
- screen-reader mode, quoted list 및 매우 긴 list가 list item을 여는 code block의 맨 위에 있는 blank line을 직접 또는 quote 내에서 버리는 문제가 수정되었습니다.
- PDF page-read error message가 수정되었습니다. accented 또는 non-Latin character가 있는 경로가 이제 읽을 수 있게 나타나고, "password" 또는 "invalid" 같은 이름의 folder는 더 이상 error가 원인을 잘못 명시하게 할 수 없습니다.
- vim mode `>>` indenting empty line, count가 line보다 긴 `r`, `2J` joining one line too many, 마지막 line에서 count(`2dd`, `2>>`) shifting 또는 deleting하는 문제가 수정되었습니다.
- vim mode cursor placement가 수정되었습니다. `dd`, `dj`, `dG` 또는 whole-line `p`/`P` 후에는 첫 번째 non-blank에, `yy`는 더 이상 이를 이동하지 않고, emoji 후 Esc는 더 이상 emoji 내부에 이를 남기지 않습니다.
- vim mode가 `.`을 반복할 때 입력된 count를 무시하는 문제가 수정되었습니다. `x`, `s`, `p`, `d` 또는 `c`일 때와 whole-line `p`/`P`, `o`, `O`, `J`, `>>` 및 `<<`가 line이 wrap될 때 잘못된 line에서 동작하는 문제도 수정되었습니다.
- vim mode가 history에서 recall된 또는 normal mode에서 queue에서 pulled back된 prompt의 끝 과정 cursor를 남기는 문제가 수정되었습니다. 이로 인해 `x`가 아무것도 하지 않았습니다.
- 매우 큰 session(compacted된 적이 없는 것 포함)을 재개하는 시간이 개선되었습니다.
- session을 재개할 수 없을 때(transcript file을 읽을 수 없음, EBADF) Windows에서 표시되는 오류가 개선되었습니다. 이제 가능한 원인과 시도할 수 있는 것을 명시합니다.
- Claude Desktop unknown-model error가 개선되었습니다. 다른 model로 전환을 제안합니다.
- permission prompt에서 unusual Unicode rendering이 개선되었습니다.
