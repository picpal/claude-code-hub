> 원문: [Claude Code v2.1.295 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)

## 변경사항

- `onFailure: "block"`이 command 및 HTTP hook에 추가됨: 시작할 수 없거나, 시간이 초과되거나, 예상치 못한 코드로 종료되는 hook이 action을 차단하고 통과시키지 않음
- Program Status Protocol (OSC 7501) 지원 추가됨: 이를 구현하는 terminal은 Claude Code가 작동 중, 대기 중, 또는 완료된 상태를 표시할 수 있음
- 인용된 텍스트가 `/copy` picker에 추가됨: 초안 메시지가 `>` 마커 없이 복사됨
- `claude plugin install`, `enable`, `disable` 및 `marketplace add`에 경고 추가됨: 작성하는 설정 파일이 로드되지 않을 경우 표시됨
- stderr에 한 줄이 추가됨 (terminal인 경우): `claude -p` 실행이 마지막 turn 후에도 열려 있을 때 대기 중인 대상을 표시함
- Claude apps gateway의 Bedrock, Vertex, Foundry 및 기타 cloud upstream에서 `timeouts.upstream_ttfb_ms` 지원 추가됨: 설정한 값이 stream 시작 제한 시간을 초과하면 failover되거나 502 오류를 반환함
- `←`이 현재 tool 완료를 대기 중일 때 turn을 중지하면 "Backgrounding cancelled" 메시지가 추가됨
- 모든 Claude apps gateway upstream에 선택사항 `models` 목록 추가됨: 나열된 model만 failover에서도 전송되며, 항목의 하나의 `*`는 wildcard임
- 관리되는 설정이 없는 머신의 사용자 설정에서 `forceLoginMethod: "gateway"` 및 `forceLoginGatewayUrl` 지원 추가됨: `/login`이 해당 Claude apps gateway에서 열림
- `claude plugin validate`에 조언 추가됨: plugin의 README에 설치 줄이 없을 때 붙여 넣을 줄을 인쇄하고 `--strict`를 사용해도 종료 코드를 변경하지 않음
- Claude apps gateway의 `inference` audit event에 `upstream_request_id` 추가됨: Amazon Bedrock, Anthropic API 또는 다른 upstream의 요청 ID로 지원 사례에 사용됨
- mod을 위한 `$.ui.notify` 추가됨: 자신의 notification 설정을 통해 native notification을 발생시키고 어떤 channel이 전송했는지 표시함
- mod의 `Button`에 children 추가됨: 문자열 및 `Text`이므로 list의 행은 내부에 chip 또는 dim detail이 있는 하나의 pressable임
- `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` 추가됨: 무인 retry mode (`CLAUDE_CODE_RETRY_WATCHDOG`)가 429 및 529 오류를 대기하는 최대 시간 제한
- Claude apps gateway의 성공적인 inference 응답에 `request-id` header 추가됨: Claude Code telemetry의 `request_id`가 gateway의 audit log와 일치함
- `[1m]` model의 모든 요청 실패 수정됨: gateway, Bedrock, Vertex 또는 Foundry가 context-1m beta를 거부할 때 Claude Code가 이제 없이 다시 전송함
- `claude -p` text 출력이 background 작업이 다른 turn을 시작했을 때 이전 응답을 삭제하는 문제 수정됨: 각 turn의 응답이 turn 종료 시 인쇄됨
- headless 및 SDK 세션에서 remote MCP server가 15초보다 긴 outage 후에도 연결 해제된 상태로 유지되거나 connection을 연결 직후 drop하는 server에 tight loop으로 재연결되는 문제 수정됨: 반복된 drop이 이제 30초까지 back off함
- server의 오류 회신에 network 오류 이름이 포함되어 있을 때 remote MCP connection이 drop되는 문제 수정됨
- pagination cursor를 반복하는 MCP server가 모든 connect에서 동일한 페이지를 최대 20번까지 요청받는 문제 수정됨
- MCP tool이 반환한 CSS, JavaScript 및 XML 파일이 .bin으로 저장되는 문제 수정됨: Read tool이 거부함, font 및 icon 파일도 이제 자체 확장자를 받음
- model이 `description` 대신 `command_description`을 전달할 때 Bash tool 호출 실패 문제 수정됨
- Claude in Chrome이 port 80 (`host:80`)으로 작성된 site deny rule을 해당 host의 일반 `http://` 페이지에 적용하지 않는 문제 수정됨
- `/plugin`의 Errors 탭이 로드 실패한 marketplace를 제거하고 Enter를 누르지 않고 묻지 않고 plugin을 제거하는 문제 수정됨
- `claude plugin marketplace add`가 plugin을 설치할 수 없는 이름의 marketplace에 대해 성공을 보고하는 문제 수정됨: 이러한 add는 이제 거부됨
- `CLAUDE_AUTO_BACKGROUND_TASKS`가 edit 또는 shell command가 뒤에서 기다리는 동안 subagent를 background로 이동하여 해당 호출이 subagent 완료 전에 시작되는 문제 수정됨
- PushNotification이 `claude remote-control` 세션에서 push가 전송되지 않았다고 표시하는 문제 수정됨: phone 메시지 직후, `/config` toggle 없이, 또는 Claude Code 내부에서 시작했을 때
- 256개 이상의 file이 한 번에 전송될 때 remote 세션에서 보낸 file이 "보증할 수 없음"으로 거부되는 문제 수정됨
- login 새로 고침 직후 시작 시 관리되는 설정을 로드하지 못하는 드문 실패 수정됨
- `/tui`이 Claude Code를 다시 시작할 수 없을 때 메시지 없이 또는 raw system 오류와 함께 종료되는 문제 수정됨
- link 주소가 text로 표시되는 문제 수정됨: 회신이 남긴 색상 또는 conceal style로 숨겨짐 (table에서 줄 바꿈되거나 question preview인 경우 포함)
- Fable model이 Claude apps gateway에 로그인한 세션의 `/model` picker에 표시되지 않는 문제 수정됨: 이러한 model이 이제 동일한 model에 대해 추가된 `modelPicker` 행 대신 built-in row를 표시함
- Claude apps gateway의 admin spend 보기가 session이 group 반송을 중지한 후 developer의 이전 group 및 group cap을 표시하는 문제 수정됨
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`이 `/usage`의 Claude apps gateway spend limit 및 status line을 숨기는 문제 수정됨: spend limit 요청이 session이 로그인한 gateway로 이동함
- 자체 linked worktree의 subagent가 parent session의 git branch, status 및 recent commit을 표시하는 문제 수정됨
- prompt에서 입력한 text가 `←`로 backgrounding을 취소했을 때 Claude가 현재 tool 끝에서 중단되는 문제 수정됨: Claude가 이제 foreground에서 계속 작동함
- `--tools` 및 `--restricted`이 launch 후 등록하는 built-in tool에 적용되지 않고, 폐기된 tool 이름이 caller의 tool set 외부의 tool에 도달하는 문제 수정됨
- Claude가 MCP server의 resource list를 대기 중일 때 interrupt가 timeout까지 turn을 종료하지 않는 문제 수정됨
- mod의 hook이 content를 본 적 없이 cut short된 deeply nested tool input을 전달받아 guard가 통과할 수 있는 문제 수정됨
- Esc가 `←`로 background로 이동한 self-paced `/loop`를 중지하지 않는 문제 수정됨: pending wakeup을 취소하면 이제 notice를 표시함
- background 세션의 command 및 hook이 Claude가 읽는 출력에 color escape code를 넣는 `FORCE_COLOR=3`을 상속하는 문제 수정됨
- `claude agents`이 두 가지 모두 session이 열려 있을 때 (예: reboot 시) 중지되면서 새로운 background service를 시작하는 문제 수정됨: shutdown을 지연시키고 interrupted session을 다시 시작할 수 있음
- `worker`라는 이름의 custom agent가 auto-mode denial notice 및 task detail view의 activity list에서 "Agent"로 표시되는 문제 수정됨
- glob pattern 위의 for-loop에 대한 Bash 권한 검사 수정됨: 권한 검사 정확성 개선됨
- Workflow subagent에서 호출된 forked skill이 main conversation 대신 호출 agent에 결과를 전달하는 문제 수정됨
- in-process agent teammate가 tool search를 통해 tool을 로드할 때까지 첫 SendMessage 호출에 실패하는 문제 수정됨
- Claude가 resume 시 unfinished background workflow이 `TaskStop`에 의해 중지되었을 수 있다고 전달받는 문제 수정됨 (이는 원인이 될 수 없음)
- connected client 또는 tasks panel에서 long-running MCP tool 호출을 중지할 때 Claude에게 전달되지 않는 문제 수정됨
- background session의 `/loop`이 다음 wakeup이 session 프로세스가 down된 동안 도래했을 때 notice 없이 중지되는 문제 수정됨: session이 이제 이를 표시함
- reply 또는 teammate의 메시지의 raw terminal hyperlink byte가 숨겨진 주소로 clickable link로 그려지는 문제 수정됨
- large git submodule이 있는 plugin marketplace가 add 또는 refresh에 실패하는 문제 수정됨: plugin 파일을 보유한 submodule만 이제 fetch됨
- `/advisor` 대화상자가 더 이상 사용할 수 없는 저장된 advisor model에 checkmark를 표시하는 문제 수정됨: 이제 "No advisor"에서 열림
- background로 이동한 MCP tool 호출에 대한 notification이 shortened task id를 표시하는 문제 수정됨
- vim mode의 `~`이 line의 마지막 문자를 지나 cursor를 이동하여 그 후 `x`가 아무것도 하지 않고, `3~`이 다음 line으로 실행되는 문제 수정됨
- macOS에서 복사한 accented text (예: file 이름)를 prompt의 중간에 붙여넣은 후 cursor가 한 문자 너무 멀리 착지하는 문제 수정됨
- 응답이 수만 줄로 실행될 때 terminal이 freezing되고 ctrl+c가 무시되는 문제 수정됨
- mod이 plugin hooks worker restart 중 reload되는 동안 만드는 호출이 `.catch`가 있는 다른 mod의 guard hook을 통과하는 문제 수정됨: 그러한 호출이 이제 거부됨
- hook module이 수천 레벨 깊게 code를 nesting하는 plugin이 로드 또는 validate에 실패하고 bare stack-overflow 메시지를 표시하는 문제 수정됨
- `claude plugin test`이 real session이 보관하는 tool call, tool result 또는 thinking block을 제거하는 `session.append` hook을 전달하는 문제 수정됨
- session이 두 번째로 kill되고 resume된 후 Claude에게 SendMessage로 background subagent를 resume할 수 있다고 전달되지 않는 문제 수정됨
- Bash command (예: `cat`)가 인쇄하지 않고 실행된 후 file이 이미 read로 처리되는 문제 수정됨
- `constructor` 또는 `prototype`이라는 이름의 plugin 옵션이 항상 기본값으로 읽히고 편집 시 plugin을 재로드하지 않는 문제 수정됨
- mod의 hot reload가 `/reload-plugins` 또는 session start가 mod의 파일을 읽는 동안 이루어진 save를 놓치는 문제 수정됨
- 승인 없이 답변을 선택하지 않고 mod hot-reload question이 전체 session에서 매 turn마다 다시 묻는 문제 수정됨
- `/model`, `/fast` 및 `/output-style`이 plugin의 `config.set` hook을 묻지 않고 설정을 저장하는 문제 수정됨
- bold text가 dim text 직후에 piped 출력에서 faint
