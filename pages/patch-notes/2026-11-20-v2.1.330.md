> 원문: [Claude Code v2.1.330 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)

## 변경사항

- 조직 로그인 추가: Anthropic의 Enterprise Admin Console에서 관리되는 조직에 로그인할 수 있으며, `claude auth login` 이후에 Claude Code가 조직의 설정을 적용하고 클라우드 제공자 또는 gateway를 사용합니다.
- easel 추가됨: 차트를 그리는 기본 제공 mod로, MCP metrics 결과 하에서 Pro, Max 및 사용 가능한 경우 macOS 및 Linux의 Team 및 Enterprise에서 사용됨; `/config`에서 자동 차트를 비활성화할 수 있습니다.
- `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` 추가: 짧은 링크가 오류를 표시하거나 스크립트가 값을 읽을 경우 전체 로그인 링크를 출력합니다.
- Self-hosted runner: `--start-dir` / `SELF_HOSTED_RUNNER_START_DIR` 추가되어 Claude가 저장소의 폴더에서 작업을 시작할 수 있으며, 설정과 hook은 이전과 동일하게 로드됩니다.
- 클라우드 및 self-hosted runner 세션에서 plugin marketplace를 가져올 수 없을 때 알림 추가 (저장소가 세션의 저장소 중 하나가 아닌 경우)
- Self-hosted runner: Anthropic 관리 git이 plugin의 자체 저장소를 거부할 때 알림 추가 (plugin 이름 및 수행할 작업 명시)
- `claude plugin install --json` 결과에 `commandPrinted` 추가, plugin의 설치 명령이 stderr에 작성되었을 때 true이고, 종료 오류가 발생했거나 중단되거나 시간 초과된 경우 `commandFailed` 추가
- Self-hosted runner의 `/metrics`에 `claude_code_self_hosted_runner_order_to_registered_seconds` 추가: work order 발급에서 등록 승인까지의 시간 (orchestrator가 생성한 runner의 경우)
- Self-hosted runner의 `/metrics`에 `claude_code_self_hosted_runner_order_to_first_session_seconds` 추가: work order에서 첫 번째 세션 인계까지의 시간 (세션을 위해 시작된 runner)
- 매우 긴 대화를 압축한 직후 Claude Code가 최대 몇 분간 멈추는 문제 수정
- WebFetch가 일부 페이지에서 세션을 몇 분간 멈추게 하고 다른 페이지에서 빈 결과를 반환하는 문제 수정
- `ExitWorktree`와 worktree 종료 대화가 실행 중인 다른 Claude Code 세션이 작업 중이던 worktree를 삭제하는 문제 수정
- 여러 Claude Code 프로세스가 동시에 사용자 설정을 저장할 때 변경사항이 손실되는 문제 수정
- 마지막 저장된 메시지가 누락되거나 잘못된 타임스탬프를 가질 때 `--continue`와 `--resume`이 빈 세션을 열거나 실패하는 문제 수정
- Linux 및 WSL에서 2분 이상 절전 후 첫 번째 프롬프트가 연결이 끊긴 연결에서 3분을 대기하는 문제 수정
- 많은 MCP tool이 API가 거부하는 입력 schema를 가질 때 "JSON schema is invalid"로 실패하고 세션 파일이 여러 메가바이트 증가하는 문제 수정
- Linux: `node_modules`와 같은 큰 무시된 폴더가 있는 느린 저장소에서 Bash 명령이 초를 대기하고 세션의 나머지에서 파일 diff를 표시하지 않는 문제 수정
- Windows: Git Bash 시작에 10~60초가 걸린 후 Bash 명령이 세션의 나머지에서 더 느리게 실행되는 문제 수정 (사용자 지정 시작 파일이 없는 머신의 경우)
- `/rewind`가 두 개의 대기 중인 프롬프트 또는 쌓인 skill이 파일을 변경한 turn 직후에 함께 실행될 때 파일의 더 오래된 버전을 복원하는 문제 수정
- 권한 프롬프트를 승인할 때 추가된 텍스트 및 이미지가 승인된 명령 또는 tool이 실패할 때 삭제되는 문제 수정
- claude.ai connector 및 plugin server의 MCP resource가 terminal의 프롬프트 상자에서 @-mention될 때 첨부되지 않는 문제 수정
- subagent 중 하나가 완료될 때 다른 subagent 또는 세션이 여전히 사용 중인 MCP server가 종료되는 문제 수정
- Chrome에서 간단한 연결 문제 후에도 Claude가 "not connected" 상태를 유지하는 문제 수정 (Chrome이 열려 있고 로그인되어 있음에도 불구하고)
- Amazon Bedrock (Mantle)의 terminal 세션이 선택된 model 없이 시작될 때 고정된 Opus model을 무시하고 fallback을 발표한 후에도 사용할 수 없는 기본 model을 계속 호출하는 문제 수정
- fullscreen 모드에서 계획이 도착할 때 입력 중이던 나머지 텍스트가 손실되는 문제 수정
- 다른 이름의 claude.ai connector가 동일한 server URL을 공유할 때 삭제되는 문제 수정 (anthropics/claude-code#101856)
- 여러 `claude plugin` 명령이 동시에 실행될 때 plugin이 설치된 목록에서 누락되는 문제 수정
- 여러 task 업데이트가 동시에 실행될 때 task dependency 및 metadata가 손실되는 문제 수정
- disk가 가득 찼을 때 `~/.claude.json`의 불완전한 백업이 유지되고 양호한 백업이 대체되는 문제 수정
- path scoped rule 또는 Read deny rule이 있는 프로젝트에서 Code Mode 후 수백 개의 파일을 읽은 코드로 인한 긴 pause 수정
- 기본 제공 chart tool이 Code Mode에서 Claude가 호출할 때 실패하는 문제 수정
- Code Mode가 auto 및 bypass permission 모드에서 script로부터 turn을 종료하도록 MCP tool의 요청을 무시하는 문제 수정
- Code Mode auto 모드에서 mod가 script가 skill을 로드한 후 note를 추가할 때 이전 thinking을 삭제하고 prompt cache를 다시 작성하는 문제 수정
- Code Mode가 Esc 및 `/compact` 후에 script가 읽은 파일을 복원하지 않는 문제 수정
- `/context`가 Code Mode에서 Claude의 첫 번째 회신 전에 system tool의 개수를 과소 계산하는 문제 수정
- 중지된 background subagent가 때때로 중지된 상태를 유지하지 않는 문제 수정
- Claude가 app이나 SDK에서 실행한 세션에서 완료된 직후 중지된 background agent를 계속 대기하는 문제 수정
- Background 세션이 계획을 승인한 후 이전 permission 모드에서 활성화되는 문제 수정
- Remote Control: phone이나 웹에서 Stop으로 종료된 background agent에 대한 알림이 terminal에 입력한 것처럼 표시되는 문제 수정
- Remote Control: mid-conversation에서 켠 후 모바일 앱이 Diff 및 pull request 버튼을 숨기거나 중지된 세션을 작동 중으로 표시하는 문제 수정
- SessionStart hook에서 작성된 환경 변수가 `claude -p --continue`로 손실되는 문제 수정
- disk가 가득 찼을 때 `claude -p`의 출력이 파일로 이동하면 메시지 없이 0으로 종료되는 문제 수정: 이제 오류를 출력하고 1로 종료하지만, 전체 NFS export는 감지되지 않을 수 있습니다.
- `/context` 후이지만 첫 번째 메시지 전에 model이 변경될 때 system prompt가 이전 model의 지시사항을 유지하는 문제 수정
- Model이 mid-turn에 변경된 후 Claude가 commit attribution reminder에 회신하고 turn을 조기에 종료하는 문제 수정; 관리되는 설정이 PR attribution 라인을 설정한 경우 여전히 발생할 수 있습니다.
- Esc가 느리거나 멈춘 language server를 대기 중인 LSP tool call을 종료하지 않는 문제 수정
- language server가 여전히 시작 중일 때 여러 호출이나 편집이 도착할 때 LSP tool call 및 diagnostics가 실패하는 문제 수정
- `/mcp`가 plugin server를 기본 제공으로 나열하는 문제 수정: 이제 "Plugin MCPs" 아래에 나타나고 `--mcp-config`와 기본 제공 server는 "Other MCPs" 아래에 나타나며, server의 페이지는 plugin의 이름을 표시합니다.
- MCP allowlist 또는 denylist가 기본 제공 chart tool을 제외할 때 모든 시작에 "MCP server blocked by enterprise policy: easel" 경고가 표시되는 문제 수정 (tool이 차단 상태로 유지됨)
- `/stats`가 로컬 시간대 대신 UTC 일로 새 활동을 계산하는 문제 수정
- `/ultrareview`가 shell이 다른 저장소로 이동한 후 실패하거나 잘못된 코드를 검토하는 문제 수정: 이제 중지하고 두 폴더의 이름을 지정합니다.
- Grep이 패턴에 multiline 모드 없이 line break를 포함할 때 일치 항목을 보고하지 않는 문제 수정; 이제 거부된 패턴을 보고합니다.
- Byte order mark로 저장된 Jupyter notebook이 Read 및 NotebookEdit tool로 잘못된 JSON으로 보고되는 문제 수정
- HTML comment를 포함하는 CLAUDE.md 및 memory 파일에서 link reference definition이 삭제되는 문제 수정
- Monitors를 실행하면 종료될 때까지 메모리에 이전 대화를 유지하는 문제 수정
- 긴 대화 뒤에 context window보다 큰 PDF가 오는 경우 third-party 제공자의 일부 Claude Desktop 세션이 "Prompt is too long"으로 turn을 종료하는 문제 수정 (예약된 작업 제외)
- 동일한 이름을 선언하는 두 개의 사용자 또는 project agent 파일 사이의 선택이 file 검색 순서에 따라 달라지는 문제 수정
- git 저장소 내에서 `claude daemon logs`가 log 파일이 없을 때 종료되지 않는 문제 수정
- Markdown이 backslash가 단락의 뒤에 나중에 오는 emoji 앞에 올 때 bold 또는 italic 텍스트 뒤의 한두 문자를 숨기는 문제 수정
- Edit가 Claude 설정 파일에서 일부 유효한 hook 명령을 거부하는 문제 수정
- 페이지 범위가 있는 `Read`가 스캔된 2쪽 spread의 양쪽 절반을 각 페이지에 표시하는 문제 수정
- HTML artifact의 Mermaid diagram에서 line break 및 class stereotype이 누락되는 문제 수정
- `/config`의 Project instructions picker가 24행 fullscreen 창에서 4개 선택 중 하나만 표시하는 문제 수정
- Subagent의 자체 subagent 및 fork가 `opusplan` 또는 `haiku` 아래의 plan 모드에서 plan mode model에서 실행되는 문제 수정
- gateway가 작은 fast model을 거부할 때 WebFetch 페이지 요약이 `/effort` 수준을 무시하는 문제 수정
- Google Cloud의 Agent Platform에서 `claude -p`가 model이 `ANTHROPIC_MODEL` 또는 설정 파일에서 나올 때 `--settings '{"fastMode":true}'`를 무시하는 문제 수정; 이제 그러한 실행이 fast mode 가격으로 청구됩니다.
- `forceLoginOrgUUID` 아래의 시작이 하나의 임시 server 오류 또는 끊어진 연결 후 거부되는
