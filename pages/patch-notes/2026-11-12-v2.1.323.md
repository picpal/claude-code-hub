> 원문: [Claude Code v2.1.323 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

## 변경사항

- Code Mode를 추가했습니다. 이는 Claude가 자신의 도구를 호출하기 위해 JavaScript를 작성하는 실험적 옵트인입니다. https://code.claude.com/docs/en/code-mode 에서 켜거나 조직에 대해 꺼볼 수 있습니다.
- `plugin.json`에 `engines["claude-code"]`를 추가했습니다. 명시된 Claude Code 버전 범위를 벗어난 플러그인은 설치, 업데이트 또는 로드되지 않으며, 설치 및 업데이트는 맞는 최신 버전을 선택합니다.
- `claude plugin validate`에 플러그인의 TypeScript hooks 모듈에 대한 타입 체크를 추가했습니다. 각 발견 결과는 경고이며, `--strict`는 이에 대해 실패합니다.
- `claude plugin validate`에 모드의 `engine.create` hook이 추가, 보류 또는 교체하는 `$` 명사를 추가했습니다.
- 타사 제공업체의 Claude Desktop 세션을 위한 관리 설정에서 `CLAUDE_CODE_AUTO_MODE_MODEL` 지원을 추가했습니다(Claude Desktop이 이 버전을 포함하면 적용됨).
- 모델에 사용 크레딧이 필요하지만 꺼져 있거나 소진된 경우 옵션 메뉴(중지, 사용 크레딧으로 전환, 업그레이드)를 추가했습니다.
- `claude -p` 및 SDK 세션에서 hook이 오래 실행되는 동안 30초마다 진행률 하트비트를 추가했습니다. Claude Desktop 같은 호스트가 턴을 중단된 것으로 인식하지 않도록 합니다(이 버전을 포함하면).
- Artifact 도구 자산 업로드에 `.docx` 지원을 추가했습니다.
- diff 패널에 `/diff to close` 힌트와 패널을 포커스 및 닫는 키를 `?` 단축키 가이드에 추가했습니다.
- Bash allow 규칙에서 변수 값에 `*`가 있는 경우(예: `Bash(PORT=* npm run dev)`)에 대한 시작 경고를 추가했습니다.
- 플러그인의 언어 서버를 시작할 수 없을 때 경고를 추가했습니다. 서버 이름과 확인할 내용을 표시합니다.
- Perforce 설정이 발견되고 모드가 꺼져 있을 때 `CLAUDE_CODE_PERFORCE_MODE`를 이름으로 지정하는 일회성 시작 알림을 추가했습니다.
- `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`를 추가했습니다(2.1.318 이후 사용 가능). 이를 `1`로 설정하면 하위 에이전트 진행률 요약과 이를 작성하는 요청을 끕니다(anthropics/claude-code#86879).
- `CLAUDE_CODE_RESUME_HINT_COMMAND`를 추가했습니다. Claude Code를 시작하는 프로그램이 이를 설정하여 종료 힌트가 자신의 이력서 명령을 이름 지정하도록 할 수 있습니다.
- `claude plugin install --json` 결과에 `unsetOptionCount`를 추가했습니다. 아직 설정되지 않은 `userConfig` 옵션의 개수입니다.
- 모드의 pane이 그려지는 props에 `isPromptCovered`를 추가했습니다. 대화 상자나 프롬프트 위의 필드가 프롬프트를 덮을 때를 나타냅니다.
- `/compact`를 다시 실행하거나 `/context` 같은 명령어 후에 실행했을 때 Claude가 아직 답변하지 않은 메시지를 요약해서 삭제하는 문제를 수정했습니다.
- 이전 세션을 재개할 때 새 메시지를 이전에 중단된 메시지에 연결하지 않은 문제를 수정했습니다.
- Claude가 매우 큰 파일을 변경한 후 다음 프롬프트에서 메모리 급증 문제를 수정했습니다.
- 실행 중인 세션에서 저장된 설정이 `settings.json`에 수행된 수동 편집을 취소하는 문제를 수정했습니다. 세션 중에 삭제한 설정 파일은 이제 삭제 상태로 유지됩니다.
- `claude plugin` 명령어와 `claude mcp list`가 토큰 갱신 중에 종료되면 Console 프로필에서 서명을 해제하는 문제를 수정했습니다.
- Edit와 Bash가 특정 `/proc` 파일에서 메모리 부족 문제를 수정했습니다. 또한 Edit이 장치 및 명명된 파이프에서 중단되거나 메모리 부족이 되는 문제를 수정했습니다.
- Claude Code가 구성 파일 저장에 실패했을 때 "메모리 부족"으로 시작하지 못하거나 로그아웃 시 저장된 자격 증명을 지우지 못하는 문제를 수정했습니다.
- streaming 없이 전송된 요청이 거부된 이미지, thinking block 또는 beta header 같은 streaming 요청에서 복구되는 오류에 실패하는 문제를 수정했습니다.
- `ExitWorktree`, worktree 종료 대화 상자 및 `/resume`이 worktree에 들어가기 전에 셸이 있던 폴더가 삭제되었을 때 잘못된 폴더에 세션을 남기는 문제를 수정했습니다.
- 악센트 및 기타 combining marks이 때때로 텍스트의 왼쪽에 착지하거나 화면에 오래된 복사본이 남거나 텍스트가 줄바꿈할 때 조용히 사라지는 문제를 수정했습니다.
- 키 chord의 마지막 키(예: ctrl+x enter의 Enter)가 chord의 자체 작업을 사용할 수 없는 대화 상자의 텍스트 필드에서 작동하는 문제를 수정했습니다.
- 명령어를 중지하기 전에 Claude Code가 실행하는 프로세스 목록을 가져오는 데 너무 오래 걸릴 때 `ps` 프로세스가 쌓이는 문제를 수정했습니다.
- `WorktreeCreate` hook으로 생성되었거나 중첩된 리포지토리에 속하는 worktree에 들어간 후 하위 에이전트 트랜스크립트 및 대형 도구 결과가 세션의 트랜스크립트와 별도로 저장되는 문제를 수정했습니다.
- 명명된 Anthropic 프로필의 세션이 `/fork`, 왼쪽 화살표 또는 `--bg`로 백그라운드에서 계속될 때 다른 로그인으로 이동하는 문제를 수정했습니다. 업데이트 중에 열려 있던 세션을 다시 열어주세요.
- 명명된 Anthropic 프로필이 누락되었거나 변경되었거나 재정의되었을 때 백그라운드 세션이 다른 로그인에서 대화를 전송하는 문제를 수정했습니다. 이제 중지되고 그렇게 표시됩니다.
- 셸의 설정 토큰이 아닌 API 키, auth token 또는 workload identity의 세션이 백그라운드에서 다른 로그인으로 이동하는 문제를 수정했습니다. 이제 중지되고 그렇게 표시됩니다.
- MCP 도구 호출이 다시 로그인을 요청하는 대신 로그인 서버의 오류(예: `TOKEN_EXPIRED`)로 끝나는 문제를 수정했습니다.
- 만료된 claude.ai 로그인이 저장된 Console 키 또는 크레딧이 없는 `ant auth login` 프로필을 대신 사용할 때 "크레딧 잔액 부족"으로 표시되는 문제를 수정했습니다.
- 명명된 Anthropic 프로필의 세션이 그 로그인을 유지할 수 없는 오래된 백그라운드 서비스로 전달되는 문제를 수정했습니다. 이제 서비스를 재시작하도록 지시합니다.
- 백그라운드 세션의 로그인이 이전 계정의 로그인 또는 기타 자격 증명을 남기는 문제를 수정했습니다. 이제 컴퓨터의 모든 세션에 대해 이를 지웁니다. 거부된 로그인은 로그인을 남기지 않을 수 있습니다.
- 백그라운드 세션이 프로필과 저장된 로그인 사이를 이동하는 문제를 수정했습니다. 업데이트가 이를 재시작했을 때입니다.
- 로그인 후 로그인을 유지한 세션이 로그인 후 로그아웃 기능 플래그를 유지하는 문제를 수정했습니다.
- Claude 앱 gateway 로그인이 만료된 후 계속 실패하는 세션을 수정했습니다. 다른 터미널에서 `/login`을 사용하여 다시 로그인하면 다음 메시지에서 계속됩니다.
- 사용자 정의 `X-Api-Key` header가 설정되었을 때 청구 알림이 `ant auth login` 조직을 이름 지정하는 문제를 수정했습니다.
- macOS: keychain이 응답하기 느릴 때 성공적인 `/login` 또는 토큰 갱신 직후에 "로그인되지 않음 · /login 실행해주세요"가 돌아오는 문제를 수정했습니다.
- 조직의 gateway가 만료된 토큰으로 403으로 응답할 때 Claude Desktop에서 턴이 실패하는 문제를 수정했습니다. Claude Code는 이제 Desktop에 새 토큰을 요청하고 다시 시도합니다.
- Amazon Bedrock이 계정의 모델을 거부할 때 표시된 오류를 수정했습니다. AWS 자격 증명을 새로 고치도록 말하지 않고 모델을 활성화하도록 말합니다.
- 세 개 이상의 세션이 한 번에 새로운 로그인이 필요할 때 `awsAuthRefresh` 또는 `gcpAuthRefresh` 명령이 때때로 두 번 실행되는 문제를 수정했습니다.
- `-p` 경고에 대한 `claude`를 수정했습니다. 종료된 claude.ai 로그인은 `claude auth logout`이 저장된 MCP 서버 로그인 및 플러그인 비밀도 제거한다고 말합니다.
- Bash 권한 프롬프트가 `.git` 또는 `.claude` 같은 민감한 경로에 쓰는 명령어에 대해 "다시 묻지 않기"를 제공하는 문제를 수정했습니다. 저장된 규칙이 다음 프롬프트를 중지하지 않습니다.
- 일부 `lsof` 명령어가 권한 프롬프트 없이 실행되는 경우를 수정했습니다.
- `cat > file <<EOF`를 사용하여 파일을 쓰는 Bash 명령어가 "1개 파일 읽음"으로 표시되는 문제를 수정했습니다.
- Bash 권한 체크가 잘못된 폴더에서 `rm`을 판단하고 bypass 권한이나 Bash allow 규칙 아래에서 위험한 제거 프롬프트를 건너뛰는 경우를 수정했습니다.
- `--permission-mode auto` 또는 설정 `defaultMode: auto`가 자동 모드를 사용할 수 없을 때 더 많이 허용할 수 있는 모드에서 시작하는 문제를 수정했습니다. 이제 Manual mode에서 시작되며, 이는 먼저 물어봅니다.
- `plansDirectory`가 설정되었을 때 계획 파일이 프로젝트 외부에 작성되는 경우를 수정했습니다. 프로젝트 내부에 머물 수 있음을 보여줄 수 없는 쓰기는 이제 거부됩니다.
- Claude가 worktree에 들어간 후 자신의 백그라운드 명령
