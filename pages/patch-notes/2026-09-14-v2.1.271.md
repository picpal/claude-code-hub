> 원문: [Claude Code v2.1.271 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.271)

## 변경사항

- Claude Code Remote 세션(클라우드 및 자체 호스팅 실행기)에 빠른 모드를 추가했습니다: 호스트의 빠른 모드 설정 또는 세션에 입력된 `/fast`가 조직에서 허용하는 곳에 적용됩니다
- 전체 화면 모드에서 `/config` 패널에 마우스 지원을 추가했습니다: 휠은 설정 목록을 스크롤하고, 설정값을 클릭하면 변경되며, 포인터 아래의 행이 강조됩니다
- `claude self-hosted-runner --drain-marker-file <path>`를 추가했습니다: SIGTERM 드레인 중에 해당 파일이 존재하면 실행기가 호스트 드레인으로 서버에 종료를 보고합니다(원격 분석만 해당)
- 자동 모드에서 샌드박싱을 사용하는 Bash, PowerShell 및 Monitor에 명령별 `allowed_domains`을 추가했습니다: 명령이 필요로 하는 호스트를 검토하고 해당 명령만 열며, 다른 호스트는 거부됩니다
- agent frontmatter 및 `--agents` JSON에 `omitClaudeMd`를 추가했습니다: 사용자 정의 및 플러그인 subagent가 user, project 및 local CLAUDE.md 파일 없이 실행되도록 하며, 관리형 정책 파일은 여전히 로드됩니다
- `claude plugin install` 및 `claude plugin update`에 `--accept-command <sha256>`를 추가했습니다: 이전 `--json` 실행에서 표시한 정확한 명령을 수락할 수 있으므로 `-y` 대신 사용할 수 있습니다
- `modelPricing` 관리형 설정 및 Claude 앱 게이트웨이 `pricing` 블록에서 1보다 큰 `multiplier`(최대 10까지)를 지원합니다: 내부 청구 요금의 마크업에 해당합니다
- Bedrock, Vertex AI, Foundry 및 LLM 게이트웨이 사용자를 Claude 데스크톱 앱으로 가리키는 스피너 팁을 추가했습니다. claude.ai 데스크톱 앱 팁은 이제 `/desktop`을 제안하며, 이는 앱 다운로드를 제공합니다
- 계정, 조직 또는 API 키를 전환한 후 캐시된 조직 정책이 재사용되고 세션 중간에 자격 증명이 변경될 때 시간별 확인까지 정책이 새로 고쳐지지 않는 문제를 수정했습니다
- 시작 후 조직 정책 로드가 완료되거나 세션 중간에 변경될 때 도구 및 명령 목록이 업데이트되지 않는 문제를 수정했습니다
- 읽거나 구문 분석할 수 없는 enterprise `managed-mcp.json`이 무시되는 문제를 수정했습니다: 이제 독점 MCP 제어를 유지하고(사용자, 프로젝트 및 플러그인 서버는 로드되지 않음) 시작 시 경고합니다
- org 정책이 `ANTHROPIC_UNIX_SOCKET`를 통해 설정된 제3자 로컬 프록시를 통해 가져오고 거부되는 문제를 수정했습니다: Remote Control을 포함한 다른 사용자 정의 게이트웨이처럼 처리됩니다
- 세션의 워커가 다시 시작된 후 워크플로우 또는 agent 승인이 적용되었을 때 클라우드 세션이 모든 subagent 도구 호출을 거부하는 문제("updatedInput … failed schema validation")를 수정했습니다
- 조직에 빠른 모드가 비활성화되어 있을 때 `/fast off`가 빠른 모드를 끄는 대신 "빠른 모드를 사용할 수 없음"이라고 답변하는 문제를 수정했습니다
- `CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK`로 시작한 세션이 API가 빠른 모드를 거부한 후 매 턴마다 빠른 요청을 재전송하는 문제를 수정했습니다: 거부가 이제 유지되고 그 이유가 표시됩니다
- `CLAUDE_CODE_RETRY_WATCHDOG` 아래의 빠른 모드가 사용량 크레딧 한도에 따라 턴에 실패하거나 오버로드를 빠른 속도로 재시도하는 대신 표준 속도로 폴백하는 문제를 수정했습니다
- Bash 권한 확인이 `fmt`, `column` 등의 명령이 읽을 파일을 놓치고 그것이 확인자가 인식하지 못하는 옵션을 따르는 문제를 수정했습니다
- Bash 권한 확인이 와일드카드가 명령의 패턴 또는 옵션 값에 있을 때 와일드카드가 확장하는 파일을 건너뛰는 문제를 수정했습니다(예: `grep -v dir/* file`)
- Bash 권한 확인이 shell 변수 선언 플래그가 실행 중인 명령을 잘못 표현하는 것을 방지하도록 수정했습니다
- 두 개의 디렉터리 변경, subshell 또는 `cd`+`git` 체인을 가진 Bash 명령이 bypass 및 auto 모드에서 `permissions.blockReadsOutsideWorkingDirectories` 아래의 프롬프트를 건너뛰는 문제를 수정했습니다
- 샌드박싱된 명령이 시작되지 않은 후 stale `.git/config.lock`이 `git checkout -b`, `git push -u` 및 `git config`를 세션의 나머지 부분에서 깨뜨리는 문제를 수정했습니다(Linux)
- 세션 외부에서 수행한 설정 파일 변경이 시스템 파일 이벤트 서비스가 포화된 macOS 머신에서 감지되지 않는 문제를 수정했습니다: watcher가 이제 폴링으로 폴백합니다
- 모든 도구가 MCP 서버에서 오는 재개된 `claude -p` 세션이 "At least one tool must have defer_loading=false"로 실패하는 문제를 수정했습니다
- LLM 게이트웨이가 비스트리밍 응답을 `text/plain`으로 반환할 때 "API returned an empty or malformed response"로 인해 턴이 실패하는 문제를 수정했습니다
- MCP 서버가 `list_changed` 알림을 tight loop에서 보낼 때 지속적인 높은 CPU 사용량 및 반복된 도구 목록 요청 문제를 수정했습니다
- MCP OAuth가 클라이언트 등록을 잘못 처리하는 문제를 수정했습니다: 동의 거부가 새로운 등록을 강제했고, 다른 리다이렉트 URI에 대한 것이 재사용되었으며, 동시 쓰기가 유효한 것을 삭제하거나 불일치하는 것을 유지할 수 있었습니다
- Claude가 전체 `mcp__server__tool` 이름 대신 MCP 도구의 bare name으로 선택할 때 도구 검색이 일치 항목을 반환하지 않는 문제를 수정했습니다
- Ctrl+O가 pending MCP 서버 재연결을 취소하고 트랜스크립트 보기가 열려있을 때 Remote Control에서 보낸 `/mcp`이 실패하는 문제를 수정했습니다
- Chrome의 Claude 프롬프트가 ToolSearch를 사용할 수 없을 때 도구를 ToolSearch를 통해 로드하도록 모델에 지시하는 문제를 수정했습니다
- 수신 세션의 권한 모드 정책에 의해 유지된 세션 간 메시지가 흔적을 남기지 않는 문제를 수정했습니다: headless 발신자는 이제 배송 통지를 받고 `SendMessage` 결과가 더 이상 읽혔음을 암시하지 않습니다
- Claude가 대화가 압축된 후에도 여전히 실행 중인 배경 명령(watch 작업 또는 dev 서버)의 두 번째 복사본을 시작하는 문제를 수정했습니다
- `/model`이 대화를 실제로 실행한 모델로 전환할 때 프롬프트 캐시를 잃는다고 경고하는 문제를 수정했습니다
- `/reload-skills`가 `/cd` 후 슬래시 메뉴와 일치하지 않는 스킬 수를 보고하는 문제를 수정했습니다
- `/resume` 및 `/continue`가 짧은 터미널의 전체 화면 모드에서 1~2개의 세션만 표시하는 문제를 수정했습니다
- `/resume` 및 `/teleport`가 이전 대화의 파일 읽기 추적을 유지하여 Claude가 재개된 대화에서 읽지 않은 파일을 편집할 수 있는 문제를 수정했습니다
- `--resume`이 재개된 세션의 모델 제품군이 구성된 기본 모델과 다를 때 1M context 윈도우(`[1m]`)를 삭제하는 문제를 수정했습니다
- `/artifacts`로 첨부된 아티팩트가 `--resume` 후 세션에서 사라지는 문제를 수정했습니다
- 배경 세션(`claude --bg`, `claude agents`)이 다른 곳에서 수행한 재발행에 대해 발행하는 아티팩트를 감시하지 않는 문제를 수정했습니다
- 첫 번째 이후의 사용자 정의 agent, 슬래시 명령 및 출력 스타일이 inode 0을 보고하는 가상 드라이브(예: Windows 드라이브로 마운트된 암호화된 자격 증명 모음)에서 로드되지 않는 문제를 수정했습니다
- 자체 호스팅 실행기 세션이 호스트 구성 디렉터리가 64 MiB를 초과할 때 모든 호스트 구성(설정, 스킬, 플러그인, MCP 서버)을 자동으로 잃는 문제를 수정했습니다: `--host-config-snapshot disk|memory`를 추가했습니다
- claude.ai에서 동기화된 스킬이 로그아웃 후 무기한 디스크에 머물러 있는 문제를 수정했습니다: `cleanupPeriodDays` 내에서 새로 고쳐지지 않은 사본은 다음 시작 시 recoverable trash로 이동합니다
- 스피너 팁이 계정 유형에 사용할 수 없거나 세션에서 비활성화된 명령을 제안하는 문제를 수정했습니다
- `/add-dir` 경로 입력을 수정했습니다: 좌우 화살표 키가 이제 커서를 이동하고 Enter는 강조된 완성뿐만 아니라 입력된 경로도 추가합니다
- 주 프롬프트 외부의 텍스트 필드가 선행 `!`를 입력한 것의 끝으로 이동하는 문제를 수정했습니다(`!foo`가 `foo!`로 나왔습니다)
- 인터랙티브 `/hooks` 메뉴가 hook matcher의 이름이 `__proto__` 또는 `constructor`와 같은 상속된 object property 이름일 때 충돌하는 문제를 수정했습니다
- 텍스트가 stale 배경색을 유지한 후 박스가 주변에서 배경을 잃는 전체 화면 렌더링 glitch를 수정했습니다
- st에서 Delete 및 rxvt-unicode에서 Alt+arrow 키가 attached 배경 세션에서 작동하지 않는 문제를 수정했습니다
- Claude Code가 종료되거나 일시 중단되거나 시작 직후 편집기를 열 때 터미널의 기능 쿼리(`^[[?1;2c`) 응답이 shell 프롬프트 또는 편집기에 나타나는 문제를 수정했습니다
- 터미널 렌더링 성능을 개선했습니다: 큰 diffs 및 긴 transcripts가 더 빠르게 렌더링되며 느린 프레임이 더 적
