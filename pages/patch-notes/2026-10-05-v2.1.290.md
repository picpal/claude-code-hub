> 원문: [Claude Code v2.1.290 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)

## 변경사항

- `turn.step` hook의 mod 결과에 `serverToolUses`를 추가했습니다: API가 실행한 도구 호출(advisor)이며, 각각 id, name, input, start 및 end를 포함합니다
- plugin hooks의 `tool.check` event에 `agentId`를 추가했습니다. 이를 통해 hook은 subagent의 권한 확인을 main session의 것과 구별할 수 있습니다
- mod의 `tool.check` hook이 읽는 question 및 verdict에 `ceiling`을 추가했습니다. 이는 tool에 대해 조직이 요구하는 승인을 명명합니다
- plugin hooks 타입 정의에 `ThemeKey` 및 `Color` 타입을 추가했습니다. 이를 통해 editor는 mod의 drawing이 명명할 수 있는 theme 색상을 나열할 수 있습니다
- `claude plugin validate`에 추가했습니다: mod가 gating site에 등록하는 각 hook이 `.catch`를 가지고 있는지 여부와 함께 나열됩니다(`--json` 아래 `gatingHooks`)
- Claude apps gateway의 sign-in 승인 페이지에 Deny 버튼을 추가했습니다: 이는 pending sign-in을 종료하므로 waiting terminal이 몇 초 이내에 중지됩니다
- `claude attach <name>` 및 `claude logs <name>`을 추가했습니다: session 이름의 일부가 id 대신 작동합니다
- `/claude-api managed-agents-onboard <url>`을 추가했습니다: page가 `ant apply` 파일로 설명하는 Managed Agents 패턴을 설정합니다
- `/claude-api managed-agents-onboard <quickstart-name>`을 추가했습니다: Console quickstart template(예: `deep-researcher`)을 `ant` CLI로 빌드합니다
- managed settings 파일이 managed settings 폴더 외부 파일로의 링크일 때 경고를 추가했습니다
- managed settings이 user-configured sandbox allowRead paths 또는 allowed domains를 무시할 때 /status 및 doctor 경고를 추가했습니다
- Claude Code의 beta header 중 하나를 400 이외의 상태로 거부하거나 두 번째 beta와 함께 거부하는 proxy 및 gateway 뒤에서 요청 실패를 수정했습니다
- 수백 개의 이미지가 있는 long session이 "Request rejected as unprocessable by the model" 오류에서 stuck되는 문제를 수정했습니다
- API의 output content filter가 Claude가 여전히 thinking하는 동안 reply를 중지했을 때 turn이 한번에 끝나는 문제를 수정했습니다. 이제 요청이 오류가 표시되기 전에 한 번 다시 시도됩니다
- resumed subagent 및 teammate이 message mid-run을 받은 후 earlier thinking 및 prompt cache를 잃는 문제를 수정했습니다
- WebFetch가 100,000자를 넘는 page text를 silently 드롭하는 문제를 수정했습니다. 이제 읽지 않은 양을 표시하고 `offset`을 취하여 계속 읽을 수 있습니다
- response가 수천 단계 깊게 nested lists 또는 quotes를 포함할 때 crash("Maximum call stack size exceeded")를 수정했습니다
- `/rewind`가 Claude가 여전히 작업하는 동안 전송된 prompt를 나열하지 않는 문제를 수정했습니다
- scheduled task(`/loop` with interval, reminders)가 conversation이 compacted된 후 resume에서 silently 복귀하지 않는 문제를 수정했습니다. 이 버전 이후에 만들어진 compaction을 포함합니다
- foreground에서 설정된 scheduled task가 ← 또는 `/background` hand-off 이후 실행되지 않고, recurring task가 모든 resume, respawn 또는 fork에서 추가 실행을 하는 문제를 수정했습니다
- headless `--json-schema` run이 connection dropped 후 structured output이 이미 전달되었을 때 `success` result에서 `is_error: true`와 함께 non-zero로 exit하는 문제를 수정했습니다
- plan mode가 server-pushed ask policy를 수행하는 non-read-only connector tool을 auto mode classifier가 승인하게 하는 문제를 수정했습니다
- project `CLAUDE.md`, rule 또는 `AGENTS.md`가 working directory 외부로 symlink되어 `permissions.blockReadsOutsideWorkingDirectories` 또는 `Read` deny rule 아래 로드되는 문제를 수정했습니다
- `xn--` host label 내부 wildcard가 있는 URL allow 및 deny pattern이 프로세스마다 다르게 일치하는 문제를 수정했습니다
- 조직에서 제공하는 MCP server가 sign in 또는 reconnect 후(headless 및 SDK session의 late result 포함) 자신의 것으로 relisted되는 문제를 수정했습니다
- `/ultrareview`가 Windows에서 `git stash create`가 실패했을 때 경고 없이 uncommitted change를 드롭하고 `git add -N` 파일이 삭제되거나 이동된 후 이를 거부하는 문제를 수정했습니다
- `plansDirectory` 설정의 backslash를 포함하는 path에 대한 project-root 확인을 수정했습니다(macOS, Linux)
- very long Remote Control 및 cloud session의 reply가 streaming in 대신 block at a time으로 표시될 수 있는 문제를 수정했습니다
- background daemon의 log가 `claude daemon run` 및 `claude daemon logs` 아래 screen에 terminal control character를 전달하는 문제를 수정했습니다. 이제 `\uXXXX` escape로 표시됩니다
- Self-hosted runner: crafted, very long line of session's error output이 runner를 몇 초 동안 freeze하는 문제를 수정했습니다
- `.catch`가 있는 plugin hook이 unloaded되고 hook이 prompt 또는 tool call에서 hooks worker를 바쁘게 유지할 때 `.catch`가 skipped되는 문제를 수정했습니다
- mod의 `turn.step` result가 mid-response model fallback이 discard한 tool call을 나열하는 문제를 수정했습니다
- Cowork cloud session의 reply가 container가 Claude가 message 또는 file을 보낸 직후 restart되었을 때 때때로 완료되지 않는 문제를 수정했습니다
- `claude plugin validate` 및 plugin loading이 option을 destructure하는 hooks module을 top-level function과 같은 이름으로 거부하는 문제를 수정했습니다
- `/ultrareview`가 `core.safecrlf=true`가 git's configuration에 설정될 때 uncommitted change를 업로드하지 못하는 문제를 수정했습니다
- `/ultrareview` upload가 checkout을 거부할 때 표시되는 오류: 각 known cause는 이제 자체 message를 가지며 fix하는 방법을 제공합니다
- Windows: skills 및 command의 multi-line `!` shell block이 파일이 CRLF line ending으로 저장될 때 실패하는 문제를 수정했습니다
- `/permissions` tab이 fullscreen mode에서 search되는 동안 클릭될 때 Claude Code가 hang되는 문제를 수정했습니다
- conversation compaction이 때때로 "null is not an object" 오류로 실패하는 문제를 수정했습니다
- plugin hook이 auto mode에서 report를 hand back하는 subagent에 대해 `turn.complete`에서 empty `answer`를 읽는 문제를 수정했습니다
- refresh가 failed reload를 따를 때 mod가 message 없이 unload되는 문제를 수정했습니다. 이제 failure line은 이전에 로드된 버전이 unload된다고 말합니다
- mod의 `prompt.submit` hook이 `next(e)`를 호출한 후 prompt를 drop하는 것이 silently ignored되는 문제를 수정했습니다: hook이 이제 failed로 reported됩니다(by name)
- mod의 pane 또는 band가 height가 변경되는 tree의 end를 따를 때 끝없이 redrawn되는 문제를 수정했습니다
- image read가 macOS 및 Windows에서 mid-read에 swap된 link를 통해 승인된 것 외부 파일을 반환할 수 있는 문제를 수정했습니다
- user-installed mod가 organization의 plugin을 unload할 수 있는 경우를 수정했습니다. 이제 mod가 unload됩니다
- `disableClaudeAiConnectors` 및 `allowedMcpServers` URL rule이 `.mcp.json`, plugin 또는 agent에서 선언된 일부 MCP entry에 적용되지 않는 문제를 수정했습니다
- mod의 inline pane이 height가 변경되는 tree에서 끝없이 redrawn되는 문제를 수정했습니다
- read block 또는 `--restricted` 아래 `@`-mention이 mid-read에 변경된 link를 통해 working directory 외부 파일을 읽을 수 있는 문제를 수정했습니다
- agent view에서 Esc가 "Press enter again to restart this session — it isn't responding"를 확인하는 문제를 수정했습니다. Esc는 이제 session을 다시 엽니다
- agent view가 session이 생성하는 worktree에 진입한 후 background session의 `/loop` run count, countdown 및 live status line을 잃는 문제를 수정했습니다
- `claude agents` session이 manual permission mode에서 reply에 paste된 image 또는 새로운 agent의 prompt를 읽기 위해 승인을 요청하는 문제를 수정했습니다
- deny 또는 ask rule이 `declare`, `typeset`, `export` 또는 `readonly`에서 prefix로 설정된 variable에서 온 command 또는 path를 누락하는 문제를 수정했습니다
- Read deny rule이 prompt에 paste 또는 drag된 image path 또는 @-mentioned folder에 대해 나열된 file name에 적용되지 않는 문제를 수정했습니다
- user-installed mod가 organization의 guard가 check를 skip하게 할 수 있는 경우를 수정했습니다. 그러한 mod은 이제 unload됩니다
- plugin hook이 mod가 non-Latin character를 holding한 long multi-line text를 draw할 때 stalling되는 문제를 수정했습니다
- agent view에서 repeated Ctrl+X가 section의 bottom session이 삭제된 후 entire next section을 삭제하는 문제를 수정했습니다
- You should know가 `language` setting을 무시하고 English로 note를 작성하는 문제를 수정했습니다
- very long message를 보낸 후 freeze되는 문제를 수정했습니다
- transcript를 expand(ctrl+o)하거나 arrow, dash 또는 box-drawing과 같은 non-ASCII character를 포함하는 large tool output에서 resize할 때 slowdown을 수정했습니다
- `claude respawn`이 saved transcript가 없는 backgrounded session에 earlier message를 re-send하는 문제를 수정했습니다(empty conversation으로 시작하는 대신)
- agent view에서 `n:` 또는 Ctrl+F search 후 Esc가 section header로 focus를 이동하는 문제를 수정했습니다. 여기서 Ctrl+X twice는 section의 모든 session을 삭제합니다
- `claude agents`가 stopped session에 전달할 수 없는 slash command를 save하고 그 session이 next time restart될 때 자체적으로 실행하는 문제를 수정했습니다
- `/ultrareview`가 `unset` 또는 `unspecified`라는 git filter driver 아래 파일에 대해 uncommitted change를 unfiltered로 업로드하는 문제를 수정했습니다. 이제 upload가 중지되고 driver 이름을 바꾸도록 요청합니다
- auto mode denial이 전체 tool을 skip하거나 Claude Code가 무시할 permission rule을 제안하는 문제를 수정했습니다
- `claude --teleport` 및 `/teleport`가 같은 이름의 tracked file을 대체한 folder의 파일을 삭제하는 문제를 수정했습니다(stash를 선택했을 때). 이제 stash가 거부되고 이유를 말합니다
- Esc가 agent view의 "Press enter again to restart this session fresh" prompt를 확인하는 문제를 수정했습니다
- agent view의 `/loop` run count가 freeze되고 countdown이 `/clear` 후 사라지는 문제를 수정했습니다. 이제 count는 새로운 conversation으로 restart됩니다
- `--channels` permission relay: session 내에서 반복되는 reply ID는 이제 다른 prompt를 승인하는 대신 무시됩니다
- `/chrome` "Reconnect extension"이 failed Chrome connection 후 browser tool을 restore하지 못하는 문제를 수
