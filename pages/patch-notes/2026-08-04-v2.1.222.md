> 원문: [Claude Code v2.1.222 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)

## 변경사항

- worktree 격리 세션 및 해당 subagent가 메인 checkout에 대해 파괴적인 git 명령을 실행할 수 있는 문제를 수정했습니다. 이제 격리가 모든 세션 유형의 파일 편집 및 Bash에 적용됩니다
- 백그라운드 agent 작업(요약, 압축, 이름 바꾸기)에서 PreToolUse auto-allow 훅이 tool 제한을 우회할 수 있는 문제를 수정했습니다
- Team 및 Enterprise의 `/usage-credits`에서 이전 요청이 거부된 멤버에 대해 "이미 usage credit 요청을 보냈습니다"라고 표시되어 새 요청을 보내지 못하는 문제를 수정했습니다
- HTTPS 프록시 뒤에서 시작 연결 확인이 응답 중단되었다가 실패하는 문제를 수정했습니다. 이제 API 요청과 동일한 proxy 인식 transport를 사용하며 명확한 메시지와 함께 timeout됩니다
- 실제로 완료된 응답에 대해 "Connection closed mid-response" 오류가 보고되는 문제를 수정했습니다
- `/usage`가 MCP server에 대한 usage를 과다 계산하는 문제를 수정했습니다. 이제 server의 share는 호출 후 모든 turn이 아닌 실제로 tool 결과를 사용한 요청만을 반영합니다
- branch가 푸시된 후 생성된 pull request(GitHub REST API 포함)에 세션이 연결되지 않는 문제를 수정했습니다
- org 제한 `model: opus` 스타일의 subagent 및 teammate family alias가 부모 model로 downgrade되지 않고 family의 최신 org 승인 model로 단계적으로 내려가지 않는 문제를 수정했습니다
- server keep-alive ping이 전송되고 있음에도 불구하고 custom `ANTHROPIC_BASE_URL` gateway에서 stream idle timeout이 발생하는 문제를 수정했습니다
- 세션 token이 유효하지 않을 때 claude.ai connector가 거짓으로 인증 필요 상태로 표시되는 문제를 수정했습니다. 이제 `/login` 힌트를 표시합니다
- MCP server가 제거된 후처럼 더 이상 로컬에서 사용할 수 없는 tool의 tool 오류가 표시되지 않는 문제를 수정했습니다
- `SendMessage`가 긴 summary를 거부하는 문제를 수정했습니다. 이제 truncate하므로 문자 수 제한으로 인해 send가 실패하지 않습니다
- subagent의 transcript 보기에서 spinner의 effort label이 세션의 effort level이 아닌 subagent의 자체 `effort:` 설정을 표시하는 문제를 수정했습니다
- 파일 watcher가 filesystem 오류를 발생시킨 경우 또는 file-watcher teardown 중 발생하는 드물지만 발생하는 crash를 수정했습니다
- `--ax-screen-reader` 모드에서 screen reader가 매번 backspace할 때마다 전체 입력 line을 다시 읽는 문제를 수정했습니다. 이제 line 끝의 deletion은 삭제된 문자만 echo합니다
- `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST`가 설정되었을 때 host model-selection key가 stale on-disk `managed-settings.json`보다 우선순위를 갖지 않는 문제를 수정했습니다
- Auto mode 안전성을 개선했습니다. `SendMessage`를 통해 다른 agent 세션으로 전송된 메시지는 이제 dispatch 전에 permission classifier로 평가됩니다
- Claude가 `disable-model-invocation`으로 skill을 호출하려고 할 때의 거부를 개선했습니다. 이제 Claude에게 workflow를 복제하는 대신 당신에게 skill을 실행해달라고 요청하도록 지시합니다
- `/diff` view, Remote Control workspace diff, Claude Code on the web 세션의 file-edit diff를 개선하여 workspace 구성 diff driver 및 textconv를 무시하고 raw git blob content를 사용합니다
- Remote Control auto-start를 변경하여 repo-local 설정(`.claude/settings.json` 또는 `.claude/settings.local.json`)이 더 이상 이를 켤 수 없습니다(끌 수는 있음). `/config`를 통해 user 범위에서 활성화하세요
- ultraplan 기능이 제거되었습니다
