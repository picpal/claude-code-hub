## 변경사항

- 드물게 발생하는 내부 레이아웃 오류 이후 프로세스가 계속 실행되었는데도 대화형 세션이 완전히 다시 그리기를 중단할 수 있는 문제를 수정했습니다
- Claude Code가 git 설치의 상위 폴더에서 실행될 때 Windows에서 `git` / Git Bash를 찾을 수 없는 문제를 수정했습니다
- 마지막 응답 이후 `/model`이 변경되었을 때 `/tui`가 세션을 이전 모델로 되돌리는 문제를 수정했습니다
- 설치 또는 업그레이드 직후 첫 번째 세션에서 교차 세션 메시징이 때때로 받은 편지함 없이 시작되는 문제를 수정했습니다
- 연결된 상태에서 Remote Control `/resume`이 재개된 대화의 제목이나 이력을 연결된 세션으로 유출하는 문제를 수정했습니다
- `claude self-hosted-runner` 세션이 세션이 푸시하지 않는 저장소에서 `checkout` hook이 실패할 때마다 실패하는 문제를 수정했습니다. 해당 저장소는 이제 경고와 함께 건너뜁니다
- self-hosted runner가 백그라운드 작업이 완료되고 후속 턴이 시작되는 사이의 간격에서 세션을 종료하는 문제를 수정했습니다
- 세션 정리가 프로젝트의 memory 폴더 내부 콘텐츠를 삭제하는 문제를 수정했습니다
- 백그라운드 plugin-cache 정리가 유일한 버전이 symlinked 개발 체크아웃일 때 플러그인의 캐시를 삭제하는 문제를 수정했습니다
- marketplace 항목이 높은 우선순위 settings tier에서 재정의될 때 다른 tier의 사용자 정의 헤더를 상속할 수 있는 settings-merge 문제를 수정했습니다. 이제 marketplace 항목은 전체 항목으로 병합됩니다
- skill 호출 후 deferred-tools 알림이 모델에 가끔 두 번 전송되는 문제를 수정했습니다
- claude.ai에서 동기화된 skill이 강화되었습니다. 더 이상 로컬 명령이나 MCP prompt를 가리지 않으며, 설명은 정제되고 레이블이 지정되며, 사용자의 머신에서는 본문이 `!` 명령을 실행하거나 `@` 파일을 확장하지 않습니다
- 교차 세션 메시지가 개선되었습니다. 발신자와 본문이 축소된 줄 대신 인라인으로 표시되며, 다른 머신의 Remote Control 세션으로 전송되는 메시지는 발신자로 Remote Control 세션 이름을 표시합니다
- Vertex AI 자격 증명 처리가 개선되었습니다. 만료되었거나 누락된 Google Cloud 자격 증명이 이제 분 단위로 재시도하는 대신 초 단위로 실패합니다
- Compaction 진행률이 개선되었습니다. 재시도 카운트다운 및 stall 힌트가 이제 진행률 표시줄만 표시하는 대신 compaction 중에 나타납니다
- 일부 터미널에서 탭 바 지터를 줄이기 위해 터미널 제목 busy-spinner glyph가 업데이트되었습니다
- Write tool이 변경되어 최신 모델이 이 세션에서 읽지 않은 기존 파일을 덮어쓸 수 있으며, Edit tool의 규칙과 일치합니다. 이전 모델은 여전히 먼저 읽기가 필요합니다
- Pro, Max, Team 플랜의 첫 사용 공지에서 auto mode 세션의 비용이 약간 더 많이 드는 것에 대한 오래된 참고사항을 제거했습니다
