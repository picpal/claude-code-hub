> 원문: [Claude Code v2.1.232 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.232)

## 변경사항

- Subagent forking이 이제 기본적으로 활성화되어 있습니다: `subagent_type: "fork"` subagent는 전체 대화 및 prompt cache를 상속받으며, 비팀원 agent가 interactive session에서 생성될 때 이제 기본적으로 백그라운드에서 실행됩니다
- prompt에서 `@`를 입력하여 이름으로 다른 Claude session을 mention할 수 있습니다. Claude는 `SendMessage`를 사용하여 해당 session에 직접 도달합니다
- `SendMessage`는 이제 ref로 먼저 확인을 요청하는 대신, 정확히 일치하는 한 개의 live session에 bare name으로 전달합니다
- 한 머신의 interactive session은 이제 고유한 이름을 유지합니다: session을 다른 live session이 이미 사용 중인 이름으로 시작하거나 이름을 바꾸면 `name-word-word` variant가 부여되고 알림을 받습니다
- "Dialog expiry" 및 "Messages from your other sessions" (cross-session inbound accept/hold/refuse)에 대한 `/config` rows를 추가했습니다
- GitLab token families (`glrt-`, `gloas-`, `glptt-`, `glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-`)에 대한 secret redaction과 routable `glpat-`/`gldt-` tokens의 전체 redaction을 추가했습니다. `glab` CLI config store는 `gh`와 동일한 sandbox 및 credential-path 보호를 받습니다
- 플러그인 마켓플레이스에 GitLab 지원을 추가했습니다: bare `gitlab.com` repo URL(중첩된 subgroup 포함)은 이제 `github.com` URL처럼 clone되며, clone auth-failure hints는 실제 git host를 표시합니다
- Settings: `additionalMarketplaces` 및 `allowedMarketplaces`는 이제 `extraKnownMarketplaces` 및 `strictKnownMarketplaces`의 더 친화적인 alias로 허용됩니다
- Enterprise policy: bare repo URL에 대한 url-typed `blockedMarketplaces` entry는 CLI가 해당 URL을 git clone으로 분류할 때 계속 해당 URL을 차단합니다
- Gateway: `desktop:` overlay는 이제 모든 released Desktop setting을 허용합니다(이전에는 11개의 hand-listed keys), 부팅 시 Desktop의 자체 schema에 대해 검증됩니다. 알려지지 않은 또는 유효하지 않은 키는 부팅에 실패합니다
- Gateway: 빈 `managed.policies[].match.groups`/`admin.admin_groups` entries와 malformed `email_domain` values(비어 있거나 `@`, whitespace, 또는 comma를 포함)는 이제 아무도 일치하지 않거나 admin access를 부여하지 않는 대신 부팅 시 실패합니다
- Fable 5는 Fable access가 있는 조직의 경우 `/advisor`에서 advisor로 다시 제공되며, usage-credits consent는 `/model fable`을 통해 설정됩니다
- PowerShell permission bypass를 수정했습니다. 여기서 variable-writing parameters는 자동으로 `$PSDefaultParameterValues`를 덮어쓸 수 있었고 나중 명령의 file access를 redirect할 수 있었습니다
- Windows permission bypass를 수정했습니다. 여기서 Git Bash는 path validation이 regular files로 본 Cygwin-style symlinks를 따랐습니다. 이제 이들을 통한 writes는 permission approval이 필요합니다
- Nested git repositories가 부모 디렉토리에서 trust를 상속하는 것을 수정했습니다. 이제 각 repository는 자체 trust confirmation이 필요합니다
- MCP connections가 server가 protocol-version probe에 답변하지 못하거나 malformed reply를 보낼 때 전체 30초 connect timeout에 대해 hanging되는 것을 수정했습니다
- Cloud session 내부의 bridge에서 호스팅되는 Remote Control sessions이 해당 session의 transcript 또는 credentials을 상속하는 것을 수정했습니다
- Claude Desktop 또는 IDE에서 시작된 Remote Control sessions이 로컬 session이 재개될 때마다 새로운 claude.ai session으로 나타나는 것을 수정했습니다. 이제 기존 session에 다시 attach됩니다
- Remote Control sessions이 idle 상태일 때 새로 attach된 clients에 도달할 수 없는 것으로 나타나는 것을 수정했습니다
- Remote Control bridge sessions이 session worker가 재시작될 때 대화 기록을 복원하지 못하는 것을 수정했습니다
- Remote Control: session이 claude.ai 또는 app에서 삭제된 대화를 재개할 때 이제 login에 대한 메시지로 실패하는 대신 replacement를 시작합니다(v2.1.227에서 regression됨)
- Cloud gateway `/login`이 managed settings 로드에 실패할 때 자동으로 종료되거나 "Press Enter to continue" 후 responsive하지 않은 terminal을 남기는 것을 수정했습니다. 이제 reason이 표시됩니다
- Native builds의 voice mode가 voice service가 connection을 거부할 때 "listening…"에서 stuck되는 것을 수정했습니다. 이제 rejection이 즉시 표시됩니다
- mTLS client certificate rotation이 restart를 필요로 하는 것을 수정했습니다. Claude Code는 이제 connection errors 시 rotated cert 및 key를 자동으로 reload합니다
- Malformed AWS 또는 Vertex region values가 request URLs를 빌드하는 데 사용되는 것을 수정했습니다. 이제 default region으로 fallback됩니다
- Bedrock, Vertex, 및 gateway deployments에서 stream idle timeout errors가 request를 실패시키는 대신 recovering하는 것을 수정했습니다
- Truncated text를 포함하는 content-sized overlays가 한 칼럼 너무 넓게 렌더링되는 것과 start-truncated text가 ellipsis로 collapse되는 것을 수정했습니다
- Long shell-command 또는 agent-description preview가 mid-emoji에서 잘렸을 때 stray garbled character를 수정했습니다
- `known_marketplaces.json`에 대한 concurrent writes로 인해 plugin marketplace가 자동으로 unregister될 수 있는 startup race를 수정했습니다
- `/update` 및 `/tui`가 relaunch를 survive하는 작업이 실행되는 동안 restart를 거부하는 것을 수정했습니다
- Usage-limit guidance가 SDK 및 remote sessions에서 unavailable slash commands를 suggest하는 것을 수정했습니다
- Interactive `--advisor fable` launches의 consent message를 수정했습니다. 이는 방금 종료된 interactive session에서 `/model fable`을 실행하도록 말했습니다
- Fullscreen streaming을 개선했습니다: long sessions는 전체 대화가 더 이상 모든 update에서 re-normalized되지 않으므로 responsive하게 유지됩니다
- Managed settings approval dialog를 개선했습니다: endpoint URLs를 표시하고, telemetry-only changes에 대해 더 명확한 wording을 사용하며, routine OpenTelemetry options을 skip하고, server-managed sandbox binary overrides(`sandbox.bwrapPath`, `sandbox.socatPath`, `sandbox.ripgrep`)에 대해 approval을 요구합니다
- `/feedback` 및 `/bug`는 이제 Claude가 responding하는 동안 invoked될 때 turn이 끝날 때까지 기다리는 대신 즉시 open됩니다
- `/plugin install plugin@marketplace`는 이제 먼저 marketplace를 refresh하므로 새로 published된 plugins은 manual marketplace update 없이 install됩니다
- `/code-review`은 high, xhigh, 및 max effort에서 이제 다른 levels처럼 background agent에서 실행됩니다
- Pasted 및 clipboard images는 event loop를 blocking하지 않고 read됩니다
- Remote Control은 이제 network blip 후 약 30분 동안 reconnecting을 유지하며 1시간에 걸쳐 spread된 몇 개의 blips 후에 더 이상 drop되지 않습니다
- Remote Control: 대화를 재개해도 이제 같은 머신의 다른 Claude Code가 여전히 가지고 있는 경우 Remote Control을 자동으로 빼앗지 않습니다. 이를 이동하려면 거기서 `/remote-control`을 실행하십시오
- Updated agent panel: completed subagents는 `/tasks` footer hint로 즉시 hide되며, "↓ N more" overflow indicator는 visibility를 위해 left로 moved됩니다
- Remote Control: terminal은 이제 session이 다른 device에 의해 taken over되었는지, 다른 app에서 ended되었는지, 또는 deleted되었는지를 표시하며 이를 undo할 수 있는 reconnect를 suggest하지 않습니다
- Bash input redirections(`< file`)는 이제 모든 platforms에서 argument spellings처럼 permission-checked됩니다
- Completed background agent를 재개할 때 표시되는 메시지를 shortened했습니다
- Cowork sessions은 더 이상 user-scope memory files의 external @-imports를 inline하지 않습니다
- Shared `/tmp`의 auto-generated cross-session messaging socket directory를 hardened했습니다: pre-planted symlink 또는 다른 user의 directory는 이제 used 대신 refused됩니다
- Linux filesystem sandbox를 protected-path bypass에 대해 hardened했습니다
- `sandbox.ripgrep`을 user, managed, 및 `--settings` settings에서만 honored하도록 changed했습니다. Project settings은 더 이상 sandbox의 ripgrep binary를 override할 수 없습니다
- Custom subagents를 생성하도록 suggest하는 startup tip과 `/powerup` tour의 matching nudge를 제거했습니다
