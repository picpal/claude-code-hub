> 원문: [Claude Code v2.1.327 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)

## 변경사항

- `/install-github-app`이 저장소를 변경하기 전에 확인을 추가했습니다.
- `claude mcp add-json <name> -`을 추가하여 stdin에서 서버의 JSON을 읽을 수 있게 했으므로 토큰이 명령줄에서 벗어날 수 있습니다. Claude Code 세션 내에서는 사용할 수 없습니다.
- 재개된 세션의 이전 메시지를 로드할 수 없을 때 줄을 추가했습니다.
- `/status`에 손상된 agent, skill, command 및 output style 파일, keybinding 오류, 사용할 수 없는 sandbox, 무시된 permission 설정 및 일치하지 않는 hook matcher의 목록을 추가했습니다.
- `/config`에서 다른 설정이 행을 무시할 때 메모를 추가했습니다.
- gateway hint header에 `x-claude-code-managed-settings-checksum`을 추가했습니다. 관리되는 설정이 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`을 설정하는 곳에서 보내집니다. 이미 그렇게 하는 곳도 포함합니다.
- `attributionProject` 설정으로 세션의 billing group을 명명할 수 있도록 지원을 추가했습니다. `admin.billing_group_tag`을 설정한 Claude apps gateway의 경우입니다.
- `/tui classic`을 fullscreen이 아닌 렌더러의 이름으로 추가했습니다. `/tui default`는 여전히 작동합니다.
- Remote Control: worktree 모드에서 서버를 중지할 때 `.env`와 같은 실행 중인 세션의 git-ignored 파일을 삭제하는 문제를 수정했습니다.
- `--use-anthropic-git-proxy`를 사용하는 자체 호스팅 runner가 시작할 때 `GIT_CONFIG_GLOBAL`로 명명한 비어있지 않은 디렉토리를 삭제하는 문제를 수정했습니다. runner는 이제 이를 유지하고 변수를 무시하며 경고합니다.
- project 범위의 `claude mcp add` 및 `claude mcp remove`가 `.mcp.json`에서 `$schema` 또는 다른 도구의 `servers`와 같은 다른 최상위 키를 삭제하는 문제를 수정했습니다.
- `/export`가 기존 파일을 묻지 않고 덮어쓰는 문제를 수정했습니다. 이제 대화상자가 묻고 `/export <name>`은 파일을 유지한 후 `/export`를 실행하라고 말합니다.
- 재시작 후 승인이 도착했을 때 Stop을 누른 후에도 허용한 명령이 계속 실행되는 문제를 수정했습니다. feature flag가 로드되지 않은 cloud 및 자체 호스팅 runner 세션에서 발생합니다.
- Enter로 `/teleport`의 로드 오류 화면을 닫는 문제를 수정했습니다.
- `/plugin`에서 클릭 후 Enter를 입력하면 플러그인이 설치 또는 비활성화되는 문제를 수정했습니다.
- 사용 한도 메뉴 후 추가 Enter에서 반정도 입력된 `!` 명령이 실행되는 문제를 수정했습니다.
- 콘텐츠에 괄호가 있는 일부 `--disallowedTools` 규칙을 수정했습니다.
- `.\scripts\build.ps1 *`와 같이 `.\`를 사용하여 스크립트의 이름을 지정하는 일부 wildcard PowerShell allow 규칙을 auto 모드가 무시하는 문제를 수정했습니다.
- auto 모드에서 실행 중인 Code Mode 스크립트가 auto 모드도 허용한 두 번째 스크립트를 Claude가 시작한 후 permission 프롬프트 및 거부를 받는 문제를 수정했습니다.
- 계정 변경 후 사전 시작된 일부 background 세션이 삭제되도록 변경했습니다.
- 터미널의 사용 한도에서 일시 중지된 workflow가 로그인 후 일시 중지 상태로 유지되도록 변경했습니다. 이전 로그인이 반환되거나 프롬프트를 입력할 때까지입니다.
- 자신의 token이 있는 중첩된 `claude`가 `forceLoginOrgUUID`에 의해 거부되는 문제를 수정했습니다. 세션의 token을 가져오지 않는 명령은 더 이상 `CLAUDE_CODE_OAUTH_SCOPES`를 가져오지 않습니다. 필요한 모든 명령에 설정하십시오.
- 프로세스가 종료된 후 같은 UUID로 다시 보낸 메시지가 있을 때 재개된 세션이 저장된 메시지를 잃는 문제를 수정했습니다.
- 세션이 빈 회신 또는 종료된 명령 후 재개되거나 다른 충돌 또는 background로 이동한 후 보상된 프롬프트를 복구할 때 answer을 잃는 경우를 수정했습니다.
- 재시작 중에 Stop을 누른 후 전송된 메시지를 원격 세션이 잊고 Claude Code가 그 후 충돌한 경우를 수정했습니다.
- `/clear` 후 생성된 작업이 손실되고 지워진 작업이 돌아오는 문제를 수정했습니다. feature flag가 로드되지 않은 cloud 또는 자체 호스팅 runner 세션이 나중에 재개될 때 발생합니다.
- output token 한도로 잘린 회신 직후 compaction이 해당 회신의 tool call과 그 결과를 잃는 문제를 수정했습니다.
- `/config` 및 유사한 명령의 설정 변경이 경고 없이 저장되지 않는 문제를 수정했습니다. 이제 프롬프트 아래의 줄이 그렇게 말합니다.
- `/rewind`가 일부 파일을 복구할 수 없을 때 말없이 닫히는 문제를 수정했습니다.
- 프롬프트가 `/tmp/a.txt`와 같은 파일 경로로 시작할 때 붙여넣은 이미지가 삭제되는 문제를 수정했습니다.
- `--agents`로 전달된 agent가 플러그인이 로드 또는 다시 로드되면 손실되는 문제를 수정했습니다.
- `--resume` picker에서 세션을 재개할 때 플러그인의 agent가 삭제되는 문제를 수정했습니다.
- Claude Code가 `https_proxy` 또는 `HTTPS_PROXY`가 bare `host:port`이고 입력 또는 출력 모두 terminal이 아닐 때 시작을 거부하는 문제를 수정했습니다(desktop app, SDK, cron).
- Linux의 Claude Code가 첫 번째 sign-in 후 Claude apps gateway에 첫 로그인할 때 또는 Code Mode를 활성화할 때와 같이 시작할 때 자신을 재시작하는 동안 shell로 돌아가는 문제를 수정했습니다.
- 모델 설정 fetch가 proxy에서 중단되었을 때와 같이 `claude -p`가 첫 번째 요청 전에 행이 되는 문제를 수정했습니다. 이제 10초 후 이들 없이 계속 진행합니다.
- 간단한 out-of-memory 오류 후 화면이 공백이거나 frozen인 상태로 유지되는 문제를 수정했습니다.
- 화면을 freezing하거나 세션을 종료할 수 있는 드문 display 오류를 수정했습니다.
- cloud 세션이 프로그램이 세션의 network proxy에 수천 개의 연결을 열어둘 때 손상되는 문제를 수정했습니다.
- mod의 `$.model.complete` 또는 `$.model.classify` 호출이 사용 한도를 만났을 때 turn이 hang되는 문제를 수정했습니다. 호출은 이제 API의 오류를 즉시 얻습니다. mod는 이 오류를 처리해야 합니다.
- 수천 개의 닫히지 않은 태그와 매우 긴 WebFetch URL이 있는 compaction 회신의 stall을 수정했습니다. WebFetch는 이제 permission 프롬프트 전에 2,000자 이상의 URL을 거부합니다.
- 수천 개의 `@` mention이 있는 메시지가 Claude가 회신하기 전에 stall되는 문제를 수정했습니다. 이제 처음 100개의 mention만 파일로 조회됩니다.
- 매우 큰 파일에 대한 쓰기를 거부한 후 프롬프트가 freezing되는 문제를 수정했습니다. 거부된 쓰기는 이제 짧은 미리 보기를 표시합니다.
- `/plugin`의 search box에 도착한 key burst로 인한 충돌을 수정했습니다.
- suspended 세션이 재개되거나 종료될 때 Linux 보안 정책이 프로세스 자신에게 신호를 보내는 것을 차단할 경우 거짓 충돌 보고 및 exit code를 수정했습니다.
- remote MCP server가 VPN drop과 같은 더 긴 outage 후 연결을 유지하지 못하는 문제를 수정했습니다. hostname 위에 https로 도달한 다른 머신의 대부분 server는 이제 약 1일 동안 background에서 재시도됩니다.
- compaction 후 Claude가 이미 완전히 읽은 프로젝트 외부의 변경되지 않은 파일에서 Edit이 "File has not been read yet"으로 거부되는 문제를 수정했습니다.
- Grep이 `head_limit` 및 `offset`으로 paging할 때 결과를 반복 또는 건너뛰는 문제를 수정했습니다. content 및 count 결과는 이제 파일 경로로 정렬됩니다.
- 알 수 없는 유형의 출력을 포함하는 Jupyter notebook의 Read 실패 문제를 수정했습니다.
- NotebookEdit이 notebook 파일의 최종 newline을 제거하는 문제를 수정했습니다.
- Read tool이 10MB 이상의 파일을 한 번에 읽기에 너무 클 때 실제 크기 대신 512KB를 보고하는 문제를 수정했습니다.
- Bash tool의 diff가 binary, too large 또는 show하기에 너무 많은 변경된 파일의 이름을 지정하지 않는 문제를 수정했습니다.
- synced 또는 remote-backed 폴더가 파일의 timestamp만 변경했을 때 artifact 게시가 "the source file changed between approval and publish"로 실패하는 문제를 수정했습니다.
- 승인한 새 artifact가 각 새 artifact의 승인을 요구하는 조직에서 cloud scheduled task의 세션에서 거부되는 문제를 수정했습니다.
- Agent SDK를 기반으로 구축된 app이 승인한 후 각 새 artifact의 승인을 요구하는 조직에서 새 artifact가 거부되는 문제를 수정했습니다.
- 요청이 목록을 더 가져오기 실패할 때 `/artifacts`가 목록의 일부를 보여주거나 "No artifacts yet"을 표시하는 문제를 수정했습니다. 이제 다시 시도한 후 전체 목록을 로드할 수 없으면 경고합니다.
- lead와 다른 모델의 in-process agent teammate가 lead의 context 한도에서 compacting되고 잘못된 모델에서 compacting되는 문제를 수정했습니다. 이제 고유한 한도 및 모델을 사용하며 해당 모델의 rate입니다.
- 완료된 subagent가 sibling subagent의 모델 및 effort에서 재개되는 문제를 수정했습니다.
- subagent가 결과를 읽지 않고 자신에 의해 종료되면 main conversation이 background agent가 완료되었음을 알리지 않는 문제를 수정했습니다. auto 모드 외부입니다.
- background agent가 desktop app, web 및 SDK에서 permission 프롬프트에 30초 이상 대기했을 때 Claude가 여전히 실행 중인 것으로 보고하는 문
