> 원문: [Claude Code v2.1.326 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

## 변경사항

- Code Mode가 에이전트 팀과 함께 활성화될 때 켜는 것을 지원하도록 추가되었습니다. 이미 켜 두었다면 팀이 활성화된 상태로 세션이 시작될 때 Code Mode로 시작됩니다
- `--allowedTools`, `--disallowedTools` 또는 `--tools` 값에 완전한 규칙처럼 보이지 않는 항목이 있을 때 시작 경고가 추가되었습니다
- 관리자가 세션 중에 `managed-mcp.json`을 추가할 때 MCP 서버가 로드 중지되는 이유를 설명하는 메시지가 추가되었습니다
- `/status`에 `DISABLE_TELEMETRY`와 같은 공급자 또는 환경 변수가 기능을 끌 때를 나타내는 행이 추가되었습니다
- `/plugin` 및 `claude plugin list`에서 `author` 또는 `homepage`와 같은 형식이 잘못된 `plugin.json` 필드가 무시될 때 메모가 추가되었습니다
- 숨겨진 시작 공지를 표시하기 위해 Ctrl+O가 추가되었습니다
- 요청이 실패한 후 수행할 작업을 말하는 힌트가 빈 프롬프트에 추가되었습니다
- 하위 에이전트 보기에서 Esc가 중지하는 `esc to stop` 바닥글 힌트가 추가되었습니다
- OpenTelemetry 리소스 속성에 `host.name` 및 `host.id`를 포함하기 위해 `OTEL_RESOURCE_INCLUDE_HOST`가 추가되었습니다(기본적으로 꺼짐)
- mod의 `Box`에 `overflowX="scroll"`, `Text`에 `maxLines` 및 `wrap="clip"`이 추가되었습니다
- 소스만 `Edit` 거부 규칙에 적용될 때 파일의 `cp`가 거부되는 문제가 수정되었습니다
- 파일을 삭제하거나 덮어쓰는 Bash 명령(`find -delete`, `cat a > b`, `sort -o`)이 기록에서 검색 또는 읽기로 합산되는 문제가 수정되었습니다
- 일부 rm이 없고 Claude Code가 안정적으로 읽을 수 없는 명령에서 Bash 권한 프롬프트의 오도적인 "Dangerous rm operation" 경고가 수정되었습니다
- 백그라운드 세션이 충돌 후, 다른 폴더에서 다시 열린 후 또는 백그라운드 서비스가 LLM 게이트웨이가 없을 때 셸이 내보낸 LLM 게이트웨이를 잃는 문제가 수정되었습니다. 이제 모델 요청 전에 중지합니다
- 백그라운드 서비스가 프로세스 목록의 프로세스 번호가 다른 사용자의 프로세스로 재사용될 때 사용자의 프로세스(예: SSH 로그인)를 종료하는 문제가 수정되었습니다
- `/permissions`에서 추가되거나 주 대화 도구 프롬프트에서 추가되는 규칙과 `/add-dir` 폴더가 설정 파일을 쓸 수 없을 때 저장된 것처럼 보이는 문제가 수정되었습니다. 터미널이 이제 경고하고 이름을 나타냅니다
- 실패한 MCP `headersHelper` 또는 신뢰하지 않는 폴더에서 실행되지 않는 것이 저장된 OAuth 새로고침 토큰이 없는 대부분의 서버에 대해 다른 세션이 해당 서버 없이 시작되도록 하는 문제가 수정되었습니다
- 특정 키 이름의 관리형 설정이 Claude Code를 시작하지 못하거나 다른 관리형 파일에 영향을 주는 문제가 수정되었습니다
- 천 수준으로 깊게 중첩된 값을 포함하는 설정 파일이 Claude Code를 충돌시키거나 간헐적으로만 적용하는 문제가 수정되었습니다. 64 수준 이상의 값이 이제 경고와 함께 삭제됩니다
- 세션 중반에 오류가 발생하여 저장된 설정 파일이 조용히 건너뛰어지는 문제가 수정되었습니다. 이제 경고가 파일 이름을 나타냅니다
- 관리형 설정에서 설정된 하위 에이전트 모델이 Claude Desktop의 Code 탭에 적용되지 않는 문제가 수정되었습니다. 이제 해당 설정이 공급자 또는 게이트웨이를 선택하지 않는 한 터미널과 같이 사용자 항목을 무시합니다
- 홈 또는 구성 디렉터리가 `/net`을 통한 심볼릭 링크로 도달되고 샌드박스 설정이 읽기를 거부할 때 Linux에서 샌드박스 명령이 시작되지 않는 문제가 수정되었습니다
- 빈 자리 표시자 파일(`.git/config.lock` 포함)이 Claude Code가 샌드박스 명령 중에 중지될 때 Linux의 프로젝트에 남겨지는 경우가 있는 문제가 수정되었습니다
- 위로 이미 신뢰하는 부모 폴더 아래에 표시되는 폴더 신뢰 프롬프트에서 Enter가 Yes에 답하는 문제가 수정되었습니다
- 설정 끝에 추가 Enter가 자동 모드를 기본값으로 설정하는 제안을 수락하는 문제가 수정되었습니다
- 시작 자동 모드 제안 위에 입력된 메시지가 손실되고 Enter가 제안을 수락하는 문제가 수정되었습니다
- 권한 프롬프트에 입력된 메모가 Tab으로 숨긴 후 Claude로 전송되는 문제가 수정되었습니다
- 관리형 설정의 PreToolUse 훅이 직접 도구 호출을 거부할 때 OpenTelemetry `tool_decision` 이벤트 또는 `permission_denials` 항목을 남기지 않는 문제가 수정되었습니다
- `/sandbox` 또는 `/permissions`에서 삭제 질문 위에 입력된 문자가 선택을 이동하는 문제가 수정되었습니다
- 재개된 세션이 이전 차례가 빈 답변으로 끝났을 때 충돌 후 최근 차례를 잃는 문제가 수정되었습니다
- Claude Code의 메모리 부족으로 재개된 세션이 이전 대화 기록을 잃는 문제가 수정되었습니다
- 다시 전송된 파일이 기능 플래그가 로드되지 않은 Linux의 Remote Control 및 클라우드 세션에서 Claude의 변경된 사본을 덮어쓰는 문제가 수정되었습니다. 사본이 `.kept-` 폴더로 이동하거나 새 파일이 저장되지 않습니다
- 백그라운드 세션이 확인 대화를 계속 진행한 세션을 열거나 중지하거나 제거할 때 종료되고 요청이 손실되는 문제가 수정되었습니다
- `claude purge`가 stdout으로 리디렉션될 때 프롬프트를 숨기는 문제가 수정되었습니다. 보이지 않는 Enter 하나가 프로젝트 데이터를 삭제할 수 있습니다. 이제 터미널에 표시됩니다
- 소비 한도 메뉴가 열렸을 때 Backspace와 Enter를 누르면 묻지 않고 월간 한도를 제거하는 문제가 수정되었습니다
- `/rewind`가 느린 백업 복사가 여전히 실행 중인 동안 `/branch`를 두 번 실행한 후 일부 파일만 복원하는 문제가 수정되었습니다
- `/rewind`가 셸 명령이 복원할 수 없는 파일을 변경했을 때 "No code changes"를 표시하는 문제가 수정되었습니다. 변경 추적이 되지 않은 차례가 "Code changes unknown"으로 읽혀집니다
- `/rewind`: Esc가 이제 요약을 취소하고, 목록이 전체 화면에서 과거 프롬프트 하나 이상을 표시하고, 긴 프롬프트가 더 이상 나중 파일 변경 손실에 대한 경고를 숨기지 않습니다
- Ctrl+C 또는 Ctrl+D를 `/skills`에서 두 번 누르면 Claude Code가 종료되고 변경 사항이 손실되는 문제가 수정되었습니다. 이제 패널을 저장하고 닫습니다
- 사용량 한도 메뉴가 입력 중인 초안을 지우고 열리는 문제가 수정되었습니다
- 붙여넣은 텍스트와 이미지가 ↑으로 Esc Esc로 삭제된 초안을 불러올 때 손실되는 문제가 수정되었습니다
- Claude의 질문에 대한 편집된 입력 답변이 Enter를 누르지 않고 이동할 때 이전 텍스트를 보내는 문제가 수정되었습니다
- 목록에서 답변한 질문으로 돌아가면 커서가 첫 번째 옵션에 놓여 Enter가 답변을 바꾸는 문제가 수정되었습니다
- `/feedback` 및 `/bug`가 확인 화면에서 스페이스를 입력할 때 보고서를 보내고 Ctrl+O 또는 Ctrl+Z 후 입력된 보고서를 잃는 문제가 수정되었습니다
- `--add-dir`, `--allowedTools` 또는 다른 목록 옵션 뒤에 입력된 프롬프트가 메시지 없이 손실되는 문제가 수정되었습니다
- `/plan <description>`이 계획 모드가 이미 켜져 있을 때 설명을 무시하는 문제가 수정되었습니다
- 유효한 PDF가 API가 같은 배치에서 다른 PDF 읽기를 거부한 후 대화에서 손실되는 문제가 수정되었습니다
- 단일 메모리 할당 실패 후 화면을 그리는 동안 세션이 끝나는 문제가 수정되었습니다
- Bedrock, Vertex 및 Foundry의 압축, 그리고 원격 측정이 꺼진 경우 메시지 중 하나에 회신하는 대신 요약하거나 Claude의 마지막 답변을 요약에서 생략하는 문제가 수정되었습니다
- Vertex AI의 이미지가 많은 세션이 요청 크기가 30 MB 한도를 초과한다는 400 오류에 걸리는 대신 압축하고 재시도하는 문제가 수정되었습니다
- `max_tokens`이 모델의 한도를 초과했을 때의 오류가 수정되었습니다. Claude Code가 이제 Anthropic API가 보고하는 최대값으로 요청을 재시도합니다
- Bash 도구의 `grep`이 일부 텍스트 파일을 조용히 건너뛰는 문제가 수정되었습니다
- 충돌한 Node 또는 Python 훅이 스택 추적의 첫 번째 줄만 표시하는 문제가 수정되었습니다. 이제 오류가 표시되고 Ctrl+O가 최대 10,000자의 출력을 표시합니다
- `/goal clear` 또는 새 `/goal`이 Stop 훅이 실행 중이고 백그라운드 작업이 여전히 진행 중일 때 입력되어도 고정되지 않는 문제가 수정되었습니다
- 자동 세션 요약이 사용량 크레딧으로 청구된 답변 후에 전송되는 문제가 수정되었습니다. `/recap`은 여전히 작동합니다
- 자동 모드가 사용량으로 계산되는 로컬 분류자에 머물러 있는 문제가 수정되었습니다. 이는 이전 Claude Code의 항목과 같은 오래된 저장
