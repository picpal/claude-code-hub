> 원문: [Claude Code v2.1.239 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.239)

## 변경사항

- 비용 추정(`/cost`, 상태 줄, `--max-budget-usd`)이 이제 데이터 거주지 워크스페이스에 대한 1.1× US 전용 추론 프리미엄을 포함합니다
- Bedrock, Vertex, Foundry 및 기타 이전에 제외된 설정에서 일회성 fullscreen renderer 오퍼를 추가했습니다. 이러한 설정에서의 새 설치는 이제 fullscreen에서 시작됩니다
- `/claude-api upgrade`를 추가하여 Python 프로젝트를 `anthropic` 0.x에서 1.x로 마이그레이션하고, 1.x에 대한 스킬의 Python 참조를 업데이트했습니다(타임아웃은 `httpx.Timeout`이 아닌 `anthropic.Timeout` 사용)
- Cloud 세션: claude.ai에서 동기화된 플러그인이 이제 `name@synced`로 표시되고, `claude plugin enable/disable <name>@synced`와 함께 작동하며, 설치한 동일 이름의 플러그인을 절대 덮어쓰지 않습니다
- Alpine/musl 빌드: 네이티브 이미지 붙여넣기, 클립보드 및 오디오 캡처 애드온이 이제 로드됩니다(runtime에서 거부한 glibc 바이너리 대신 musl 빌드 바이너리)
- 월간 지출 한도가 이미 소진되었을 때 표시되는 사용 한도 메시지가 이제 세션 또는 주간 한도가 재설정될 때를 표시합니다
- 응답 Content-Type 헤더를 제거하는 프록시 뒤에서 Bedrock 스트리밍을 수정했습니다. 이전에는 모든 턴을 비스트리밍으로 다시 실행하여 청구된 API 호출을 조용히 두 배로 늘렸습니다
- SSO 프로필과 `awsAuthRefresh`를 사용하여 Bedrock에서 HTTPS 프록시 뒤에 있을 때 Claude Code가 시작 시 중단되는 문제를 수정했습니다. 자격증명 사전 확인이 이제 `HTTPS_PROXY`를 준수합니다
- 더 이상 존재하지 않는 디렉토리에서 Claude Code를 시작할 때 발생하는 원시 크래시 덤프를 수정했습니다. 이제 명확한 메시지를 출력합니다
- Claude Code 플러그인이 연결되어 있을 때 JetBrains IDE 터미널에서 Edit 및 Write 호출이 약 5초 동안 일시 중지되는 문제를 수정했습니다
- 프롬프트가 대기 중인 상태에서 Esc를 누르면 다음 턴이 조기에 완료될 수 있는 경쟁 상태를 수정했습니다. 이는 세션을 유휴 상태로 두고 Claude가 여전히 작업 중이며 나중에 다시 제출하여 작업을 반복할 수 있게 했습니다
- WebFetch가 의도된 15분이 아닌 전체 세션 동안 만료된 페이지 콘텐츠를 메모리에 유지하는 문제를 수정했습니다
- Cloud 세션(웹, 데스크톱 및 모바일 앱의 Claude Code)이 유휴 워커 재시작 후 plan 모드를 벗어나 재개되는 문제를 수정했습니다
- MCP elicitation 형식이 fullscreen 모드에서 터미널보다 높을 때 잘리는 문제를 수정했습니다. 이제 형식이 창에 맞고, 숨겨진 필드는 스크롤링으로 접근할 수 있으며 Accept/Decline은 항상 표시됩니다
- Cloud 세션에서 mid-session 재연결 시 일시적 5xx 이후 또는 SDK `setMcpServers()`를 통해 원격 MCP 서버가 실패 상태로 남아 있는 문제를 수정했습니다
- 이름 변경 후 약 64 KB 이상의 대화가 작성된 경우 커스텀 세션 제목이 `/resume`에서 사라지는 문제를 수정했습니다
- `/resume`이 경로가 `_`, `-` 또는 `.`과 같은 문자만 다른 다른 디렉토리의 세션을 선택하는 문제를 수정했습니다
- `/resume`과 agents 보기가 파일만 접촉되었거나 단순히 다시 열렸을 때 세션이 최근에 변경되었다고 표시(및 재정렬)하는 문제를 수정했습니다
- 모든 프로젝트 모드의 `/resume`이 삭제된 디렉토리(예: 제거된 worktree)로 `cd`하도록 말하는 문제를 수정했습니다. 이러한 세션은 이제 현재 디렉토리에서 재개됩니다
- fullscreen 모드에서 `dark-ansi` 테마가 배경과 같은 색으로 확장된 도구 결과를 렌더링하는 문제를 수정했습니다
- fullscreen renderer 프롬프트가 답변할 수 없을 때마다 매번 다시 나타나는 문제를 수정했습니다. 이제 3번의 실행 후 중단됩니다
- `**/`로 시작하는 `.worktreeinclude` 패턴이 대상이 gitignored 디렉토리에 있을 때 조용히 아무것도 일치시키지 않는 문제를 수정했습니다
- `.md` 파일이 UTF-8 BOM으로 시작하는 agents, skills 및 commands가 조용히 무시되는 문제를 수정했습니다
- `/insights`가 일부 모델에서 응답에 리터럴 `<message>` 태그를 에코하는 문제를 수정했습니다
- marketplace `metadata.pluginRoot`가 효과가 없는 문제를 수정했습니다. 베어 플러그인 소스 이름이 이제 문서에서 설명한 대로 이를 아래에서 해결합니다
- 브라우저 기반 터미널의 마우스 이동이 마우스 보고서가 여러 쓰기에 걸쳐 도착할 때 프롬프트에 `"35;150;7M"`과 같은 텍스트를 삽입하는 문제를 수정했습니다
- effort/ultracode 상태 배지 색상에 대한 커스텀 테마 재정의가 무시되는 문제를 수정했습니다
- OpenTelemetry trace fragmentation을 수정했습니다. `PreToolUse` 훅으로 연기된 도구 실행이 이제 새 trace를 시작하는 대신 원래 턴의 trace에서 재개됩니다
- agent 보기의 vim 모드를 수정했습니다. 이제 Escape가 NORMAL 모드로 전환되고 프롬프트를 지우는 대신 텍스트를 유지합니다
- `selection:copy` keybinding이 Shift+Arrow 키로 확장된 텍스트 선택을 조용히 드롭하는 문제를 수정했습니다
- `/voice` 시작 팁이 `voice.enabled` 설정을 통해 음성 받아쓰기가 활성화된 후에도 계속 나타나는 문제를 수정했습니다
- shell 모드(`!`) Tab 완성이 `./script` 경로에서 `./`를 드롭하여 셸이 명령을 실행할 수 없게 하는 문제를 수정했습니다
- fullscreen 모드가 권한 프롬프트에 응답하거나 터미널 창을 클릭할 때만 다시 포커스를 맞추도록 버튼을 누르는 문제를 수정했습니다
- fullscreen 모드의 슬래시 명령 패널(예: `/config`, `/model`)이 최신 메시지를 덮는 문제를 수정했습니다. 이제 대화가 패널 위에 고정됩니다
- `/workflows` 상세 대화가 Claude가 아직 응답 중일 때 열렸을 때 터미널을 오버플로우하고 헤더를 화면 밖으로 잃어버리는 문제를 수정했습니다
- Linux sandbox가 존재하지 않는 `.git/config.worktree`를 읽을 수 없게 하여 `extensions.worktreeConfig`이 설정된 repos의 모든 sandboxed git 명령을 중단시키는 문제를 수정했습니다
- 세션의 작업 디렉토리가 삭제된 후 "posix_spawn ENOENT"로 인해 훅이 실패하는 문제를 수정했습니다. 이제 프로젝트 루트 또는 홈 디렉토리에서 실행됩니다
- 패턴이 rules 디렉토리 또는 대상 대신 symlink를 지정할 때 `claudeMdExcludes`가 symlinked `.claude/rules` 파일을 제외하지 않는 문제를 수정했습니다
- 두 Claude Code 프로세스가 하나의 백그라운드 작업의 상태를 공유할 때 Remote Control로 폭주하는 세션 제목 동기화를 수정했습니다(2.1.232 regression). 제목 업데이트가 이제 중복 제거되고 속도 제한됩니다
- 제목이 `/`로 시작하는 세션이 `SendMessage`로 주소 지정이 불가능하고 `ListAgents`에서 "(untitled)"로 표시되는 문제를 수정했습니다
- Ctrl+W, Ctrl+U, Ctrl+K, Option+Backspace, Option+D 및 vim `df`/`dt`가 커서가 내부에 있을 때 손상된 `[Pasted text #N]` placeholder를 남기는 문제를 수정했습니다
- 마스크된(암호 스타일) 입력(예: 로그인 코드 필드)이 Ctrl+Y로 다른 곳에 붙여넣거나 이중 Esc로 지워질 때 프롬프트 히스토리에 저장될 수 있게 하는 문제를 수정했습니다
- 검색 상자에서 Ctrl+Backspace가 단어 대신 한 문자를 삭제하는 문제를 수정했습니다
- 조직 정책 확인에 의해 거부된 요청이 거부가 표시되기 전에 다시 전송되는 문제를 수정했습니다
- 압축 후 표시된 알림을 개선하여 스킬의 원래 인수가 새 요청으로 다시 실행되지 않도록 했습니다
- 도구 사용 행의 긴 파일 경로가 이제 한 줄에 유지되도록 중간에 잘립니다
- 원격 세션이 긴 `SessionStart` 또는 `Setup` 훅이 실행되는 동안 keep-alive를 계속 전송하므로 컨테이너가 mid-hook에서 유휴 상태로 제거되지 않습니다
- `/goal`: 장기 실행 백그라운드 작업에 대한 반복 체크인이 이제 매 30분마다 반복되는 대신 백오프됩니다(30분, 그 다음 1시간, 그 다음 매 2시간마다)
- `/goal`: `claude --resume` 선택기에서 세션을 재개하면 이제 활성 목표가 복원됩니다
- `ListAgents`가 이제 세션에 자신의 이름(피어가 메시지를 보내는 데 사용하는 이름)을 알려주고, `SendMessage`를 자신의 이름으로 보내면 "no agent named …" 대신 그렇게 표시됩니다
- `ListAgents` 및 `/list-agents`가 이제 라이브 팀원을 나열합니다(이전에는 subagents 및 다른 세션만 나타났으므로 연락 가능한 팀원이 없는 것처럼 보였습니다)
- `keybindingFlavor: "readline"`이 이제 단어 키에 대해서도 Bash와 일치합니다. Alt+F 및 Ctrl/Option+→이 단어 끝에서 멈추고, Alt+D가 그곳으로 삭제합니다(Ctrl+Y가 붙여넣습니다) 및 구두점이 단어를 구분합니다
- Persistent retry 모드(`CLAUDE_CODE_RETRY_WATCHDOG`)가 이제 리셋을 무한정 기다리는 대신 조직 지출 한도 및 잔액 부족 오류에 대해 즉시 실패합니다
