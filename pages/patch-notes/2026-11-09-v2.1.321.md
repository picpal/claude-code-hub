> 원문: [Claude Code v2.1.321 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

## 변경사항

- Claude Fable 5.2(`claude-fable-5-2`)를 추가했으며, 이제 기본 Fable 모델입니다 — 1M context, $8/$40 per Mtok이며 cache reads는 $0.20/Mtok입니다
- `claude remote-control`에 `--settings <file>`을 추가했으며, 이것이 시작하는 모든 세션에 설정 파일을 적용합니다. 파일이 변경되면 `claude remote-control`을 다시 시작할 때까지 새 세션이 시작되지 않습니다
- MCP OAuth 요청이 서버가 리다이렉트할 때 refresh token과 같은 secrets을 다른 호스트로 보내는 문제를 수정했습니다
- read-only Bash 명령이 권한 프롬프트 없이 sandbox 외부에서 실행되는 경우를 수정했습니다
- Bash 권한 확인이 잘못된 폴더에서 파일 쓰기를 판단하고 프롬프트를 표시하지 않는 경우를 수정했습니다
- deny rules 및 protected-file 프롬프트가 디렉토리에 `cp` 또는 `mv`로 쓰는 파일에 적용되지 않는 문제를 수정했습니다
- Fable로 전환 후 "Draws from usage credits" 메모가 Fable을 포함하는 요금제의 Enterprise seats에서 표시되는 문제를 수정했습니다
- fallback model이 첫 모델이 응답 전에 차단되었을 때 요청을 거부하거나 중단된 응답을 언급하는 경우가 있는 문제를 수정했습니다
- `claude mcp login`이 Claude Code가 등록한 서버에 다시 로그인할 때마다 SEP-2352 issuer 경고를 출력하는 문제를 수정했습니다
- `NotebookEdit`이 호출이 셀을 지정하지 않았을 때 network paths(UNC shares, WSL folders, `/net` mounts)에서 notebook의 첫 번째 셀을 삭제하거나 덮어쓰는 문제를 수정했습니다
- Edit이 여러 일치 항목 중 첫 번째를 변경하거나, 빈 `old_string`에서 전체 파일을 교체하거나, network paths(UNC shares, WSL folders, `/net` mounts)에서 notebook을 텍스트로 편집하는 문제를 수정했습니다
- `/config`가 새 세션이 auto mode에서 시작될 때 Manual을 기본 권한 모드로 표시하는 문제를 수정했습니다. "Auto (default)"에서 Space를 누르면 이제 Don't Ask를 저장하며, Plan은 저장하지 않습니다
- Windows: `FileChanged` hooks가 session의 working directory에 소문자 드라이브 문자가 있을 때 첫 번째 shell 명령 후 `watchPaths`를 통해 설정된 경로에 대해 중단되는 문제를 수정했습니다
- `--plugin-dir .` 및 `--plugin-dir ./builtin`이 Claude Code의 built-in plugins에 대해 생성된 type 파일을 `builtin` 폴더에 쓰는 문제를 수정했습니다
- context 사용 추정이 정확한 token counts를 사용할 수 없을 때 tool definitions을 과다 계산하는 문제를 수정했습니다
- `/compact`가 web 및 mobile의 Remote Control에서 두 번 표시되는 문제를 수정했습니다
- plugin auto-updates 및 `/plugin` marketplace updates가 repository의 각 worktree 또는 폴더에 대해 plugin을 다시 다운로드하는 문제를 수정했습니다
- auto mode가 `git stash`와 같이 folder가 제거되었다가 mid-session에 복구된 후 project skills, commands 및 agents가 누락된 상태로 유지되는 문제를 수정했습니다. worktree 진입 후도 포함합니다
- `claude -p`가 background 명령이 10분 후 중단될 때 30분이 되는 것으로 Claude에 알려주는 경우가 있는 문제를 수정했습니다
- cloud sessions에서 `pkill`, `pgrep` 및 `pidwait`이 session's own parent processes와 일치하는 문제를 수정했습니다
- Claude in Chrome 및 computer use server processes가 proxy 뒤에서 연결을 stall할 때 parent가 종료한 후 살아있는 문제를 수정했습니다
- 큰 hook output이 Claude를 같은 tool call의 다른 hook's output을 보관한 파일로 가리키는 문제를 수정했습니다
- Claude Code를 embed하는 apps이 다른 hook's `ask` reason 대신 자신의 PreToolUse hook's `ask` reason을 얻는 경우(둘 다 ask할 때)를 수정했습니다
- PreToolUse hook's `ask`이 다른 hook's `defer`가 먼저 완료되고 honor할 수 없을 때 손실되는 문제를 수정했습니다
- 권한 프롬프트 및 background tasks에서 드물게 crash가 발생하는 문제를 수정했습니다
- project skills, commands 및 agents가 Claude가 worktree를 진입한 후 SDK 및 desktop sessions의 menu에서 사라지는 문제를 수정했습니다
- macOS에서 `/desktop`이 Claude Desktop이 설치되지 않았다고 말하지만 `~/Applications`에 있는 문제를 수정했습니다
- OpenTelemetry repository attributes(`vcs.*`)이 pre-started process에서 시작하는 Claude Desktop sessions에서 누락되는 문제를 수정했습니다
- WebFetch가 model이 page를 읽었을 때 텍스트를 반환하지 않으면 "No response from model"을 page content로 Claude에 전달하는 문제를 수정했습니다. 이제 호출이 명확한 오류로 실패합니다
- screen reader mode가 Claude Code 시작 중에 system clock이 뒤로 이동했을 때 startup에서 prompt를 지연시키는 문제를 수정했습니다
- command의 panel이 dialog 종료 후 돌아오지 않아 다음 redraw까지 screen에 panel이나 prompt가 없는 경우가 있는 문제를 수정했습니다
- project's MCP server가 desktop app에 같은 이름의 MCP server 또는 extension이 있을 때 Claude Desktop Code tab session의 첫 번째 메시지 후 연결이 끊기는 문제를 수정했습니다
- 연결이 응답 중간에 끊어질 때 turn이 "API Error: EPROTO: The TLS handshake failed"로 끝나는 문제를 수정했습니다. partial reply는 유지되거나 요청이 2.1.302 이전처럼 재시도됩니다
- 큰 파일에서 반복적으로 single lines을 읽는 long sessions에서 high memory use를 수정했습니다
- fast mode가 fast serving이 rate-limited, overloaded 또는 failing할 때 replies를 손실하거나 모델을 전환하거나 몇 분 동안 재시도하는 문제를 수정했습니다. 이제 같은 모델에서 먼저 standard speed를 시도합니다
- Claude가 중단되었을 때 여러 background agent reports가 대기 중인 후 한 요청이 의도한 것보다 훨씬 많은 background agent reports를 전달하는 문제를 수정했습니다
- Claude Desktop Code tab session의 메시지가 Claude가 아직 작업 중일 때 입력한 후 다른 sessions에서 일시 중지되는 문제를 수정했습니다
- `claude agents`가 `--verbose`와 같은 flag가 line에도 있을 때 `agents` 이전에 입력된 `--permission-mode`, `--dangerously-skip-permissions`, `--model`, `--effort` 또는 `--agent`을 무시하는 문제를 수정했습니다
- Remote Control이 desktop app에서 "login expired"로 off로 표시되지만 connection이 여전히 열려있는 경우를 수정했습니다. 왜냐하면 app이 briefly할 수 없었기 때문입니다 sign-in token을 hand over하려고
- Remote Control 메시지가 "Queue for later"로 전송되어 running turn의 중간에 Claude에 도달하는 문제를 수정했습니다
- session start에서 주어진 git status가 git status가 실패했을 때 clean으로 읽히는 문제를 수정했습니다. 이제 unavailable로 읽힙니다
- session start에서 주어진 git status가 변경사항이 staged되지 않았을 때 나열된 첫 번째 파일을 staged로 표시하는 문제를 수정했습니다
- cloud session의 connector가 매우 긴 이름의 resources를 나열할 때 hang 또는 out-of-memory crash를 수정했습니다
- Remote Control이 session's history가 여전히 uploading되는 동안 연결이 영구적으로 종료된 후 connected로 표시되는 문제를 수정했습니다
- screen reader mode가 agent view에서 conversation으로 돌아올 때 꺼지는 문제를 수정했습니다
- screen reader mode y/n 질문이 질문이 열릴 때 입력된 텍스트 끝의 stray "y"를 yes로 간주하는 문제를 수정했습니다
- cloud sessions가 host이 허용되고 network proxy가 연결할 수 없을 때 host이 아마도 허용되지 않는다고 Claude에 알려주는 문제를 수정했습니다
- MCP server가 reconnected 후 또는 session's directory가 변경되어도 tools가 여전히 loading 중일 때 connected로 no tools로 표시되는 경우가 있는 문제를 수정했습니다
- Claude가 여러 Bash 명령을 한 번에 보낼 때 earlier one이 folders를 변경한 경우 명령이 잘못된 폴더에서 실행되는 경우가 있는 문제를 수정했습니다
- cloud 및 Remote Control sessions에서 Claude가 보낸 파일이 upload가 proxy에서 HTTP 507을 받을 때 즉시 실패하는 문제를 수정했습니다. 이제 upload가 두 번째 시도를 받습니다
- transcript가 읽혀질 때 memory가 부족하면 새 메시지가 저장되지 않고 `claude -p`, SDK 및 VS Code sessions가 hang되는 문제를 수정했습니다
- network의 무언가가 연결을 accept하지만 TLS handshake에 절대 응답하지 않을 때 sign-in, token refresh 및 logout이 indefinitely를 기다리는 문제를 수정했습니다
- 보낸 파일이 text-direction 또는 control characters를 숨기는 이름을 hold할 때 Claude apps에서 다른 이름 아래 표시되는 문제를 수정했습니다. Claude는 이제 such a file을 보내기를 거부합니다
- sub-agent progress summaries가 model이 tool call로 응답한 후 요청을 끝까지 실행하는 문제를 수정했습니다
- Bash reads(예: `grep -r foo "$PWD/src"`)가 path가 typed out된 같은 명령이 asking 없이 실행될 때 permission을 묻는 문제를 수정했습니다
- Claude apps gateway가 `desktop` setting이 managed MCP server's `oauth.omitResource`와 같은 newer field를 hold할 때 시작을 거부하는 문제를 수정했습니다. 이제 경고하고 serve합니다
- Bash 명령이 `.zshrc`가 `KSH_OPTION_PRINT`를 설정하는 zsh users에 대해 empty로 돌아오는 문제를 수정했습니다
- macOS: 유효한 MDM profile을 읽기가 느릴 때 startup에서 "Unable to read managed policy settings"를 수정했습니다. 이제 read는 한 번 재시도되며, timeout은 timeout으로 보고됩니다
- agent view가 아무것도 typed되지 않은 상태에서 update로 restart할 때 다른 agent view's saved input text를 지우는 문제를 수정했습니다
- remote sessions가 restart 후 `UserPromptSubmit` hook이 replayed permission answer를 block할 때 reply를 제공하지 않는 문제를 수정했습니다. 이 hooks는 이제 해당 replay에서 실행되지 않습니다
- `claude remote-control`이 terminal's input이 끝났을 때 첫 번째 실행 질문에서 Enter 없이 입력된 `y`를 accept하는 문제를 수정했습니다
- Claude Desktop이 policy에 `code:` rules이 없는 Claude apps gateway 뒤에서 spend limit warnings를 표시하지 않는 문제를 수정했습니다
- fullscreen sessions with some plugins가 tool result가 짧아져서 screen의 top에서
