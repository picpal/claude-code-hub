## 변경사항

- auto mode를 telemetry 또는 feature flag가 꺼진 상태로 변경했습니다. LLM gateway 뒤를 포함하여 서버가 확인할 수 없는 호출이 요청되거나 거부되며, 기본 제공 분류기로의 fallback이 없습니다. `CLAUDE_CODE_AUTO_MODE_SERVER=0`을 설정하여 기존 동작을 유지할 수 있습니다(Bedrock, Vertex 및 Foundry는 변경되지 않음).
- LLM gateway 뒤의 auto mode를 변경했습니다. `CLAUDE_CODE_AUTO_MODE_SERVER=1`은 `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS`가 설정된 경우에도 서버 측 확인을 켭니다. 관리되는 설정에서 후자를 설정한 경우 `1`도 설정해야 합니다.
- 터미널에서 MCP task에 대한 지원을 추가했습니다. MCP 서버가 tool call을 task로 실행할 때 Claude Code는 즉시 백그라운드로 이동하고 완료되었을 때 Claude에 결과를 알립니다.
- `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` 환경 변수를 추가했습니다. 이를 설정하면 Claude Code가 MCP task를 백그라운드로 즉시 이동하지 않고 tool call 내에서 대기합니다.
- `permissions.denyInsteadOfPrompting` 설정을 추가했습니다. 권한 prompt를 기다리는 tool call이 거부되고 턴이 계속됩니다. 이는 터미널 세션, subagent 및 teammate에서 적용됩니다.
- `/claude-api latency-optimize`를 추가했습니다. Claude API 코드가 사용자를 대기시키는 위치를 찾고 eval에 대해 더 빠른 설정을 시도합니다.
- `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` 환경 변수를 추가했습니다. 이는 telemetry를 끄지 않고 feature-flag fetching을 중지하며, 모든 flag는 기본 제공 기본값을 사용합니다.
- Claude apps gateway 뒤의 개발자가 spend limit이 없을 때 `/usage`에 오늘, 이번 주 및 이번 달의 spend를 추가했습니다. gateway가 이 버전 이상을 실행하는 경우에 적용됩니다.
- Claude apps gateway에 `admin.pooled_conflict_rule` 및 `admin.pooled_priority_order`를 추가했습니다. 여러 그룹에 속한 개발자를 위해 어떤 pooled 그룹 budget이 먼저 지불하는지 설정합니다.
- Claude apps gateway에 선택적 `login_notice` 설정을 추가했습니다. gateway의 브라우저 검증 페이지와 Claude Code의 sign-in 화면에 운영자가 정의한 메시지를 표시합니다.
- Claude apps gateway에 `CLAUDE_GATEWAY_LOG_FORMAT=json`을 추가했습니다. operational 로그 라인이 `severity`, `time` 및 `message`를 포함한 JSON이 되어 필드에서 레벨을 읽는 로그 수집기를 지원합니다.
- Claude apps gateway에 부팅 경고를 추가했습니다. 다른 policy의 `availableModels`도 한 policy가 이름으로 나열하는 custom model id를 허용하는 경우를 경고합니다.
- Claude apps gateway에 시작 경고를 추가했습니다. `desktopHome`이 없는 policy 중 `coworkTabEnabled: false` 또는 `chatSessionRetentionDays`에 의존하는 경우를 Claude Desktop의 11월 10일 변경 전에 경고합니다.
- claude.ai login이 종료되고 Claude Code가 `ant auth login`에서의 sign-in으로 계속될 때 경고를 추가했습니다. 이는 Claude Console 조직으로 사용량을 청구합니다.
- Claude Code가 `ant auth login`에서의 sign-in을 사용하는 경우 시작 시 청구되는 Claude Console 조직의 이름을 지정하는 라인을 추가했습니다.
- `/tasks`에 "Earlier in this session" 행을 추가했습니다. 완료된 subagent를 나열하므로 목록에서 제거되거나 재시작한 후에도 하나를 다시 열고 메시지를 보낼 수 있습니다.
- cloud 세션에서 `/loop` 확인에 참고를 추가했습니다. timer가 컨테이너와 함께 중지되며, 지속되는 loop 옵션을 제공합니다.
- 더 이전 handshake를 사용하는 MCP 서버가 연결되지 않거나 빈 결과를 반환하는 문제를 수정했습니다. Claude Code가 더 이전 서버에서만 사용하는 extension을 선언했기 때문입니다.
- claude.ai connector에서 `--resume` 후 오래 실행되는 MCP tool call이 결과를 보고하지 않는 경우가 있는 문제를 수정했습니다.
- Claude Code가 실행하는 폴더에 `HEAD`라는 파일이나 폴더가 있을 때 claude.ai 및 모바일 앱에서 세션의 diff를 로드하지 못하는 문제를 수정했습니다.
- git repository의 최상위 수준에 `HEAD`라는 파일이나 폴더가 있을 때 `/diff`가 "Diff unavailable"을 표시하는 문제를 수정했습니다.
- 파일을 편집한 64개 이상의 턴이 있는 세션에서 `/diff` pane이 공백으로 열리는 문제를 수정했습니다.
- 앞에 공백, tab 또는 줄 바꿈이 있는 slash command가 실행되지 않고 plain text로 Claude에 전송되는 문제를 수정했습니다.
- login을 새로 고침할 때마다 401로 실패하고 다른 세션에서 401을 발생시키는 요청 문제를 수정했습니다.
- `/context`가 모든 이후 턴에서 전체 visual grid를 Claude에 전송하는 문제를 수정했습니다. Claude는 이제 테이블만 읽습니다.
- 안전 확인을 사용할 수 없어 action이 거부되었을 때 `claude -p`가 auto mode에서 0으로 종료되는 문제를 수정했습니다. 이제 text 및 JSON 출력이 1로 종료됩니다.
- Linux에서 네트워크 파일 시스템(NFS, SMB, Lustre 등)에 있는 프로젝트에 대해 Claude Code가 시작 시 모든 프로젝트 파일을 나열하는 경우가 있는 문제를 수정했습니다.
- 클라이언트가 model change와 auto mode 요청을 연속으로 보낼 때 auto mode가 잘못 거부되는 경우가 있는 문제를 수정했습니다.
- server 측 검토가 세션에 도달하지 않을 때(예: LLM gateway 뒤) `/status`가 "Auto mode server: Enabled"을 표시하는 문제를 수정했습니다.
- 조직이 feedback을 거부한 후 Claude가 작성한 feedback, survey 및 `/feedback`이 계속 나타나는 문제를 수정했습니다.
- Claude가 third-party gateway에서 feedback을 작성하는 문제를 수정했습니다. 여기서는 feedback을 보낼 수 없습니다.
- permission rule 또는 `autoMode` 설정이 매우 클 때 auto mode가 이유를 말하지 않고 action을 거부하는 문제를 수정했습니다. 이제 설명하고, `autoMode` deny rule이 설정되지 않은 경우 터미널에서 묻습니다.
- quoted word로 작성된 명령을 Bash deny 및 ask rule이 놓치는 경우가 있는 문제를 수정했습니다.
- subagent hand-back report가 verbose mode 외에서 확장될 때 내부 marker 및 provenance note를 표시하는 문제를 수정했습니다.
- `claude -p --resume`이 prompt를 사용하고 MCP 서버가 누락된 경우 deferred tool call을 잃는 문제를 수정했습니다. run이 이제 1로 종료되고, call을 유지하며, 이후 입력을 거부합니다.
- 정보 메시지에서 SDK 클라이언트로 전송된 text가 삭제되는 경우가 있는 문제를 수정했습니다.
- 디스크가 가득 찼을 때 Agent SDK host가 generic exit-code 오류 대신 실패한 run의 자체 오류 메시지를 받지 못하는 문제를 수정했습니다.
- `CLAUDE_CODE_RESUME_INTERRUPTED_TURN`이 세션이 다른 permission mode에서 다시 시작될 때 plan mode에서 중단된 턴을 다시 실행하는 문제를 수정했습니다.
- Claude Code가 해당 파일을 작성한 후 몇 초 이내에 settings 파일을 편집할 때 무시되는 문제를 수정했습니다.
- legacy name의 config 파일이 경고 없이 설정을 숨기는 문제를 수정했습니다. Claude Code는 이제 home에 두 개의 config 파일이 있고 어느 것이 사용 중인지 stderr에 알립니다.
- read-only 폴더에 저장하거나 bind-mounted 파일로 저장할 때 디스크가 가득 차면 `~/.claude.json`, settings 및 편집된 파일이 비거나 잘리는 문제를 수정했습니다(한 번에 하나의 세션만 저장).
- Write가 덮어쓸 파일을 읽을 수 없을 때 턴을 refusal로 끝내는 문제를 수정했습니다.
- 거의 즉시 완료되는 background Bash 명령이 완료된 것으로 보고되면서 output을 잃는 문제를 수정했습니다.
- Bash tool의 변경된 파일 diff가 명령이 끝나기 직전에 작성한 파일을 놓치는 문제를 수정했습니다.
- `opus-5-5` 같은 오타난 model 이름이 Claude Code를 업데이트하도록 말하는 문제를 수정했습니다. 이제 의도한 model을 제안합니다.
- notebook이 permission prompt가 열려 있는 동안 변경되었을 때 `NotebookEdit`이 잘못된 cell을 변경하는 경우가 있는 문제를 수정했습니다.
- `/login` 성공 화면에서 Enter를 누른 후 ~0.5초 hang이 발생하는 문제를 수정했습니다. dialog가 이제 즉시 dismiss되고 post-login refresh가 백그라운드에서 실행됩니다.
- screen reader mode에서 질문에 대한 "Other" 답변을 입력하는 동안 Ctrl+G가 external editor를 열지 않는 문제를 수정했습니다.
- Monitor의 WebSocket watch가 `CLAUDE_CODE_PROXY_RESOLVES_HOSTS`가 설정되고 머신에 DNS가 없을 때 proxy 뒤에서 "could not resolve" 오류로 실패하는 문제를 수정했습니다.
- `claude plugin eval` warning이 호출되면 안 되는 tool에 대해 `max: 0`을 제안하는 문제를 수정했습니다. 이는 pass할 수 없습니다.
- background plugin auto-update가 업데이트된 plugin 버전에 의해 추가된 dependency를 설치하지 않는 문제를 수정했습니다.
- Cmd+click이 tmux의 Ghostty에서 agents view에서 열린 세션의 링크를 열지 않는 문제를 수정했습니다.
- `.claude/skills`의 mod hot reload가 삭제된 직후 파일을 놓치고 return을 놓치는 문제를 수정했습니다.
- `/rewind`가 `/branch` 전 checkpoint로 코드를 복원할 때 "No files were restored" 오류로 실패하는 문제를 수정했습니다.
- `/claude-api` skill이 Console web setting이 Managed Agents 세션에 적용되지 않는다고 말하는 문제를 수정했습니다. credential 및 permission 예제를 더 엄격하게 했습니다.
- `timeout DURATION` 같은 plain으로 감싸진 read-only 명령에 대한 불필요한 permission prompt를 수정했습니다. 예: `timeout 30 rg foo`
- WebFetch가 claude.ai shared-chat 링크를 빈 페이지로 설명하는 문제를 수정했습니다. 이제 shared chat을
