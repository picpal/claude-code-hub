> 원문: [Claude Code v2.1.300 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)

## 변경사항

- mod의 prompt decorations에 `virtualText`를 추가하였습니다: prompt 상자에 표시되지만 draft나 제출된 prompt에 입력되지 않는 텍스트입니다
- OpenTelemetry `api_request` 이벤트에 `cache_creation_5m_tokens`과 `cache_creation_1h_tokens`을 추가하여 lifetime별로 cache 쓰기를 분류하였습니다
- mod을 위해 `$.ui.view({ agentId })`을 추가하였습니다: agent의 transcript을 main view에서 볼 수 있으며, `$.ui.view({})`로 돌아갈 수 있습니다
- mod의 `Text`에 `dir` prop을 추가하였습니다: 오른쪽에서 왼쪽으로 읽는 텍스트이며, Windows와 VS Code의 terminal에서 행이 해당 방향으로 읽혀지고 오른쪽에 정렬됩니다
- AWS의 Claude Platform에 `/advisor`를 추가하였습니다: `/advisor`, `advisorModel` 또는 `--advisor`로 선택할 때까지 advisor가 실행되지 않으며, `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`로 이를 해제할 수 있습니다
- trace span에 OpenTelemetry GenAI semantic-convention attributes를 추가하였습니다(`gen_ai.provider.name`, `gen_ai.conversation.id`, `gen_ai.tool.name`, `error.type` 등)
- `agent.spawn` mod hook에서 workflow agent의 `prompt`과 `model`을 다시 작성하는 기능을 추가하였습니다(이전에는 workflow agent만 거부할 수 있었습니다)
- prompt 상자의 텍스트가 입력 없이 변경될 때 발생하는 `prompt.change` mod hook을 추가하였습니다: 회수된 history 항목, 초기화, 실행 취소 또는 plugin의 fill 시
- cloud session이 session 자체의 네트워크 설정에서 organization policy가 host를 차단했을 때 Claude에게 잘못 알리는 문제를 수정하였습니다
- `/autocompact`이 더 작은 auto-compact window를 선택했을 때 높은 token 사용량에 대해 경고하는 문제를 수정하였습니다
- SessionEnd hook이 background command가 실행 중일 때 exit할 때 실행되지 않는 경우가 있는 문제를 수정하였습니다
- `claude --help`이 `--restricted` 설명에서 제거된 tool을 언급하는 문제를 수정하였습니다
- `claude agents`이 pull request 중 하나의 데이터가 불완전하게 반환되었을 때 pull request의 상태를 refresh하지 않는 문제를 수정하였습니다
- cloud session의 container가 교체된 후 background agent가 이미 한 번 resume되었을 때 Claude가 agent를 lost로, resumable하지 않은 것으로 알리는 문제를 수정하였습니다
- typed message가 있는 subagent가 완료 직후 `/tasks`에서 사라지는 문제를 수정하였습니다(conversation으로 돌아갈 방법이 없었습니다)
- child를 보는 동안 완료된 parent agent가 breadcrumb에서 사라지는 문제를 수정하였습니다(child가 top level에서 다시 rooted되어 표시됨)
- agents view가 burst로 도착한 input에서 "up", "down" 또는 "escape"와 같은 typed word를 해당 key로 인식하는 문제를 수정하였습니다(peek를 mid-reply로 이동시키거나 draft를 clear할 수 있음)
- automatic tool search(`ENABLE_TOOL_SEARCH=auto`)이 conversation 도중(예: MCP server가 resume 후 reconnect할 때)에 부분적으로 꺼지는 문제를 수정하였습니다
- `forceLoginOrgUUID`로 거부된 login이 거부된 organization의 token을 저장하거나 `/login` 후에 live로 두는 문제를 수정하였습니다
- Claude Desktop 및 Remote Control session의 diff view가 reftable repository에서 conflicted cherry-pick 또는 revert를 감지하지 못하는 문제를 수정하였습니다
- Artifact tool의 verbose와 ctrl+o line reading이 call의 input이 도착하는 동안 `Artifact("(unprintable path)")`로 표시되는 문제를 수정하였습니다(row는 Bash처럼 "Waiting…"과 "Running…"으로 표시됨)
- session을 resume한 후 작성된 첫 번째 transcript entry가 crash로 transcript의 마지막 line이 짧게 잘려도 손실되는 문제를 수정하였습니다
- Unicode line 또는 paragraph separator(U+2028, U+2029)를 포함할 때 `/branch`이 message를 drop하고 `claude purge`이 subfolder project를 skip하는 문제를 수정하였습니다
- Claude Code가 `--worktree`로 시작할 때 plugin `WorktreeCreate`과 `WorktreeRemove` hook이 실행되지 않는 문제를 수정하였습니다(`--tmux`에서는 아직 미해결)
- reftable ref storage를 사용하는 repository에서 `git commit -q` 후 OpenTelemetry `tool_result` event가 `git_commit_id`를 누락하는 문제를 수정하였습니다
- mod의 `prompt.submit` hook이 다시 작성하거나 drop한 prompt가 여전히 OpenTelemetry `user_prompt` event 및 interaction span에서, session title 요청에서 typed로 기록되는 문제를 수정하였습니다
- mod hot-reloading에 대한 Claude를 위한 note가 transcript에 typed로 표시되는 문제를 수정하였습니다
- agent hook이 `model`을 무시하는 문제를 수정하였습니다: `haiku`와 같은 aliases가 이제 resolve되고, subagent의 model이 더 이상 override하지 않으며, unavailable model이 action을 허용하는 대신 caller의 model로 fallback됩니다
- tag 또는 branch가 commit ID처럼 명명되었을 때 `--worktree` session이 때때로 잘못된 commit에서 시작하는 문제를 수정하였습니다(starting git status가 new worktree의 branch가 아닌 다른 branch를 명명함)
- reftable ref storage를 사용하는 repository에서 branch가 ".invalid"로 표시되고 `--worktree`이 worktree를 다시 열지 못하는 문제를 수정하였습니다
- Claude가 session scratchpad의 파일을 bare filename이나 relative path가 아닌 full path로 명명하는 문제를 수정하였습니다
- `claude remote-control` server가 brief sign-in error(예: locked keychain) 후 connection renewal을 포기하는 문제를 수정하였습니다(이제 retry하고, `claude /login`을 실행해야 할 때 경고함)
- `--worktree`이 origin의 default branch를 fetch할 수 없을 때 bare repository의 worktree에서 실패하는 문제를 수정하였습니다(fallback base는 이제 main repository의 HEAD가 아닌 current checkout의 HEAD임)
- VS Code, Cursor 또는 Devin Desktop integrated terminal에서 Claude Code를 시작할 때 extension을 확인하기 위해 editor의 command-line tool을 두 번 실행하는 문제를 수정하였습니다(이제 한 번 실행함)
- mod의 `prompt.edit` hook이 `chat:newline` keybinding(Ctrl+J 또는 rebound Enter)으로 입력된 newline에 대해 raised되지 않는 문제를 수정하였습니다
- API가 MCP tool의 input schema를 거부했을 때 모든 turn에서 400 error로 실패하는 문제를 수정하였습니다(Claude Code가 이제 conversation의 나머지 부분에서 해당 tool을 parameters 없이 전송함)
- headless 또는 Agent SDK session을 resume할 때 compaction이 output token limit에서 cut된 reply 후에 발생했을 때 compaction이 유지한 recent message를 손실하는 문제를 수정하였습니다(이 버전부터의 compaction)
- MCP server가 compaction 후에 connection을 마친 경우 Claude가 server의 tool 및 instruction에 대해 다음 tool call까지 알리지 못하는 문제를 수정하였습니다
- 여러 session을 제공하는 computer에서 Remote Control session이 아직 실행 중일 때 stopped로 표시되는 문제를 수정하였습니다
- compaction이 같은 turn에서 retried 또는 unfinished reply를 따랐을 때 headless 또는 Agent SDK session을 resume할 때 compaction summary를 손실하거나 pre-compaction history를 복원하는 문제를 수정하였습니다
- Claude가 background command의 output file을 polling하거나 command 실행 중 sleep하는 문제를 수정하였습니다
- feature flag 및 staged rollout이 OS certificate store를 통해서만 trusted된 certificate를 가진 TLS-inspecting proxy 뒤에서 stale로 유지되는 문제를 수정하였습니다
- `claude daemon stop --any`이 "stopped"를 출력하면서 stuck background service가 계속 실행되는 문제를 수정하였습니다(이제 wait하고, force-kill service하며, service가 여전히 있으면 exit 1로 말함)
- telemetry가 꺼져 있을 때 `claude daemon stop`이 output 없이 exit하고 session이 running으로 listed된 문제를 수정하였습니다
- Cowork cloud session에서 Write, Edit 및 NotebookEdit이 자신의 computer의 path에 대해 success를 보고하는 문제를 수정하였습니다(file이 도착하지 않은 경우)
- Claude가 session을 resume하는 history에서 deferred tool을 listed하지 않았을 때 conversation 초반에 로드된 tool을 다시 검색하는 문제를 수정하였습니다
- secondary(dim) text가 dark ANSI theme 및 16-color terminal에서 normal text와 같게 보이는 문제를 수정하였습니다
- cloud session이 organization의 policy를 읽을 수 없을 때 turn당 5분 hang되는 문제를 수정하였습니다(이제 turn이 promptly 끝나고 이유를 말함)
- cloud session이 session이 long reply 중에 restart한 후 이미 answered message를 두 번째로 실행하는 경우가 있는 문제를 수정하였습니다
- Self-hosted runner: runner 및 orchestrator가 아무도 output을 읽지 않을 때 freeze되는 문제를 수정하였습니다(poll, `/healthz` 또는 `SIGTERM` shutdown 없음, log는 latest 256 KiB 유지 및 count drop(Windows 제외))
- Cowork cloud session에서 WebFetch를 개선하여 page가 다시 fetch되는 대신 moments ago에 실패했음을 Claude에게 알리도록 했습니다
- built-in `plugin-authoring` skill에서 mod sharing을 개선하였습니다: Claude가 open 전에 mod의 파일을 key에 대해 scan하고, project 외부의 folder를 scan하기 전에 물어봅니다
- Claude 3 model이 @-mentioned PDF에 대해 받는 note를 개선하여 읽지 않고 답하는 경우를 줄였습니다
- artifact update를 개선하였습니다: Claude가 이제 작은 change를 apply하고 한 번의 call에서 artifact를 republish하며, 더 큰 edit은 단일 response 내에서 수행합니다
- `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` session을 CA-bundle, tool-proxy, git TLS 및 `SSL_CERT_FILE`과 같은 git config variable을 settings에서 무시하도록 변경하였습니다(Claude Desktop에서는 project setting에서만)
- exit를 background command를 stop하도록 요청한 후 1.5초 후에 force-kill하도록 변경하였습니다(fullscreen mode에서는 이전에 running 상태로 남겨질 수 있었습니다)
- Claude Desktop의 Code tab을 `forceLoginGatewayUrl`이 session의 hostname을 제공하는 Anthropic-operated gateway를 명명할 때 managed setting을 적용하도록 변경하였습니다(gateway는 start에서 reachable해야 함)
- `claude gateway`를 `desktop:` policy key에서 start 시 stop하도록 변경하였습니다(Claude Desktop이 gateway에서 사용할 수 없는 key, 이전에는 warning과 함께 시작됨)
- telemetry가 disabled되었을 때에도 api.anthropic.com에 대한 large request가 gzip compression을 사용하도록 변경하였습니다(`CLAUDE_CODE_GZIP_REQUEST_BODIES=0`으로 해제 가능)
- `claude-api` skill을 archive 또는 delete를 요청하지 않으면 Managed Agents session을 남기도록 변경하였습니다
