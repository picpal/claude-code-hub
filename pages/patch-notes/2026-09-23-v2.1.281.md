> 원문: [Claude Code v2.1.281 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.281)

## 변경사항

- Claude Desktop 키가 최신 버전인 경우 `desktop` 정책 블록에서 Claude apps gateway를 지원하도록 추가했습니다. 여기에는 `blockReadsOutsideWorkingDirectories` 및 `disableBypassPermissionsMode`를 포함합니다.
- Claude apps gateway Bedrock upstreams에 `assume_role`을 추가했습니다. gateway는 필요한 경우 다른 AWS 계정의 STS를 통해 가정한 IAM 역할로 Bedrock을 호출하며, 개발자당 선택적으로 하나의 세션을 사용합니다.
- Claude apps gateway Bedrock upstreams에 `guardrail: {id, version}`을 추가하여 Amazon Bedrock 보안 기준을 이를 통해 전송되는 모든 요청에 적용합니다. 모든 Bedrock upstreams에서 설정하거나 설정하지 않아야 합니다.
- Claude apps gateway 구성에 `telemetry.resource_attributes`를 추가하여 Claude Desktop 및 `/login` 세션의 원격 분석에 고정 레이블을 지정합니다.
- `settings.json`에 `"attribution": false`를 추가하여 모든 commit 및 PR 속성을 숨깁니다. 이전 CLI 버전은 이를 포함하는 설정 파일을 건너뜁니다. 버전 간에 공유되는 파일에서 객체 형식을 유지하세요.
- 2026-07-28 프로토콜 연결에서 MCP URL 모드 유도를 추가했습니다. 서버가 Claude Code에 브라우저 기반 플로우를 열도록 요청할 수 있으며, 서버가 완료를 확인할 방법이 없을 때 대기 대화 상자가 화면에 남아 있지 않습니다.
- MCP 서버 확인을 `claude plugin validate`에 추가했습니다. `.mcp.json` 항목이 로드 시 자동으로 삭제될 수 있으며, 선언되지 않은 `${user_config.*}` 참조 및 안전하지 않은 URL을 보고합니다.
- `/insights`에 auto 모드 권장사항을 추가했습니다. 최근 세션에서 auto 모드가 처리할 수 있는 권한 프롬프트의 수를 추정합니다.
- `/skills`, `/mcp` 및 `/plugin` 설치됨 목록에 전체 화면 모드에서 스크롤바를 추가했습니다. `/workflows`가 이제 가지고 있는 것처럼 마우스가 목록 위에 있을 때 나타나며 클릭하거나 드래그할 수 있습니다.
- API 요청이 재시도되는 동안 세션을 종료할 수 있는 충돌("unrecoverable interface error")을 수정했습니다.
- `--max-turns`를 무시하고 무한 재시도할 수 있는 턴을 수정했습니다. 모델이 구문 분석 불가능한 도구 호출과 출력 제한 잘림을 번갈아 사용할 때 발생합니다.
- 재개된 세션이 변경된 형태의 이전 턴을 다시 전송하는 문제를 수정했습니다. 병렬 도구 호출 턴, MCP 도구 호출의 입력 또는 서버가 여전히 재연결 중인 도구 검색 결과, 또는 로드 턴이 중단된 도구 검색 결과입니다. 이로 인해 API가 대화의 이전 추론을 삭제할 수 있습니다.
- 매우 큰 세션을 재개하면 마지막 몇 개의 메시지만 복원되는 문제를 수정했습니다.
- 보류 중인 권한 프롬프트 중에 다시 시작한 후 재개된 세션이 이전과 다른 기록을 전송하는 문제를 수정했습니다. 이로 인해 그 지점부터 프롬프트 캐시가 손상됩니다.
- 도구 호출 중에 종료된 세션을 재개하는 문제를 수정했습니다. Claude는 이제 호출을 확인하고 해당 결과를 알 수 없음으로 표시되며, 수동 재개는 더 이상 숨겨진 "Continue" 메시지를 추가하지 않습니다.
- 이전 advisor 결과가 있는 세션에서 API가 더 이상 읽을 수 없어 매 턴마다 하나의 요청이 실패하고 이전 추론을 반복적으로 손실하는 문제를 수정했습니다. 기록은 이제 한 번만 수복됩니다.
- 도구 검색이 꺼진 상태에서 MCP 서버가 대화 중에 연결을 끊거나 재개 후에도 여전히 연결 중일 때(예: proxy 또는 gateway 뒤) 프롬프트 캐시가 손실되는 문제를 수정했습니다.
- proxy 또는 gateway가 스트림을 깨끗하게 종료하면서 응답이 완료되지 않음으로 표시되는 문제를 수정했습니다. 도구 호출이 중복된 스트림 이벤트에서 두 번 실행됩니다.
- proxy가 응답 중간에 스트림 이벤트를 삭제할 때 "Content block not found"로 실패하는 응답을 수정했습니다. 부분 응답이 유지되며 웹 검색은 이미 도착한 결과를 유지합니다.
- 연결이 스트림의 최종 이벤트 전에 끊어질 때 완료된 빈 응답이 두 번 요청되는 문제를 수정했습니다.
- proxy가 trailing usage-only 프레임을 전송할 때 stop reason이 손실되는 문제를 수정했습니다.
- `CLAUDE_CODE_RETRY_WATCHDOG` 세션이 429/529 대기 실행 후 첫 5xx 또는 끊어진 연결에서 실패하고 5xx의 긴 `Retry-After`에서 상한 없이 자동으로 대기하는 문제를 수정했습니다.
- fast 모드가 서버에서 `Retry-After: 0`을 전송할 때 속도 제한 요청을 연속으로 재시도하는 문제를 수정했습니다.
- 과도한 크기의 이미지를 반환한 도구가 형제 도구 호출을 답변하지 않음 상태로 두고 계속 실행되거나 최종 메시지 없이 턴을 종료하는 문제를 수정했습니다.
- 모델이 너무 긴 이름으로 도구를 호출한 후 대화가 "tool_use.name: String should have at most 200 characters"에 영구적으로 갇히는 문제를 수정했습니다.
- Claude Code가 자신의 메모리 사용량을 읽을 수 없을 때(예: 파일 디스크립터가 부족한 경우) 도구 호출이 "Failed to get memory usage"로 실패하거나 실행 후 실패한 것으로 보고되는 문제를 수정했습니다.
- `--input-format stream-json` 세션(Agent SDK, VS Code 확장) 및 예약된 cloud 세션이 이전 assistant 메시지에 일반 문자열 콘텐츠가 있을 때 매 턴마다 오류로 실패하는 문제를 수정했습니다.
- 비대화형 세션(`-p`, Agent SDK)이 세션 중간에 시작된 디렉토리가 삭제된 후 다음 턴에서 실패하는 문제를 수정했습니다.
- 호스트 측(SDK) MCP 서버가 있는 headless 세션이 호스트가 핸드셰이크 중간에 응답을 중지할 때 첫 메시지에서 멈추는 문제를 수정했습니다. 원격 세션은 이제 최대 몇 초 정도만 대기합니다.
- MCP 서버 또는 플러그인이 구성되지 않았을 때 managed-settings 네트워크 요청(약 80ms, 네트워크에 도달할 수 없을 때 17초 이상)에서 대화형 시작이 대기하는 문제를 수정했습니다.
- 3MB보다 큰 PDF를 읽거나 @-언급할 때 응답하기 전에 최대 2분의 지연이 발생하는 문제를 수정했습니다.
- 특정 PDF 페이지의 읽기가 중단되어 페이지 렌더링이 최대 2분 동안 실행되는 문제를 수정했습니다.
- 권한 대화 상자 및 첨부 파일 확인이 승인 전에 macOS의 `/.vol`, `/.nofollow` 또는 `/.resolve` 경로를 읽는 문제를 수정했습니다. 이는 네트워크 마운트에 도달할 수 있습니다.
- 대상이 명령 치환 출력(예: `rm -rf "$(pwd)"`)인 재귀적 `rm`이 auto 및 `--dangerously-skip-permissions` 모드에서 프롬프트 없이 실행되는 문제를 수정했습니다. 이제 Bash 허용 규칙이 있어도 요청하며, `CLAUDE_CODE_DISABLE_SUBSTITUTION_RM_PROMPT=1`로 실행하지 않는 한 요청합니다.
- NUL 바이트를 포함하는 권한 규칙이 와일드카드 일치로 확장되는 문제를 수정했습니다. 이러한 규칙은 이제 아무것도 일치하지 않습니다.
- sandbox `excludedCommands` 항목이 `git rev-parse --git-dir`, 쉘 기본 제공으로 명명된 프로그램 및 `[WIP]` 또는 `#` 줄을 포함하는 commit 메시지와 일치하지 않는 문제를 수정했습니다.
- sandboxed Bash 명령이 `CLAUDE_CODE_TMPDIR`이 설정될 때 `$TMPDIR`에 쓸 수 없는 문제를 수정했습니다.
- `claude --bg`가 workspace 신뢰 프롬프트를 통과하지 않은 디렉토리에서 백그라운드 세션 및 해당 프로젝트 hooks을 시작하는 문제를 수정했습니다. 이제 먼저 신뢰를 요청하거나 대화형으로 실행되지 않을 때 종료됩니다.
- `--setting-sources`(및 SDK `settingSources`)이 생성된 세션으로 전달되지 않는 문제를 수정했습니다. teammates, `/bg`, `claude agents` 세션 및 `--worktree --tmux`는 이제 상위의 제한으로 시작됩니다.
- Read, Write, Edit 및 NotebookEdit을 수정했습니다. null 바이트를 포함하는 파일 경로는 이제 전체 턴을 종료하는 대신 명확한 오류로 해당 도구 호출을 실패합니다.
- Write가 두 매개변수 이름 아래에서 동일한 값으로 파일 경로 또는 콘텐츠를 두 번 제공하는 호출을 거부하는 문제를 수정했습니다.
- CLAUDE.md 및 작업 디렉토리 내의 `--add-dir` 디렉토리의 규칙 파일이 headless 및 SDK 세션에서 모델에 두 번 전송되는 문제를 수정했습니다.
- 원격 세션이 권한 프롬프트 및 sandbox 네트워크 액세스 프롬프트가 겹치고 둘 다 답변된 후 "needs approval"에 머물러 있는 문제를 수정했습니다.
- cloud 세션이 worker 재시작 직전에 완료된 백그라운드 에이전트에 대해 Claude에 알려주지 않는 문제를 수정했습니다.
- 예약된 routine 및 알림 턴이 원격 세션에서 첫 도구 호출 후까지 turn-start 공지(새로운 도구, MCP 변경, 날짜, todos)를 수신하지 않는 문제를 수정했습니다.
- 예약된 작업 및 `/loop` wakeup이 배달에 실패했을 때 매초마다 다시 발생하여 Claude Code가 턴 끝에 종료될 수 있는 문제를 수정했습니다.
- Remote Control이 조직 정책이 로드되지 않았을 때 "disabled by your organization's policy"를 보고하는 문제를 수정했습니다. 이제 fetch를
