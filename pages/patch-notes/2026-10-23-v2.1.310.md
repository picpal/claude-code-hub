> 원문: [Claude Code v2.1.310 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.310)

## 변경사항

- Monitor tool을 추가하고 Bedrock, Vertex, Foundry의 플러그인 모니터를 지원하며, telemetry 또는 nonessential traffic이 비활성화되었을 때 긴 foreground sleep도 차단됩니다
- `effort-2025-11-24` beta 값 또는 mid-conversation system message를 거부하는 일부 gateway 및 호환 서버 뒤에서 요청이 실패하는 문제를 수정했습니다. Claude Code는 이제 이들 없이 재시도합니다
- `cleanupPeriodDays`를 매우 큰 값으로 설정했을 때 background cleanup이 붙여넣은 이미지 같은 최근 파일들을 삭제하는 문제를 수정했습니다
- "Prompt is too long" 오류 후 compaction이 base64 또는 SVG 같은 dense text가 있는 대화를 너무 많이 유지하여 다음 요청이 실패할 수 있는 문제를 수정했습니다
- 파일 읽기 권한 프롬프트가 symbolic link의 대상을 표시하지 않는 문제를 수정했습니다
- 질문의 auto-continue timeout이 긴 편집 후 external editor가 닫히는 순간에 실행되는 문제를 수정했습니다
- Windows: Git Bash가 없을 때 PreToolUse 및 PermissionRequest hook이 quoted path 같은 quoted string만 있는 hook의 command일 경우 tool call을 통과시키는 문제를 수정했습니다
- Auto mode의 working directory 외부의 첫 읽기 전 프롬프트를 개선했습니다. 이제 해당 읽기를 차단하면 shell command가 권한을 요청할 때를 표시합니다
- transcript file이 매우 클 때 compaction 중 non-interactive session(`-p`, Agent SDK)의 메모리 사용을 개선했습니다
- mod의 `Image`를 `allow-passthrough` 및 `focus-events`가 활성화된 tmux 내에서 kitty, Ghostty, iTerm2 3.5+ 전체 화면 렌더링으로 그리도록 개선했습니다. 이전에는 `alt` text만 표시했습니다
- Linux: `/sandbox` 및 sandbox startup warning을 개선하여 Ubuntu의 user namespace에 대한 AppArmor 제한을 명시하고, bubblewrap이 sandbox를 시작하지 못하게 할 때 이를 해제하는 방법을 표시합니다
- Non-interactive session에서 server의 elicitation이 답변되지 않은 상태로 timeout되는 MCP tool call의 오류를 변경했습니다. 이제 Claude에게 답변이 없었으며 호출을 반복하지 말 것을 알립니다
- [VSCode] plan review card의 "Send feedback and keep planning" 버튼에 Enter를 눌렀을 때 계획을 승인 대신 의견을 다시 보내는 문제를 수정했습니다
- [VSCode] Session history의 Web tab에서 열린 cloud session에 대해 "Switch branch & continue"를 수행한 후 panel이 "Something went wrong"을 표시하는 문제를 수정했습니다
- [Cloud sessions] Claude Code cloud session 및 Remote Control 권한을 Enterprise custom role에 추가하여 Owner가 역할별로 각각에 대한 접근을 제어할 수 있도록 했습니다
- [Cloud sessions] cloud environment의 setup script를 파일에서 로드할 Choose file 버튼을 추가했습니다
- [Cloud sessions] cloud environment edit dialog에서 실패한 저장 및 보관이 dialog 내에 오류를 표시하지 않는 문제를 수정했습니다
- [Cloud sessions] 실패한 routine API token action이 toast만 표시하는 문제를 수정했습니다. 이제 오류가 routine edit dialog에 표시됩니다
- [Cloud sessions] session start checklist를 개선하여 cloud environment의 setup script 출력을 scrolling box에 표시합니다
- [Cloud sessions] admin settings에서 Cloud sessions 또는 Remote Control을 켜는 것을 변경하여 확인을 요청하고 해당 권한이 있는 custom role을 나열합니다
- [Cloud sessions] cloud environment dialog를 변경하여 네트워크 접근, setup script 및 환경 변수를 모든 editor를 한 번에 나열하는 대신 행에서 열도록 했습니다
- [Claude Tag] `!restart` 및 `!help` 같은 `!` command를 bold, italic 또는 strikethrough로 전송할 때 Claude Tag가 일반 메시지로 취급하는 문제를 수정했습니다
- [Claude Tag] background refresh of bundle list가 실패할 때 Claude Tag admin channel 및 workspace page가 load error로 대체되는 문제를 수정했습니다
- [Claude Tag] Claude Tag의 admin settings 내 spend limits page가 channel name이 로드되는 중일 때 어떤 channel도 filter와 일치하지 않는다고 보고하는 문제를 수정했습니다
- [Code Review] Code Review admin section이 repository list의 refresh에 실패한 후 repository 및 switch를 숨기는 문제를 수정했습니다
- [Code Review] Code Review admin section을 개선하여 첫 로드를 재시도하고 여전히 실패할 때 Try again banner를 하나만 표시합니다
