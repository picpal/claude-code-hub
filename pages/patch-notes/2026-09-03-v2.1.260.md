> 원문: [Claude Code v2.1.260 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.260)

## 변경사항

- 전체 화면 모드에서 대화 옆에 열리는 diff panel을 추가했으며, `/diff`로 토글할 수 있으며 Claude가 편집하는 커밋되지 않은 변경 사항을 표시합니다
- `/cost` 및 상태 줄의 `prompt_cache` 필드에 prompt-cache 누락의 가능한 원인을 추가했습니다 (예: tool 정의 또는 system prompt 변경, TTL을 초과하여 대기)
- 헤드리스 세션에 `/reload-plugins`을 추가했으므로 Claude Code Desktop 및 SDK 명령 목록에 나타납니다
- 데스크톱 앱, Remote Control 및 기타 헤드리스 (`-p`/Agent SDK) 세션을 위해 `/advisor`의 텍스트 형식을 추가했습니다 (`/advisor`, `//advisor <model>`, `/advisor off`)
- `openid`를 다시 요청할 때만 refresh에서 id_token을 반환하는 IdP를 위해 Claude apps gateway에 `oidc.scope_on_refresh`을 추가했습니다
- `desktop` policy 블록의 최신 Claude Desktop 키를 지원하도록 Claude apps gateway를 업데이트했습니다 (`userPluginMarketplacesEnabled` 및 `userPluginUploadsEnabled` 포함)
- 경로에 괄호를 포함하는 `Edit`/`Write`/`Read` permission 규칙이 Bash sandbox에 의해 잘못되거나 무시되어 "읽기 전용" 폴더를 쓰기 가능하게 만드는 문제를 수정했습니다
- 컴파일할 수 없는 패턴 (예: 닫히지 않은 `[`)을 가진 하나의 파일 permission 규칙이 모든 파일 편집을 `Invalid regular expression`으로 실패하게 만드는 문제를 수정했습니다. 이제 이러한 deny 규칙은 명시된 리터럴 경로를 보호합니다
- Bash permission 검사가 REPORTTIME, REPORTMEMORY 또는 DIRSTACKSIZE 할당에서 command substitution을 숨기는 zsh 명령을 자동으로 승인하는 문제를 수정했습니다. 이제 승인을 위해 프롬프트합니다
- 기업 root CA가 OS 인증서 저장소에만 있을 때 Bedrock 모델 검색, token 계산 및 AWS SSO/STS credential 호출이 "unable to get local issuer certificate"로 실패하는 문제를 수정했습니다
- macOS에서 `permissions.blockReadsOutsideWorkingDirectories`이 샌드박스된 git에서 사용자의 git config를 숨기고 worktree로 격리된 sub-agent의 자체 checkout을 숨기는 문제를 수정했습니다
- 이전 `/login`에서 남은 API 키도 있는 claude.ai Enterprise/Team 사용자에 대해 managed 설정이 로드되지 않는 문제를 수정했습니다
- `/status`가 로그인한 claude.ai 계정과 구성된 API 키를 마치 둘 다 적용되는 것처럼 나열하는 문제를 수정했습니다. 사용 중이지 않은 credential은 이제 표시됩니다
- bundled skill의 alias (예: `/doctor`의 `checkup`)를 키로 하는 managed `skillOverrides` 항목이 적용되지 않고, `Skill(name)` deny 규칙이 `<dir>:name`으로 나열된 nested skill을 다루지 않는 문제를 수정했습니다
- `model: fable` agents가 `ANTHROPIC_DEFAULT_FABLE_MODEL` pin의 `[1m]` 태그를 무시하고 조용히 200K context window로 실행되는 문제를 수정했습니다
- 이를 사용할 수 있는 조직에 대해 `/model` picker가 Fable 5.1을 표시하지 않는 문제를 수정했습니다 (이는 `/model claude-fable-5-1`로 입력했을 때만 허용됨)
- Claude Fable 5.1의 prompt caching이 tool 결과 후에 연결된 context를 다루지 않아 모든 tool-call 턴에서 캐시되지 않은 input으로 재전송되는 문제를 수정했습니다
- plugin hook 로드 실패 후 모델 전환이 세션의 나머지 부분에서 차단된 채로 유지되는 문제를 수정했습니다. 이제 각 전환은 다시 확인하고 원인을 명시합니다
- organization에서 관리하는 plugin의 marketplace를 로드할 수 없을 때 모델 전환이 세션 동안 차단되는 문제를 수정했습니다
- SDK 제공 MCP server (예: Desktop connector)가 첫 턴에서 누락되고 다음 턴에만 나타나는 문제를 수정했습니다
- 클라우드 호스팅 claude.ai 세션에서 connector가 추가되거나 제거될 때 Chrome의 Claude 도구가 작업 중간에 "Not connected"로 실패하는 문제를 수정했습니다
- flags, joined emoji 및 accented letters가 줄 바꿈에 걸쳐 분할되고, flag 또는 joined emoji가 terminal의 마지막 두 열에 떨어질 때 stale text가 화면에 남아 있는 문제를 수정했습니다 (이제 `…`으로 표시됨)
- Remote Control이 유효한 모델 이름이 아닌 모델 pick을 수락하는 문제를 수정했습니다. 이제 다음 메시지에서 실패하는 대신 오류로 거부됩니다
- `/rewind` 및 `--rewind-files`이 checkpoint backup 파일이 누락되고 실제로 아무것도 복원되지 않았을 때 성공을 보고하는 문제를 수정했습니다
- `/rewind`이 rewound-away 턴의 stale file-read tracking을 남겨두어 "File unchanged since last read" stub과 외부 편집 후 전체 파일 재주입을 야기하는 문제를 수정했습니다
- `-p --resume`/`--continue` (데스크톱 앱에서 사용)이 세션의 worktree 디렉토리가 git 메타데이터를 잃은 후 매번 재시도마다 실패하는 문제를 수정했습니다. 이제 한 번 실패한 후 worktree 없이 재개됩니다
- SendMessage를 통해 다른 agent를 재개한 sub-agent가 해당 agent의 완료로 절대 깨어나지 않는 문제를 수정했습니다 (알림이 주 대화로 전송됨)
- agent team: in-process teammate의 transcript가 긴 API 재시도 대기 중에 메시지를 잃거나 공백이 되는 문제를 수정했습니다 (예: `CLAUDE_CODE_RETRY_WATCHDOG` 아래에서) retry 공지가 실제 메시지를 제거합니다
- 백그라운드로 이동한 세션이 ListAgents에 두 번 나타나는 문제를 수정했습니다 (동일한 이름의 phantom "interactive" twin 하나와 뷰어에서 SendMessage 전달을 받음)
- 많은 세션이 project 디렉토리를 공유할 때 intermittent "task output swap refused" 오류를 수정했습니다
- 전체 화면에서 Ctrl+Z가 shell을 alternate screen에 남기고 일시 중지된 인터페이스에 그려지는 문제를 수정했습니다
- context 압축이 길게 진행되는 동안 Workflow tool subagent가 stalled로 다시 시작되는 문제를 수정했습니다
- URL marketplace의 plugin이 host 앱 (예: Claude Desktop)에 의해 디렉토리로 저장될 때 "marketplace entry path does not stay inside the marketplace directory"로 설치 실패하는 문제를 수정했습니다
- claude.ai, 데스크톱 앱 또는 모바일 (Remote Control)에서 운영하는 세션에서 artifact가 게시될 때 추가 브라우저 탭이 열리는 문제를 수정했습니다
- 일부 Cowork 세션에서 Artifact tool의 첫 호출이 "Invalid tool parameters" 검증 오류로 실패하는 문제를 수정했습니다
- skill 또는 slash 명령을 실행할 때 IDE line 선택이 제거되는 문제를 수정했습니다 ("N lines selected" context가 이제 Claude에 도달함)
- nested subgroup의 GitLab 프로젝트를 위한 repository 검색을 수정했습니다 (예: `gitlab.com/group/subgroup/project`)
- GitLab repository에서 작업할 때 렌더링된 출력의 `owner/repo#123` issue 참조가 github.com으로 링크되는 문제를 수정했습니다. 이제 gitlab.com issue로 링크됩니다
- Glob/Grep: permission 검사 전에 search path가 disk에서 탐사되는 문제를 수정했습니다. 누락된 경로는 이제 Read처럼 permission이 결정된 후 보고됩니다
- 2.1.259 변경사항을 되돌렸습니다 (Bash 인수에 `Read()` deny 규칙 적용). 모든 모드에서 `Read(./**/build/**)` 규칙 아래의 `npm run build`를 거부하고 auto 모드에서도 `cd … && grep`에 프롬프트하게 만들었습니다
- structured output 개선: Workflow `agent({schema})`는 충족될 수 없는 JSON Schema를 미리 거부하고, retry-cap 오류는 이제 마지막 검증 실패를 포함합니다
- unpushed commit이 있는 백그라운드 세션 삭제 개선: 메시지가 이제 branch 및 commit 개수를 명시하고, 다시 삭제하면 worktree를 버립니다
- Claude apps gateway의 refresh-실패 로그를 개선하여 실패한 단계를 명시합니다
- non-interactive (`-p` / SDK) 세션의 idle CPU 사용량을 개선했습니다
- Amazon Bedrock의 Claude apps gateway 개선: aborted request의 input token은 이제 one-token request 대신 AWS의 무료 CountTokens API (grant `bedrock:CountTokens`)로 계산됩니다
- `\(`이 경로 구분자가 아닌 escaped parenthesis로 읽혀지는 `Edit(C:\dir\(name)\**)` 같은 규칙에 대한 settings 오류를 개선했습니다. 이제 명확한 철자법을 제안합니다
- 1M-context 모델의 auto-compact 개선: Opus 및 Fable 세션은 이제 1M-token limit 직전에 압축되고, 매우 큰 context의 복구 압축은 더 이상 10분에 time out되지 않습니다
- `/ultrareview` 및 `claude ultrareview`를 개선하여 긴 실행 cloud review를 최대 45분 대기 (이전 30분)
- Claude Fable 5.1의 `/effort`를 개선했으므로 세션 중 effort 변경이 더 이상 prompt cache를 무효화하지 않습니다
- bundled `claude-api` skill을 업데이트했으므로 Go, Java 및 C# 샘플이 현재 세대 모델 ID를 사용하고, 더 저렴한 worker 또는 sub-agent 모델도 현재 세대여야 함을 명확히 했습니다
- 전체 화면 모드에서 `ctrl+l` / `cmd+k`을 terminal `clear`처럼 transcript view를 지우도록 변경했습니다. 위로 스크롤하여 이전 메시지를 봅니다
- 닫는 괄호 뒤에 텍스트가 있는 permission 규칙 (예: `Bash(ls) x`)을 변경했습니다 (아무것도 일치하지 않았음). 이제 조용히 무시되는 대신 잘못된 설정으로 보고됩니다
- server-managed 설정을 변경했으므로 managed CLAUDE.md (`claudeMd`)는 더 이상 security approval dialog를 트리거하지 않습니다. hook, shell-command, sandbox 및 unsafe `env` 설정은 여전히 승인이 필요합니다
- Claude in Chrome을 변경하여 조직의 Claude in Chrome admin 설정을 따릅니다. admin이 이를 끄면 `--chrome`, `/chrome` 및 browser tool을 사용할 수 없습니다
- Claude apps gateway를 변경하여 Claude Desktop 1.15200.0 이상에서 읽은 list 형식으로 `orgPluginSettings`을 전송합니다. 더 오래된 desktop은 이를 무시합니다
- Claude apps gateway를 변경하여 `desktop` policy가 `managedMcpServers` 또는 `orgPluginSettings`
