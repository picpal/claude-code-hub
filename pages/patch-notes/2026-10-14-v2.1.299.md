> 원문: [Claude Code v2.1.299 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)

## 변경된 사항

- `CLAUDE_CODE_DISABLE_FILE_MENTIONS` 환경변수를 추가했습니다: Claude는 `@` 파일 언급의 경로를 받아서 파일 도구로 읽으며, 파일의 내용을 받지 않습니다
- 터미널에 유휴 압축 기능을 추가했습니다: 약 54분 동안 유휴 상태로 있던 200K+ 토큰 대화는 1시간 프롬프트 캐시가 만료되기 전에 압축되므로, 다음 메시지가 모두 다시 처리하지 않습니다
- `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`를 추가했습니다 (유휴 압축의 200K 토큰 최솟값을 변경할 수 있음); settings.json의 `"idleCompaction": false`로 끌 수 있습니다. 둘 다 v2.1.290 이상이 필요합니다
- `$.prompt.media`를 추가했습니다 (관리 설정으로 설치된 mod의 `prompt.submit` 훅에서 프롬프트에 첨부된 이미지 또는 문서의 바이트를 읽을 수 있습니다)
- `$.session.identity()`를 추가했습니다 (관리 설정으로 설치된 mod용): 세션의 로그인 방식, 관리 `forceLoginOrgUUID`가 해당 조직을 나열할 때의 조직 및 이메일
- mod의 `Text`에 `size`, `weight`, `mono`, `tabular`을 추가했습니다 (`xs`부터 `xl`까지의 이름 있는 간격 단계를 `Box`에 추가); `bold`는 `weight` 대신 사용되지 않습니다
- `claude self-hosted-runner orchestrator`에 `--shutdown-drain-sec`을 추가했습니다: SIGTERM에서 폴링을 중지하고 진행 중인 폴 및 실행 중인 spawn 훅에 최대 그 만큼의 초를 제공합니다
- skill의 frontmatter, source, plugin 이름 및 파일 경로를 mod의 `skill.prompt` 훅이 받는 것에 추가했습니다
- agent 뷰에 `/effort` 및 `/fast`를 추가했습니다 (새 세션이 시작되는 것을 설정할 수 있음); 그곳의 베어 `/model`, `/effort` 또는 `/fast`는 이제 선택기를 엽니다
- 백그라운드 세션에서 시작된 `--safe-mode`에 대한 "안전 모드" 라인을 agents 뷰 peek 패널에 추가했습니다
- bypass 권한을 사용할 수 있기 때문에 plan 모드가 대부분의 편집 또는 명령 전에 요청하지 않을 때 일회성 알림을 추가했습니다
- `claude plugin eval`에 `--disallow-tools` 및 `disallowed_tools` 사례 필드를 추가했습니다 (Agent와 같은 특정 기본 도구를 eval 실행에서 제외할 수 있습니다)
- Claude Desktop의 Code 탭에서 attribution 블록을 끄는 지원을 추가했습니다: Claude apps gateway의 `code` 정책의 `env`에서 `CLAUDE_CODE_ATTRIBUTION_HEADER=0`을 설정합니다
- Claude apps gateway 뒤의 Claude Code 세션에서 attribution 블록에 필드를 추가했습니다; `CLAUDE_CODE_ATTRIBUTION_HEADER=0`으로 블록을 제거합니다
- `session.append` mod 훅에 `queue` door를 추가했습니다 (mod에서 transcript의 큐 레코드를 전송된 프롬프트와 다르게 만들 수 있습니다)
- `/plugin` 및 `claude plugin validate`에서 조직이 Claude Code를 관리하는 경우 mod의 훅을 건너뛰는 것을 명명하는 알림을 추가했습니다
- `/usage` 경고에서 최대 effort, 워크플로우, always-on 컨텍스트 및 대규모 도구 결과를 추가했습니다
- 거부된 클라우드 세션의 오류를 수정했습니다 (`apiKeyHelper`의 키가 사용 중일 때 잘못된 조직을 가리킬 수 있음)
- 커스텀 `ANTHROPIC_BASE_URL`의 끝이 "Prompt is too long · automatic compaction failed"인 gateway 특정 모델 이름의 세션을 수정했습니다 (200K 토큰 근처에서 요청을 보내는 대신)
- 모든 턴 끝에 프롬프트를 제출하는 mod를 수정했습니다 (headless 실행을 `--max-turns`, `--max-budget-usd`, 인터럽트 또는 호스트의 대화 끝 이후로 유지)
- 클라우드 세션이 도구 그룹의 한 줄 레이블 다음에 모델의 follow-up 텍스트를 표시하는 경우가 있었던 것을 수정했습니다
- Write 및 Edit 도구가 config 디렉터리 경로에 `.claude`가 없을 때 accept-edits 모드에서 세션의 mods 폴더에 mod를 묻지 않고 생성하는 것을 수정했습니다
- 설치된 mod가 원격으로 끄진 후에도 열린 세션에서 실행을 유지하는 것을 수정했습니다; 이제 턴 사이에 언로드됩니다
- Cowork 및 claude.ai 클라우드 세션에서 Edit 및 Retry가 메시지가 `UserPromptSubmit` 또는 mod `prompt.submit` 훅이 여전히 실행 중일 때 중지되는 경우 실패하는 것을 수정했습니다 (2.1.296의 회귀)
- 설명 없이 시작된 agent 팀원이 프롬프트의 일부 자격증명을 task 설명에 유지하는 것을 수정했습니다
- Remote Control 또는 클라우드 세션의 claude.ai 뷰가 느린 연결을 통해 대량의 이벤트를 업로드할 수 없을 때 고정되는 것을 수정했습니다
- sandboxed shell 명령이 `--plugin-dir` 폴더에 쓸 수 있는 것을 수정했습니다 (Claude Code는 그 코드를 다시 로드하고 sandbox 외부에서 실행합니다)
- 하중 디버그 로깅(`--debug`, `--debug-file`) 중 메모리 성장 및 디버그 로그가 쓰기를 중지한 디스크 또는 네트워크 마운트에 있을 때 종료 시 행(hang)을 수정했습니다
- 디버그 출력이 stderr로 이동하고 부모 프로세스가 읽기를 중지할 때 메모리가 무한 증가하는 것을 수정했습니다
- `rm`을 실행하지 않는 shell `-c` 스크립트에서 rm 프롬프트를 수정했습니다. 런타임에 스크립트에서 빌드된 rm은 Claude Code가 읽을 수 없을 때 `CLAUDE_CODE_STRICT_INLINE_SHELL_RM_PROMPT=1`을 하지 않는 한 프롬프트하지 않습니다
- fullscreen 모드의 확장 transcript 행에서 단어를 double-clicking하면 행을 선택하는 대신 축소하는 것을 수정했습니다
- `claude mcp list`, `claude doctor` 및 `/status`가 빈 `.mcp.json`을 유효하지 않은 것으로 보고하는 것을 수정했습니다
- `/btw`가 fullscreen에서 위로 스크롤할 때 transcript를 아래로 점프하는 것을 수정했습니다
- sandboxed 명령이 WSL2에서 `bwrap: Can't mkdir /mnt/c/Program Files/ClaudeCode`로 실패하는 것을 수정했습니다 (sandbox가 Windows 드라이브에 쓸 수 있을 때)
- scheduled wakeups (ScheduleWakeup)이 Agent SDK, IDE 및 `claude remote-control` 세션에서 백그라운드 작업이 실행되는 동안 실행되지 않는 것을 수정했습니다
- mod의 `prompt.submit` 다시 쓰기가 붙여넣은 이미지가 있거나 읽을 수 없는 이미지가 있는 일부 프롬프트에 대해 자동으로 삭제되어 입력한 그대로 프롬프트를 전송하는 것을 수정했습니다
- Remote Control 프롬프트가 같은 배치의 다른 queued 프롬프트를 전달하지 못했을 때 손실되는 것을 수정했습니다
- 훅을 전달한 Remote Control 프롬프트가 다음 queued 프롬프트의 훅을 중단할 때 prompt history에서 삭제되는 것을 수정했습니다
- 로그인, MCP 서버 및 프로젝트 신뢰가 sandboxed 명령이 config 디렉터리에 빈 `.config.json`을 남겼을 때 Linux에서 손실되는 것으로 보이는 것을 수정했습니다
- `/sandbox`가 프로젝트 폴더를 쓸 수 없기 때문에 설정을 저장할 수 없을 때 성공을 보고하는 것을 수정했습니다; 이제 변경 사항이 없으며 이유를 말합니다
- SDK 및 headless 세션이 호스트가 auto 모드를 지원하지 않는 모델로 전환한 후 auto 모드에 머무르는 것을 수정했습니다
- MCP config에서 `constructor` 또는 `prototype`이라는 이름의 MCP 서버가 연결되지 않는 것을 수정했습니다
- `constructor` 또는 `toString`이라는 이름의 MCP 서버의 도구가 auto 모드 및 bypass 권한 모드에서 권한을 요청하는 것을 수정했습니다
- 다른 Claude Code 프로세스가 claude.ai-synced 플러그인을 업데이트했을 때 시작 중에 가짜 "synced[0] commands path not found" 플러그인 오류를 수정했습니다
- Artifact 도구가 커넥터 또는 기타 액세스를 요청하는 게시가 서버 또는 프록시(HTTP 403)에서 거부되었을 때 다시 시도를 권고하는 것을 수정했습니다; 이제 그렇게 말하고 사용자에게 알려줄 사항을 표시합니다
- Cowork 클라우드 세션이 시간 초과 또는 최근 동기화를 다시 사용하는 다시 시작의 플러그인 다시 로드 후 이전 계정 플러그인에 머무르는 것을 수정했습니다
- 문서 블록이 Claude가 작업 중일 때 전송된 자신의 메시지에서 삭제되는 것을 수정했습니다
- Chrome의 Claude가 브라우저가 연결되지 않았을 때 권한을 요청하는 것을 수정했습니다; 이제 확장 프로그램이 연결되지 않았음을 말합니다
- fullscreen "Update installed" 알림이 유휴 "/clear to save tokens" 힌트 뒤에 숨겨지는 것을 수정했습니다; 이제 힌트 옆에 표시됩니다
- mod 훅이 `.catch` 포함 또는 미포함이 다른 mod의 noun을 기다릴 때 끝나지 않고 다시 실행되는 것을 수정했습니다 (mod의 작업은 호출 외부에서 수행됩니다)
- Claude apps gateway가 정책의 `availableModelsMatch: exact` 또는 `deniedModels`이 차단하는 모델을 제공하는 것을 수정했습니다; 이제 400으로 답하고 모델 목록에서 제외합니다
- 관리 설정 파일이 `ANTHROPIC_BASE_URL`을 설정할 때 server-managed 설정 요청이 Anthropic에 third-party gateway의 API 키를 전달하는 것을 수정했습니다
- 커스텀 `ANTHROPIC_BASE_URL`을 통한 스트림이 180초 동안 데이터가 도착하지 않은 후 중단되는 것을 수정했습니다; 이제 300초를 기다리며, 기능 플래그 로드 여부와 관계없이 입니다
- mod의 `tool.describe` 또는 `prompt.section` 응답이 `$.ui.invalidate` 후 변경되었을 때 Claude에 도달하지 않는 것을 수정했습니다; 새 응답이
