## 변경사항

- `strictKnownMarketplaces` 및 `blockedMarketplaces` 관리 설정에 소유자 와일드카드 항목(`"owner/*"`)을 추가하여 GitHub org의 모든 marketplace repo를 허용하거나 차단할 수 있도록 함
- workflow agents, forked skills, slash commands 또는 resumed background agents의 요청된 subagent model이 제한되었을 때 경고를 추가하여 부모 model이 대신 실행되도록 함
- cloud sessions에서 `/teleport` 힌트를 추가하여 `claude --teleport <session id>`로 로컬에서 계속 진행하는 방법을 표시
- 작성된 명령어가 권한 검사에서 자신의 일부를 숨길 수 있는 Bash 권한 우회 문제를 수정
- 탭이나 보이지 않는 Unicode로 채워진 명령어가 더 이상 승인 대화에서 명령어의 일부를 숨길 수 없도록 권한 프롬프트를 수정
- workflow scripts가 동적 `import()`을 사용하여 workflow sandbox 외부의 코드를 실행할 수 없도록 수정
- agent definition의 `bypassPermissions` mode가 org bypass-permissions disable policy를 무시하는 권한 gap을 수정
- mid-session `/cd` 이후 session을 재개할 때 빈 상태로 돌아오는 문제를 수정
- gateway model discovery가 `vertex_ai/claude-*` 또는 `bedrock/anthropic.claude-*`와 같은 provider-prefixed IDs로 등록된 Claude models를 숨기는 문제를 수정
- Anthropic model IDs가 아닌 `modelOverrides` keys가 session의 canonical model ID로 취급되는 문제를 수정하였으며, 이제 문서화된 대로 알 수 없는 keys는 무시됨
- 관리 설정: server-delivered settings가 더 이상 machine-local `managed-settings.json` 또는 MDM profile의 env block을 비활성화하지 않으며, admin env는 이제 key별로 병합됨
- `sandbox.filesystem.denyWrite`가 working directory를 포함할 때 Linux에서 sandboxed commands 시작에 실패하는 문제를 수정
- forked background agents가 rebuild 중 fork의 parent prompt 실패 시 session의 나머지 기간 동안 "already resuming" 상태로 고정되는 문제를 수정
- resumed session의 history가 malformed diagnostics attachment를 포함할 때 매 turn마다 실패하거나 interactive app이 응답하지 않는 오류 화면에 남는 문제를 수정
- 특이한 `git push` output을 파싱할 때 발생하는 드물지만 발생하는 hang 문제를 수정
- `CLAUDE_CODE_DISABLE_1M_CONTEXT`를 고정 목록뿐만 아니라 native 1M window를 가진 모든 Claude model을 auto-compaction을 통해 200K로 제한하도록 변경하였으며, auto-compaction이 session을 200K로 유지하지 못할 때 시작 경고가 나타남
- auto-compact를 변경하여 인식할 수 없는 model IDs의 sessions를 가정된 context window 내에서 유지하고 이를 초과하도록 하지 않음. 이전 동작을 복원하려면 `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1`을 설정
- `/review`를 `/code-review`의 alias로 변경하여 현재 diff 또는 PR을 검토함(`/code-review <level> <pr#>`), deep cloud review를 위해 `/code-review ultra`를 사용
- effort level이 없는 `/code-review`를 변경하여 마지막에 입력한 level을 재사용하도록 함, `/code-review high`와 같은 level을 입력하여 변경
