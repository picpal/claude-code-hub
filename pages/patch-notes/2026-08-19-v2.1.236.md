> 원문: [Claude Code v2.1.236 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.236)

## 변경사항

- `ANTHROPIC_DEFAULT_MODEL` environment variable를 추가했습니다: 새 세션이 시작될 때의 모델을 설정하며, `/model` 선택은 여전히 이를 재정의하고 재시작 후에도 유지됩니다 (`ANTHROPIC_MODEL`과 달리)
- cross-session `SendMessage`에 `notify_when_idle`을 추가했습니다: 이 머신의 다른 Claude Code 세션에 다음으로 유휴 상태가 될 때 한 번의 알림을 보내도록 요청합니다 — opt-in, 일회성, 폴링 없음 (macOS 및 Linux)
- Sandbox: macOS에서 wildcard read-deny 규칙 (예: `**/.env`)이 이제 허용된 읽기 영역 내에서 우선 적용되며, 일치하는 디렉터리의 내용을 포함하고, 거부된 파일의 이름을 바꾸어도 우회할 수 없습니다
- 세션이 전환한 디렉터리가 제거된 후 clipboard copy, background housekeeping, background 세션, 및 local MCP 로그가 손상되는 문제를 수정했습니다 (2.1.229 이후)
- fullscreen renderer가 단일 실패한 시작 후 영구적으로 실패하는 문제를 수정했습니다: 이제 모든 후속 시작 시 종료하는 대신 classic renderer로 폴백합니다
- `/model` picker가 터미널보다 더 높게 렌더링되는 문제를 수정했습니다: 이제 창에 맞는 만큼의 모델만 표시하고, 나머지는 스크롤로 접근 가능합니다
- 잘못된 closing tag로 인해 메시지 텍스트가 summary 필드 내에 남아있을 때 `SendMessage` 호출이 거부되는 문제를 수정했습니다
- subprocess 시작에 실패할 때 처리되지 않은 promise rejection을 수정했습니다. 예를 들어 Windows interop이 비활성화된 WSL의 `powershell.exe` (2.1.234의 regression)
- fullscreen mode에서 터미널 크기가 조정된 후 다음 업데이트까지 새로 전송된 메시지가 표시되지 않는 경우가 있는 문제를 수정했습니다
- multi-line prompt를 지운 후 prompt 위에 남아있을 수 있는 빈 띠와 fullscreen mode에서 터미널 크기를 조정했다가 다시 조정한 후 pane이 다시 그려지지 않는 문제를 수정했습니다
- managed-settings 승인 prompt가 시작 시 나타나지 않으면서도 첫 번째 키 입력을 승인으로 캡처하는 경우가 있는 문제를 수정했습니다
- tmux의 terminal tab 제목이 점프하는 문제를 수정했습니다 (iTerm tmux integration): 이제 제목은 960ms마다 애니메이션하는 대신 텍스트가 변경될 때만 작성됩니다
- cloud environments 목록이 비어있거나 잘못된 형식으로 반환될 때 불명확한 오류를 수정했습니다
- Fable 5 처음 사용 시 usage-credits prompt가 Remote Control을 사용할 때 답변이 없으면 60초 후 fallback model을 자동 선택하는 문제를 수정했습니다
- `~/.claude.json`의 캐시된 guest-pass reward가 잘못된 형식일 때 spinner tips가 나타나지 않고 반복되는 background 오류가 발생하는 문제를 수정했습니다
- 세션의 작업 디렉터리가 삭제된 후 SDK/VS Code 세션에서 skills hot-reload가 모든 skills 변경 시 오류를 발생시키는 문제를 수정했습니다 (2.1.229+)
- self-hosted runner 세션이 유휴, retire, 또는 startup timeout으로 해제될 때 post-session hook이 완료되기 전에 다른 runner에서 재개되는 경우가 있는 문제를 수정했습니다
- Clawd mascot의 눈과 발이 일부 글꼴 크기의 iTerm2에서 고르지 않게 렌더링되는 문제를 수정했습니다
- 가끔 발생하는 runaway session recaps를 수정했습니다: recap 텍스트 (자동 및 `/recap`)는 이제 400자로 제한되며, 단어 경계에서 잘립니다
- 시작 성능을 개선했습니다: session counter는 이제 background에서 작성됩니다
- auto mode를 개선했습니다: `Monitor` allow 규칙이 이제 auto mode가 활성화되어 있는 동안 따로 설정되므로 Monitor 명령은 Bash 명령과 동일한 방식으로 검토됩니다
- Bedrock, Vertex AI, Foundry에서 auto mode를 개선했습니다, 그리고 telemetry가 비활성화될 때: classifier는 이제 Claude API와 동일한 기본값을 사용하며, severity-scored classification을 포함합니다
- auto mode를 개선했습니다: git status 확인은 더 이상 repo의 `status.showUntrackedFiles=no` 설정으로 인해 깨끗한 트리라고 잘못 보고할 수 없습니다
- `/model` picker를 변경했습니다: 이제 최신 모델의 이름만 강조하므로 highlight는 목록의 임의 부분이 아닌 새 릴리스를 표시합니다
- `/goal`: 목표가 장시간 실행되는 background 작업 뒤에 있는 유휴 세션이 이제 당신의 복귀를 기다리는 대신 30분 후 (그 다음 1h, 2h) 자동으로 체크인합니다
- `/usage`는 이제 Team 및 Enterprise 멤버를 위한 usage-credits spend 행을 표시하고, 아무것도 사용되기 전에 0%의 capped 행을 표시합니다
- print/SDK mode의 SIGTERM은 더 이상 종료하기 전에 interrupted turn이나 synthetic tool denial을 기록하지 않습니다; 실행 중인 명령은 여전히 종료되고 프로세스는 여전히 code 143으로 종료됩니다
- slash-command typo 또는 이 세션에서 사용 불가능한 명령에서 Enter를 누르면 이제 가장 가까운 fuzzy match를 실행하는 대신 이를 보고합니다; prefix 및 alias는 여전히 실행됩니다
- Remote Control은 이제 CLI가 종료되거나 터미널이 닫힐 때 세션을 몇 초 내에 오프라인으로 표시합니다
- `SendMessage`는 이제 rapid burst가 세션의 inbox가 허용하는 것을 초과할 경우 세션에 대한 추가 메시지를 사전에 거부하고, 전송된 것으로 보고하면서 dropped되는 대신
- prompt 경계의 session title chip을 footer의 오른쪽 가장자리와 정렬했습니다
- 오른쪽 정렬된 footer 항목 (goal indicator, session state, background agent status) 및 truncated notice가 이제 prompt 영역의 나머지 부분과 일관된 오른쪽 margin을 공유합니다
- [VSCode] transcript에 screen reader 지원을 추가했습니다: 회신, 권한 요청, 오류, 및 상태 변경에 대한 live announcement, 그리고 turn별 heading 네비게이션
