> 원문: [Claude Code v2.1.287 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)

## 변경사항

- Claude Mods가 추가되었습니다: plugins이 이제 더 깊은 동작을 수정할 수 있습니다
- You should know가 추가되었습니다. 이는 내장 mod으로, side agent가 당신이나 Claude가 놓칠 수 있는 것을 감시하고 플래그를 지정합니다. `/plugin enable cc-plugin-you-should-know@builtin`으로 활성화할 수 있습니다 (telemetry가 활성화된 first-party sessions의 경우)
- agents view에 `n:<text>` filter가 추가되었습니다. 이는 session names과 tasks와 일치합니다. filter는 이제 일치 항목을 축소된 섹션에 표시하며, Enter는 첫 번째 일치 항목을 엽니다
- OpenTelemetry `user_prompt` event에 `prompt_text`가 추가되었습니다. 이는 `prompt`의 복사본으로 dotted keys를 중첩하는 backends용입니다. `prompt`를 삭제하거나 마스킹하는 곳이면 이것도 삭제하거나 마스킹하십시오 (anthropics/claude-code#70763)
- 2025-11-25 protocol의 MCP servers로부터 URL prompts가 추가되었습니다 (예: 로그인). 이 업데이트 후 server가 더 이상 연결되지 않으면 MCP config entry에 "bareElicitationCapability": true를 추가하십시오
- Windows: Bash tool을 거부하면 PowerShell tool도 비활성화되어 Claude가 shell tool을 갖지 못할 때의 startup warning이 추가되었습니다
- Self-hosted runner: GitHub CLI가 설치되지 않은 macOS 및 Linux machines에서 Anthropic-managed git을 사용하는 sessions을 위해 built-in `gh api` (REST only)가 추가되었습니다
- user account를 가지지 않은 agent가 소유한 remote sessions에서 organization이 이를 허용할 때에도 fast mode가 꺼진 상태로 유지되는 문제가 수정되었습니다
- reconnect request가 응답을 받지 못했을 때 Remote Control이 수 분 동안 messages를 받지 못하는 문제가 수정되었습니다. 이제 30초 후에 포기하고 재시도합니다
- hook의 script file이 누락되었을 때 `asyncRewake`로 구성된 hooks가 "found issues" notifications으로 Claude를 계속 깨우는 문제가 수정되었습니다. 이제 broken hook이 한 번만 보고됩니다
- model의 response stream이 데이터 도착이 없는 상태로 정지되어 있을 때 tool heartbeats이 SDK hosts에 도달하지 못하는 문제가 수정되었습니다
- Bedrock 및 Vertex startup model checks이 강제된 `availableModels` list를 무시하여 `/model`이 하나의 Opus row로 축소될 수 있는 문제가 수정되었습니다
- Claude in Chrome browser picker가 Chrome에 도달할 수 없을 때 JSON parse error를 표시하는 문제가 수정되었습니다
- `/model`에서 Fable을 선택할 때 현재 version의 id를 저장하여 저장된 기본값이 Opus 및 Sonnet처럼 최신 Fable을 따르도록 하는 문제가 수정되었습니다
- Opus 5.5와 Sonnet 5.5 (`/model`, `opusplan`) 간 전환이 이전 MCP tool announcements를 다시 쓰는 문제가 수정되었습니다. 이는 이전 extended thinking을 삭제할 수 있었습니다
- reply가 thinking으로 시작되었을 때 mid-response에 도착하는 Amazon Bedrock Guardrails blocks이 guardrail의 message 대신 API error로 turn을 끝내는 문제가 수정되었습니다
- 같은 command가 `~` 또는 wildcard path로 output을 리디렉션할 때에도 위험한 `rm` (`/` 또는 home directory의 것)이 always-ask safeguard를 잃는 문제가 수정되었습니다
- `claude -p` 및 SDK sessions이 reply가 실행 중일 때 model이 전환된 후 모든 나중 message에 model fallback을 반복하는 문제가 수정되었습니다
- folder의 CLAUDE.md가 session을 재개하거나 compaction 후에 두 번째로 첨부되는 문제가 수정되었습니다
- agent가 종료되고 session이 시작된 worktree를 제거한 후 `claude agents`에서 다시 열 수 없는 background sessions이 수정되었습니다
- `/advisor` pairing checks가 수정되었습니다: Sonnet 5.5는 이제 Opus 4.7 및 4.8을 조언할 수 있으며, API가 거부할 조언자는 조용히 삭제되는 대신 미리 플래그되었습니다
- Bash permission prompts가 "Contains simple_expansion"과 같은 내부 parser names 대신 plain explanation을 표시하는 문제가 수정되었습니다
- slow 또는 busy machines의 fullscreen sessions이 long conversation에서 scroll key가 눌린 상태로 "Claude Code exited after an unrecoverable interface error"로 종료되는 원인이 수정되었습니다
- organization per-tool permission ceilings이 `__proto__`라는 이름의 MCP tool에 대해 조용히 삭제되는 문제가 수정되었습니다
- Claude가 large MCP results을 paging하도록 지시받았을 때 Read의 offset 및 limit을 사용하여 JSON으로 저장하는 문제가 수정되었습니다. 이는 하나의 긴 line을 분할할 수 없습니다
- compaction 후에 tool result 내부에서 전달되는 commit attribution reminder가 수정되었습니다
- screen reader mode가 search boxes (예: /resume 및 /permissions) 및 sign-in code fields의 입력된 text에서 커서를 멀리 떨어뜨리는 문제가 수정되었습니다
- screen reader mode가 /rewind's summarize options에서 아무것도 입력되지 않았을 때 Enter를 거부하는 문제가 수정되었습니다. 추가된 context는 선택 사항입니다
- screen reader mode가 approval prompts에 "Tab to amend" hint를 표시하는 문제가 수정되었습니다. Tab은 아무 작동도 하지 않습니다
- screen reader mode가 /permissions 및 /mcp에서 아무 작동도 하지 않는 arrow keys를 나열하고, 빈 menus에서 또는 search box가 keys를 가지고 있을 때 "Select with numbers"를 표시하는 문제가 수정되었습니다
- screen reader mode가 file edit approval prompts 및 기타 diffs의 changed lines을 누락하는 문제가 수정되었습니다
- screen reader mode가 `claude --teleport` progress screen 및 MCP form field가 확인되는 동안 모든 spinner frame에서 screen reader로 다시 전송되는 문제가 수정되었습니다
- `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS`가 session-title 및 prompt-hook requests에서 structured-output format을 제거하지 못하는 문제가 수정되었습니다. Bedrock-backed gateways가 이를 거부합니다
- screen reader mode가 두 번째 approval prompt의 상단 lines, 변경된 /config row 또는 rejected-plan line을 누락하는 문제가 수정되었습니다. 이전 screen이 terminal window보다 더 컸을 때입니다
- `--include-partial-messages`가 cut-short reply의 `message_stop`을 late로 또는 전혀 전송하지 않는 문제가 수정되었습니다. apps가 reply를 여전히 진행 중인 것으로 표시할 수 있습니다
- `claude agents`가 background session이 기다리고 있는 permission prompt를 표시하지 않는 경우가 수정되었습니다
- `/ultrareview`가 upload가 읽을 수 없는 committed `.gitattributes` (예: UTF-16으로 저장된 것)에서 멈출 때 `.git/info/attributes`에 대해 조언을 주는 문제가 수정되었습니다
- `claude remote-control`이 HTTP proxy 뒤에 등록하지 못하는 문제가 수정되었습니다. 오도하는 "Check your organization permissions" error가 표시되었습니다 (anthropics/claude-code#97352)
- Linux의 sandboxed Bash commands이 Claude Code executable에서 open handle을 상속하는 문제가 수정되었습니다
- running-tool dot 및 three spinners이 "Reduce motion" setting이 켜진 상태에서도 계속 움직이는 문제가 수정되었습니다. /rewind's confirm screen이 당신이 note를 입력하는 동안 "ago" time을 업데이트합니다
- `claude agents`의 times이 screen reader mode에서 매초 변경되는 문제가 수정되었습니다. 이제 최대 10초마다 변경됩니다
- revoked claude.ai login이 generic `API Error: 401` 대신 "OAuth token revoked"를 표시하는 문제가 수정되었습니다. `-p` mode에서 error는 이제 "Failed to authenticate"로 시작합니다
- `/ultrareview` upload refusals가 repository's settings file로 명명된 variable을 자신의 user settings에 복사하도록 조언하는 문제가 수정되었습니다
- `--output-format stream-json` 및 SDK가 prompt로 `/<skill>`을 입력하여 실행된 `context: fork` skill run의 turns을 streaming하지 못하는 문제가 수정되었습니다. Skill tool의 fork도 마찬가지입니다
- /feedback 및 /bug: pre-filled GitHub issue가 더 이상 최근 error messages를 포함하지 않습니다. confirmation screen은 이제 report의 일부로 나열합니다
- `claude plugin marketplace add --sparse` 및 `git-subdir` plugin installs이 "transport 'http' not allowed"로 실패하는 문제가 수정되었습니다. repository가 plain http로 제공될 때입니다
- cloud sessions이 compaction 중에 session이 재시작될 때 이전 conversation을 잃는 경우가 수정되었습니다
- startup `--plugin-url` download와 겹치는 plugin reload가 session's cached copy of the plugin archive를 손상시키는 문제가 수정되었습니다
- `/desktop`이 Claude Desktop 열기가 timeout되거나 너무 많은 output을 인쇄했을 때 partial output을 인용하는 문제가 수정되었습니다. error는 이제 원인의 이름을 지정합니다
- MCP connector tool call이 간헐적으로 두 번 실행되거나 server가 지원하는 MCP protocol version을 변경했을 때 connector's calls이 재시작까지 실패하는 문제가 수정되었습니다
- synced plugins의 SessionStart hooks이 새로운 cloud sessions에서 실행되지 않는 문제가 수정되었습니다
- transcript의 "N hooks ran" summary 및 verbose debug log의 matched-hooks count가 Claude Code's internal callbacks를 포함하는 문제가 수정되었습니다. 하나의 configured hook이 더 이상 two로 표시되지 않습니다
- cloud 및 Remote Control sessions에서 Claude가 보낸 files이 30초 timeout 직후 upload가 완료되었을 때 실패하는 문제가 수정되었습니다. 이제 35초를 기다립니다
- mid-session에 추가된 repositories이 cloud 및 SDK sessions에서 skills 및 plugins을 로드하지 못하고 CLAUDE.md를 late로 로드하는 문제가 수정되었습니다. Claude가 directory를 변경한 후입니다
- PNG, JPEG 및 WebP images이 side가 8,000 pixels 이상인 경우 remote session에서 전송하지 못하는 문제가 수정되었습니다. Claude는 이제 scaled-down copy를 전송합니다
- Claude apps에서 보낸 messages이 17개에서 20개의 첨부 files로 전달될 때 처음 16개만 전달되는 문제가 수정되었습니다
- headless sessions이 하나의 거부된 call 후에 MCP server를 authentication이 필요한 것으로 보고하는 문제가 수정되었습니다. 나중 calls이 성공했음에도 불구하고입니다
- macOS: `claude remote-control`로 시작된 Remote Control sessions이 Mac이 idle sleep으로 전환되었을 때 mid-turn에서 멈추는 문제가 수정되었습니다
- Windows: interactive `claude`가 input이 piped 또는 redirected되었을 때 "Raw mode is not supported"로 hang 또는 crash되는 문제가 수정되었습니다. 이제 이유를 표시하고 종료합니다 (piped input의 경우 `-p`를 사용하십시오)
- Bedrock, Vertex, Mantle: model availability checks이 `CLAUDE_CODE_SKIP_*_AUTH` 아래에서
