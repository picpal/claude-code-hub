## 변경사항

- [VSCode] Focus view를 추가했습니다: 도구 활동을 확장 가능한 턴별 요약 뒤에 숨기고 실시간 실행 중인 도구 표시기가 있는 채팅 메뉴 토글로, `Ctrl+Alt+F` 또는 "Claude Code: Toggle Focus view" 명령으로 전환됩니다
- Linux 및 WSL의 sandbox 자격 증명 파일에 대해 `mode: "mask"`를 추가했습니다 — sandbox 명령은 sentinel 복사본(전체 파일 또는 `extract` regex로 캡처한 범위만)을 읽고, sandbox 프록시는 송신 시 실제 값을 대체합니다. macOS의 파일 마스킹은 `deny`로 폴백됩니다
- `claude plugin validate`에 marketplace 또는 plugin 이름이 Claude Desktop의 관리 marketplace 동기화에서 거부될 경우 경고를 추가했습니다
- prompts 및 tool descriptions를 이전 모델을 위해 작성된 패턴으로 감사하기 위한 `claude-api` skill에 `prompt-audit` 하위 명령을 추가했습니다
- `[[ ]]` regex 조건식에서 zsh이 숨겨진 명령을 실행할 수 있는 Bash tool permission-check bypass를 수정했습니다. 영향을 받는 명령은 이제 권한을 요청합니다
- Windows에서 따옴표 문자가 포함된 경로를 잘못 처리하는 PowerShell permission checks를 수정했습니다. 해당 경로는 이제 승인을 요청합니다
- thinking 토글이 thinking off로 시작한 세션의 나머지 부분에서 영향을 미치지 않는 문제를 수정했습니다. MCP server를 mid-connect에서 비활성화하면 더 이상 자동으로 되돌아가지 않습니다
- `--mcp-config`의 MCP servers가 print mode(`-p`)의 첫 턴 전에 연결되지 않아 모델이 tool calls를 리터럴 텍스트로 내보내는 문제를 수정했습니다
- @-mentioned files이 Esc를 눌러 prompt를 철회하고 다시 제출할 때 자동으로 삭제되는 문제를 수정했습니다
- `constructor`와 같은 built-in object properties의 이름을 따는 SDK MCP tools에 대해 API requests를 준비할 때 발생하는 crash를 수정했습니다
- thinking이 비활성화되었을 때 effort `xhigh`/`max`에서 WebSearch가 400 error로 실패하는 문제를 수정했습니다
- sandbox 프록시를 통한 sandboxed large uploads이 TLS errors로 실패하는 문제를 수정했습니다
- Team 및 Enterprise spend-limit 메시지가 개별 spend limit 대신 조직의 월간 limit을 잘못 지적하는 문제를 수정했습니다
- AWS SSO named profiles를 사용한 Bedrock authentication이 stray `HOME` environment variable을 설정한 Windows 머신의 desktop-managed sessions에서 실패하는 문제를 수정했습니다
- `CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0`이 interrupted-turn auto-resume을 비활성화하지 않는 문제를 수정했습니다. falsy 값이 이제 적용됩니다
- sleep에서 깨어날 때의 드문 race condition으로 인해 두 Claude Code 프로세스가 동시에 동일한 MCP connector 또는 WIF OAuth token을 새로 고치려고 하여 재인증을 강제하는 문제를 수정했습니다
- Claude Code Desktop 또는 claude.ai에서 세션의 이름을 바꾸어도 CLI의 세션 이름이 업데이트되지 않는 문제를 수정했습니다. 모든 이름 바꾸기 surface의 세션 이름이 이제 sanitize됩니다
- `/help`, `/feedback` 같은 terminal-only built-ins의 이름을 따는 plugin- 및 org-delivered skills이 non-interactive sessions에서 호출 불가능한 문제를 수정했습니다
- plugins가 다시 로드된 후 "Plugins changed" 알림이 지워지지 않고 남아있는 문제를 수정했습니다
- Vim mode 수정: yank register가 이제 dialogs, history search, 및 transcript view에서 유지되고 자동으로 비워지지 않습니다
- Vim mode 수정: prompt를 비운 상태로 되돌리면 이제 agent view로 돌아가기 전에 "press ← again" confirm을 활성화합니다
- Google Vertex AI에서 tool search를 개선했습니다: Claude 4.5-generation 이상의 모델에서 재활성화되었습니다
- auto mode를 개선했습니다: parallel tool calls에 대한 permission checks가 이제 cache-efficient이고, 체크가 pending되는 동안 mode를 전환하면 stale result를 적용하는 대신 안정적으로 prompt를 표시합니다
- 결정 전반에서 cached conversation prefix를 재사용하여 auto-mode permission checks의 prompt-cache 비용을 절감했습니다
- Stats panel을 개선하여 token 총합에 cache tokens를 계산하고, input, output, cache read, 및 cache write별로 breakdown을 표시합니다
- `/ultrareview` error messages를 개선했습니다: 어떤 repo가 base와 공유하는 history가 없을 때, branch가 없는 checkout은 이제 생성하도록 조언하는 upfront 거부가 되고, 이미 완료된 clones에서 `git fetch --unshallow`을 제안하지 않습니다
- Windows startup을 개선했습니다: 프로세스 생성 시간이 이제 PowerShell을 생성하는 대신 native kernel32 call로 읽히므로, `powershell.exe`를 gate하는 endpoint security tools가 더 이상 prompt하지 않습니다
- background sessions가 작업을 보존하기 위해 commit 및 push하도록 변경했습니다. task에서 필요한 경우에만 draft PR을 열고, CLAUDE.md git instructions를 따르며, 항상 작업이 있는 위치를 보고하여 종료합니다
- `/plugin install`을 변경하여 stale marketplace catalog를 새로 고치고 plugin을 찾을 수 없다고 보고하기 전에 다시 시도하도록 했습니다
- `/plugin`에서 설치된 plugins를 항상 `/reload-plugins`을 요청하는 대신 안전할 때 즉시 활성화하도록 변경했습니다
- plugins가 `skills` path로 `"."`를 허용하도록 변경했고, root-level `SKILL.md` validation error이 이제 plugin root를 사용하도록 제안합니다
- `/status`를 변경하여 세션 종류를 표시합니다: `interactive`, 또는 `attached` 또는 `unattended`인 background job
- emoji autocomplete을 변경하여 `:thumbsup:`, `:thumbsdown:`, `:love:` 같은 일반적인 alternate shortcodes를 허용합니다
- `/fork`로 fork된 sessions을 원본 세션의 checkout에서 작업하는 대신 자신의 새 worktree를 생성하도록 변경했습니다
- Claude in Chrome을 변경하여 더 이상 필요하지 않으면 열어놓은 browser tabs을 닫도록 했습니다
- fast mode를 변경하여 silent하게 실패하는 대신 mid-session에 usage credits이 부족할 때 stream에 보고하도록 했습니다
- Monitor 변경: 어떤 output도 생성하지 않고 종료되는 watch가 이제 "stream ended"를 보고하는 대신 그렇게 말합니다
- Gateway `model` field validation을 변경했습니다: non-string 값은 forward되는 대신 400으로 거부됩니다
- approval prompts에서 반복되는 "Permission mode changed while the auto-mode classifier call was queued" 알림을 제거했습니다
