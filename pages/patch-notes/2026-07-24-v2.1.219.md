> 원문: [Claude Code v2.1.219 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

## 변경사항

- Claude Opus 5(`claude-opus-5`)를 추가하였으며, 이제 기본 Opus 모델입니다 — 1M context, fast mode에서 Mtok당 $10/$50
- `sandbox.network.strictAllowlist` 설정을 추가하여 샌드박스 명령어에 대해 허용 목록에 없는 호스트를 프롬프트 없이 거부할 수 있습니다
- `/add-dir` 또는 SDK `register_repo_root` 제어 요청이 세션 중간에 새로운 작업 디렉토리를 등록한 후 발생하는 `DirectoryAdded` hook을 추가하였습니다
- headless stream-json init event에 `mcp_server_errors`를 추가하여 config validation에 의해 건너뛴 `--mcp-config` 항목을 나열합니다. terminal 실행은 시작 경고를 출력합니다
- 권장 Dynamic workflow size guideline을 모든 설정 파일에서 설정할 수 있도록 `workflowSizeGuideline` 설정 키를 추가하였습니다. 하나가 설정된 동안 `/config` 행은 숨겨집니다
- stream-json에서 중첩 subagent 전달을 추가하였습니다. depth-2 이상에서 생성된 subagent는 `--forward-subagent-text`가 설정되었을 때 나타나며, 생성한 Agent `tool_use` id로 키 지정됩니다
- `claude -p` text 출력에서 turn이 mid-stream API 오류로 실패할 때 이미 생성된 답변이 제거되는 문제를 수정하였습니다
- server가 연결에 실패할 때 `claude mcp list` 및 `/mcp`에 HTTP status 및 error text를 추가하고, MCP config 값에 숨겨진 선행 또는 후행 공백이 있을 경우 경고를 추가하였습니다
- self-hosted runner가 재시작되는 동안 승인한 권한이 세션이 재개될 때 제거되는 문제를 수정하였습니다. 이제 승인된 action이 실행됩니다
- Fable 모델 행이 이를 포함하는 요금제에 대해 "Requires usage credits"를 표시하는 문제를 수정하였습니다(stale cache가 레이블을 기록한 경우)
- self-hosted runner가 시작되는 동안 SIGTERM이 도착하면 lease가 만료될 때까지 stale active 행이 남는 문제를 수정하였습니다. 이제 깔끔하게 등록 해제됩니다
- self-hosted runner spawn 및 session failure에 구조화된 failure 카테고리를 추가하여 hook error, runner crash, config error를 구분할 수 있습니다
- `/model` picker가 merged Opus 행을 "Opus" 대신 "Opus (1M context)"로 표시하는 문제를 수정하였습니다
- GNU screen 내에서 copy-on-select가 선택 영역을 복사하는 대신 base64를 terminal에 출력하는 문제를 수정하였습니다
- Remote Control client가 model switch, reconnect, 또는 실패한 org check 후 stale fast-mode status를 유지하는 문제를 수정하였습니다
- Windows에서 `CLAUDE_CODE_GIT_BASH_PATH`가 경로가 bash/sh binary가 아닐 때 종료되거나 bash로 사용되는 문제를 수정하였습니다. 이제 경고와 함께 무시됩니다
- Vim mode: 빈 prompt에서 ← 키를 누르면 이제 NORMAL mode에서가 아닌 agent view로 반환됩니다
- screen-reader mode가 매 keystroke마다 전체 input 행을 다시 쓰는 대신 입력된 문자만 echo하도록 수정하였습니다
- "Remote Control is only available via api.anthropic.com" error를 이를 야기한 특정 설정을 명시하도록 개선하였습니다
- `claude --teleport`를 개선하여 현재 checkout이 세션의 repo와 일치하지 않을 때 현재 checkout이 가리키는 repo를 표시합니다
- dynamic workflow를 medium size guideline(15개 미만의 agent를 목표)으로 기본값 설정하도록 변경하였습니다. `/config`에서 Dynamic workflow size를 사용하여 다른 size 또는 unrestricted를 선택할 수 있습니다
- managed MCP allowlist/denylist `${VAR}` 항목을 settings-file env가 아닌 startup environment 및 managed-settings env에서 확인하도록 변경하였습니다
- `/model` picker를 변경하여 최신 모델의 이름만 강조 표시하므로 강조 표시가 임의의 부분 집합 대신 새 release를 표시합니다
- 실행 중인 workflow status 행에 현재 기본 workflow size를 추가하고, 변경을 위해 `/config`로의 포인터를 추가하였습니다
- Opus 4.7을 fast mode에서 제거하였습니다. `/fast`는 이제 Opus 5 및 Opus 4.8에 적용됩니다
- claude-api skill을 Claude Opus 5로 기본값 설정하도록 업데이트하였으며, Opus 4.8에서의 migration path를 제공합니다
- Subagent는 이제 기본적으로 depth 3까지 중첩 subagent를 생성할 수 있습니다(이전: 1). nesting을 비활성화하려면 CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1을 설정하십시오
