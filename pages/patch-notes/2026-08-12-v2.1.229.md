## 변경사항

- `claude remote-control --continue`를 문서화하여 가장 최근의 Remote Control 세션을 재개할 수 있도록 함
- 자체 호스팅 runner 세션에 server 제공 Claude Code hook 지원 추가, 관리형 환경 동작과 일치시킴
- gateway streaming 응답에 SSE keepalive ping 추가하여 장시간 thinking 일시 중지 중 유휴 타임아웃 연결 끊김 방지, Vertex 및 Bedrock upstream에서 발생
- plugin marketplace `command` source 추가: 로컬 command (예: IDE)가 plugin 디렉토리를 출력하며, 각 세션마다 다시 확인되고 재시작 없이 적용됨; `mode: "link"`를 사용하여 그 자리에서 사용함
- `ListAgents`가 이제 연결이 끊긴 Remote Control 세션을 `offline`으로 표시하고 클라우드 세션을 `cloud`로 레이블 지정함
- 스트리밍 중 긴 응답이 부분적으로 사라지고 터미널에서 두 번 인쇄되는 문제 수정
- tool call이 문자열이 아닌 `glob`, `file_path` 또는 `command` 값을 가질 때 error 화면으로의 충돌 수정 (`--resume`으로 영향을 받은 세션을 재개할 때도 포함)
- progress bar 또는 markdown table이 매우 좁은 터미널 창에서 렌더링될 때 발생하는 RangeError 충돌 수정 (`claude --continue`/`--resume`이 시작 시 충돌할 수도 있음)
- Windows에서 tool call 또는 message가 extended-length (`\\?\`) 또는 UNC 경로로 파일을 참조할 때의 충돌 수정
- `CLAUDE_CODE_ATTRIBUTION_HEADER`를 통해 attribution header를 비활성화하는 사용자의 모든 tool call에서 auto mode 실패 수정 (직접 Anthropic API 연결)
- 사용자 정의 `ANTHROPIC_BASE_URL` gateway를 사용하는 claude.ai 구독자의 `/model` Sonnet/Opus 1M 거부 수정
- 리다이렉트 URI에서 `localhost` 대신 `127.0.0.1`을 사용하여 strict authorization server의 MCP OAuth 수정
- laptop 터미널에서 slash command 입력 후 Remote Control client가 stuck working spinner를 표시하는 문제 수정
- `/install-github-app`에서 생성된 Claude Code Review workflow가 pull request에 review를 게시하지 않고 완료되는 문제 수정
- IDE extension이 연결된 상태에서 수천 개의 IDE diagnostic이 있는 파일을 편집한 후 다중 초 UI 정체 수정
- one-shot `claude plugin` command가 오래된 plugin 버전의 정리를 방해할 수 있는 stray liveness file을 남기는 문제 수정
- CPU 제한 container 내부의 동적 workflow가 container의 CPU limit 대신 호스트 machine의 core count를 사용하는 문제 수정
- atomic file 대체 후 file-watcher handle 누수 및 scheduled-tasks watcher가 network 또는 virtual filesystem에서 실패했을 때 Windows에서의 미포착 error 수정
- SDK 및 `--input-format stream-json` 세션이 whitespace 전용 message를 제출할 때 400 API error를 받는 문제 수정
- message만으로 API의 32 MB request limit을 초과하는 conversation이 image 또는 document를 제거할 수 없을 때 compaction을 재시도하는 문제 수정; 이제 명확한 메시지와 함께 한 번만 실패함
- OpenTelemetry export가 Desktop에서 관리되는 gateway가 telemetry endpoint일 때도 그 gateway에 의해 거부되는 문제 수정
- 자체 호스팅 runner 및 기타 원격 세션이 `managed-mcp.json`이 배포되고 server가 MCP server를 제공할 때 시작 시 종료되는 문제 수정; 이제 해당 server는 warning과 함께 건너뜀
- 자체 호스팅 runner repository 준비가 Git Credential Manager prompt에서 hang되는 문제 수정; 이제 credential이 누락되었을 때 git이 빠르게 실패함
- workflow fan-out을 개선하여 동일 접두사 형제 agent를 stagger하여 이후 agent가 캐시된 prompt 접두사를 읽도록 함, 다시 지불할 필요 없음 (`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0`으로 비활성화)
- "prompt is too long" error를 개선하여 왜 automatic compaction이 복구할 수 없는지 설명함, `/compact`만 제안하지 않음
- Sandbox 개선: network domain list의 IPv6 literal이 이제 괄호로 묶임 (`[::1]:443`), 모호한 철자는 fail-closed로 적용되고 `/doctor`로 플래그 지정됨
- `/login`을 업데이트하여 성공적인 login 후 `CLAUDE_CODE_OAUTH_TOKEN` override warning을 반복함
- `/commit-push-pr`를 변경하여 위험한 플래그 (`--force`, `--amend`, `--no-verify` 등)가 있는 git/gh command가 더 이상 자동 승인되지 않음
- 자체 호스팅 runner Windows 시작을 변경하여 명시적 `--base-dir` 필요; Windows에서 default checkout directory가 없음
- [VSCode] "Report a problem" 및 `/bug`가 이제 retired survey link 대신 built-in feedback dialog를 열도록 함
- [VSCode] `/btw` side-question panel을 경계를 드래그하여 side-docked 및 stacked layout 모두에서 크기 조정 가능하게 함
- [VSCode] sidebar에 session group 추가 — 우클릭으로 생성, 이름 바꾸기, 삭제; Cmd/Ctrl- 또는 Shift-클릭으로 여러 세션을 한 번에 이동
