> 원문: [Claude Code v2.1.331 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

## 변경사항

- Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry 및 AWS의 Claude Platform의 터미널 세션에서 Code Mode 지원이 추가되었습니다
- Claude apps gateway에 `oidc.groups_jsonpath`가 추가되어 작은 JSONPath 부분 집합(RFC 9535)으로 객체 목록의 일치하는 항목에서 그룹을 읽을 수 있습니다
- `claude doctor`에 API 연결 섹션이 추가되어 API에 도달할 수 있는지 여부를 보고하고, HTTP 상태 또는 오류를 표시하거나 테스트되지 않은 이유를 설명합니다
- tap-mode 음성 받아쓰기가 인식된 음성이 15초 없거나 2분 제한에 도달하면 자동으로 중지될 때 알림이 추가되었습니다
- `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`이 추가되어 압축된 응답을 차단하는 프록시 뒤에서 압축되지 않은 모델 응답을 요청할 수 있습니다. 아직 self-hosted runner나 Remote Control에는 권장되지 않습니다
- Claude apps gateway에 `CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1`이 추가되었습니다. `oidc.use_proxy: true`를 사용하면, 로그인 요청이 `NO_PROXY`가 설정되어 있어도 프록시에 `https` IdP의 호스트명을 전달합니다
- `gen_ai.usage.*`, `gen_ai.response.model` 및 `gen_ai.operation.name`이 `claude_code.llm_request` trace span에 추가되었습니다. `gen_ai.usage.input_tokens`에는 프롬프트 캐시 토큰이 포함됩니다
- 플러그인 매니페스트에 `optionalDependencies`가 추가되었습니다. 플러그인은 이를 나열하는 플러그인 목록과 함께 설치되며 독립적으로 비활성화하거나 제거할 수 있습니다
- 로컬 또는 WebSocket 서버의 형식이 잘못된 일부 응답으로 인해 MCP tool call이 최대 30분 동안 중지되는 문제가 수정되었습니다
- PushNotification이 스케줄된 실행과 같은 헤드리스 실행에 터미널이 첫 1분 동안 활성화되었다고 말하는 대신, 모바일 푸시가 요청되었는지 여부를 말하지 않는 문제가 수정되었습니다
- `/install-github-app`이 저장소를 찾지 못할 때 설정 경고 후 저장소 단계를 건너뛰고, Esc가 workflow 목록 및 로그인 단계에서 돌아가지 않는 문제가 수정되었습니다
- 한 줄 tool 결과가 좁은 창에서 줄임표 없이 잘리고, Auto mode 탭의 Markdown 별 및 forked skill을 중지하는 hook의 이유가 두 번 표시되는 문제가 수정되었습니다
- `/diff`가 24~26행의 창에서 key hint를 숨기고 파일을 선택하지 않으며, 커밋이 없는 저장소에서 `git add -N`으로 추가된 파일을 생략하는 문제가 수정되었습니다
- 첫 실행 theme 목록이 짧은 창에서 너무 적은 테마를 표시하고, /usage 및 기타 tall screen이 표시되지 않는 문제가 수정되었습니다
- `/bug`이 fullscreen에서 해당 Yes 및 No 답변을 긴 보고서 뒤에 숨기고, Yes가 매우 짧은 창에서 view를 벗어나는 문제가 수정되었습니다
- /compact 및 auto-compact가 요약이 특정 XML 태그를 인용할 때 conversation summary의 일부를 잃는 문제가 수정되었습니다
- Claude가 Agent tool의 permission rule이 이미 끝난 subagent에 대해 대기 중인 message를 삭제한 경우 이를 통보받지 못하는 문제가 수정되었습니다
- Remote Control message가 완료되는 중인 reply 위에 표시되는 경우가 있는 문제가 수정되었습니다
- Claude Desktop에서 transcript를 읽는 Stop hook이 마지막 reply를 놓치는 문제가 수정되었습니다. SubagentStop hook이 이제 그것도 기다립니다
- Claude가 여전히 생각하는 동안 reply가 조용해지면 cloud 세션에서 turn 및 subagent가 실패하거나 다른 곳에서 긴 reply로 인해 timeout이 되는 문제가 수정되었습니다. Claude Code가 이제 요청을 한 번 더 시도합니다
- Claude가 읽는 cloud 또는 network 파일의 내용이 stall되면 Esc 및 Stop이 약 1분 이상 대기하는 문제가 수정되었습니다
- `--resume` 또는 `--continue`로 재개된 Code Mode 세션이 다른 permission mode에서 thinking 및 prompt cache를 잃는 문제가 수정되었습니다. 요청하는 mode에서 시작한 세션이 그 mode의 script 제한을 유지합니다
- Code Mode가 script가 실행 중일 때 `!` 또는 slash command를 입력하면 약 1초마다 요청을 보내는 문제가 수정되었습니다
- 중단되거나 실패한 plugin 업데이트가 나중에 skill 또는 기타 component가 누락된 상태로 로드되는 partial plugin folder를 남기는 문제가 수정되었습니다(anthropics/claude-code#102186)
- Windows: FAT32 및 exFAT drive에 대한 파일 쓰기가 일부 plugin 세션에서 매번 permission을 요청하는 문제가 수정되었습니다
- Claude가 null output 또는 traceback이 없는 error output이 있는 notebook을 읽지 못하는 문제가 수정되었습니다
- rewind가 restore 실패 후 파일을 삭제하는 문제가 수정되었습니다
- auto mode가 때때로 `/loop`를 중지하려는 Claude의 호출을 거부하여 다음 wake-up이 실행되도록 남겨두는 문제가 수정되었습니다
- Workflow agent의 background shell 및 MCP server가 보고서를 반환한 후에 계속 실행되는 경우가 있는 문제가 수정되었습니다
- Windows: `/desktop`이 더 이상 된 Claude Desktop installer를 다운로드하고, 더 이상 된 install의 folder가 남아 있으면 업데이트를 요청하는 문제가 수정되었습니다
- `claude plugin install`, `marketplace add` 및 유사한 command가 요청할 수 없는 managed settings 승인이 필요할 때 output 없이 중지되는 문제가 수정되었습니다
- subagent의 model에 대한 permission rule(예: `Agent(model:*)`)이 이 버전에서 시작된 명명된 model이 없는 subagent에 대한 Claude의 follow-up message를 차단하는 문제가 수정되었습니다
- PermissionRequest hook이 local settings 외부에서 `Skill(name:*)` allow rule을 저장하지 않는 문제가 수정되었습니다
- "Ask your admin"이 team의 pooled group budget이 차단할 때 자신의 limit을 raise하도록 요청하고, admin이 지난 몇 분 내에 요청을 승인했을 때 "Request sent"라고 말하는 문제가 수정되었습니다
- Code Mode가 긴 script output의 중간을 잃는 문제가 수정되었습니다. Claude가 이제 uncut text의 경로를 받습니다(anthropics/claude-code#111373)
- hold-to-talk dictation이 Claude Code가 바쁠 때 조기에 중지되고 단어를 잃는 문제가 수정되었습니다
- Code Mode with `--bare`이 Claude에 script가 호출할 수 있는 항목을 말하지 않는 문제가 수정되었습니다
- custom API endpoint가 tool name이 없는 tool call을 반환할 때 crash가 발생하는 문제가 수정되었습니다. call이 이제 오류로 실패하고 session이 계속됩니다
- Windows: machine의 memory가 거의 없을 때 가능한 crash가 수정되었습니다
- CLI가 일부 reply에서 freeze되고, quoted text가 때때로 누락되거나 두 번 표시되는 문제가 수정되었습니다
- Windows: Claude Code가 registry의 managed settings에 Japanese와 같은 non-ASCII character가 포함되어 있으면 시작을 거부하는 문제가 수정되었습니다(anthropics/claude-code#93280)
- Windows: Remote Control client가 새 subagent에 대해 step을 표시하지 않는 문제가 수정되었습니다
- @-mention이 `@file#10-12`로 작성되면 그 행만이 아닌 전체 file을 attach하는 문제가 수정되었습니다
- Claude가 pasted artifact invitation link를 잘못 읽는 문제가 수정되었습니다. 이제 invitation을 수락하고 artifact의 고유 link를 paste하도록 요청합니다
- sandboxed Bash command가 temp disk가 가득 찬 경우 file rule이 command를 temp directory 밖으로 유지하는 sandbox에서 시작하지 못하는 문제가 수정되었습니다
- Improved 화면 reader mode의 typing 속도는 특히 긴 session에서입니다
- Improved 시작 시간: 다른 session 직후에 시작된 session은 더 이상 model list를 기다리지 않으며, git repository 없고 `.claude/settings.local.json` 없는 session은 더 이상 git을 기다리지 않습니다
- Windows: machine에 custom shell start-up file이 없는 경우 session에서 첫 Bash command의 속도가 개선되었습니다
- plugin auto-update notice가 이제 새로 설치하는 plugin의 이름을 dependency로 나열되어 있는 것으로 별도로 나열합니다
- Code Mode tool search가 MCP tool의 description을 더 많이 표시하도록 개선되었습니다(limit, format 및 default 포함)
- `/login` 및 `claude auth login --console`에서 표시된 Console sign-in link가 개선되었습니다. 이제 훨씬 짧습니다
- Claude의 artifact 목록이 개선되었습니다. 이제 웹 페이지를 표시하므로 Claude가 Claude Docs connector로 열려고 시도할 가능성이 낮습니다
- 짧은 terminal의 folder trust prompt가 개선되었습니다. fullscreen `/cd` 및 `/add-dir`은 선택 항목을 더 적은 행에 표시하고, 시작 시 prompt는 많은 경고가 있을 때 folder path를 view에 유지합니다
- `/ide`에서 auto-connect를 중지하는 질문과 subagent의 view에서 `/clear`, `/compact` 또는 `/rewind`에 대한 질문이 Yes를 먼저 나열하도록 변경되었습니다. 여전히 No에서 시작하므로 Down을 누른 후 Enter는 이제 No를 답변합니다
- `PermissionDenied` hook의 `retry: true`가 Claude에 말하는 내용이 변경되었습니다. 그 호출을 요청했을 때만 거절된 호출을 다시 한 번 하세요
- 2026년 11월 30일 이후의 향후 release에서 변경됨: managed `extraKnownMarketplaces`의 plugin marketplace는 기본적으로 auto-update됩니다. 하나를 opt out하려면 그 항목에서 `"autoUpdate": false`를 설정하세요
- Windows: managed settings in registry로 시작하도록 변경됨: 업그레이드 전에 확인하세요. `HKLM` policy는 `managed-settings.json`을 override하고 broken value는 시작을 중지할 수 있습니다
- [VSCode] logout할 때 경고 및 revoke page에 대한 link가 추가되었고, claude.ai login을 revoke하려는 요청이 확인되지 않을 때 표시됩니다
- [VSCode] 매우 큰 selection 또는 attach된 text file을 보낼 때 notice가 추가되었으며, "Prompt is too long" 아래에 큰 부분의 이름과 다음 단계를 나열하는 조언이 있습니다
- [VSCode] "Add Cell to Chat"이 notebook cell menu에 추가되어 cell을 output 또는 error와 함께 attach합니다
