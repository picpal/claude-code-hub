> 원문: [Claude Code v2.1.293 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)

## 변경사항

- Claude Haiku 5.5(`claude-haiku-5-5`)를 추가했으며, 이제 Anthropic API의 기본 Haiku 모델입니다 — 1M context, $0.10/$0.50 per Mtok (100K 이상의 프롬프트의 경우 $0.50/$2.50)
- `subagentStatusLine` payload에 `agentType`을 추가했으므로 스크립트가 사용자 정의 subagent 유형을 구분할 수 있습니다
- mods를 위해 `$.tool.register`에 `isDeferred`를 추가했습니다: `false`는 도구 검색 뒤에 있지 않고 처음부터 프롬프트에 도구의 schema를 나열합니다
- Claude가 context compaction 이전의 자신의 마지막 작업을 완료된 것으로 취급하고 완료된 작업을 취소하거나 다시 수행하는 문제를 수정했습니다
- HTTP MCP connection이 종료될 때까지 전송한 모든 요청을 유지하는 메모리 누수를 수정했습니다
- Claude가 작업 중일 때 전송된 메시지가 `←`이 세션을 백그라운드로 이동할 때 손실되는 문제를 수정했습니다. 대기 중인 메시지가 이동할 수 없으면 `←`은 이제 제자리에 유지되고 그렇다고 표시합니다
- `/model` effort `←`/`→`이 최고 또는 최저 수준을 넘어 래핑되어 실수로 Low를 모델의 기본 effort로 저장할 수 있었던 문제를 수정했습니다
- `/tui`가 `--chrome`으로 시작한 세션에서 Chrome에서 Claude를 연결 해제하고 `--no-chrome`을 무시하는 문제를 수정했습니다
- Claude가 호스트, 권한 규칙 또는 `--tools` 목록이 해당 도구를 제거한 세션(재개된 세션 포함)에서 `SendMessage`로 subagents에 계속하거나 메시지를 보내도록 지시받는 문제를 수정했습니다
- Subagents 및 `--agent` 세션이 자신의 도구 목록이 해당 도구를 생략했을 때만 기본 제공 도구가 전체 세션에 대해 비활성화되었다고 지시받는 문제를 수정했습니다
- claude.ai 동기화 skill의 편집된 설명이 새로운 대화 또는 `/clear`까지 모델에 도달하지 않는 경우가 있는 문제를 수정했습니다
- `claude logs`, `stop`, `kill`, `rm` 및 `claude daemon status`, `stop`, `uninstall`이 로그인이 만료되었거나 곧 만료될 때 로그아웃하는 경우가 있는 문제를 수정했습니다
- 세션 폴더를 읽는 데 일시적인 오류가 발생한 후 바닥글의 agents 수가 사라지는 문제를 수정했습니다(예: 열린 파일이 너무 많음)
- `worker`라는 이름의 사용자 정의 agent가 시작할 때 "Agent"로 표시되고 agent가 완료된 후 agent 상세 dialog의 제목이 agent 유형을 잃는 문제를 수정했습니다
- Artifact tool의 transcript 행이 publish 호출이 여전히 streaming되는 동안 `Artifact("(unprintable path)")`로 읽히는 문제를 수정했습니다
- `/ultrareview` upload이 Linux에서 설정 파일이 "파싱될 수 없음"이라는 이유로 다른 checkout 내부의 repository 같은 일부 repository를 잘못 거부하는 문제를 수정했습니다
- `/ultrareview` upload의 split-index 파일에 대한 거부가 git이 index를 읽을 수 없게 할 수 있는 git 명령을 조언하는 문제를 수정했습니다
- 매우 긴 Remote Control 및 cloud 세션의 replies가 streaming되는 대신 한 번에 한 블록씩 나타날 수 있었던 문제를 수정했습니다
- Remote Control이 모든 자격 증명 복구 후 세션의 시작 이력을 다시 업로드하는 문제를 수정했습니다
- PushNotification이 `claude remote-control`로 시작한 세션에서 "Remote Control inactive"를 보고하는 문제를 수정했습니다
- mod의 `classic.*` 이벤트에 대한 hooks이 plugin hooks worker가 재시작되는 동안 건너뛰어져 설정 hooks이 이들 없이 응답하도록 하는 문제를 수정했습니다
- `$.session.append`를 호출하는 mods의 `claude plugin test`가 실패하는 문제를 수정했습니다. 테스트는 새로운 `mock.session`으로 append된 행을 다시 읽을 수 있습니다
- `claude plugin eval`이 Macs의 Docker Desktop에서 Bash를 부여하는 모든 실행(`~/.docker/bin` 아래의 links)을 거부하는 문제를 수정했습니다. 거부는 이제 자격 증명 저장소의 어느 부분이 link를 보유했는지 명명합니다
- Claude apps gateway가 `desktop` policy가 Claude Desktop의 기본 제공 browser 키(예: `builtinBrowserEnabled`)를 설정할 때 시작을 거부하는 문제를 수정했습니다
- `claude agents`가 백그라운드 세션이 동의만 `.claude/settings.local.json` 또는 `--settings` 파일에 저장했을 때 무시하는 bypass 권한을 제공하는 문제를 수정했습니다. 이제 동의를 먼저 요청하며, 무시하는 세션은 유지되는 짧은 notice를 표시합니다
- `←`이 프롬프트에 미전송 텍스트가 있는 경우(이제 이동을 취소함) 또는 질문이 답변을 기다리는 경우 10초 후 세션을 백그라운드로 이동하는 문제를 수정했습니다
- 권한 prompt에서 Esc 또는 No (feedback 없음)이 `←`이 방금 세션을 백그라운드로 이동하도록 눌렀을 때 turn을 중지하지 않는 문제를 수정했습니다
- 세션 폴더를 읽을 수 없을 때(예: 열린 파일이 너무 많음) agents view가 세션 목록을 placeholder 행으로 일시적으로 대체하는 문제를 수정했습니다
- path-scoped rules 및 nested CLAUDE.md 파일이 Claude가 Read tool 대신 Bash tool의 단일 파일 cat, head, tail, sed -n 또는 grep 명령으로 파일을 볼 때 로드되지 않는 문제를 수정했습니다
- 같은 단어로 시작하고 끝나는 paste된 텍스트가 때로 입력된 것처럼 Claude로 전송되는 문제를 수정했습니다
- paste된 직후 입력한 accent가 마지막 글자에 병합될 때 paste 텍스트의 skill 이름이 입력된 것으로 취급되는 문제를 수정했습니다
- `/feedback`이 보고서가 전송 중일 때 Ctrl+O 또는 Ctrl+Z 후 drafts 목록으로 돌아가 전송을 취소하기 불가능하게 하는 문제를 수정했습니다
- `claude purge`가 파일 또는 폴더를 삭제할 수 없을 때 조용히 중지하는 문제를 수정했습니다(exit 0, 또는 terminal에서 hang). 이제 나머지를 삭제하고, 삭제할 수 없었던 항목을 나열하고, exit 1을 실행합니다
- keybindings.json 검사를 수정했습니다: lone " " (space key)은 더 이상 오류로 보고되지 않으며, "ctrl+ k" 같은 key는 이제 warning을 받습니다
- vim mode `>>` 및 `<<`이 space만 있는 줄에서 cursor를 줄의 끝을 지나가게 하여 다음 `x`이 아무것도 삭제하지 않는 문제를 수정했습니다
- vim mode: Visual mode (`V` 다음 `d`)에서 전체 줄을 삭제한 후 cursor는 첫 번째 non-blank에 위치하고, 그 뒤의 `.`는 cursor의 줄에서 작동합니다
- Windows: status line, hook 또는 shell 명령을 중지할 때 같은 process ID가 지정된 관련 없는 process를 종료하는 경우가 있는 문제를 수정했습니다
- 2.1.281부터 denial이 정확한 명령뿐만 아니라 결과를 포함한다는 것을 Claude에 알린 auto mode denial 메시지 변경을 되돌렸습니다
- cloud 세션이 container restart 후 pending `/loop` wakeup 또는 scheduled task를 잃은 후 asleep 상태를 유지하는 2.1.290 fix를 되돌렸습니다. Claude는 더 이상 이를 알려주지 않으며, 세션은 asleep 상태를 유지합니다
- Team 및 Enterprise 조직의 startup을 개선했습니다: policy 및 managed 설정은 더 일찍 fetch되며, stalled 요청은 3초 후 재시도됩니다
- Chrome의 Claude를 개선했습니다: browser가 tabs를 느리게 보고할 때 page action이 더 적게 거부됩니다
- cloud 세션에서 browser에 도달할 수 없을 때 Chrome의 Claude 메시지를 개선했습니다: 한 개 이상의 조직에 속하면 이제 extension이 같은 조직에 서명되어야 하며, 변경 방법을 설명합니다
- Bash edit diff note를 개선하여 command 실행 중에 변경된 나열된 파일을 명시했습니다. 다른 process의 write를 포함할 수 있습니다
- artifacts: Claude는 2주 이상 된 정확한 버전의 libraries를 pin합니다
- claude.ai skill syncing을 변경하여 no session이 사용 중일 때 10분마다가 아니라 약 40분마다 변경 사항을 확인합니다
- agent 목록 및 MCP server의 순서를 model에 알려지도록 변경했습니다: non-ASCII 문자가 있는 이름은 이제 ASCII 이름 뒤에 정렬됩니다
- OpenTelemetry `claude_code.at_mention` logging을 변경하여 prompt가 읽힐 때마다 최대 100개의 agent 및 100개의 MCP-resource 이벤트를 emit합니다
- Self-hosted runner: orchestrator가 constant 5 대신 4~6초마다 polls 사이에서 sleep하도록 변경했으므로 하나의 environment의 여러 replicas가 동시에 polling을 중지합니다
- [Claude Tag] Claude in Slack이 workspace가 workspaces 전체에 공유된 Enterprise Grid channels에서 설정되지 않았다고 하는 문제를 수정했습니다. Slack이 연결되지 않은 workspace를 사용하여 메시지에 label을 지정할 때입니다
- [Claude Tag] Claude in Slack이 admin이 channel의 connectors, plugins, skills 또는 rules를 변경했을 때 channel에서 중반에 중지하는 문제를 수정했습니다. 변경은 Claude가 완료되면 적용됩니다
- [Claude Tag] Claude in Slack에서 extra notes가 있는 thread의 routine을 지금 실행하도록 요청할 때 다시 post할 수 없는 별도의 run을 시작하는 문제를 수정했습니다. run은 이제 해당 thread에서 계속됩니다
- [Claude Tag] Claude Tag admin 설정에서 access bundle의 Add a connector dialog이 Google sign-in 후 모든 Google connector를 연결된 것으로 표시하는 문제를 수정했습니다
- [Claude Tag] Claude Tag admin 설정을 개선하여 아직 연결되지 않은 Enterprise Grid를 Connect 버튼과 함께 나열합니다
- [Claude Tag] Claude in Slack을 변경하여 announcement channels(admin만 post 가능)에 intro를 post하지 않고 join합니다
- [Claude Tag] Claude Tag admin 설정의 channel rules 제한을 각 workspace 및 organization-wide Slack page의 20에서 50으로 변경했습니다
- [Code Review] Code Review의 Add a repository dialog을 개선하여 추가할 수 없었던 각 repository와 이유(예: missing GitHub write access)를 나열합니다
