> 원문: [Claude Code v2.1.307 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.307)

## 변경사항

- `/claude-api api-version`을 추가하여 Claude API 코드를 API 버전 `2026-10-21`로 이동했습니다
- 각 tool call에 대해 permission rule, auto mode, safety check, hook 또는 sandbox가 중지, 프롬프트되거나 반환될 때마다 `claude_code.safety_event` OpenTelemetry 이벤트를 추가했습니다
- `CLAUDE_CODE_DISABLE_1M_CONTEXT`가 설정되어 있고 model이 `opus[1m]`과 같은 `[1m]` suffix가 있는 alias일 때 model-not-found 오류로 인해 요청이 실패하는 문제를 수정했습니다
- custom `ANTHROPIC_BASE_URL` gateway 및 효과가 없는 Foundry에서 `prompt-caching-scope` beta header가 전송되는 문제를 수정했습니다
- macOS에서 login keychain이 locked된 상태일 때 `claude -p`에서 MCP server가 "needs authentication"으로 표시되던 문제를 수정했습니다. 이제 이유를 표시하며, unlock 후 다음 실행에서 새로운 sign-in 없이 연결됩니다
- MCP server가 연결 중일 때 macOS 또는 Linux 컴퓨터가 sleep 상태로 전환되면 timeout으로 보고되고 headless 실행에서 계속 실패 상태로 유지되던 문제를 수정했습니다
- connection이 call 중에 닫힐 때 HTTP MCP tool call이 두 번 전송되던 문제를 수정했습니다. 이제 read-only 또는 idempotent tool만 retry됩니다
- background task가 실행 중일 때 turn이 때때로 SDK MCP server의 최신 tool 없이 시작되던 문제를 수정했습니다
- 많은 PDF 페이지, 이미지 또는 기타 큰 tool result를 읽는 turn의 일부 "Autocompact is thrashing" 오류를 수정했습니다
- cloud session에서 `/autocompact`가 session 재시작 후 기본 window로 돌아가던 문제를 수정했습니다
- `/clear`로 지운 conversation이 cloud 또는 self-hosted runner session이 재시작될 때 때때로 돌아오던 문제를 수정했습니다
- Claude apps gateway session에서 `CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS`가 무시되던 문제를 수정했습니다
- `OTEL_EXPORTER_OTLP_HEADERS`가 설정되어 있을 때 Claude apps gateway 뒤의 Claude Desktop session에서 telemetry가 거부되던 문제를 수정했습니다
- `/permissions` > Recently denied에서 denied shell command를 표시하지 않고, auto mode의 local classifier가 재시도된 command를 확인할 때 해당 위치의 approval을 무시하던 문제를 수정했습니다. 이제 row를 승인하면 설명이 아닌 command의 이름이 표시됩니다
- `/help` 및 `/` command menu에서 `/claude-api`와 같은 bundled skill의 long model-facing description이 short description 대신 표시되던 문제를 수정했습니다
- subagent transcript가 streamed response에 대해 placeholder token usage와 empty stop reason을 기록하던 문제를 수정했습니다
- Agent SDK의 `setModel()` 및 이를 기반으로 한 app을 통한 model switch가 API가 model을 확인하는 데 5초 이상 걸릴 때 거부되던 문제를 수정했습니다. Claude Code는 이제 최대 15초까지 대기합니다
- connected app(예: desktop app이 idle session을 archive할 때)을 통해 중지된 background command가 Claude에 사용자가 중지한 것으로 보고되던 문제를 수정했습니다. 이제 notice에 output file 이름이 표시됩니다
- Cowork cloud session의 WebFetch가 사이트가 4xx status 또는 robots.txt 거부로 응답할 때 tool error를 보고하던 문제를 수정했습니다. 이제 local session처럼 normal result입니다
- directly configured GitHub MCP server의 write tool이 desktop app의 Code tab에서 아무것도 생성하지 않고 닫히는 form을 표시하던 문제를 수정했습니다
- server가 재사용된 connection을 닫았을 때 Artifact tool read가 connection reset으로 실패하던 문제를 수정했습니다
- Self-hosted runner: `--use-anthropic-git-proxy`를 사용한 session이 이전 session에 의해 clone에 남겨진 `.claude/settings.local.json`을 commit하던 문제를 수정했습니다
- Self-hosted runner: checkout hook 중에 session을 archive하거나 requeue하거나 runner를 중지할 때 hook의 process가 계속 실행되고 runner의 slot이 유지되던 문제를 수정했습니다
- 구문 분석할 수 없는 tool call에서의 복구를 개선했습니다. Claude Code는 이제 turn을 error로 종료하기 전에 call을 최대 2번 재시도합니다
- 함께 시작된 fork subagent를 개선했습니다. 이제 각각이 어느 launch가 자신의 launch인지 알려지므로 fork가 서로의 작업을 시작하려고 시도할 가능성이 훨씬 줄어듭니다
- Browser sign-in을 개선했습니다. 이제 success page가 계정 profile 로드를 대기하지 않고 sign-in이 완료되는 즉시 나타납니다
- cloud 및 self-hosted runner session의 web search 오류를 개선했습니다. 403으로 거부된 검색이 이유를 제공하는 경우 이제 generic "Authentication error" 대신 해당 이유를 표시합니다
- cloud session에서 desktop app의 MCP server 중 하나가 연결할 수 없을 때 첫 reply까지의 시간을 개선했습니다
- transcript에 큰 pasted image 또는 PDF read가 포함된 session의 Remote Control connect time을 개선했습니다
- WebSearch budget이 소진되었을 때 Claude가 받는 notice를 변경하여 browser에서 또는 computer use를 통해 search engine을 query하지 않도록 알립니다
- `axScreenReader` setting 및 settings `env` block의 `CLAUDE_AX_SCREEN_READER`을 user, managed 또는 `--settings` settings에서만 적용하도록 변경했습니다(2.1.305 이후)
- Self-hosted runner: checkout hook을 기본적으로 30분 후에 중지하도록 변경하여 session의 setup이 실패합니다. session이 더 오래 필요한 경우 `--checkout-hook-timeout-min`을 높이거나 `0`으로 설정하십시오
- Self-hosted runner: Anthropic-managed git을 위해 구성된 certificate file을 CLI처럼 trusted certificate를 filter하도록 변경했습니다. `[runner:warn]` line은 제외된 certificate의 개수를 표시합니다
- [VSCode] microphone button에 voice dictation이 저절로 중지될 때(인식된 음성 없이 15초 또는 2분 제한) notice를 추가하여 이유와 지금까지의 text가 유지됨을 알립니다
- [VSCode] Show more로 확장된 long prompt가 전체 chat panel을 덮던 문제를 수정했습니다. 이제 pinned prompt는 panel의 40%로 제한되고 scroll됩니다
- [VSCode] LaTeX math가 있는 list item 또는 table cell의 일부가 rich text editor에 새로운 list 또는 table로 paste되던 문제를 수정했습니다
- [VSCode] `NODE_EXTRA_CA_CERTS`가 `~/.claude/settings.json`에만 설정되어 있을 때 TLS-inspecting proxy 뒤에서 dictation이 실패하던 문제를 수정했습니다. 이제 `CLAUDE_CODE_CERT_STORE`도 따릅니다
- [VSCode] "still open somewhere else" notice를 변경하여 extension restart에서 남겨진 Claude process도 포함하도록 했습니다. 이는 보통 약 10분 내에 자동으로 종료됩니다
- [VSCode] voice dictation을 변경하여 CLI처럼 trusted certificate를 filter합니다
- [VSCode] extension의 자체 request를 변경하여 CLI처럼 trusted certificate를 filter하고, environment 또는 user settings에서 명시된 `NODE_EXTRA_CA_CERTS` file을 신뢰합니다
- [Cloud sessions] repository picker가 search가 실행 중일 때 "No repositories match"이라고 말하던 문제를 수정했습니다. 이제 결과가 도착할 때까지 "Searching…"을 표시합니다
- [Cloud sessions] self-hosted environment의 "Waiting for a runner" status가 잘리던 문제를 수정했습니다. on-demand runner를 사용하면 이제 마지막 message부터 count up하고 실패한 시도를 표시합니다
- [Code Review] `@claude review stop`(`off` 및 `pause`도 포함)을 Code Review에 추가하여 pull request의 `@claude review always` subscription을 새로운 review를 시작하지 않고 종료합니다
