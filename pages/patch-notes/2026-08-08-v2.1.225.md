## 변경사항

- Claude Code의 사용 경고에 gateway spend-limit 지원 추가; 한도 도달 메시지는 이제 상한, 리셋 시간 및 운영자의 메시지를 표시합니다 (gateway 2.1.225 이상 필요)
- 신뢰할 수 없는 디렉토리에 대한 `claude agents`에 workspace trust 프롬프트 추가; `claude`의 동작과 일치합니다
- long-lived `CLAUDE_CODE_OAUTH_TOKEN`을 저장된 로그인의 short-lived token으로 바꾸면서 발생하는 일시적 401 수정; 재시작할 때까지 headless 세션을 중단시킵니다
- macOS에서 MCP OAuth servers가 keychain 읽기 시간 초과 후 마치 인증되지 않은 것처럼 401 오류 폭주로 간헐적 실패 수정
- auto mode에서 자체 permission check의 safety-filter 거부를 consecutive-block 한도로 계산; 작업은 여전히 거부되지만 모델은 이제 재시도하는 대신 계속 진행하도록 지시됩니다
- headless 세션 및 시작 중에 cross-session 메시지가 공지 또는 만료 없이 주차된 채로 남아있는 문제 수정
- 매우 큰 대화가 압축된 후 Remote Control 세션 재개 시 대화 기록이 손상되는 문제 수정
- agents 목록의 다른 프로젝트에 있는 세션 위에 마우스를 올리면 다음 agent가 시작되는 디렉토리가 변경되는 문제 수정
- `claude self-hosted-runner`에서 `--base-dir`을 생성하거나 쓸 수 없을 때 등록 후 모든 세션이 실패하는 문제 수정; 이제 명확한 오류와 함께 시작 시 종료됩니다
- 웹 세션의 Claude Code가 stuck으로 잘못 보고되고 재연결할 때마다 증가하는 event backlog를 다시 보내는 문제 수정
- Remote Control 개선: Claude 앱에서 첨부된 사진은 이제 별도의 tool call로 디스크에서 읽는 대신 Claude에 직접 표시됩니다
- [VSCode] Focus view에서 최신 to-do list, pending 질문의 context 및 settled 답변이 접혔다 풀리는 문제 수정; thinking-only fold는 "Thought for Ns"를 표시하고 차례가 완료되면 다시 접혀집니다
- SendMessage는 이제 Remote Control 세션을 이름으로 다른 머신의 대화를 시작할 수 있습니다 (`ListAgents`는 이를 `name [ref]`로 표시합니다). 처음 메시지를 보낸 후에만 회신하는 대신입니다
- SendMessage: 이미 확인한 Remote Control 수신자는 자체 목록을 확인할 수 없을 때 이 머신의 같은 이름 세션으로 절대 교체되지 않습니다
