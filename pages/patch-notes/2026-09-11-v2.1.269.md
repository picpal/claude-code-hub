> 원문: [Claude Code v2.1.269 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)

## 변경사항

- `claude plugin eval`을 추가했습니다: Claude Code에 대해 플러그인의 평가 스위트를 실행하고 채점된 재현 가능한 결과(JSON + HTML 보고서)를 얻습니다. `claude plugin eval --help`를 참조하세요.
- `/output-style [name]`을 추가했습니다: Remote Control 및 클라우드와 기타 헤드리스 세션에서 출력 스타일을 나열하고 전환합니다.
- Bash 도구가 파일 편집을 처리할 때(`bashEditDiffEnabled` 설정) Bash 도구 결과에 Bash 명령이 변경한 파일의 diff를 추가했습니다.
- `OTEL_METRICS_INCLUDE_REPOSITORY`을 추가했습니다: OpenTelemetry 메트릭 및 이벤트에 `vcs.*` 저장소 속성으로 태그를 지정합니다. `OTEL_LOG_TOOL_DETAILS`를 사용하면 커밋 이벤트가 `vcs.ref.head.*`를 가집니다.
- `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS`을 추가했습니다: LLM gateway의 `/v1/models` 검색 시간 초과를 연장합니다(기본값 3초).
- 프롬프트, 한 줄의 작업 요약 및 응답만 있는 뷰에 대해 `/focus`를 제안하는 스피너 팁을 추가했습니다.
- `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`(1-256)을 추가했습니다: 추론 바운드 팬아웃에 대해 Workflow 도구의 실행당 동시 에이전트 제한을 높입니다.
- 응답이 출력 토큰 제한에서 중단되고 자동으로 재개된 후의 턴에서 프롬프트 캐시가 부분적으로 무효화되는 문제를 수정했습니다.
- Claude가 생각 중간에 중단된 후 세션을 재개할 때 이전 컨텍스트가 재전송되는 방식이 변경되어 프롬프트 캐시 재사용이 손상되는 경우를 수정했습니다.
- kitty 프로토콜 터미널에서 F1/F2/F4가 작동하지 않고 st에서 Delete가 작동하지 않으며, rxvt-unicode에서 Alt+화살표가 Escape로 작동하고, WezTerm에서 Shift+구두점이 시프트되지 않은 키를 입력하는 문제를 수정했습니다(2.1.247의 회귀).
- 백그라운드 에이전트가 여전히 실행 중인 동안 원격 및 헤드리스 세션이 "입력 대기 중"을 보고하는 문제를 수정했습니다(`CLAUDE_CODE_BG_TASKS_REPORT_RUNNING=0`을 설정하여 이전 동작을 복원할 수 있습니다).
- 터미널의 기능 쿼리에 대한 응답(`^[[?1;2c`)이 일부 터미널에서 시작 시 stray text로 나타나는 문제를 수정했습니다.
- 전체 화면에서 터미널 크기를 조정한 후 트랜스크립트의 위쪽 또는 아래쪽 행이 공백이 되는 문제를 수정했습니다.
- `!`로 시작하는 deny 또는 ask 권한 규칙이 그 규칙을 작성한 설정 소스 이외에 적용되는 문제를 수정했습니다. 이러한 규칙은 이제 자신의 소스 내에서만 적용되며, 단순한 `!` 부정은 무시됩니다.
- 압축 후 Claude에 전달되는 git 상태를 수정했습니다: 이제 세션 시작 시의 상태가 아닌 현재 상태입니다.
- 원격 세션이 재개될 때 동기화된 플러그인 MCP 서버가 연결되지 않는 문제를 수정했습니다.
- 모델이 전환되거나 요청이 턴 중간에 재시도될 때 재개된 헤드리스 세션이 턴의 응답을 잃는 문제를 수정했습니다.
- 백그라운드 작업의 온디스크 레코드에서의 터미널 이스케이프 코드, 줄 바꿈 및 과도한 텍스트가 작업이 재개될 때 작업 목록 및 작업 알림에 도달하는 문제를 수정했습니다.
- CMYK JPEG 이미지가 "cannot decode"로 첨부되지 않는 문제를 수정했습니다. 이제 다른 JPEG처럼 변환 및 크기 조정됩니다.
- 관리되는 설정 승인 대화상자가 스킴 없이 설정된 gRPC 텔레메트리 엔드포인트에 대한 수집기 이름을 지정하지 않는 문제를 수정했습니다.
- 플러그인 `headersHelper` 동의 프롬프트가 다른 호스트로 오독될 수 있는 URL 경로를 표시하는 문제를 수정했습니다.
- 플러그인 오류가 `@`로 시작하는 폴더 이름이 있는 상대 Windows 경로 대신 `[redacted URL]`을 표시하는 문제를 수정했습니다.
- 터미널의 네이티브 커서가 활성화되어 있을 때 권한 규칙, 자동 모드 규칙, 디렉토리 추가, 세션 이름 변경 및 피드백 검토 텍스트 필드에 커서가 누락되는 문제를 수정했습니다.
- `/fork` 영수증에 대한 반복된 클릭(각각 1초 미만의 간격)이 현재 도구가 완료될 때까지 기다리는 동안 세션을 즉시 백그라운드로 처리하지 않는 문제를 수정했습니다.
- `shutdown` 매개변수를 거부하는 플러그인 LSP 서버(예: rust-analyzer)가 세션 끝에서 실행 중인 상태로 남아 있는 문제를 수정했습니다. 이제 `shutdown`이 실패해도 `exit`가 전송됩니다.
- 속성 미리 알림이 CLAUDE.md 또는 메모리 규칙을 재정의하여 커밋 및 풀 요청 속성을 금지하는 문제를 수정했습니다. 관리되는 설정으로 설정된 행은 여전히 적용됩니다.
- 일본어, 중국어, 태국어 및 단어 사이에 공백 없이 작성된 기타 언어의 텍스트에 대해 프롬프트 제안이 삭제되는 문제를 수정했습니다.
- GNOME Terminal 및 Konsole 버전(이를 지원하지 않음)에서 터미널의 이름으로부터 동기화된 출력이 가정되는 문제를 수정했습니다.
- `--output-format stream-json` 결과의 `permission_denials`이 경로 범위 deny 규칙으로 차단된 Read, Edit 및 Write 호출을 생략하는 문제를 수정했습니다.
- SDK 또는 데스크톱 앱을 통해 실행된 세션이 다른 세션의 에이전트 목록에서 알 수 없는 상태를 표시하는 문제를 수정했습니다.
- Bedrock, Vertex, Foundry 및 계정이 기본 Opus 모델에 도달할 수 없는 gateway 배포에서 `/insights`가 실패하는 문제를 수정했습니다(대신 세션 모델을 사용).
- 다른 Claude Code 프로세스가 동시에 로그인을 새로 고칠 때 세션에 대해 조직 정책 제한이 로드되지 않는 문제를 수정했습니다.
- Claude Desktop 세션이 Bedrock, Vertex 또는 gateway를 사용할 때 상황별 "Claude가 필요로 하는 것" 턴 종료 알림 텍스트를 받지 않는 문제를 수정했습니다.
- MCP 서버가 업데이트된 구성만 서버 URL의 쿼리 매개변수 순서를 변경할 때 다시 연결되는 문제를 수정했습니다.
- 프롬프트 상자의 위쪽 테두리가 백그라운드 에이전트의 이름이나 설명에 줄 바꿈이 있거나 터미널보다 너클 때 추가 행으로 분할되는 문제를 수정했습니다.
- 자동 압축에 요약할 완전한 이전 교환이 없을 때 세션이 "프롬프트가 너무 길음"에서 영구적으로 고착되는 문제를 수정했습니다(주로 매우 큰 프롬프트가 있는 Agent SDK 세션).
- `/goal` 실행이 API 오류, 네트워크 끊김 또는 토큰 제한 후 자동으로 정지되는 문제를 수정했습니다: 목표가 이제 백오프를 사용하여 재시도하거나, 일시 중지하고 이유를 말하며, 사용량 제한이 재설정될 때까지 포함합니다.
- 클라우드 세션의 프롬프트 캐시 누락을 수정했습니다: 첫 요청 전에 잠시 서버 구성을 대기합니다.
- 만들어진 도구 호출 및 출력을 포함한 `/btw` 답변을 수정했습니다: 측면 질문이 이제 이를 작성하지 않도록 지시되며, 나타나는 모든 것이 실행되지 않은 것으로 표시됩니다.
- `CLAUDE_CODE_RESUME_INTERRUPTED_TURN`이 6시간 이전에 API 오류로 실패한 턴을 다시 실행하거나, 설정된 경우 `CLAUDE_CODE_RESUME_INTERRUPTED_TURN_MAX_AGE_MS`보다 오래 전에 다시 실행하는 문제를 수정했습니다.
- 관리되는 설정을 통해 활성화된 조직 플러그인이 헤드리스 세션 및 Claude Desktop에서 로드되지 않는 문제를 수정했습니다(Desktop이 이 CLI 버전을 번들로 제공하면). 다음 세션에서 로드됩니다.
- 세션에 추출된 플러그인 아카이브가 다른 로컬 사용자에게 읽을 수 있고, 추출된 파일이 아카이브의 월드 쓰기 가능 비트를 유지하며, 부실한 파일이 재추출을 유지하는 문제를 수정했습니다.
- Bash `tee` 명령이 작성하는 파일에 `Edit()` deny 규칙과 쓰기 경로 확인이 적용되지 않는 문제를 수정했습니다. 이제 `Bash(tee:*)` allow 규칙은 더 이상 작업 디렉토리 외부의 대상을 포함하지 않습니다.
- `22c` 같은 stray character 또는 터미널의 색상 또는 버전 응답이 느린 연결(ssh, 브라우저 터미널)을 통해 시작 시 프롬프트에 입력되는 문제를 수정했습니다.
- 터미널의 블록 커서가 rxvt-unicode에서 전체 화면을 나간 후 또는 다시 들어간 후 인터페이스 아래에 표시되는 문제를 수정했습니다.
- 커서 블록이 rxvt-unicode의 전체 화면 모드에서 외부 편집기(Ctrl+G)에서 반환한 후 표시되는 문제를 수정했습니다.
- 인터페이스가 전체 화면 모드 외부에서 외부 편집기(Ctrl+G)에서 반환한 후 두 번 그려지는 문제를 수정했습니다.
- Konsole에서 인터페이스가 외부 편집기에서 반환한 후 두 번 그려지는 문제를 수정했습니다.
- Windows: PowerShell 도구 명령이 백그라운드로 전송되어 Claude Code가 종료될 때 중단되는 문제를 수정했습니다.
- `/diff` 패널을 개선했습니다: 먼저 로딩 상태를 표시하는 대신 한 단계로 완전히 렌더링된 상태로 열립니다.
- 일본어,
