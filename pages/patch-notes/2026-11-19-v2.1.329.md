> 원문: [Claude Code v2.1.329 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)

## 변경사항

- 폴더의 hook이 선언된 위치를 표시하는 신뢰 대화상자 경고를 추가했습니다
- Claude Desktop 및 기타 비대화형 호스트에서 managed settings의 hook 로드에 실패할 때 대화에 경고를 추가했습니다
- 이 세션의 예약된 작업, `/loop` wakeups, 목표 및 이 대화의 fork를 `/tasks`에 추가했습니다. x는 묻고 나서 하나를 중지합니다
- `/mcp`의 서버 페이지에 "Server message" 행을 추가했습니다. 이는 연결을 거부하는 원격 HTTP MCP 서버의 JSON-RPC 오류 메시지를 표시합니다
- `/status`에 "Marketplace auto-update" 행을 추가했습니다. 자동 업데이트를 받지 않는 managed marketplaces와 그 이유를 표시합니다
- OpenTelemetry 이벤트 및 메트릭이 활성화된 상태에서 Code Mode를 켜는 지원을 추가했습니다. 각 도구 호출은 보낸 이벤트를 전송합니다. tracing은 여전히 이를 끕니다
- 네트워크 stall이나 파일 lock으로 인해 `~/.claude.json`이 읽을 수 없게 되고 저장 중에 초기화되는 것을 고쳤습니다
- macOS에서 Claude Code가 Keychain에서 읽을 수는 있지만 저장할 수 없을 때의 반복된 로그아웃을 고쳤습니다. 이제 해당 세션은 만료 시 중지되고 이유를 표시합니다. 다른 세션은 로그인된 상태로 유지됩니다
- `/terminal-setup`이 block 주석 주변의 VS Code 설정 또는 keybindings 파일을 손상시키고, keybindings.json에 닫히지 않은 문자열이 있을 때 성공을 보고하면서 Shift+Enter 바인딩을 잃는 것을 고쳤습니다
- IDE diff를 통해 수락된 파일이 마지막 newline 없이 저장되고, VS Code에서 diff를 저장하여 수락할 때 BOM(Byte Order Mark)을 잃는 것을 고쳤습니다
- `/teleport`에서 클라우드 세션을 선택할 때 열린 대화를 대체하는 것을 고쳤습니다. 이제 선택은 `/clear`처럼 새 세션을 시작하고, `/resume`은 이전 세션을 되돌립니다
- `/usage-credits`가 브라우저를 연 후 Pro 및 Max 사용자에게 다시 로그인하도록 요청하고, 브라우저가 열리지 않고 작업이 usage credits을 위해 중지되면 8초 후에 링크가 사라지는 것을 고쳤습니다
- `/usage`가 usage credits이 모두 사용되었거나 월간 한도에 도달했을 때 OFF라고 표시하고, `/model`이 Pro 및 Max 사용자에게 해당 한도가 usage credits을 사용하는 모델을 차단할 때를 알려주지 않는 것을 고쳤습니다
- 지출 한도 메뉴가 지출을 월간 한도로 표시하고 좁은 창에서 포인터 아래의 행을 wrap하는 것을 고쳤습니다
- 끝없이 인쇄하는 상태 줄 script가 prompt를 freeze하고 gigabytes의 메모리를 사용하는 것을 고쳤습니다
- managed settings 승인 후 --resume picker, 신뢰 대화상자 또는 다른 set-up 화면이 대기 중일 때 빈 frozen 화면이 나타나는 것을 고쳤습니다
- `/model`에서 Default를 선택할 때 Default 행이 이미 저장된 모델을 표시하고 있는 경우 저장된 모델을 조직의 기본값으로 대체하는 것을 고쳤습니다
- 토큰 refresh가 실행 중일 때 MCP 서버의 인증을 지우고 나서 다시 로그인하는 것을 고쳤습니다
- 느린 reconnect 후에 stall된 background MCP 작업을 고쳤습니다. Claude Code는 이제 HTTP MCP 서버가 이전 protocol 버전에 남아있을 때 대부분의 HTTP MCP 서버를 자동으로 재연결합니다
- MCP 서버 또는 웹사이트가 `application/octet-stream`으로 보낸 PDF, 이미지 및 `.docx`, `.xlsx` 또는 `.pptx` 파일이 .bin으로 저장되어 Claude가 PDF와 이미지를 읽을 수 없게 되는 것을 고쳤습니다
- `/code-review <pr number>`가 때때로 pull request 대신 checked-out 브랜치를 검토하고 그렇게 말하지 않는 것을 고쳤습니다. 이제 `gh pr diff`로 pull request를 읽거나 할 수 없을 때 말합니다
- `/code-review`가 permission 프롬프트에서 중지되고, 대부분의 모델에서 존재하지 않는 `~/.claude/CLAUDE.md`를 찾으려는 것을 고쳤습니다
- Self-hosted runner: `--push-outcome-on-release`가 때때로 git host의 세션 branch를 삭제하는 것을 고쳤습니다
- Code Mode가 Esc 후에 script의 finished edits과 중지된 명령을 숨기고, 종료 시 이를 잃는 것을 고쳤습니다
- Code Mode의 runaway loop이 머신의 메모리를 채우는 것을 고쳤습니다. 이제 한계에서 중지됩니다
- 중지되면서 resume 중이던 background agent가 계속 실행되는 것을 고쳤습니다
- background shell 명령이 종료될 때까지 이전 대화의 메모리를 사용하는 것을 고쳤습니다
- Remote Control이 compaction 또는 `/clear` 후 Claude Desktop, IDE 또는 SDK에서 실행한 세션의 이전 대화 메모리를 사용하는 것을 고쳤습니다
- Stop이 hung AWS credential_process 또는 sign-in 호출을 대기하는 동안 Bedrock의 Claude Desktop 세션에서 요청을 종료하지 않는 것을 고쳤습니다
- Claude가 Opus 4.8 및 Opus 5에서 처음 시도할 때 파일을 보내지 못하는 경우가 있는 것을 고쳤습니다
- Claude가 연결된 MCP 서버의 도구를 로드할 수 없다고 통지받지 않고, tool search가 있는 세션에서 도구가 없는 서버로 간주하는 것을 고쳤습니다
- `claude mcp login` 및 `/mcp`가 서비스의 클라이언트 등록이 폐기되었을 때(HTTP 410 Gone) 서비스가 Claude Code에서의 sign-in을 허용하지 않는다고 말하는 것을 고쳤습니다
- claude.ai-synced plugin hook이 macOS의 세션이 여전히 실행 중일 때 "Plugin directory does not exist" 오류로 실패하는 다른 경우를 고쳤습니다
- auto mode가 작업 디렉터리 밖을 가리키거나 자신을 가리키는 symlink를 `rm` 하기 위해 수동 승인을 요청하는 것을 고쳤습니다
- `/sandbox`가 Linux에서 `allowUnixSockets` 항목을 허용으로 나열하는 것을 고쳤습니다. 이들은 거기서 그 socket을 열지 않으며, `/sandbox`는 이제 그렇게 말합니다
- Esc를 두 번 눌러 `/install-github-app`에서 sign-in을 종료하는 잘못된 코드를 지우는 것을 고쳤습니다
- Remote Control: 앱이 선택한 level을 아직도 표시하면서 restart 후 세션이 첫 번째 effort level로 돌아가는 것을 고쳤습니다(Ultracode에서 시작하는 세션은 아직 아님)
- 제거된 plugin의 MCP 서버가 `reload_plugins` 후 또는 계정의 plugin 목록에서 삭제될 때 headless 세션에서 연결된 상태로 유지되는 것을 고쳤습니다
- Claude Docs connector의 도구가 같은 주소의 plugin 또는 MCP 서버 연결에 실패할 때 사라지고, 오류가 잘못되게 `/login`을 제안하는 것을 고쳤습니다
- 새 skills, commands 또는 agents 폴더가 `--add-dir`이 작업 디렉터리를 지정하거나 Claude Code가 홈 폴더에서 시작할 때 누락되는 것을 고쳤습니다
- pre-warmed 프로세스에서 시작한 세션이 프로젝트의 `.claude/settings.json`에서 `autoCompactWindow` 설정을 무시하는 것을 고쳤습니다
- `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`가 settings.json에서 제거된 후 실행 중인 세션에서 계속 적용되는 것을 고쳤습니다
- Agent tool의 `effort` 매개변수가 agent 팀의 명명된 teammates에 대해 무시되는 것을 고쳤습니다
- `/auto-mode-setup`이 프로젝트를 스캔하여 제안할 규칙을 찾을 때 최근 auto mode 거부를 무시하는 것을 고쳤습니다. 이제 이들로부터 allow 규칙을 제시할 수 있으며, 저장되기 전에 각각을 검토합니다
- permission 규칙 또는 디렉터리를 추가한 후 자신의 `.claude/settings.local.json`이 읽을 수 없거나 형식이 잘못된 subfolder 또는 worktree에서 거짓 "Couldn't save this change" 경고가 표시되는 것을 고쳤습니다
- cloud 세션이 실패한 요청 후에 Claude에 네트워크 proxy 체크를 실행하도록 하고, auto mode가 이를 차단하는 것을 고쳤습니다
- headless rewind 및 fork가 모델 변경 후 바로 보낸 메시지가 여전히 대기 중일 때 진행되는 것을 고쳤습니다
- Claude가 cloud 세션이 재시작되는 동안 background 작업이 중지되었을 때 통지받지 않는 것을 고쳤습니다
- `/team-onboarding`이 서버가 업로드를 거부했을 때 가이드가 Team 및 Enterprise 계획에서 공유되었다고 보고하는 것을 고쳤습니다
- fullscreen, `/help`, history 검색 및 background 작업 목록에서 prompt의 panels과 questions이 잘리고, 짧은 창에서 행 또는 제목이 손실되며, 대화상자에서 tables이 wrap되는 것을 고쳤습니다
- resumed 세션이 세션이 종료될 때 잘린 edits, questions 및 plans에 대해 "Rejected" 또는 "Declined"을 표시하는 것을 고쳤습니다
- `/passes`가 서버 오류 후 잘못된 passes 수를 표시하고, 게스트 pass가 남아있지 않을 때 공유를 위해 usage credits을 제시하는 것을 고쳤습니다
- `claude --help` 출력이 다른 프로그램으로 파이프될 때 중단되는 것을 고쳤습니다
- `/terminal-setup`이 macOS 27의 Terminal.app에서 "Use Option as Meta key"를 켜고, 거기서 Shift+Enter 대신 Option+Enter를 제안하는 팁을 고쳤습니다
- Self-hosted runner: Anthropic-managed git을 통해 복제된 Git LFS 저장소에서 setup이 실패하는 것을 고쳤습니다. 세션은 이제 pointer 파일에서 시작되고, `git lfs pull`은 콘텐츠를 가져옵니다
- SSH 호스트 alias, GitHub SSH 인증서 또는 GHE.com SSH 사용자와 함께 git remote에서 시작하지 않는 self-hosted 환경의 세션을 고쳤습니다. 미해결 alias의 오류는 두 개의 git 명령을 제공합니다
- self-hosted runner 세션의 remote MCP 서버가 timeout 또는 네트워크 오류 후 도구 없이 유지되거나(
