> 원문: [Claude Code v2.1.317 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)

## 변경사항

- `/schedule`에 새로운 cloud scheduled task가 요청하지 않은 connector를 가져올 때 경고를 추가했으며, 이를 제거하는 방법을 표시합니다
- web 또는 shell tool call이 계정 이메일 주소를 네트워크로 전송하기 전에 확인하는 검사를 추가했습니다
- Agent SDK hook callbacks에 `onFailure: "block"`을 추가했으므로, 실패한 callback이 작업이 실행되도록 허용하는 대신 작업을 차단합니다
- Claude Desktop의 Code 탭에 조직의 remote managed settings이 세션에 로드되지 않았을 때의 알림을 추가했으며, 로드된 후에도 다른 알림을 추가했습니다
- auto mode의 check에서 subagent의 tool call에 대한 답변이 없을 때의 알림을 추가했으며, 이전에는 main view에 아무것도 남지 않았습니다
- OTel metrics, events 및 spans에 `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider` 및 `anthropic.custom_base_url`을 추가했습니다
- Claude apps gateway admin API에 cost report `GET /v1/organizations/analytics/cost`를 추가했으며, 총 지출, 개발자별, 일별 또는 IdP group별로 기간 동안의 과거 지출을 읽을 수 있습니다
- `admin:`이 설정된 Claude apps gateways에 각 개발자의 IdP groups의 일일 기록을 추가했으며, `admin.identity_retention_days` 동안 유지되고 cost report가 이를 기준으로 그룹화합니다
- `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`를 추가했습니다: self-hosted runner에서 이를 `1`로 설정하면 session 내에서 `claude -p`를 실행할 때 해당 session의 ID 및 transcript를 사용하며, 이는 이전 버전과 같습니다
- 일부 Claude desktop sessions에서 첫 번째 turn 후 project 및 local MCP servers가 연결 해제되는 문제를 수정했습니다
- base URL로 설정된 LLM gateway가 server-side safety check에 대해 403 또는 422로 응답할 때 auto mode가 매 turn마다 실패하는 문제를 수정했습니다 (apiKeyHelper가 있는 403은 변경되지 않음)
- `claude auth status`가 느린 token refresh가 저장되기 전에 종료되어 다음 실행에서 로그아웃될 수 있는 문제를 수정했습니다
- project의 `effortLevel` 설정이 app이 미리 시작한 후 project에서 열기하는 sessions에 의해 무시되는 문제를 수정했습니다 (예: desktop app의 Code 탭의 새 sessions)
- `claude --from-pr`이 linked session이 첫 번째 페이지보다 오래된 경우 많은 sessions가 있는 projects에서 "No conversations found"를 보고하는 문제를 수정했습니다
- 두 개의 동시 permission prompts 중 두 번째가 claude.ai 및 mobile apps에서 파일 경로 또는 명령을 표시하지 않는 문제를 수정했습니다
- Remote Control 및 SDK hosts가 mod의 tool calls에서 "다시 묻지 않기"를 제공하는 문제를 수정했습니다
- session titles이 title이 생성되는 동안 새 메시지 또는 Stop이 도착할 때 cloud 및 SDK sessions에서 손실되는 문제를 수정했습니다
- self-paced `/loop` wakeups이 Claude가 요청에서 필드를 생략할 때 예약되지 않는 문제를 수정했습니다
- auto mode in cloud sessions이 Artifact tool이 업로드, 데이터베이스에 쓰기 또는 outputs folder를 통해 파일을 저장할 때 승인을 위해 중지되는 문제를 수정했습니다
- claude.ai에서 동기화된 skills이 디스크에 쓸 수 없을 때 손실되거나 10분마다 다시 다운로드되는 문제를 수정했습니다
- `/schedule`이 생성하거나 업데이트한 후 cloud scheduled task의 next run time 및 link를 결과에서 제외하는 문제를 수정했습니다
- screen readers가 screen reader mode에서 running subagent의 elapsed time 및 token count를 매 변경 시마다 말하는 문제를 수정했습니다
- region 또는 network block (HTTP 403)이 sign-in failure로 표시되는 문제를 수정했습니다; 이제 오류는 block을 설명합니다
- synced plugin이 동일한 server를 포함할 때 Claude가 작동하는 claude.ai connector가 authorization이 필요하거나 cloud sessions에서 실패했다고 말하는 문제를 수정했습니다
- `claude -p`가 full disk 또는 quota가 transcript 또는 ~/.claude.json writes를 손실할 때 0으로 종료하는 문제를 수정했습니다; 이제 오류를 인쇄하고, text 및 json output에서 1로 종료합니다. Full NFS exports가 누락될 수 있습니다
- 시작 후 처음 1초 정도 동안 설정 파일에 대한 편집이 설정 파일이 다시 변경될 때까지 적용되지 않는 문제를 수정했습니다
- 일부 실행이 cleanup을 건너뛰는 machines에서 old transcripts이 정리되지 않는 문제를 수정했습니다 (예: `--setting-sources`를 사용하는 실행)
- deleted agent team inboxes가 teammate의 late message에 의해 다시 생성되는 문제를 수정했습니다
- re-created agent teammate이 이전 shutdown approval에 의해 team에서 제거되는 문제를 수정했습니다
- stored scheduled tasks가 scheduled tasks이 꺼진 후 나열하거나 삭제하기 불가능한 문제를 수정했습니다
- Claude가 하나를 삭제하도록 요청받았지만 어느 것을 삭제할지 명명하지 않을 때 가장 최근에 업데이트된 `/team-onboarding` guide를 삭제하는 문제를 수정했습니다
- Claude가 server가 delete를 거부했을 때 `/team-onboarding` guide가 삭제되었다고 말하는 문제를 수정했습니다
- Claude apps gateway가 Amazon Bedrock의 "Input is too long." 오류를 숨기고 있어 sessions이 "upstream rejected the request" 대신 매 turn마다 실패하는 문제를 수정했습니다
- self-hosted runner sessions이 plan이 승인을 기다리는 동안 다시 시작될 때 최근 turns 또는 전체 대화를 손실하는 문제를 수정했습니다
- 매우 큰 CLAUDE.md가 마지막으로 전송된 이후 변경된 sessions에서 automatic compaction 후 "Prompt is too long"이 발생하는 문제를 수정했습니다
- 많은 plugins을 등록하는 commands와 함께 headless sessions의 높은 memory use 및 느린 startup을 수정했습니다
- stdio MCP servers가 env config에서 빈 값으로 설정할 때 빈 `AWS_BEARER_TOKEN_BEDROCK`을 받는 문제를 수정했습니다; 이제 변수가 unset되어 server가 machine의 자체 AWS credentials을 사용할 수 있습니다
- root certificate renewal 후 일부 TLS-inspecting proxies 뒤에서 API requests이 "unable to get local issuer certificate"로 실패하는 문제를 수정했습니다
- 매우 긴 conversations이 compaction이 자신의 요청을 단축해야 할 때 이전 summary를 손실하는 문제를 수정했습니다
- PDF의 자체 metadata가 Read 및 @-mentions 하에서 페이지 수를 적게 계산하게 만드는 문제를 수정했습니다
- `DISABLE_PROMPT_CACHING_OPUS` 및 `DISABLE_PROMPT_CACHING_SONNET`이 `[1m]`, other-region 및 default model의 undated spellings에 영향을 미치지 않는 문제를 수정했습니다
- `/artifacts` 및 Artifact tool의 shared list가 200개 이상의 자체 shared artifacts이 있을 때 shared artifacts을 표시하지 않는 문제를 수정했습니다
- Claude가 search가 time limit에 도달했을 때 partial Grep 및 Glob results을 완료된 것으로 처리하는 문제를 수정했습니다
- `https://` endpoint로의 OpenTelemetry exports이 proxy를 통해 다른 export가 여전히 진행 중일 때 시작될 때 전송되지 않는 문제를 수정했습니다
- OpenTelemetry exports을 `http://` endpoint로 차단하는 (HTTP 403) proxy로의 connection attempts이 범람하는 문제를 수정했습니다
- OpenTelemetry exports이 절대 응답하지 않는 proxy 뒤에서 무기한 hang되는 문제를 수정했습니다; 이제 10초 후 timeout되거나 `OTEL_EXPORTER_OTLP_TIMEOUT` up to 30초 후 timeout됩니다
- resumed sessions이 Claude에게 이미 알고 있던 file change를 다시 알리는 문제를 수정했습니다
- Claude가 tool이 switched off되어 이전 호출이 실패한 후 resumed session에서 built-in tool을 사용하지 않는 문제를 수정했습니다
- `/remote-control`이 Remote Control이 `disableRemoteControl` setting으로 꺼져 있다는 것을 말하는 대신 "Unknown command"로 답변하는 문제를 수정했습니다
- agent team teammates이 tmux 또는 iTerm2 panes에서 lead session이 manual mode에 있을 때 auto mode로 시작되는 문제를 수정했습니다
- background session이 upgraded 또는 retired될 때 permission mode의 방금 만든 변경을 손실하는 문제를 수정했습니다
- Ctrl+C가 prompt에서 입력된 텍스트를 지우기 위해 누를 때 모든 running background agents을 중지하는 문제를 수정했습니다
- /feedback이 report가 전송되는 동안 "Enter to confirm"을 표시하는 문제를 수정했습니다
- stopped shell command의 child processes가 SIGTERM을 두 번 받아 일부 programs이 cleanup을 건너뛸 수 있는 문제를 수정했습니다
- `claude -p`가 cloud 또는 self-hosted runner session 내에서 실행될 때 해당 session의 ID를 공유하는 문제를 수정했습니다: session의 transcript에 썼고, restart가 잘못된 conversation을 재개할 수 있었습니다
- `claude -p`가 cloud 또는 self-hosted runner session 내에서 실행될 때 자체 title을 생성하고 해당 session으로 전송하는 문제를 수정했습니다
- Microsoft Foundry에서 표시되는 오류를 개선했습니다: Azure credentials을 로드할 수 없을 때 이제 이를 확인하거나 새로 고칠 것을 말하며, `cloud_credential_error`로 보고합니다
- `/design-sync`를 개선하여 설계 시스템이 Claude로 이동했을 때를 미리 알리고, upload에서 실패하는 대신 빌드하기 전에 중지합니다
- 필수 Claude apps gateway에 연결할 수 없을 때의 startup error를 개선했습니다: sign-in 대신 네트워크를 가리키고, gateway의 TLS certificate을 확인할 수 없을 때를 말합니다
- exit에서 표시되는 "Resume this session with" 힌트를 개선하여 `--resume` 앞에 launch했던 flags를 반복합니다 (예: `--chrome --debug`)
- self-hosted runners이 server errors에서 복구하는 방식을 개선했습니다: 501 또는 529가 아닌 5xx 후 runner의 다음 poll은 실패한 것을 재사용하는 대신 새로운 connection을 엽니다
- self-hosted runner sessions이 server errors에서 복구하는 방식을 개선했습니다: 501 또는 529가 아닌 5xx 후 session은 실패한 것을 재사용하는 대신 새로운 connections을 엽니다
- self-hosted runner sessions이 connections이 답변을 중지할 때 복구하는 방식을 개선했습니다: heartbeat가 응답을 받지 못한 후 session은 각 idle을 차례로 시도하는 대신 새로운 connections을 엽니다
- SendMessage를 변경하여 running background agent로의 메시지가 더 빨리 도착합니다: running command는 중지되지 않고 background로 이동합니다
