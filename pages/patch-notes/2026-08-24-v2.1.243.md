> 원문: [Claude Code v2.1.243 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.243)

## 변경사항

- `/usage`에 Loops 분석을 추가했습니다: 루프별 실행 횟수, 총 토큰, 실행당 토큰, 마지막 실행으로 runaway 또는 chatty `/loop` 작업을 쉽게 식별할 수 있습니다
- `modelPicker` 설정을 추가했습니다: `/model` 피커를 순서가 지정되고 레이블이 있는 모델 목록(Vertex/Bedrock id 포함 모든 id 철자)으로 구성하여 기본 제공 라인업에 추가하거나 대체할 수 있습니다
- `promptCacheTtl` 및 `subagentPromptCacheTtl` 설정을 추가했습니다. API 키 및 클라우드 제공자 사용자가 메인 대화에서 1시간 prompt cache를 유지하면서 subagent는 5분으로 유지할 수 있습니다
- `modelPricing` 관리 설정을 추가했습니다. 조직의 계약된 모델별 요금 및 할인 승수가 목록 가격 대신 `/cost`, 상태 줄 및 원격 측정 비용 수치에 사용됩니다
- `/login` → Anthropic Console 아래에 keyless sign-in을 추가했습니다: API 키 생성과 함께 "Sign in with your Console account"(권장)를 사용하여 API 키를 허용하지 않는 조직도 로그인할 수 있습니다
- `/status`에 `Skipped sources` 줄을 추가했습니다. 이는 존재하지만 더 높은 우선순위의 관리 소스가 활성화되어 있기 때문에 적용되지 않은 관리 설정 소스(예: `managed-settings.json`)를 나열합니다
- `/mcp` 및 `/plugins`에 `managed` 마커를 추가했습니다. 조직에서 인증이 관리되는 claude.ai 커넥터에 표시됩니다
- Claude Code를 웹에서 연결하지 않은 claude.ai 사용자를 `/web-setup`으로 안내하는 팁을 추가했습니다
- GitHub이 웹에서 Claude Code(Pro/Max)에 연결되었는지 여부를 표시하는 `/status` 줄을 추가했습니다. 연결되지 않았을 때 `/web-setup`을 가리킵니다
- 각 subagent가 실행된 모델(및 effort 레벨)을 `/tasks` 및 agent 상세 대화 상자에 추가했습니다
- 비대화형(`-p`) 및 SDK 세션에서 원격 MCP server가 연결 끊김 후 복구되지 않는 문제를 수정했습니다. 이제 자동으로 다시 연결하거나 실패로 보고합니다
- Linear와 같이 client ID metadata document를 지원하는 server에서 desktop app에서 시작한 MCP server sign-in이 "Invalid redirect URI"로 실패하는 문제를 수정했습니다
- 임시 서버 측 비활성화가 캐시되었다가 이후 flag fetch가 실패할 때 auto mode가 시작 시 사용 불가능한 상태로 유지되는 문제를 수정했습니다
- API가 잠시 과부하 상태였고 클라이언트에게 재시도를 요청할 때 약 1분 대기 후 auto mode tool call이 "temporarily unavailable"로 거부되는 문제를 수정했습니다
- `/model` 피커가 Ultracode 선택을 조용히 무시하는 문제를 수정했습니다. 이제 Ultracode를 선택하면 현재 세션에 적용됩니다
- `/resume`이 가장 최근 50개 세션만 나열하는 문제를 수정했습니다. 이제 피커는 스크롤할 때 더 많은 항목을 로드합니다
- 중간 turn restart 후 클라우드 세션이 pending hook 또는 background-task notification이 일반 continuation message 대신 prompt로 다시 전송되어 재개되는 문제를 수정했습니다
- 2.1.232 socket-directory hardening 이후 user namespace 및 rootless container 내에서 cross-session messaging이 조용히 꺼지는 문제를 수정했습니다
- 텍스트가 컨테이너 밖으로 튀어나올 때(예: `/login`의 sign-in URL) 화면의 다른 부분이 다시 그려질 때 앞 열이 손실되는 문제를 수정했습니다
- 이모지 바로 뒤에 입력한 맞춤법이 틀린 단어에 `spellcheck`이 밑줄을 긋지 않는 문제를 수정했습니다
- background subagent가 마지막 background Bash task가 완료될 때 깨어나지 않는 문제를 수정했습니다
- Anthropic API가 응답을 시작하지 않을 때 세션이 10분 이상 조용해지는 문제를 수정했습니다: 이제 요청은 약 3분 후 시간 초과되고 한 번 재시도한 후 `API Error: No response from API`를 표시합니다
- auth, model-availability 및 기타 클라이언트에서 생성한 오류 메시지가 오류 줄 대신 model output처럼 렌더링되는 문제를 수정했습니다
- CI의 workload identity federation을 수정했습니다: 한 작업의 프로세스는 single-use token을 다시 교환하지 않고 교환된 token을 공유합니다. 거부된 교환은 서버 메시지와 함께 빠르게 실패합니다
- 로그인으로 시작한 세션(예: `/logout` 후 첫 번째 실행)에서 시작 시 서버 관리 `companyAnnouncements`가 표시되지 않는 문제를 수정했습니다
- `Bash(cat *)`와 같은 hook `if` 조건이 명령에 `$()` 또는 backtick command substitution이 포함된 후 더 많은 인수가 포함된 경우 관련 없는 Bash 명령에서 발동하는 문제를 수정했습니다
- `marketplace` 필드로 선언된 plugin dependency가 두 plugin이 `--plugin-dir`을 통해 함께 로드될 때 절대 해결되지 않는 문제를 수정했습니다
- `/reload-plugins`가 마지막 LSP plugin이 비활성화된 후 LSP tool을 유지하는 문제를 수정했습니다. 이제 대화를 다시 읽을 수 있는 LSP plugin 변경 전에도 경고합니다
- `--agents`가 invalid JSON 또는 invalid agent definition을 조용히 무시하는 문제를 수정했습니다. 이제 `--mcp-config`처럼 명확한 오류와 함께 종료합니다
- `~/.claude.json`에 invalid MCP server entry가 있을 때 `/status`가 파일명 없이 "Found invalid entries in: ."을 표시하는 문제를 수정했습니다
- `/clear`가 이름이 새 세션에 대해 유지되었음에도 불구하고 prompt bar에서 `/rename` 세션 이름을 제거하는 문제를 수정했습니다
- `~/.claude/history.jsonl`에 malformed entry가 포함되어 있을 때 Ctrl+R history search 및 up-arrow history가 끊기는 문제를 수정했습니다
- `~/.claude` history에서 Ctrl+[ 이 vim INSERT mode를 떠나지 않는 문제를 수정했습니다. 이는 modified key를 인코딩하는 터미널(modifyOtherKeys / kitty protocol)에서 발생합니다
- `localhost`이 `NO_PROXY`에 나열되었지만 lowercase `no_proxy`에는 없을 때 local IDE connection이 `HTTPS_PROXY`를 통해 라우팅되는 문제를 수정했습니다(그리고 때때로 실패). 이제 두 표기법이 모두 준수됩니다
- blocked command가 여전히 exit 0(예: `curl`이 proxy의 403 페이지를 출력)으로 종료될 때 sandbox network-violation details가 Bash tool result에서 손실되는 문제를 수정했습니다
- 상태 줄 `rate_limits` 필드 및 `/usage`이 세션이 유휴 상태인 동안 창이 재설정된 후에도 rate-limit window의 재설정 전 사용 비율을 표시하는 문제를 수정했습니다
- `claude --teleport <session>`이 session picker처럼 변경사항을 stash할 수 있는 옵션을 제공하지 않고 uncommitted changes에서 종료되는 문제를 수정했습니다
- 더 오래된 GitHub CLI(gh auth token 없음)가 이미 인증된 경우 `/web-setup`이 반복적으로 로그인하도록 요청하는 문제를 수정했습니다
- auto-update가 설정된 버전을 정리한 후 Chrome의 Claude이 Claude Code에 대한 연결을 잃는 문제를 수정했습니다. 이제 native host는 stable `claude` launcher를 통해 시작됩니다
- [VSCode] 기능 flag를 처음 fetch하기 전에 시작된 세션(예: 설치 직후)이 기본 permission mode 대신 auto mode 또는 구성된 기본 mode에서 열리는 문제를 수정했습니다
- [VSCode] subagent tool activity 중에 Focus view 섹션이 자동으로 축소되는 문제를 수정했습니다
- 시작 시간을 개선했습니다: sandbox 및 MCP bring-up이 더 이상 첫 프레임을 차단하지 않으며, bare launch는 subcommand registration을 건너뛰고, workflow discovery, settings 및 trust-store work가 더 저렴합니다
- native install 및 auto-update download 크기를 개선했습니다: binary는 이제 zstd-compressed입니다(Linux x64에서 약 340 MB 대신 75 MB)
- `ANTHROPIC_AUTH_TOKEN`을 사용하여 Anthropic API에 대해 인증하는 세션의 사용 원격 측정 조직에 대한 attribution을 개선했습니다. 따라서 해당 data-handling setting이 적용됩니다
- native binary 크기를 개선했습니다: bundled skill 및 prompt text를 더 컴팩트하게 저장하여 약 2 MB 더 작습니다
- native build의 메모리 사용량을 개선했습니다: 전체 bundle을 resident에 유지하지 않고 코드를 요청 시 로드합니다(세션당 대략 40–70 MB 메모리 절약)
- 장시간 실행되는 세션의 peak memory usage를 개선했습니다(runtime이 이제 heap이 증가할수록 더 빨리 garbage-collect합니다)
- SSH를 통한 `/login`을 개선했습니다: sign-in URL이 즉시 나타나고, `c`를 누르면 항상 성공을 주장하지 않고 URL이 복사된 방식을 보고하며, 팁은 fullscreen에서 텍스트를 선택하는 방법을 설명합니다
- thinking이 꺼진 상태에서 effort `xhigh`/`max`를 사용할 때의 오류를 개선했습니다: 이제 레벨, thinking을 비활성화한 설정 및 `/effort high`를 fix로 표시합니다
- `/loop`를 개선했습니다: Claude가 할 일이 없는 연속적인 wake-up은 이제 각각을 출력하는 대신 터미널의 단일 줄로 접습니다
- sandboxed Bash tool prompt를 변경했습니다. 더 이상 허용된 network host를 나열하지 않으므로 Claude는 요청을 시도하고(새 host를 승인할 수 있음) 나열되지 않은 host가 차단되었다고 가정하지 않습니다
- `/model` picker 및 bundled `claude-api` skill을 업데이트했습니다. Sonnet 5의 $2/$10 per Mtok pricing을 제한된 시간 promo가 아닌 표준 목록 가격으로 표시합니다
- macOS의 computer use를 변경했습니다. desktop, Dock 또는 Finder 창을 클릭하려면 다른 app처럼 access dialog를 통해 Finder에 권한을 부여해야 합니다
- `/model`, `/fast` 및 `/effort`를 변경했습니다. Bedrock, Vertex, Foundry 및 telemetry가 비활성화된 경우에도 turn이 끝날 때까지 대기하지 않고 즉시 실행합니다
- `claude remote-control`이 mid-session에 환경을 버릴 때 종료되고 attached Remote Control session을 stranding하는 문제를 수정했습니다. 이제 복구합니다
