> 원문: [Claude Code v2.1.328 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)

## 변경사항

- Claude Opus 4.6 및 Sonnet 4.6에 대한 auto mode를 Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry 및 Claude apps gateway에 추가했습니다. 권한 모드가 없는 대화형 세션이 이 모드에서 시작됩니다.
- command 및 HTTP hooks처럼 `mcp_tool` hooks에 `"onFailure": "block"`을 추가했습니다. 호출이 실패한 hook은 작업을 차단합니다.
- 권한 프롬프트를 건너뛴 세션의 메시지가 클라우드 세션에서 보류되고 삭제될 수 있음을 알리는 경고를 추가했습니다.
- OpenTelemetry exporter에 endpoint가 없어서 데이터가 손실될 가능성이 높을 때 `/status`와 `claude doctor`에 공지를 추가했습니다.
- `CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME`을 추가했습니다. 이를 통해 호스트는 `claude -p --resume`과 `--continue`가 hook이 연기한 tool call을 실행하지 못하도록 중단할 수 있습니다.
- Claude Code를 embed하는 앱이 policy plugin의 `allowManagedModsOnly` 옵션을 켤 수 있도록 지원을 추가했습니다. admin의 managed settings는 여전히 우선합니다.
- policy의 `maxEffortLevel`이 valid effort level이 아닐 때 Claude apps gateway에 시작 경고를 추가했습니다.
- Self-hosted runner: `--capacity 1`에서 세션이 repository에 사용할 folder의 이름을 지정하기 위해 `--repository-folder`을 추가했습니다. 이는 symbolic link가 될 수 없는 base folder 아래의 경로를 대체합니다.
- Self-hosted runner: 호스트의 settings.json이 세션이 무시하는 default permission mode를 설정할 때 시작 경고를 추가했습니다.
- Self-hosted runner: `claude self-hosted-runner orchestrator`에 `--hook-label`을 추가했습니다. 선택한 session labels을 `spawn-runner` hook에 전달합니다.
- Self-hosted runner: `claude --environment`에 `--metadata key=value`을 추가했습니다. 이는 session을 `spawn-runner` hook용으로 label합니다.
- Self-hosted runner: orchestrator의 `/metrics`에 `claude_code_self_hosted_orchestrator_session_queue_wait_by_reason_seconds`을 추가했습니다. 다시 열린 session의 대기를 새로운 session의 대기와 구별할 수 있게 합니다.
- Self-hosted runner: orchestrator metric인 `claude_code_self_hosted_orchestrator_sessions_given_up_total`를 추가했습니다. Anthropic이 session의 runner 시작을 포기한 빈도를 원인별로 계산합니다.
- `echo ====` 또는 `[ a == b ]`와 같이 `=`로 시작하는 단어에서 중단되는 Bash commands in zsh의 "not found" 오류를 수정했습니다. `=cmd`는 더 이상 command의 경로로 확장되지 않습니다.
- 자동 compaction이 `/compact`처럼 재구축하는 대신 session의 이전 system prompt를 재사용하는 문제를 수정했습니다.
- 매우 길거나 잘못된 입력에서 markdown rendering이 freezing되는 문제를 수정했습니다.
- 드문 screen freezes를 수정했습니다.
- 직후 입력할 때 permission prompt 또는 질문에서 Esc가 자주 손실되는 문제를 수정했습니다. Alt를 Esc 및 key로 보내는 terminals에서 unused Alt 또는 Option key가 이제 거기서 거부됩니다.
- 느린 연결이 paste 또는 terminal의 reply를 두 부분으로 나눌 때 prompt에 입력되는 문제를 수정했습니다.
- 느린 연결로 인해 scheduled tasks file을 읽을 수 없거나 telemetry 또는 feature flags가 꺼져 있을 때 scheduled task를 저장하면 project의 다른 saved tasks가 지워지는 문제를 수정했습니다.
- project의 scheduled tasks file에 typo가 있는 scheduled task가 해당 file이 다음 번에 저장될 때 삭제되는 문제를 수정했습니다.
- 재개된 cloud session이 message가 늦게 저장되었을 때 compaction summary 또는 recent messages를 잃을 수 있는 경우를 수정했습니다.
- spinner의 token counts와 subagents의 retried reply를 두 번 계산하고, streamed되지 않은 replies를 놓치고, Claude가 생각하는 동안 멈춰있는 문제를 수정했습니다.
- usage credits가 mid-response에서 소진될 때 표시되는 오류를 수정했습니다. 이는 rate limit으로 명명했습니다.
- gateway가 betas를 거부할 때 `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS`를 설정한 Claude Desktop 외부에서 auto mode가 모든 turn에서 실패하는 문제를 Bedrock, Agent Platform, Foundry 또는 Claude apps gateway에서 수정했습니다.
- `CLAUDE_STREAM_IDLE_TIMEOUT_MS`가 gateways, custom base URLs 및 cloud providers에서 5분 connection limit을 연장하지 못하는 문제를 수정했습니다.
- 대형 tool results 후 scheduled tasks가 아닌 third-party providers의 일부 Claude Desktop sessions가 "Prompt is too long"으로 최종적으로 종료되는 문제를 수정했습니다. 가장 큰 것들이 이제 제외됩니다.
- input schema가 `anyOf`, `oneOf` 또는 `allOf`로 시작하는 MCP tools가 third-party providers 또는 telemetry 또는 feature flags가 꺼져 있을 때 누락되는 문제를 수정했습니다.
- invalid input schema가 있는 MCP tool이 third-party providers 또는 telemetry 또는 feature flags가 꺼져 있을 때 requests를 실패하게 하는 문제를 수정했습니다. tool이 이제 제외되고 Claude에게 이유가 전달됩니다.
- Bedrock, Google Cloud의 Agent Platform 또는 Foundry가 progress summary의 effort setting을 거부할 때 effort가 session의 subagent의 model에 대해 꺼지는 문제를 수정했습니다. (2.1.327의 regression)
- permission prompt가 auto 또는 bypass mode 외부에 있거나, plan approval 또는 질문이 10분 동안 열려있을 때 Code Mode가 script를 중단하는 문제를 수정했습니다.
- Code Mode scripts이 이전 script가 실행 중인 동안 연결한 MCP server를 호출하지 못하는 문제를 auto 및 bypass-permissions modes에서 수정했습니다.
- Code Mode scripts이 `claude --resume` picker에서 선택한 session에서 background에서 실행되지 않는 문제를 auto 또는 bypass permissions mode에서 수정했습니다.
- 한 reply가 여러 scripts를 실행한 session을 재개할 때 Code Mode가 loaded skill, hook context 또는 permission approval과 함께 입력된 note를 잃는 문제를 수정했습니다.
- Code Mode script가 picker에서 session을 재개하거나 permission을 묻는 mode에서 실행했을 때 중단되었음을 Claude에게 알리지 않는 문제를 수정했습니다.
- Code Mode가 이전 failed script가 설정하지 않은 top-level variables에 대해 조용히 `undefined`를 사용하는 문제를 수정했습니다.
- Code Mode scripts이 failing command의 long output이 cut될 때 알림을 받지 못하는 문제를 수정했습니다.
- Code Mode가 `{` block으로 시작하는 valid scripts를 거부하는 문제를 수정했습니다.
- Code Mode가 top-level `await`와 top-level `return`을 모두 사용하는 scripts를 거부하는 문제를 수정했습니다.
- script가 작은 file을 읽거나 쓴 후 Code Mode에서 @-mentioned small file이 attach되지 않는 문제를 수정했습니다.
- Code Mode가 `write()`와 `edit()`을 호출할 수 없는 read-only subagents에게 제공하는 문제를 수정했습니다.
- Esc 다음에 `/model`과 같은 command가 오면 Claude가 Code Mode에서 스스로 turn을 시작하는 문제를 수정했습니다.
- Code Mode에서 Claude가 workflows를 요청할 때만 실행하거나 `/config`에서 설정한 workflow size를 알리지 못하는 문제를 수정했습니다.
- Remote Control이 동일한 disconnect message를 반복하고, reconnect할 수 없는 session을 retry하도록 말하는 문제를 수정했습니다.
- remote session이 느려졌을 때 waiting permission prompt가 손실되고 그 answer가 무시되는 문제를 수정했습니다.
- 대권 후 `/clear`가 뒤따를 때 cloud sessions이 cleared conversation을 재개하는 문제를 수정했습니다.
- remote session이 runner 또는 worker가 손실된 후 dropped model stream이 retry되었을 때 turn의 tool calls와 results를 잃는 문제를 수정했습니다.
- 방금 시작되었거나 제목에 @가 있는 cloud 및 Remote Control sessions이 Remote Control이 켜진 session에서 cross-session messaging에 도달할 수 없는 문제를 수정했습니다.
- Claude가 cloud sessions이 절대 reply할 수 없다고 알림을 받는 문제를 수정했습니다. 이제 reply가 올 수 있을 때와 result를 얻기 위한 다른 방법을 배웁니다.
- `/diff`, Remote Control sessions의 Changes pane 및 edit 옆의 diff가 command가 다른 repository로 이동한 후 committed work을 제외하는 문제를 수정했습니다.
- Remote Control이 IDE extension 또는 다른 SDK app에서 실행되는 session을 workflow가 마지막으로 progress를 낸 후 1시간 이상이 지난 후 열었을 때 running workflow의 agents를 보여주지 않는 문제를 수정했습니다.
- Remote Control: Remote Control이 켜진 후 idle Desktop 또는 VS Code session이 running으로 표시되는 문제를 수정했습니다.
- SDK interrupt가 background agents를 중단한 후 model이 background agents가 여전히 running 중이라고 말하는 문제를 수정했습니다.
- desktop app 및 SDK hosts의 Send now가 stopped web search에서 결과를 찾지 못했다고 Claude에게 말하는 문제를 수정했습니다.
- Cmd를 보고하는 terminals에서 Cmd+letter가 prompt에 입력되는 문제를 수정했습니다.
- GNOME Terminal에서 Ctrl+click이 link를 두 번 여는 문제, side mouse buttons가 clicks으로 작동하는 문제, fullscreen mode에서 pause 후 첫 번째 wheel notch가 반대 방향으로 무시되는 문제를 수정했습니다.
- tmux 및 ssh 외부 Konsole의 Shift+Enter, terminals that speak kitty keyboard protocol에서 non-Latin keyboard layouts의 Alt shortcuts를 수정했습니다.
- Linux: Claude Code가 Ctrl+Z로 suspended되었을 때 `xclip` 또는 `wl-copy`가 설치되어 있으면 다른 apps에서 pasting이 freezing되는 문제를 수정했습니다.
- Linux: Ctrl+V가 clipboard image를 놓치고, 이전 image를 pasting하거나 hanging되는 문제를 수정했습니다.
- fullscreen mode에서 복사된 텍스트가 quote bar를 포함하고, drag가 upward로 scroll할 때 line wraps에서 spaces를 잃고, "Jump to bottom" pill 아래의 words가 누락되는 문제를 수정했습니다.
- `!` command에 pasted된 image path가 attachment가 되는 문제를 수정했습니다.
- `?` shortcuts list가 열려있는 동안 Ctrl+C가 no exit warning을 보여주지 않는 문제를 수정했습니다.
- fullscreen mode의 Ctrl+R search와 `/theme` color editor가 keys가 함께 도착할 때 wrong row를 선택하고, keys가 거기와 `/config` 및 `/plugin`의 search에서 drop되는 문제를 수정했습니다.
- GNU screen 내에서 wrong 또는 missing colors 문제를 수정했습니다.
- fullscreen mode에서 많은 background notifications가 open dialogs의 top border를 자르는 문제를 수정했습니다.
- background agent로의 message가 pasted image 대신 long file path를 보여주는 문제를 수정했습니다.
