> 원문: [Claude Code v2.1.280 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)

## 변경사항

- Claude Opus 5.5(`claude-opus-5-5`)를 추가했으며, 이제 기본 Opus 모델입니다 — 1M context, Mtok당 $4/$20 (캐시 읽기 Mtok당 $0.20)
- 전체 화면 모드의 더 많은 리스트에 마우스 지원을 추가했습니다: 휠로 `/skills` 리스트를 스크롤할 수 있으며, `/plugin`의 스킬 상태 옵션을 클릭할 수 있습니다
- MCP 도구 설명 및 서버 지침에 대한 2,048자 제한을 변경하기 위해 `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`를 추가했습니다 (세션의 모든 MCP 서버에 적용)
- `hook_execution_complete` OpenTelemetry 이벤트에 hook 출력 크기 및 파일로 저장된 oversized 출력의 개수를 추가했습니다
- symlinked 경로를 통한 쓰기가 in-tree 스펠링으로 판단되던 문제를 수정했습니다: 쓰기가 도달하는 프롬프트 이름, `acceptEdits`, allow 규칙 및 auto mode는 더 이상 외부에 도달하는 항목을 승인하지 않습니다
- auto mode가 safety check에서 검토를 거부했을 때 작업을 계속해서 재시도하던 문제를 수정했습니다. 이제 작업은 한 번 거부되며, 재시도가 도움이 되지 않을 것임을 명시합니다
- auto mode가 safety check에서 응답을 받지 못했을 때 일시 중지 없이 작업을 계속해서 거부하던 문제를 수정했습니다. 재시도가 이제 back off하며, 10회 연속 후 메시지와 함께 턴이 중지됩니다
- 모델이 `file_path` 및 `content` 대신 `path`, `file_text`, `file_content` 또는 stray `description`을 보낼 때 Write 호출 검증 실패 문제를 수정했습니다
- Ctrl+C 또는 Ctrl+D를 대부분의 대화에서 두 번 누를 때 (`/model`, `/effort`, `/config`, `/status`, `/usage`, `/plugin`, `/sandbox`, `/permissions`, `/artifacts`, `/mobile`, `/login`, `/upgrade`, `/usage-credits`, `/install-github-app`, `/setup-bedrock`, `/setup-vertex`) 대화를 닫는 대신 Claude Code를 종료하던 문제를 수정했습니다
- 터미널 창만 앞으로 가져온 클릭이 포인터 아래의 항목도 트리거하던 문제를 수정했습니다 — search picker, 탭 바, agent/workflow 행, slash-command 링크 및 suggestion dropdown에서
- stray `n`이 대화를 닫고 stray `y`가 대화를 확인하던 문제를 수정했습니다. Enter와 Esc가 수락 및 취소를 합니다 (`keybindings.json`에서 `y`/`n`을 `confirm:yes`/`confirm:no`에 바인드하여 복원)
- 대화의 텍스트 필드가 그 키에 대한 keybinding에 입력된 문자, 숫자 또는 Space를 잃던 문제를 수정했습니다
- Enter에서 보이지 않는 문자가 제거된 후 Windows 터미널에서 프롬프트 라인이 계속 scrambled되던 문제를 수정했습니다. 이제 화면이 다시 그려져 전송될 정확한 텍스트를 검토할 수 있습니다
- 보이지 않는 문자 정리에서 Persian 및 Arabic 텍스트가 Latin 단어나 숫자에 suffix를 붙이기 위해 사용하는 zero-width non-joiner를 제거하던 문제를 수정했습니다 (예: "PDF"의 복수형)
- voice dictation이 Ctrl+C에서 중지되지 않던 문제를 수정했습니다 (프롬프트는 지워졌지만 마이크는 계속 녹음 중), Esc가 transcript 처리 중 취소하지 못했습니다. Space를 누른 채로 transcript 보기 및 vim NORMAL mode에서 dictation을 시작하던 문제를 수정했습니다
- host app (Claude Desktop, VS Code, SDK)에서 수행된 모델 전환이 Claude가 작업 중인 동안 발생하면 다음 프롬프트에서 prompt-cache miss가 발생하던 문제를 수정했습니다
- resumed fork subagent가 처음 사용한 도구 리스트를 다시 전송하지 않고 도구 리스트를 재구성하던 문제를 수정했습니다. 이로 인해 해당 agent의 prompt caching이 손상되었습니다
- subagent hand-back 메시지가 verbose mode 외에서 확장될 때 내부 provenance preamble을 표시하던 문제를 수정했습니다
- 폴더의 `manifest.json`이 해당 이름을 나열할 때 `installed_plugins.json`이 GitHub repository 또는 branch나 tag를 추적하는 git URL에서 plugin을 업데이트한 후 install-time commit을 유지하던 문제를 수정했습니다
- `~/.claude/skills/` 폴더의 `manifest.json`이 그들의 이름을 나열할 때 해당 폴더의 스킬이 `~/.claude/skills/.trash/`로 이동되던 문제를 수정했습니다
- session feedback survey가 light 및 ANSI theme에서 hover highlight를 표시하지 않던 문제를 수정했습니다
- `/workflows`가 유일한 run을 열기 전에 한 행짜리 리스트를 잠깐 표시하던 문제를 수정했습니다
- 전체 화면 모드에서 마우스 휠이 숨겨진 옵션이 있는 selection list를 스크롤하지 않던 문제를 수정했습니다 (예: `/model`, `/permissions`)
- 꺼진 스킬이 `/plugin` 및 `/skills`에서 로드 실패한 plugin과 동일한 빨간색 ✘를 표시하던 문제를 수정했습니다. 꺼진 상태는 이제 dim ◯를 표시합니다
- multi-select 옵션 설명이 옵션 번호 아래가 아닌 레이블 아래에 들여써지던 문제를 수정했습니다
- `/plugin`, `/skills` 및 `/mcp`의 search box가 전체 화면 모드에서 오른쪽 테두리를 잃던 문제를 수정했습니다
- `/mcp`가 서버 리스트에서는 △를 표시하지만 detail 보기에서는 동일한 서버에 대해 ⚠를 표시하던 문제를 수정했습니다. 리스트, detail 보기 및 `/plugin`이 이제 모두 ⚠를 표시합니다
- Home과 End가 `/config` settings 리스트 및 `/model`, `/memory`, permission prompt와 같은 selection list에서 아무것도 하지 않던 문제를 수정했습니다
- `/skills` 메뉴의 PgUp/PgDn이 첫 번째 또는 마지막 스킬을 지나 wrap하던 문제를 수정했습니다. 이제 거기서 중지합니다
- Tab이 `/config` 리스트의 선택된 설정 값을 자동으로 변경하던 문제를 수정했습니다. 이제 거기서 아무것도 하지 않습니다
- 모든 턴에서 "role 'system' must precede an 'assistant' message" API 오류로 conversation이 실패하던 문제를 수정했습니다
- advisor와의 conversation이 모든 턴에서 proxy 또는 gateway 뒤에서 API Error 400 "Input tag 'advisor_20260301'"로 실패하던 문제를 수정했습니다. 이제 요청이 이를 제외하고 재시도합니다
- 저장된 history가 로드할 수 없는 MCP 도구에 대한 malformed notice를 포함할 때 session이 모든 턴과 `/compact`에서 실패하던 문제를 수정했습니다
- saved transcript가 malformed system message 또는 파일 리스트 없이 memory-saved notice를 포함할 때 session을 재개할 때 crash가 발생하던 문제를 수정했습니다
- long-running fullscreen session이 "Claude Code exited after an unrecoverable interface error"로 종료되는 원인 중 하나를 수정했습니다: 손상된 cached message list이 이제 재구성됩니다
- settings 파일 또는 편집 후 다시 읽는 파일이 read 중간에 named pipe로 바뀔 때 Claude Code가 hanging되던 문제를 수정했습니다
- settings 파일이 아직도 `~/.claude.json`에 `null` 또는 `"false"`와 같은 값을 포함할 때 `/config`가 crash되고 일부 on/off 프리퍼런스가 잘못 읽혀지던 문제를 수정했습니다
- unfinished background agent, shell 또는 workflow를 사용하여 session을 재개할 때 무엇이든 입력하기 전에 model turn이 자동으로 시작되던 문제를 수정했습니다
- headless 및 SDK session에서 background subagent로 전송된 메시지가 subagent가 턴을 마칠 때 자동으로 손실되던 문제를 수정했습니다
- 보고서가 읽혀지기 전에 그것을 실행한 conversation이 compacted될 때 finished subagent의 보고서가 손실되던 문제를 수정했습니다
- LSP plugin이 활성화되어 있을 때 background subagent가 LSP tool을 사용할 수 없던 문제를 수정했습니다
- background shell task가 benign non-zero exit (예: 일치하는 것이 없는 grep)을 실패로 보고하던 문제를 수정했습니다
- session에 전달된 환경 변수가 NUL 문자를 포함할 때 background session (`claude --bg`)이 git, hook, plugin 및 기타 helper 프로그램을 실행할 수 없던 문제를 수정했습니다
- background subagent가 실행 중일 때 Ctrl+C를 3~4회 눌러야 종료되던 문제를 수정했습니다. 이제 2회 누르면 종료됩니다
- sent prompt가 input에 들어올 때 (예: Esc를 눌러 편집, rewind, startup hook 실행 중 Esc 누르기) IDE 선택이 손실되던 문제를 수정했습니다
- `!` shell-mode 프롬프트가 Ctrl+S로 stashed되었을 때 복원할 때 plain 프롬프트로 돌아오던 문제를 수정했습니다. `/`가 file 경로를 나열하던 문제를 수정했습니다
- temp 디렉토리가 가득 차 있거나, writable이 아니거나, 다른 사용자가 소유한 경우 `claude agents`가 오류 대신 blank, unresponsive screen을 표시하던 문제를 수정했습니다
- `claude mcp remove` 후 동일한 이름으로 다시 추가된 MCP server가 reconnecting 대신 여전히 authentication이 필요한 것으로 표시되던 문제를 수정했습니다
- background plugin marketplace auto-update가 git credential helper를 무시하여 private-repo marketplace가 매 실행마다 re-cloned되거나 업데이트되지 않던 문제를 수정했습니다
- official marketplace의 snapshot 파일이 link이거나 너무 클 때 `claude plugin update`가 plugin의 recorded commit을 clear하고 version을 "unknown"으로 이동하던 문제를 수정했습니다
- 조직의 정책을 로드할 수 없을 때 (예: web proxy 뒤) Artifact tool이 자동으로 사라지던 문제를 수정했습니다. 이제 Claude가 무엇이 차단하는지 말합니다
- artifact republish가 해당 capability가 없이 다시 전송되었을 때 저장된 database access 규칙을 자동으로 reset하거나 viewer profile scope를 drop하던 문제를 수정했습니다. 이제 거부됩니다
- `/ultrareview`가 stopped cloud review를 completed로 또는 재시도할 오류로 보고하던 문제를 수정했습니다. session이 삭제되었거나 로그인한 계정이 변경되었을 때 full timeout을 기다리던 문제를 수정했습니다
- Claude app이 /compact 또는 /clear 직후 Remote Control 및 cloud session에 대한 missing 또는 stale context 사용량 수치를 표시하던 문제를 수정했습니다
