> 원문: [Claude Code v2.1.277 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)

## 변경사항

- AGENTS.md 지원 추가: CLAUDE.md가 없는 프로젝트에서 Claude Code가 대신 AGENTS.md를 읽습니다. `/config`의 "Project instructions"에서 변경할 수 있습니다(아직 Bedrock, Vertex, Foundry에서는 지원되지 않음)
- Claude apps gateway의 유일한 egress가 forward proxy인 경우를 위해 `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` 추가: 모든 아웃바운드 요청이 proxy에 hostname을 전달하므로 로컬에서 resolver할 필요가 없습니다
- Claude apps gateway upstream의 선택적 `headers:` map 추가: provider 앞에 실행되는 proxy에 정적 헤더를 보낼 수 있습니다
- 백그라운드 작업이 완료되었을 때 업데이트가 대기 중임을 나타내는 줄 추가(예: `/tasks` 패널이 열려 있을 때)
- 내부 오류로 인해 결과 없이 중단될 수 있던 `claude -p` 및 Agent SDK 세션 수정: 이제 오류를 보고하고 종료 코드 1로 종료합니다
- `--resume` 후를 포함하여 이전 assistant 턴이 다른 콘텐츠 옆에 빈 텍스트 블록을 보유했을 때 모든 요청이 "text content blocks must be non-empty" 오류로 실패하는 대화 수정
- 동일한 머신에서 현재 빌드와 함께 이전 Claude Code 빌드(예: IDE 확장의 번들된 CLI)가 실행될 때 예기치 않게 로그아웃되는 문제 수정
- `~/.claude.json`에 잘못된 형식의 `customApiKeyResponses` 값이 있을 때 `ANTHROPIC_API_KEY` 사용자의 대화형 시작 중단 또는 오류 수정
- proxy가 잘못된 버전을 반환할 때 최소 또는 최대 버전이 설정되어 있으면 update 확인에서 30분마다 오류가 발생하고 `claude update`가 중단되는 문제 수정: 잘못된 형식의 `minimumVersion`은 이제 무시됩니다
- winget 또는 apk로 관리되는 설치에서 `claude update`가 버전 조회 실패 시 "up to date"를 보고하는 문제 수정
- 세션 또는 다른 프로그램이 사용 중인 플러그인 버전을 재설치할 때 `claude plugin install`이 때때로 실패하고 설치된 복사본을 손상시키는 문제 수정: 변경되지 않은 복사본은 이제 그대로 유지됩니다
- 시스템이 프로세스, 메모리 또는 파일 핸들 부족으로 검색을 시작할 수 없을 때 Grep과 Glob이 일치 항목이 없다고 보고하는 문제 수정: 이제 이를 나타내는 오류를 반환합니다
- 대상 경로가 기존 디렉토리일 때 Write 도구가 턴을 거절된 권한으로 자동 종료하는 문제 수정: 이제 명확한 오류를 보고합니다
- Edit 도구가 이스케이프된 백슬래시 다음에 `uXXXX` 텍스트를 `\uXXXX` 이스케이프로 취급하는 문제 수정: 이로 인해 비ASCII 문자 편집이 이스케이프된 백슬래시 시퀀스를 재작성할 수 있었습니다
- 매우 큰 비ASCII 텍스트를 포함하는 편집이 파일과 일치하지 않을 때 Edit 도구가 "String not found in file" 대신 "Invalid regular expression: regular expression too large"를 보고하는 문제 수정
- 도구 호출의 파일 경로에 이스케이프 시퀀스로 작성된 `\u0000`이 포함되어 있을 때 턴이 "Path contains null bytes"로 조기 종료되는 문제 수정: 이스케이프된 제어 문자는 이제 리터럴 텍스트로 유지됩니다
- 플러그인의 LSP 서버가 종료되거나 stdin을 닫을 때 백그라운드 세션(`claude --bg`)이 종료되는 문제 수정
- `~/.claude.json`에 잘못된 형식의 `claudeAiMcpEverConnected` 값이 있을 때 `/mcp` 또는 `/plugin manage` 열기 시 충돌 수정
- `~/.claude.json`에 잘못된 형식의 `theme` 값이 있을 때 시작 시 충돌 수정
- 프롬프트가 터미널 색상 코드를 포함하는 텍스트(예: 히스토리에서 회수된 프롬프트 또는 외부 편집기에서 로드된 텍스트)를 보유할 때 충돌 수정
- 저장된 히스토리에 일반 문자열로 저장된 assistant 메시지를 포함하는 세션을 재개할 때 충돌 수정
- 느린 또는 로드가 높은 머신의 세션이 첫 번째 spinner가 나타날 때 "Claude Code exited after an unrecoverable interface error"로 종료되는 경우가 있는 문제 수정
- 내부 렌더링 오류 후 화면이 나머지 세션 동안 업데이트를 중단할 수 있는 드문 경우 수정
- Claude가 응답한 직후 Windows에서 턴이 "Out of memory" 같은 오류로 중단될 수 있는 드문 경우 수정: 해당 응답의 도구 호출이 실행되지 않았습니다
- `/clear` 후 계속된 세션(재시작, `--continue`, `--resume`)이 SessionStart 훅이 출력을 인쇄할 때 첫 번째 메시지의 일부를 누락하는 문제 수정: 이로 인해 전체 prompt-cache 누락이 발생했습니다
- 다른 agent의 메시지(예: subagent의 SendMessage)가 턴 중간에 도착할 때 도착 위치 대신 "Ran N shell commands" 행 아래에 표시되는 문제 수정
- fullscreen `/resume` picker 및 프롬프트 영역을 덮는 다른 패널에서 드래그로 텍스트를 선택한 후 "copied" 알림이 나타나지 않는 문제 수정
- Bash 명령이 샌드박싱이 활성화되어 있는 동안 샌드박스 외부에서 실행될 때 `$TMPDIR`이 확장되지 않는 문제 수정
- Cowork 클라우드 세션에서 WebFetch 및 WebSearch가 사용된 fetch 예산 또는 admin 정책과 같이 요청이 거부된 이유를 Claude에 알려주지 않는 문제 수정
- proxy가 설정되어 있을 때 Claude apps gateway의 telemetry relay가 `NO_PROXY`에 나열된 수집기 hostname 또는 도메인을 무시하는 문제 수정
- 잘못된 형식의 `strictKnownMarketplaces` 또는 `blockedMarketplaces` 항목이 전체 enterprise marketplace 정책을 자동으로 비활성화하는 문제 수정
- 실패한 auto-update가 `~/.cache/claude/staging`에 큰 스테이징 다운로드를 남기는 문제 수정
- `/plugin`이 Installed 탭의 메시지에서 터미널 제어 문자를 제거하지 않는 문제 수정(예: 실패한 플러그인 업데이트의 오류)
- `/plugin` → Installed 및 `/skills`이 `constructor` 또는 `toString`과 같은 기본 제공 Object 속성처럼 이름 지어진 skill 또는 레거시 명령으로 충돌하는 문제 수정
- 다중 선택에서 모든 설치가 실패할 때 `/plugin`이 메시지 없이 닫히는 문제 수정
- 제거된 플러그인이 `/plugin` Installed에서 "failed to load" 행으로 재나타나고 Remove가 그러한 행을 지우지 않는 문제 수정
- 공식 marketplace의 플러그인이 `installed_plugins.json`에 commit 없이 기록되고, 고정된 commit 플러그인을 업데이트한 후 `installed_plugins.json`이 이전 commit을 유지하는 문제 수정
- 플러그인 reload 미리보기가 종료될 때까지 미리본 모든 플러그인 아카이브 복사본을 압축 해제한 상태로 유지하고, reload가 다운로드 실패 시 폴백하는 캐시된 `--plugin-url` 아카이브를 덮어쓰는 문제 수정
- `~/.claude.json`이 잘못된 형식의 placeholder 레코드를 보유할 때 Remote Control 세션 부기 실패 수정
- 취소된 claude.ai 로그인 후의 오류가 만료된 Anthropic 프로필을 비난하는 문제 수정: 이제 `/login`으로 시작합니다
- `claude agents` dispatch 입력에서 키 반복 또는 매우 빠른 입력 중에 입력된 또는 붙여넣은 텍스트가 때때로 스크램블되는 문제 수정
- 잘못된 형식의 hook 목록이 없는 stop 훅 요약을 포함하는 저장된 대화본을 재개할 때 충돌 수정
- `keybindings.json`이 Chat context에서 Enter를 재바인딩할 때(예: `chat:queueSubmit`으로) 선택된 agent 패널 행에서 Enter를 누르면 아무 일도 일어나지 않는 문제 수정
- Windows에서 작업 폴더의 경로가 길 때(약 120자 이상) PDF 페이지 읽기 실패 수정
- headless resume(`claude -p --resume`, SDK, VS Code 확장 창 reload)이 세션의 비용 및 사용량 합계를 0으로 시작하는 문제 수정: headless 세션이 이제 종료 시 합계를 저장합니다
- `.claude/skills`가 tracked되지 않을 때 주 repository의 project skill이 `--worktree` 세션에서 로드되지 않는 문제 수정
- `sandbox.excludedCommands` glob이 한 부분만 일치할 때 전체 compound Bash 명령을 샌드박스에서 면제하는 문제 수정: 이제 모든 부분이 일치해야 합니다
- 재개된 subagent 및 teammate가 로드한 MCP 도구 정의를 다시 렌더링하는 문제 수정: 이로 인해 해당 agent의 prompt caching이 중단되었습니다
- rate-limited artifact 게시가 Claude에 재시도를 중단하도록 지시하는 문제 수정: Claude가 아무것도 게시되지 않았고 동일한 게시를 다시 보낼 시기를 받습니다
- 대화의 이전에 기록된 첨부파일이 resume 또는 재시작 후 다시 렌더링되는 문제 수정: 이로 인해 extended thinking이 삭제되고 prompt cache를 놓쳤습니다
- Console 로그인이 서버가 API 키 생성을 거부할 때 서버의 메시지를 표시하는 대신 "Request failed with status code 400"만 표시하는 문제 수정
- Claude가 여전히 작업 중일 때 입력한 메시지가 때때로 모델에 의해 무시되는 문제 수정
- SDK 및 headless(`-p`) 사용을 위한 세션 시작 개선: 첫 번째 턴이 더 이상 per-directory CLAUDE.md 조회를 기다리지 않습니다
- Claude apps gateway의 loopback 오류 메시지 개선: `CLAUDE_GATEWAY_ALLOW_LOOPBACK` 이름을 나타냅니다
- `/plugin` Installed 개선: plugin과 별도로 나열된 MCP 서버는 이제 어느 plugin에 속하는지 표시합니다
- 이미 설치된 plugin에 대한 `claude plugin install` 개선: 이제 marketplace가 더 최신 버전을 제공할 때 그를 표시하고 `claude plugin update` 명령을 이름 지습니다
- 로고 아래 startup notice 오버플로우 줄 개선: 이제 "+N more · /status" 대신 "N more notices hidden"을 읽습니다
- Prompt 처리 개선: 프롬프트의 보이지 않는 Unicode 포맷팅 및 태그 문
