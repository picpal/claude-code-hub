> 원문: [Claude Code v2.1.234 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.234)

## 변경사항

- `CLAUDE_CODE_PROJECT_DIR_NAME` 선택 환경 변수를 추가했습니다: 각 세션마다 자체 config 디렉토리를 제공하는 호스트에서는 프로젝트별 transcript 디렉토리에 짧은 이름을 선택할 수 있습니다
- `selection:clear` keybinding action을 추가했습니다: 텍스트로 앱 내 텍스트 선택을 지울 수 있도록 키를 바인딩할 수 있으며, agents 뷰에서도 작동합니다
- 푸터 및 statusline에 GitLab merge request 배지를 추가했습니다: GitLab remote와 인증된 glab CLI가 있는 repo는 draft/pending/green 상태와 함께 MR !N을 표시합니다
- Claude Code는 이제 claude.ai 사용량 제한이 재설정되면 자동으로 세션을 계속합니다; `/config`에서 끄기 ("Continue automatically at usage limit")
- Claude는 이제 계정 이메일을 당신을 식별하기 위해서만 사용하도록 지시받으며, 당신이 요청하지 않는 한 관련 없는 서비스에 이메일을 전송하지 않습니다
- 보안: 원격 파일 읽기, 세션 복원, CLAUDE.md 포함, workflow 스크립트 및 파일 업로드는 이제 Windows NT-namespace (`\??\`) 경로를 거부하여, NTLM credential-leak 벡터에 대한 남은 사전 승인 파일 접근을 강화합니다
- 매우 긴 세션에서 auto mode가 대화가 압축된 후 sandbox 명령의 네트워크 접근을 반복적으로 확인하고 거부하는 문제를 수정했습니다
- 배경 subagent tool 권한 프롬프트에 답할 때 session 범위 권한 답변(거부 포함)이 삭제되는 문제를 수정했습니다
- 비스트리밍 fallback 경로의 API 응답(일반적으로 third-party 게이트웨이를 통한)에 thinking 필드가 없는 thinking 블록 또는 text 필드가 없는 text 블록이 포함되어 있을 때 발생하는 crash를 수정했습니다
- 특이한 Unicode 시퀀스를 포함하는 일부 메시지에 대해 markdown 렌더링이 극도로 느려지는 문제를 수정했습니다
- `ListAgents`에서 복사한 recipient를 `SendMessage`가 거부하는 문제를 수정했습니다(세션 이름이 200자 제한이거나 이모지가 많을 때)
- 비정상적인 userinfo를 가진 git remote의 호스트를 repository 감지가 잘못 읽어서 잘못된 호스트에 대해 링크 및 repo 관련 동작을 생성하는 문제를 수정했습니다
- MCP diagnostics가 해결된 secrets를 출력하는 문제를 수정했습니다: scope-conflict 경고는 이제 구성된 `${VAR}` 형식을 표시하며, connection-failure 세부 정보는 server origin만 표시합니다
- `strictKnownMarketplaces` allowlist가 git에서 실제로 연결할 호스트와 다른 호스트를 가진 SCP 스타일 git marketplace 소스를 수용하는 문제를 수정했습니다
- `/login` OAuth URL 같은 modal 텍스트가 전체 화면에서 복사할 때 문자가 손실되는 문제를 수정했습니다
- 렌더링된 markdown의 `---` 수평선이 다음 줄로 이어지는 문제를 수정했습니다
- 연속된 shell 명령이 중간에 todo/task 업데이트가 끼어들 때 여러 "Ran 1 shell command" 행으로 분할되는 문제를 수정했습니다
- `!` shell 명령이 실행 중일 때 `/permissions` 같은 대화가 열렸을 때 명령이 완료되면 닫히는 문제를 수정했습니다
- 대기 중인 `!` shell 명령이 up-arrow를 눌러 대기 중인 입력을 편집한 후 모델에 일반 텍스트로 전송되는 문제를 수정했습니다
- 대기 중인 메시지가 여전히 대기 중일 때 prompt 히스토리에 다시 나타나는 문제를 수정했습니다. 대기 중인 메시지를 선택할 때 Esc는 더 이상 turn을 중단하지 않으며, `!` mode는 mid-turn submit 후 더 이상 붙지 않습니다
- "Try the new fullscreen renderer?" 프롬프트를 수락하면 session이 권한 mode(예: `--dangerously-skip-permissions`), tool allow/deny 규칙, model 또는 effort 플래그 없이 다시 시작되는 문제를 수정했습니다
- `/tui`가 launch `--allowed-tools`/`--disallowed-tools` 규칙을 다시 시작할 때 삭제하는 문제를 수정했습니다. 이제 session에 restart가 이월할 수 없는 제한이 있을 때 그 이유와 함께 전환을 거부합니다
- 디렉토리를 처음 본 후 repository가 그곳에 존재하기 전에 trust 프롬프트가 repository 범위 경고를 생략하는 문제를 수정했습니다
- permission re-prompt 중에 IDE diff 탭이 닫힐 때 새 프롬프트에 이전 입력으로 답할 수 있는 경우를 수정했습니다
- Claude Code Desktop 또는 VS Code에서 호스팅된 Remote Control 세션 중에 사용자에게 전송된 파일은 이제 업로드되어 빈 카드를 표시하는 대신 휴대폰 및 웹에서 열립니다
- `/login` 중에 `CLAUDE_CODE_OAUTH_TOKEN`이 설정되어 있을 때, 만료된 토큰 알림이 더 이상 Claude의 자동으로 재개된 turn으로 새어나가지 않습니다 — 이제 당신에게만 나타납니다
- 권한 미리보기는 이제 inbound trust gate로 인정된 channel 서버에만 릴레이하며, server의 명시적 permission-capability opt-out은 존중됩니다
- 권한 미리보기에서 credential 마스킹은 더 이상 approver로부터 명령, 경로 또는 목적지를 숨길 수 없습니다; 크기가 큰 private-key 블록은 이제 완전한 강도의 redaction 아래에서 redact됩니다
- 권한 미리보기에서 마스킹하는 provider API 토큰은 이제 shell 구분 기호가 직접 뒤따를 때도 마스킹됩니다
- Claude Desktop inter-session 메시지가 cross-session 메시징이 비활성화된 것으로 읽힐 때 recipient session에서 조용히 삭제되어, 발신자의 쿼리가 많은 시간 동안 "thinking" 상태로 남는 문제를 수정했습니다
- Remote Control: 이 컴퓨터를 다른 claude.ai 계정 또는 조직에 로그인하면 이제 몇 시간 후 잘못된 HTTP 404 대신 초 단위로 실행 중인 세션을 중지하고 그 이유를 표시합니다
- Claude Code Desktop 또는 VS Code에서 시작된 Remote Control 세션은 이제 휴대폰 및 claude.ai/code를 세션의 권한 mode(및 claude.ai/code를 model)에 대해 변경 시 업데이트 상태로 유지합니다
- Remote Control: 휴대폰 또는 claude.ai/code에서 선택한 effort는 이제 terminal 및 Desktop/VS Code 호스팅 세션에 적용되며, 세션은 연결된 클라이언트에 effort 수준을 게시합니다
- `SendMessage` 및 `ListAgents`는 이제 계정의 세션 목록이 너무 길어서 완전히 확인할 수 없을 때 표시하며, 보이지 않는 세션을 부재로 취급하지 않습니다
- 만료된 Anthropic profile credential은 이제 claude.ai 로그인이 우선할 때 `/login`으로 안내합니다
- Transcript를 개선했습니다: 당신의 prompt는 이제 응답과 동일한 방식으로 markdown(강조된 코드 블록, 인라인 코드, 목록)을 렌더링합니다
- "API returned an empty or malformed response" 오류를 개선했습니다: 이제 반환된 항목(content type, body kind, size, request ID) 및 원본 streaming request가 실패한 이유를 표시합니다
- 자동 생성된 세션 제목을 개선했습니다: 이제 요청을 다시 말하는 문장(예: "Fix the login button on mobile") 대신 짧고 구체적인 이름(예: "Login button bug")으로 읽습니다
- 빌트인 `claude-api` skill을 로드하는 context cost를 ~200k+ tokens에서 ~25k로 줄었습니다(reference docs를 온디맨드로 로드)
- `/permissions`를 이제 Claude가 작업 중일 때 열 수 있습니다 — 규칙 변경은 현재 turn의 나머지에 적용됩니다
- `/add-dir <path>`를 이제 Claude가 작업 중일 때 사용할 수 있습니다; `/add-dir`, `/autocompact`, `/theme`, `/help`, `/config` 및 `/advisor` 대화는 fullscreen TUI에서 mid-turn으로 열립니다
- `/goal`은 이제 요청을 기다렸다가 유지하는 대신(예: 취소된 auth, 소진된 credit balance 또는 context overflow) 복구 불가능한 오류로 turn이 죽을 때 알림과 함께 자신을 지웁니다
- `/goal`: 배경 작업이 goal을 30분 이상 대기하게 할 때, Claude는 이제 무한정 대기하는 대신 작업을 확인합니다(set `CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0` to opt out)
- `claude setup-token`은 이제 예상치 못한 추가 인수를 조용히 무시하는 대신 거부합니다
- fullscreen mode에서 Esc를 변경했습니다: 더 이상 마우스 텍스트 선택을 지우지 않습니다. 평소대로 중단하거나 닫으며 선택은 강조된 상태로 유지됩니다
- auto mode가 모든 Agent tool 호출 아래에 표시한 중복 "Allowed by auto mode classifier" 줄을 제거했습니다
- `/config`에서 "Default teammate model" 설정을 제거했습니다; agent-team teammates는 이제 spawn이 지정하지 않는 한 leader의 model을 사용합니다
- 실행 중인 tool 헤더의 경과 시간 카운터를 흐리게 하여 bold 수와 더 이상 경쟁하지 않도록 했습니다
- Turn 사이에 배송된 배경 작업 알림은 이제 mid-turn 배송과 일치하는 `<system-reminder>` 태그 내 모델로 전송됩니다
- Mantle: 메인 루프 model이 이미 선택되어 있을 때 시작 시 admin-pin 가용성 probe를 건너뜁니다
- Windows: startup은 이제 `~/.claude.json`이 읽기 전용일 때 반복된 rename 재시도에서 지연되지 않습니다
