> 원문: [Claude Code v2.1.286 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.286)

## 변경사항

- 여러 권한 요청이 쌓일 때 권한 프롬프트에 "2 of 5"와 같은 카운트를 추가했습니다
- fullscreen 모드에서 리스트의 "N more" 행에 대한 마우스 지원을 추가했습니다: 클릭하면 리스트의 해당 끝으로 이동하며, hover 및 pressed 상태를 지원합니다
- gcpAuthRefresh 또는 awsAuthRefresh 자격증명이 만료될 때 Claude Code 프로세스 및 IDE 확장이 각각 로그인 브라우저를 여는 문제를 수정했습니다
- `claude --resume` 및 `--continue`가 병렬 tool 호출의 배치 후 모든 턴을 잃는 경우가 있는 문제를 수정했습니다 (이전 세션이 충돌하거나 종료되었을 때)
- tool 또는 hook이 텍스트 대신 객체, 숫자 또는 불린을 반환한 후 발생하는 API 400 에러를 수정했습니다 (resumed 세션 포함)
- 매우 큰 히스토리를 가진 cloud 세션이 트랜스크립트가 로드되는 중에 container가 중지되어 절대 깨어나지 않는 문제를 수정했습니다
- Claude apps gateway의 spend meter가 1시간 prompt cache 쓰기를 더 저렴한 5분 요금으로 청구하고, web search와 같은 server-side tool을 실행하는 streamed turn에서 첫 번째 model call의 input token만 계산하는 문제를 수정했습니다
- 다른 Claude Code 윈도우에서 `/login`이 성공한 후에도 macOS 세션이 "Not logged in" 또는 "Login expired"를 표시하는 문제를 수정했습니다 (남은 `~/.claude/.credentials.json`이 존재할 때)
- Anthropic API가 default model 또는 model alias가 해석되는 model을 거부할 때 모든 턴이 실패하는 문제를 수정했습니다: Claude Code는 이제 같은 tier의 이전 model로 한 번 재시도합니다
- 조직의 정책이 Remote Control을 끄면 Remote Control 세션 (including `claude remote-control`)이 연결된 상태로 남아있는 문제를 수정했습니다: 이제 알림과 함께 연결이 끊깁니다
- fallback model이 빠르게 실행될 수 없을 때 거부 및 `--fallback-model` 재시도가 실패하는 문제를 수정했습니다: 이제 표준 속도로 실행되며, interactive 세션에서 일회성 알림을 표시합니다
- MCP discovery cache가 활성화되어 있을 때 headless 세션이 성공적인 재인증 후 "MCP servers require authentication" 상기를 반복하는 문제를 수정했습니다
- `claude auth status`가 Console 로그인의 저장된 API key를 `claude.ai`로 보고하는 문제를 수정했습니다: 이제 `api_key`를 보고하며, VS Code 확장은 해당 세션을 API key 세션으로 처리합니다
- `/status`가 Anthropic profile을 API key 옆에 마치 둘 다 효력이 있는 것처럼 나열하는 문제를 수정했습니다: profile은 이제 사용 중이 아님으로 표시됩니다
- Remote Control을 통해 전송된 메시지에 첨부된 파일이 도착하지 않았을 때 Claude에 알려지지 않는 문제와, 파일이 마지막 다운로드 시도에 10초만 걸리는 문제를 수정했습니다
- Claude Code가 종료되는 중에 도착한 Remote Control 메시지가 배달됨으로 표시된 후 답변되지 않는 문제를 수정했습니다: 이제 다음 세션 실행을 위해 queued에 남아있습니다
- MCP error 메시지가 "Bearer" 또는 "Basic" 앞에 자격증명의 값을 표시하는 문제를 수정했습니다
- percent-encoded Bearer token이 error 메시지에서 부분적으로만 masked되는 문제를 수정했습니다
- redacted log 및 transcript가 zero-width space와 같은 보이지 않는 문자를 포함한 secret의 key name을 표시하는 문제를 수정했습니다
- log 및 transcript가 `)`, quotes, `]`, `&` 또는 두 번째 `@`와 같은 punctuation을 포함하는 URL password의 일부를 표시하거나, ssh URL의 `[::1]`과 같은 bracketed host로 `/`를 넘어가는 문제를 수정했습니다
- `/feedback`이 disk에 저장하는 zip의 session transcript이 secret redaction 후 invalid JSON line을 포함하는 문제를 수정했습니다
- MCP connector가 server가 더 이상 사용하지 않는 MCP handshake를 drop한 후 최대 하루 동안 도구를 나열하지 않는 문제를 수정했습니다
- 반복되는 MCP 로그인 요청이 Claude로부터 대기 중인 로그인 링크를 대체하여 해당 링크가 작동하지 않을 수 있는 문제를 수정했습니다
- `/usage`가 server가 여전히 연결 중이거나 방금 연결된 (예: 재시작 직후) 동안 수행된 tool call에 대해 MCP server에 credit을 부여하지 않는 문제를 수정했습니다
- claude.ai에서 활성화된 plugin이 transient server error 후 세션에 대해 Claude Code에서 가끔 사라지는 문제를 수정했습니다
- running subagent에 입력된 메시지가 subagent가 읽은 후 transcript에 두 번 표시되는 문제를 수정했습니다
- subagent hand-back 메시지가 subagent에 등록된 이름이 없을 때 agent의 이름 대신 raw task id를 표시하는 문제를 수정했습니다
- foreground subagent가 task-tracking tool (TaskCreate/Get/Update/List, TodoWrite)을 활성화한 세션에서 누락되는 문제를 수정했습니다
- worktree isolation으로 spawn된 subagent가 첫 번째 파일 읽기에서 worktree 복사본으로부터 project CLAUDE.md 및 해당 import를 두 번째로 로드하는 문제를 수정했습니다
- Workflow tool subagent가 응답 중간에 connection이 몇 분 동안 중단될 때 원래 prompt에서 재시작되는 문제를 수정했습니다
- background agent 또는 teammate의 transcript를 보는 중에 입력한 `/compact`, `/clear`, `/rewind`가 main conversation에 자동으로 작용하는 문제를 수정했습니다: dialog가 이제 대상을 명시하고 먼저 확인을 요청합니다
- background job이 승인을 기다리는 동안 완료됨으로 표시되는 문제를 수정했습니다
- commit attribution reminder가 model fallback이 한 턴만 지속될 때 tool output 내에서 재전송되는 문제를 수정했습니다
- collapsed row (예: "Thought for 4s")의 단어 사이 공간을 클릭할 때 fullscreen 모드에서 행을 확장하지 않고 강조하는 문제를 수정했습니다
- 자세한 정보가 없는 행 (예: 긴 이름의 action row)이 list 화면의 다른 모든 행의 자세한 정보를 오른쪽으로 밀어내는 문제를 수정했습니다
- 매우 긴 이름의 파일이 cloud 세션에 첨부될 때 도달하지 않는 문제를 수정했습니다
- Claude Code가 로드를 거부하는 marketplace의 plugin error가 발생하는 문제를 수정했습니다: 이제 "not found" 대신 이유와 수정 방법을 표시합니다
- `/plugin`의 Discover tab이 행이 해당 이름을 따옴표로 표시할 때 "Checking … for new plugins" 줄에서 marketplace 이름을 따옴표 없이 표시하는 문제를 수정했습니다
- commit guidance를 개선했습니다: project 또는 user skill에 `verify`라는 이름의 skill이 포함되어 있으면, Claude는 이제 commit 바로 전에 실행하도록 지시받습니다 (docs-only 및 tests-only commit 제외)
- subagent 보기에서 send now (ctrl+enter)를 개선했습니다: subagent의 running command가 background로 이동하여 메시지가 바로 읽혀집니다
- background agent의 메시지 응답을 개선했습니다: 더 이상 사용자가 말한 내용의 별도 recap으로 시작하지 않습니다
- claude.ai artifact link read를 개선했습니다: WebFetch는 이제 Artifact tool의 read와 같은 질문을 요청합니다 (세션의 network access가 켜져 있을 때는 artifact prompt 없음, 꺼져 있을 때는 artifact당 하나), 그리고 auto-mode yes는 더 이상 user만 답할 수 있는 경우를 계산하지 않습니다
- fetch, skill, file read, sandbox network, Claude in Chrome, workflow script 및 notebook edit permission prompt를 file edit prompt의 모양과 일치하도록 개선했습니다
- Bash, PowerShell 및 Monitor permission prompt를 개선하여 대시 줄 사이에 command를 표시합니다 (file edit prompt와 일치)
- fullscreen 모드의 list scrollbar를 개선했습니다: 대부분의 list에서 bar는 "N more" 행이 나타났다 사라질 때 이동하지 않으며, 이제 클릭하거나 누르고 있을 수 있는 ↑/↓ arrow를 포함합니다
- external editor (Ctrl+G)를 개선했습니다: line number를 받는 editor는 이제 prompt의 cursor가 있는 줄에서 엽니다
- 많은 skill 또는 plugin command가 설치되어 있을 때 입력 중인 slash command 제안 responsiveness를 개선했습니다: command description이 이제 word prefix로 일치합니다
- output style picker를 개선했습니다: Default 대신 현재 style에서 열리며, 각 style의 설명이 이름 아래 줄에 표시됩니다: number key는 더 이상 style을 선택하지 않습니다
- `/hooks`를 개선했습니다: hook의 detail 화면의 closing line이 "it" 대신 "this hook"을 말합니다
- model fallback notice 및 autocompact-thrashing error를 개선하여 fallback이 context window를 1M에서 200K token으로 줄였을 때를 표시합니다
- host가 이미 연결된 MCP server에 대해 MCP server enable을 재전송할 때 SDK 및 `-p` 세션의 responsiveness를 개선했습니다
- Claude apps gateway가 `/protocol`에서 제공하는 protocol page를 개선했습니다: 이제 unknown input을 거부하지 말도록 하며 Claude Code가 오늘 전송하는 것과 일치합니다
- nothing이 실행 중이거나 queued일 때 전송된 prompt가 회색 대신 normal text color로 바로 표시되도록 변경했습니다
- 실패한 API 요청이 재시도되는 방식을 변경했습니다: 하나의 limit이 이제 전체 model call을 포함하므로, default retry 설정으로 실패한 call이 최대 14개의 요청을 전송합니다
- `--bare`를 변경하여 command line에 명시된 MCP server만 연결하고, model에 system reminder를 보내지 않으며, background task를 시작하지 않도록 했습니다: `--bare`에서 timeout에 도달한 shell command는 이제 background로 이동하는 대신 중지됩니다
- send-now key (ctrl+enter)를 변경하여 skill's own shell command를 끝내는 대신 background로 이동하도록 했습니다
- WebFetch error를 변경하여 rate-limited domain safety check의 경우 Claude에 loop에서 재시도하지 말도록 지시합니다
- plugin 설치를 변경하여 git repository 또는 folder인 npm source를 거부하고, plugin dependency를 registry package에서만 설치하도록 했습니다
- list 화면 (`/artifacts`, `/mcp`, `/skills`, `/hooks` 등)을 변경하여 각 행의 자세한 정보를 이름 후 한 열에 정렬하도록 했습니다
- list의 overflow 행을 변경하여 "N more above" / "N more below" 대신 "↑ N more" / "↓ N
