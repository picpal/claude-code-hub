> 원문: [Claude Code v2.1.283 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)

## 변경사항

- gateway hint headers에 `x-claude-code-prompt-id`를 추가하여 LLM gateway가 한 사용자 prompt를 처리하는 요청들을 그룹화할 수 있도록 했습니다. `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`로 옵트인할 수 있습니다.
- `availableModelsMatch` managed setting을 추가했습니다. `"exact"`로 설정하면 `availableModels` 항목이 지정한 모델 버전만 허용하여 새 릴리스는 목록에 추가될 때까지 차단됩니다.
- `deniedModels` managed setting을 추가하여 `availableModels`이 허용하더라도 특정 모델을 차단할 수 있습니다.
- `OTEL_LOG_TOOL_CONTENT=1`일 때 MCP tool, WebFetch 및 WebSearch 출력을 `tool.output` OpenTelemetry span event에 추가했습니다.
- `/doctor prompt-audit` (또한 `/checkup prompt-audit`)를 추가하여 CLAUDE.md 파일, skill, agent 및 command를 감사하고 오래된 모델을 위해 작성된 prompting 패턴을 찾을 수 있습니다.
- 전체화면 모드에서 다른 세션의 잘린 메시지를 클릭하여 확장할 수 있는 기능을 추가했습니다.
- `--plugin-dir` load-failure 항목의 stream-json `system/init` `plugin_errors`에 `path`를 추가하여 로드되지 않은 디렉토리를 지정합니다.
- Claude apps gateway config에 옵트인 `load_test_mode` 블록을 추가했습니다. 요청이 빌드 및 서명되지만 업스트림으로 전송되지 않으며 클라이언트는 미리 정해진 응답을 받으므로 배포를 부하 테스트할 수 있습니다.
- Amazon Bedrock의 Mantle endpoint를 위한 `mantle` upstream provider를 Claude apps gateway에 추가했습니다.
- SDK 세션이 turn이 조기에 종료되었을 때 deferred tool call 또는 finished tool result를 잃고, worker 재시작 후 held approval prompt를 잃으며, non-streaming fallback의 `result.usage`를 잃는 문제를 수정했습니다.
- MCP progress notification이 오래 실행되는 tool call이 백그라운드로 이동한 후 폐기되는 문제를 수정했습니다. 백그라운드 작업이 이제 최신 진행률을 표시합니다.
- 세션이 종료되는 동안 stdio MCP server가 시작되고 있을 때 남아있는 문제를 수정했습니다.
- stateless remote MCP server (예: 재배포 중인 proxy)의 짧은 HTTP 404가 해당 서버를 연결된 것으로 표시하면서 나머지 세션 동안 사용할 수 없게 만드는 문제를 수정했습니다.
- 유효한 URL이 없는 server의 MCP sign-in이 불명확한 SDK 오류로 실패하는 문제를 수정했습니다. `/mcp`이 더 이상 이러한 server에 대해 Authenticate를 제안하지 않습니다.
- 원격 측정이 비활성화되었을 때 `/usage` 및 VS Code usage meter에 주간 Fable limit이 나타나지 않는 문제를 수정했습니다.
- `/model`이 plain id가 거부된 경우에 date 또는 `-v1:0` suffix를 가진 id로 Sonnet 4.6 또는 Sonnet 5를 수락하는 문제를 수정했습니다.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`이 다른 모델을 지정할 때 `/model` picker가 하드코딩된 Haiku 버전과 가격을 표시하는 문제를 수정했습니다.
- 모델 fallback 중에 시작된 dynamic workflow가 configured model을 재시도하지 않고 fallback model에서 모든 agent를 실행하는 문제를 수정했습니다.
- Haiku가 세션의 main model일 때 `DISABLE_PROMPT_CACHING_HAIKU`이 효과가 없는 문제를 수정했습니다.
- `claude plugin validate`가 Claude Code가 설치할 수 없는 plugin 또는 marketplace name을 수락한다고 하는 문제를 수정했습니다. `marketplace.json`의 이러한 name은 이제 검증에 실패합니다.
- `claude plugin validate`가 `outputStyles`, `themes`, `monitors` 또는 `lspServers` 경로가 누락되었거나 plugin 디렉토리 외부를 가리키는 plugin을 통과시키는 문제를 수정했습니다.
- `claude plugin details`가 `plugin.json`에서 서버를 선언하는 plugin에 대해 0 MCP server를 표시하는 문제를 수정했습니다.
- `claude plugin marketplace remove`가 marketplace로 언제 plugin을 제거했는지 표시하지 않는 문제를 수정했습니다. 이제 제거된 plugin들을 나열합니다.
- `claude plugin uninstall`이 id가 대소문자로만 다른 두 설치된 plugin 중 하나를 제거할 때 지정된 plugin에 해당 범위의 `enabledPlugins` 항목이 없으면 다른 plugin의 옵션 및 secret도 제거하는 문제를 수정했습니다.
- version을 선언하지 않는 plugin이 캐시된 파일이 누락되었을 때 설치된 것이 아닌 source의 최신 commit에서 자동으로 복구되는 문제를 수정했습니다.
- 사용자 설치 plugin 및 marketplace가 예를 들어 bind-mounted devcontainer에서 home 또는 config 디렉토리가 이동한 후 "cache-miss"로 로드되지 않는 문제를 수정했습니다.
- `installed_plugins.json`이 유효하지 않은 plugin id에 대한 기록을 보유할 때 plugin을 표시하지 않는 문제를 수정했습니다. 이러한 파일이 다시 로드됩니다.
- `installed_plugins.json`이 이 버전이 읽을 수 없는 기록을 보유할 때 재작성되어 기록이 손실되는 문제를 수정했습니다. `claude plugin` command가 이제 기록의 이름을 지정하고 복구 방법을 표시합니다.
- screen-reader 모드에서 permission dialog가 인용된 command와 경로를 dialog 자신의 텍스트인 것처럼 읽는 문제를 수정했습니다.
- `/context`가 MCP server instruction을 계산하지 않는 문제를 수정했습니다. 이제 자신의 행으로 나타나고 전체에 계산됩니다.
- Warp terminal의 markdown link가 클릭 가능한 하이퍼링크가 아닌 일반 텍스트로 렌더링되는 문제를 수정했습니다.
- `claude mcp add`, `add-json` 및 `remove`가 예를 들어 sandbox 내에서 사용자 또는 로컬 config 파일을 쓸 수 없을 때 성공을 보고하는 문제를 수정했습니다.
- cloud 세션에서 reply의 첫 단어가 Claude가 작성할 때 stream되지 않고 늦게 나타나는 문제를 수정했습니다.
- Claude의 내장 keybinding guide가 chord가 1초 후 시간 초과된다고 하고 `cmd`를 `meta`의 별칭이라고 부르는 문제를 수정했습니다. 이는 대부분의 terminal이 전송하지 않는 `cmd+` shortcut을 만들 수 있습니다.
- `keybindings.json`이 `ctl+k` 같은 오타난 modifier를 자동으로 수락하는 문제를 수정했습니다. 이제 debug log에서 경고하고 수정안을 제안합니다.
- `footer:openSelected`가 `keybindings.json`에서 재바인드되거나 언바인드된 후 footer hint가 여전히 "Enter to view"라고 표시하는 문제를 수정했습니다.
- 빠르게 함께 입력된 key (type-ahead, key repeat, ssh 또는 tmux를 통한 burst)가 stale state에 대해 처리되는 문제를 수정했습니다.
- worktree checkout이 CA certificate이 `GIT_CONFIG_COUNT` environment pair로 git에 전달될 때 certificate 검증에 실패하는 문제를 수정했습니다.
- sandboxed `git`이 credential helper에 sandbox proxy의 로그인을 저장하도록 요청하여 "failed to store"를 인쇄하는 문제를 수정했습니다.
- managed `sandbox` setting이 중첩된 값이 하나 유효하지 않을 때 완전히 무시되는 문제를 수정했습니다. 유효하지 않은 값은 이제 실패하고 나머지 블록이 적용됩니다.
- Claude Code가 git repository의 하위 디렉토리에서 시작되었을 때 Claude의 자동 메모리 note 편집이 sensitive-file write로 차단되는 문제를 수정했습니다.
- `DISABLE_TELEMETRY` 또는 `DO_NOT_TRACK`으로 원격 측정을 끌 때 Remote Control이 유료 요금제에서 사용할 수 없는 문제를 수정했습니다.
- `/remote-control` menu가 좁은 terminal에서 QR-code hint를 단어 중간에 자르는 문제를 수정했습니다.
- vim mode `.`이 Shift+Enter newline을 제거하여 cursor를 accented letter 내에 남기고 마지막 행에서 `3J` 또는 Visual-mode `J` 후 이전 change를 반복하는 문제를 수정했습니다.
- vim mode cursor placement: normal mode에서 10,000자가 넘는 prompt를 회상해도 cursor가 끝 너머에 남지 않으며, `V` 다음 `p`는 이제 첫 번째 non-blank에 착지합니다.
- vim mode `J`가 Vim과 다른 spacing으로 line을 join하고 (예: `)` 앞의 space 또는 tab 뒤), 마지막 행에서 `3J` 또는 Visual-mode `J`이 Vim처럼 cursor를 이동하지 않는 문제를 수정했습니다.
- Windows: PowerShell tool이 `cmd /c rd`, `rmdir`, `del` 또는 `erase`가 `Remove-Item`이 거부하는 drive root, home folder 및 기타 folder를 삭제하도록 허용하는 문제를 수정했습니다.
- `/mcp` tool list를 개선했습니다. 한 번에 더 많은 tool을 표시하고 page key 및 mouse로 scroll하며 조직이 차단한 tool을 경고 아이콘으로 표시합니다.
- MCP tool result를 개선했습니다. MCP tool이 반환한 이미지는 이제 파일에도 저장되어 Bash, Read 및 기타 tool이 열 수 있습니다.
- `/tasks`를 개선했습니다. 행이 status icon, name과 전체 facts를 표시하고, title과 key hint는 많은 task에서도 화면에 유지되며, 목록이 paging key, mouse wheel 및 click을 얻습니다.
- `/help`, `/hooks`, `/copy`, `/chrome`, `/memory`, `/ide`, `/release-notes`, `/rewind`, `/diff`, `/remote-env`, `/plugin` 및 기타 picker의 list를 page key, mouse wheel 및 click으로 개선했습니다.
- search box 옆의 list (예: `/skills` 및 `/artifacts`)를 개선하여 search box가 key를 가질 때 pointer를 dim으로 그려 하나의 pointer만 강조 표시됩니다.
- compaction spinner를 개선했습니다. 이제 timer가 compaction이 시작할 때 시작되고 summary의 token을 stream하면서 계산하여 percentage bar를 대체합니다.
- MCP server에 sign in한 후 표시되는 browser page를 개선했습니다. centered layout, dark mode 및 새로운 artwork입니다.
- Skill tool의 reply를 개선했습니다. skill이 로드되지 않은 plugin에 속할 때 Claude가 skill이 설치되지 않은 대신 plugin을 로드할 수 없다고 말합니다.
- Claude Code configuration에서 `prompt-audit`를 개선했습니다. stale path, stale command 및 contradicting instruction file이 이제 report를 선도하고, Claude Code가 문서화한 thinking keyword는 유지됩니다.
- 완전히 읽을 수 없는 `installed_plugins.json`에서의 복구를 개선했습니다. 내용은 rebuild되기 전에 옆의 파일에 유지되고, `claude plugin list`가 해당 파일의 이름을 지정합니
