> 원문: [Claude Code v2.1.257 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.257)

## 변경사항

- Claude Fable 5.1(`claude-fable-5-1`)을 추가했으며, 이제 기본 Fable 모델입니다 — 1M context, Mtok당 $10/$50이며 cache read는 Mtok당 $0.25입니다
- "Time format"(`timeFormat`) 및 `timeZone` 설정을 추가했습니다: 12시간, 24시간, 24시간 UTC 또는 turn-end clock 및 transcript-view timestamp를 위한 strftime 패턴
- cloud metadata-credential fetch, egress evasion 및 cross-tenant reach이 환경에서 예상되는 것으로 표시되지 않는 한 자동 모드에서 더 이상 자동 승인되지 않도록 Containment Escape rule을 자동 모드에 추가했습니다
- 모든 subagent에 `CLAUDE_CODE_SUBAGENT_MODEL` (또는 main model)을 적용하고, per-spawn 및 agent-definition model override를 무시하도록 `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`를 추가했습니다
- `/effort`에서 현재 세션에 대해서만 effort를 변경하도록 `s`를 추가했으며, `/model`과 동일하게 작동합니다
- killed session에 의해 남겨진 stale sandbox mask file을 위한 `/doctor` warning을 추가했습니다
- auto mode에서 working directory 외부의 첫 파일 읽기 전에 일회성 prompt를 추가했으며, 이러한 읽기를 차단할 수 있는 옵션이 있습니다(`permissions.blockReadsOutsideWorkingDirectories`)
- gateway가 제공한 discovered `/model` picker entry의 `description` 지원을 추가했습니다(`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`); 설명이 없는 entry는 여전히 "From gateway"로 표시됩니다
- 시작 후에 생성된 `.claude/` 폴더의 설정이 재시작 시까지 선택되지 않는 문제를 수정했습니다
- agent view에서 `←`로 dispatched된 세션이 항상 원본 세션의 permission mode에서 시작되어 대상 디렉토리의 `defaultMode` 및 agent의 `permissionMode`를 override하는 문제를 수정했습니다
- `claude agents`에서 Ctrl+G의 `keybindings.json` rebind가 무시되는 문제를 수정했습니다; 이제 Ctrl+S / Ctrl+T는 새로운 `Agents` context를 통해 rebind할 수 있습니다
- macOS npm install에서 self-update 중 background session이 시작되지 않고 Windows에서 재사용된 process id를 가리키는 stale daemon lock file로 인해 시작되지 않는 문제를 수정했습니다
- slash-command panel 뒤에서 response가 streaming 되는 동안 working spinner가 멈추는 문제를 수정했습니다
- background session의 `state.json` `detail`이 scheduled wake-up 후 자신의 dispatch prompt를 반복하는 문제를 수정했습니다
- `claude agents`가 re-prompted된 background session을 Completed에 남겨두고 다시 완료되는 문제를 수정했습니다; Completed는 이제 최신 완료 시간 순으로 정렬됩니다
- 방금 삭제된 디렉토리에서 `claude --bg`가 "backgrounded"를 보고하고 crashed session row를 남기는 문제를 수정했습니다; 이제 reason을 출력하고 exit 1로 종료합니다
- Remote Control이 mid-session 중에 연결되어 Bash tool definition을 다시 전송하여 prompt-cache miss를 유발하는 문제를 수정했습니다
- doubly-listed custom `Authorization` header가 Bedrock, Mantle, Vertex 및 WIF의 configured credential을 override하고, Vertex setup wizard가 `~/.config/anthropic`에서 leftover Anthropic profile을 선택하는 문제를 수정했습니다
- Claude apps gateway가 stray host `Authorization` 또는 profile header를 Foundry, Vertex 및 Bedrock으로 전송하고, Foundry Entra ID upstream이 `ANTHROPIC_FOUNDRY_API_KEY` 설정될 때 시작되지 않는 문제를 수정했습니다
- leftover Anthropic API key 또는 auth token이 API-key mode의 Foundry subscription key와 함께 전송되는 문제를 수정했습니다
- message role 없이 저장된 후 실행할 것이 없는 상태로 실행되는 `/schedule` routine의 문제를 수정했습니다
- `claude agents`가 background session이 다른 세션에서의 message 승인을 기다리고 있거나 누가 보냈는지를 표시하지 않는 문제를 수정했습니다
- Ctrl+S로 opened background session 내에서 stash된 prompt가 session이 idle 또는 stopped되었다가 reopened될 때 손실되는 문제를 수정했습니다
- telemetry(OTEL) 설정이 server-managed settings를 통해 pushed되어 warm start 시 무시되는 문제를 수정했습니다(desktop-app Code session 포함)
- teammate permission request가 leader의 mailbox write이 잠깐 locked되었을 때 두 번 답변되는 문제를 수정했습니다
- command의 auto-continued response가 streaming 되는 동안 in-flight turn 아래에 phantom duplicate slash-command row가 rendering되는 문제를 수정했습니다
- `policyHelper` `timeoutMs` 및 `refreshIntervalMs` 값이 timer maximum(2147483647) 이상이어서 실패 또는 millisecond마다 re-run되는 문제를 수정했습니다; 이제 clamped됩니다
- 다른 subagent의 transcript로 전환한 후 token counter가 freeze 또는 crawl되는 문제를 수정했습니다. background subagent 및 teammate의 counter는 이제 response가 streaming될 때 live로 업데이트됩니다
- trailing dot(`example.com.`)로 작성된 sandbox network host: `deniedDomains` entry가 sandbox 내부의 host를 차단하지 않았으며, 이러한 host에 대해 "don't ask again"이 계속 prompt하는 문제를 수정했습니다
- Remote Control consent prompt(Esc 또는 `claude remote-control`에서 `n`)를 닫으면 consent로 계산되어 다음 요청이 묻지 않고 연결되는 문제를 수정했습니다
- `/mcp` reconnect 및 enable이 startup 후 loaded되어야 하는 managed MCP allow/deny list 또는 `strictPluginOnlyCustomization`이 차단해야 할 settings-file MCP server를 연결하는 문제를 수정했습니다
- `strictPluginOnlyCustomization`이 MCP를 plugin-only server로 lock할 때 `claude mcp remove`가 remote server의 stored OAuth credentials를 남기는 문제를 수정했습니다
- Claude app에서 시작된 Remote Control(`claude remote-control`) session이 선택된 model을 무시하고 machine의 default에서 실행되는 문제를 수정했습니다
- `allowManagedPermissionRulesOnly`가 enabled될 때 `--disallowedTools` 및 session deny rule이 첫 settings reload 후 dropped되는 문제를 수정했습니다
- `--resume`이 backgrounded conversation을 두 번 나열하고 `--continue`가 stalled pre-background copy를 reopen하는 문제를 수정했습니다; `--continue`는 이제 finished background session도 open합니다
- fullscreen mode에서 `!` shell command output을 클릭하여 expand할 수 없는 문제를 수정했습니다
- 더 오래된 Claude Code binary를 실행 중인 background session이 auto-update 후에도 누적되지 않고 retired되는 문제를 수정했습니다
- `claude agents --json`이 terminal을 raw mode로 잠깐 전환하고 exit할 때 다른 프로그램의 terminal 설정을 되돌리는 문제를 수정했습니다
- Proactive output style session이 background command를 시작한 Monitor 또는 여전히 실행 중인 Monitor가 idle하는 동안 filler message와 repeated log read로 busy-loop되는 문제를 수정했습니다
- computer sleep, dropped connection 또는 server error로 인해 stream 중간에 response가 cut off될 때 subagent가 중지되는 문제를 수정했습니다; 이제 incomplete response로 종료하지 않고 자동으로 continue합니다
- `claude agents` session 내 `/btw` panel에서 `←`이 작동하지 않는 문제를 수정했습니다: 이제 agents list로 돌아가며(mid-answer도 포함), panel은 session을 reopen할 때 돌아옵니다
- advisor model이 set된 session이 background request(compaction, `/recap`, prompt suggestion)에서 prompt cache를 빠뜨리고 매번 full conversation을 uncached로 re-send하는 문제를 수정했습니다
- `claude -p`가 최종 result 약 5초 후에 model이 armed한 Monitor가 여전히 실행 중인 동안 exit되는 문제를 수정했습니다; 이제 watch가 fire하거나 time out될 때까지 대기합니다
- matching command가 compound command 또는 subshell 내에서 실행될 때 auto mode에서 `permissions.ask` rule이 skip되어 confirmation prompt 없이 실행되는 문제를 수정했습니다
- plugin이 declared command, agent, skill, hook 또는 symlink인 기타 component path를 통해 자체 디렉토리 외부의 파일을 읽을 수 있는 문제를 수정했습니다; 이러한 path는 이제 error로 refuse됩니다
- `/add-dir`이 현재 working directory 내의 directory를 reject하는 문제를 수정했습니다; 이제 `--add-dir`과 같이 startup에서 해당 directory의 skill, command 및 agent를 load합니다
- stopped된 subagent를 transcript view에서 resume할 때 main agent에 알리지 않는 문제를 수정했습니다
- ANSI-colored text(예: CI log)를 `/feedback` 같은 dialog에 붙여넣을 때 crash되는 문제를 수정했습니다
- project의 `.mcp.json`이 FIFO 또는 device-file symlink일 때 `claude mcp add/remove`가 hang되거나 memory를 exhaust하는 문제를 수정했습니다; 이제 actionable message로 빠르게 fail합니다
- non-JSONL data를 `claude -p --input-format stream-json`으로 pipe할 때 unbounded memory growth가 발생하는 문제를 수정했습니다; 이제 명확한 error로 빠르게 fail합니다
- subagent 또는 다른 tool이 실행 중인 동안 turn을 background(`←` 또는 Ctrl+B)할 때 가끔 background session이 해당 tool을 rejected로 처리하는 대신 re-run하는 문제를 수정했습니다
- Bash `Read()`/`Edit()` deny rule이 `< file` redirect 및 `tac`, `egrep` 같은 reader command에 적용되지 않는 문제를 수정했습니다; 모든 argument 또는 redirect target에 대한 deny rule이 이제 command를 refuse합니다
- transcript가 5 MB를 초과했을 때(예: 많은 image를 읽은 후) subagent를 resume하거나 message할 때 "No transcript found"로 fail되는 문제를 수정했습니다
- worktree-isolated session이 git을 건드리지 않는 Bash loop, `$VAR` read, `"$(…)"` 및 heredoc을 "too complex to verify that it stays inside the worktree"로 refuse하는 문제를 수정했습니다
- conversation을 empty로 rewind한 후 `/model` 및 `/effort`가 prompt-cache warning을 표시하는 문제를 수정했습니다
- image가 per-request size cap을 초과한 후 long screenshot-heavy session에서 모든 turn에 prompt-cache miss가 발생하는 문제를 수정했습니다
- Edit permission prompt의 diff view가 emoji 및 multi-code-point character를 incorrect width로 rendering하는 문제를 수정했습니다
- WebSocket MCP server connection 실패가 underlying error 대신 "[object ErrorEvent]"로 logged되는 문제를 수정했습니다
- 다른 Claude Code process가 npm update를 다운로드 중일 때 background session이 "Couldn't start the background service"로 open되지 않는 문제를 수정했습니다; 이제 start가 대기합니다
- shell에서 detach된 background command(예: `timeout` 또는 `setsid` 아래)가 task stop 또는 Claude Code exit 후에도 survive하는 문제를 수정했습니다
- tasks panel 또는 connected client에서 background command를 stop할 때 Claude에 알리지 않는 문제를 수정했습니다
- background subagent를 stopping할 때 monitor가 실행 중인 상태로 남는 문제를 수정했습니다
- linked worktree의 sandboxed git command가 subdirectory로 `cd`한 후 repository의 common `.git` directory에 대한
