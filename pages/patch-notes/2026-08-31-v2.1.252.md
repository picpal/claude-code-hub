## 변경사항

- Mac의 일부에서 "task output swap refused (tasks dir moved or linked)" 오류로 Bash commands가 실패하는 문제를 수정했습니다
- .claude/settings.local.json이 아직 없는 프로젝트에서 "always allow"가 저장되지 않는 문제를 수정했습니다
- claude.ai와의 연결이 저하되었을 때 tool이 완료된 후 Claude Desktop 또는 VS Code에서 호스팅하는 Remote Control 세션이 수 분 동안 정지하는 문제를 수정했습니다
- 매우 큰 실패 출력(예: 디스크 가득 참으로 인한 git 오류)을 포함한 background task 알림이 API 요청 크기 제한을 초과하게 하는 문제를 수정했습니다
