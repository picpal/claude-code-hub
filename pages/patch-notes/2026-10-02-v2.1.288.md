> 원문: [Claude Code v2.1.288 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)

## 변경사항

- `$.ui.selection()`을 mods에 추가하였습니다: 전체 화면 모드에서 마지막으로 선택한 텍스트를 반환하며, 선택 영역이 하나의 transcript 행 내에 있을 경우 그 행을 반환합니다
- GitHub CLI가 없는 이미지를 사용하는 cloud sessions에 built-in `gh api`를 추가하였고, 파일 이름, jq filters 또는 GitHub 오류에서 터미널로 제어 문자를 보내는 built-in의 문제를 수정하였습니다
- Ctrl+C로 지워진 prompt의 복구 기능을 추가하였습니다: 빈 prompt에서 Up을 누르면 붙여넣은 텍스트 및 이미지를 포함한 draft가 복원됩니다
- MCP server가 tool call 중에 더 많은 OAuth scope을 요청할 때 재인증 prompt를 추가하였습니다
- /code-review에 `--max-findings <n>|all`을 추가하여 일반적인 제한보다 더 많거나 적은 발견 사항을 보고할 수 있도록 하였습니다; 선택 항목은 `--max-findings default`를 전달할 때까지 재사용됩니다
- agents view에서 Ctrl+F를 추가하여 session을 이름으로 찾을 수 있도록 하고, Alt+↑/↓를 추가하여 그룹 간에 이동할 수 있도록 하였습니다; 이들 및 이름 바꾸기는 keybindings.json에서 재바인딩할 수 있습니다
- plan을 승인할 때 Shift+Tab을 포함하여 새로운 permission mode의 screen reader mode 공지를 추가하였습니다
- 응답 중 API timeout이 turn을 실패시키는 문제를 수정하였습니다: non-interactive sessions 및 subagents는 이제 부분 응답에서 계속되며, thinking-only 응답은 다시 시도됩니다
- 마지막 reply가 0 token 사용을 보고했을 때 "Prompt is too long" 오류 대신 auto-compacting되지 않는 긴 conversations의 문제를 수정하였습니다
- `--resume`이 때때로 compaction이 방금 복원한 파일 및 기타 context를 삭제하는 문제를 수정하였습니다
- 재개된 session이 때때로 turn의 마지막 response를 저장하지 않아 다음 `--resume`에서 prompt가 답변되지 않은 상태로 표시되는 문제를 수정하였습니다
- 동일한 session이 로드 중에 파일을 다시 작성할 때 resume이 가끔 잘린 transcript를 로드하는 문제를 수정하였습니다
- 2.1.286 이전에 시작된 conversation을 재개할 때 model의 이전 thinking을 삭제하는 문제를 수정하였습니다
- Mantle에서 또는 structured outputs를 거부하는 gateway 뒤에서 session titles, memory recall 및 prompt hooks가 실패하는 문제를 수정하였습니다; structured outputs를 끄기 위해 `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS`를 추가하였습니다
- 차단된 tool이 Bash가 아닐 때 auto mode denials이 Claude를 Bash permission rule로 가리키는 문제를 수정하였습니다
- Bedrock 및 Mantle의 auto mode가 WebFetch summary 또는 `sonnet` subagent와 같은 이전 model에 대한 요청 후 나머지 session에서 local classifier로 전환되는 문제를 수정하였습니다
- 새로 선택한 model에서 다시 시작된 cloud sessions이 server가 이를 거부했을 때도 그 model로 응답하는 문제를 수정하였습니다
- Cowork cloud sessions이 승인되지 않은 URL에 대한 WebFetch permission prompt가 5분 동안 응답이 없은 후 입력 대기 중으로 표시된 상태로 유지되는 문제를 수정하였습니다
- Cowork cloud session을 다른 기기에서 시작한 phone이 참여할 때 prompt suggestions이 표시되지 않는 문제를 수정하였습니다
- Claude Code 재시작 전에 그려진 view에서 pressed될 때 mod의 button이 때때로 다른 button의 action을 실행하는 문제를 수정하였습니다
- 하나의 `Code` element가 parse되지 않는 diff를 보유할 때 plugin의 pane에 아무것도 표시되지 않는 문제를 수정하였습니다; 이제 plain code로 그립니다
- plugin LSP servers가 `initializationOptions` 및 `settings`에서 substituted values 또는 manifest defaults 대신 literal `${user_config.*}` 및 `${CLAUDE_PLUGIN_ROOT}` placeholders를 수신하는 문제를 수정하였습니다
- plugin의 `tool.call` hook이 Bash를 실패하게 하고 worktree에서 실행되는 subagents의 파일 검색이 잘못된 폴더를 읽게 하는 문제를 수정하였습니다
- `git-subdir` plugin installs가 실패하거나 이전 git(2.39 이전, 예: Ubuntu 22.04의 2.34)에서 불완전한 plugin을 cache하는 문제를 수정하였습니다
- `--plugin-dir`으로 로드된 plugins이 `/plugin`에서 "Configure options"을 표시하지 않는 문제를 수정하였습니다
- plugin이 reload되거나 disabled될 때 background sessions이 그 timer 또는 read 중 하나가 여전히 실행 중이면 끝나는 문제를 수정하였습니다
- 인용되지 않은 delimiter를 가진 sandboxed heredocs(`python3 <<EOF`)이 body가 plain text와 simple `$VAR` references만 포함할 때 sandbox auto-allow 아래에서 모든 run에서 승인을 요청하는 문제를 수정하였습니다
- Bash tool permission check을 수정하여 shell이 산술로 평가할 value를 가진 `BASHPID` assignment 전에 prompt하도록 하였으며, 이전에는 자동으로 허용되었습니다
- fullscreen sessions이 plugin 또는 mod이 prompt 위에 rows를 표시할 때 background tasks dialog를 열 때 "unrecoverable interface error"로 종료되는 문제를 수정하였습니다
- Claude가 그 session이 이를 보유했을 때 메시지를 다른 session으로 delivered로 보고하는 문제를 수정하였습니다: 공지는 이제 delivered되지 않았음을 나타내고 session 이름을 지정하며, SDK sessions에서 Claude는 이제 mid-turn에서 이를 배울 수 있습니다
- OpenTelemetry `claude_code.tool.blocked_on_user` spans이 `-p` 및 SDK sessions과 PreToolUse hook approvals에서 `unknown` source 또는 decision을 보고하는 문제를 수정하였습니다
- 답변 없이 끝난 permission asks이 `-p` 또는 interrupted turn에서 `tool_decision` event를 방출하지 않는 문제를 수정하였습니다
- Cowork cloud sessions의 Edit and Retry이 history가 여전히 저장되었음에도 불구하고 `/compact` 전에 전송된 메시지를 거부하는 문제를 수정하였습니다
- Unattended sessions(`CLAUDE_CODE_RETRY_WATCHDOG`)이 매우 긴 response stream이 실패한 후 수 시간 동안 재시도하는 문제를 수정하였습니다; Claude Code는 이제 다시 stream하고, 세 번의 timeout 후에 포기합니다
- `/login`이 자격증명을 secure storage에 저장할 수 없을 때 "Login successful"을 보고하는 문제를 수정하였습니다; 이제 실패를 표시하고, 새로운 login이 적용되지 않았을 때 재시도를 제안합니다(anthropics/claude-code#73861)
- Bedrock credential lookup 중 Stop이 때때로 session을 요청 종료 대신 fallback model로 이동하는 문제를 수정하였습니다
- laptop이 다른 Claude Code process가 sign in 중일 때 sleep에서 깨어날 때 두 번째 `gcpAuthRefresh`/`awsAuthRefresh` browser sign-in이 열리는 문제를 수정하였습니다
- agent teams의 문제를 수정하였습니다: name으로 spawned된 plugin-defined agent는 이제 defaults 대신 자신의 prompt, tools, disallowedTools 및 effort로 실행됩니다
- headless(`-p` / SDK) sessions이 `timeout` 또는 systemd와 같은 supervisor가 SIGCONT와 함께 SIGTERM을 보낼 때 가끔 무시하는 문제를 수정하였습니다
- 다시 시작된 cloud sessions이 organization의 enforced model list가 거부하는 model을 복원하는 문제를 수정하였습니다
- MCP tool calls이 remote server의 result가 16 MB를 초과하거나 parse될 수 없을 때 때때로 두 번 실행되는 문제를 수정하였습니다
- Claude Desktop의 Code tab의 subagents이 `memory`라는 user-configured MCP server의 tools를 전혀 얻지 못하는 문제를 수정하였습니다
- Claude in Chrome이 auto mode를 사용할 수 없을 때(예: `disableAutoMode` 또는 이전 model) 허용한 site에서 모든 screenshot 및 page read 전에 묻는 문제를 수정하였습니다; typing, navigation 및 JavaScript는 여전히 묻습니다
- `claude plugin install`이 GitHub SSH key가 없는 macOS 및 Linux machines에서 GitHub-source plugins의 경우 실패하는 문제를 수정하였습니다: clone은 이제 HTTPS로 폴백되고 공지를 인쇄합니다
- `sandbox.credentials.files` entries on git config files이 `permissions.blockReadsOutsideWorkingDirectories`가 켜져 있을 때 적용되지 않는 문제를 수정하였습니다
- Claude가 Team 및 Enterprise plans이거나 managed settings가 있는 machines에서 Artifact tool로 slides 또는 design을 시작할 때 organization의 design systems를 누락하는 문제를 수정하였습니다
- Claude Code 재시작 후 Windows에서 keyboard가 작동하지 않는 문제를 수정하였습니다(Claude apps gateway의 첫 sign-in, provider setup, `/tui`)
- 매우 많은 `Agent(...)` entries를 나열하는 tools를 가진 agent를 launch할 때 stall이 발생하는 문제를 수정하였습니다
- Claude 3 Opus 및 Claude 3 Sonnet의 sessions이 전체 PDF가 conversation에 들어온 후 모든 turn에서 실패하는 문제를 수정하였습니다
- npm auto-updater이 platform-native binary가 다운로드를 실패했고 placeholder `claude` stub만 설치되었을 때 성공을 보고하는 문제를 수정하였습니다
- Remote Control cleanup이 여전히 연결되어 있거나 다른 Claude Code process에 의해 방금 re-attached된 session을 archive하는 문제를 수정하였습니다
- `owner/repo` plugin marketplaces가 SSH 및 HTTPS fetch가 모두 실패할 때 두 번째 시도의 오류만 표시하는 문제를 수정하였습니다; 두 오류가 이제 표시되며, 처음 시도한 transport가 맨 위에 있습니다
- Write 또는 Edit이 파일을 생성하거나 변경할 때 path-scoped `.claude/rules` 및 nested CLAUDE.md files이 로드되지 않는 문제를 수정하였습니다(이전에는 Read만 로드했습니다)
- bypassPermissions mode이거나 shell allow rule 아래의 `bash -c` 또는 `sh -c` script 내의 위험한 `rm`(예: `/` 또는 home directory의)이 prompt 없이 실행되는 문제를 수정하였습니다(anthropics/claude-code#96300)
- LSP tool calls이 language server가 dynamic capability registration를 사용하거나 응답을 중단할 때 무한정 hang되는 문제를 수정하였습니다; requests은 이제 60s 후에 timeout됩니다(per-server `requestTimeout`)
- `idle_prompt` notification hooks이 background agents이 여전히 실행 중일 때 발생하는 문제를 수정하였습니다(anthropics/claude-code#93672)
- PreToolUse 및 PermissionRequest hooks이 이들 matching에 실패했거나 tool의 input을 JSON으로 직렬화할 수 없을 때 skipped되는 문제를 수정하였습니다; call은 이제 blocked됩니다
- fresh environment 또는 model switch 후의 첫 번째 request이 server의 built-in output limit 및 auto-compact window를 사용
