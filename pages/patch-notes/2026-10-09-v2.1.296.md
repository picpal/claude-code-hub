> 원문: [Claude Code v2.1.296 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.296)

## 변경사항

- Claude apps gateway의 `managed.policies[]`에 `code` 키를 추가했습니다. `cli`와 동일한 설정이며 Claude Desktop의 Code 탭에도 적용됩니다. `desktop` 외에도 Claude Desktop의 gateway mode를 활성화합니다.
- subagent frontmatter 및 `--agents` 정의에 `autoCompactWindow`를 추가했습니다. subagent가 주요 대화의 window보다 더 일찍 자동으로 압축할 수 있습니다.
- `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`을 추가해 모든 workflow agent를 하나의 model에서 실행하고 다른 subagent들은 각각의 model을 유지하도록 했습니다.
- `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` environment variable을 추가해 overloaded(529) 요청을 재시도할 때 backoff의 최대 지연 시간을 더 길게 설정할 수 있습니다.
- `/plugin`에 다른 활성화된 plugin이 동일한 이름을 가지고 있어 hook이 생략된 plugin에 대한 참고사항을 추가했습니다.
- Read tool에 `allow_large` 옵션을 추가해 Claude가 파일 전체가 필요하고 context에 여유가 있을 때 일반적인 크기 제한을 초과하는 텍스트 파일을 한 번의 호출로 읽을 수 있습니다.
- managed settings의 `PreToolUse` hook이 `"continue": false`로 tool call을 거부하고, managed `prompt` hook이 하나를 차단하되 call을 거부하면서도 turn을 종료하지 않는 문제를 수정했습니다.
- managed settings의 PostToolUse hook이 일부 session에서 `updatedMCPToolOutput`을 적용하지 않는 문제를 수정했습니다.
- headless session이 폴더의 `.mcp.json` 또는 plugin MCP server를 시작할 때 해당 폴더에 대해 비활성화된 상태로 전환된 후 디렉토리를 변경하거나 plugin을 다시 로드하는 문제를 수정했습니다.
- `allowedProviders`를 `"gateway"`로 제공하는 Claude apps gateway가 사용자 설정에서 해당 gateway를 명명한 laptop을 잠그는 문제를 수정했습니다.
- managed settings이 `forceLoginGatewayUrl` 없이 `forceLoginMethod`를 `gateway`로 설정한 machine에서 저장된 Claude apps gateway 로그인이 무시되는 문제를 수정했습니다(2.1.295에서의 regression).
- `--teleport`가 session의 기록을 읽을 수 없을 때 빈 대화를 여는 문제를 수정했습니다.
- Haiku 5.5 및 adaptive thinking만을 사용하는 다른 model에 대한 token count가 일부 gateway 뒤에서 실패하고 다른 곳에서는 budget thinking으로 계산되는 문제를 수정했습니다.
- 재개된 subagent가 session shutdown으로 인해 중단된 tool call을 사용자가 거부했다고 통보받는 문제를 수정했습니다.
- hook output이 plugin hint tag처럼 보이는 텍스트를 포함할 때 변경되는 문제를 수정했습니다.
- 공유된 transcript 및 debug log의 secret redaction이 JSON 내에 shell string으로 작성된 값을 포함해 값이 없는 키를 따르는 일부 값을 놓치는 문제를 수정했습니다.
- MATE Terminal 같은 오래된 VTE 기반 terminal에서 복사 후 화면에 인쇄되는 잘못된 `52;c;…` escape sequence 문제를 수정했습니다.
- `/diff` panel이나 dialog가 열려있는 동안 toast와 notification이 보이지 않은 채 대기하는 문제를 수정했습니다.
- `UserPromptSubmit` hook이나 mod의 `prompt.submit` hook 중 Esc를 누르거나 interrupt가 발생할 때 headless session이 종료되고, 입력한 prompt가 지워지거나 확인되지 않은 prompt가 통과되는 문제를 수정했습니다.
- headless session 시작 후 로드된 plugin의 SessionStart hook이 동일한 이름 또는 다른 철자의 다른 plugin이 이미 실행된 경우 건너뛰어지는 문제를 수정했습니다.
- `claude self-hosted-runner`가 등록이 거부될 때 오해의 소지가 있는 오류를 출력하는 문제를 수정했습니다. 이제 org admin setting의 이름을 지정하거나 재시작된 on-demand runner가 새로운 work order가 필요하다고 명시합니다.
- self-hosted runner session의 git fetch, pull 및 push가 `--capacity`가 1 이상인 runner에서 동일한 repository의 다른 session이 시작될 때 실패하는 문제를 수정했습니다.
- workflow script가 약 20,000 레벨보다 깊게 중첩된 결과, agent option 및 기타 값을 자동으로 truncate하고, 깊게 중첩된 결과가 큰 task output 파일을 작성하는 문제를 수정했습니다.
- plugin의 served `$` method가 주요 session의 작업 디렉토리 대신 calling agent의 디렉토리에서 실행되고 calling hook이 보유한 turn을 무시하는 문제를 수정했습니다.
- `$.agent.register`이 mod의 hook에서 mod가 다시 로드되거나 제거된 후에도 실행 중일 때 성공하는 문제를 수정했습니다. 이제 call이 거부됩니다.
- `$.http.fetch`이 mod에서 response가 4 MiB body limit보다 큰 `Content-Length`를 선언할 때 `HEAD` request를 거부하는 문제를 수정했습니다.
- `claude plugin marketplace add`, `marketplace update` 및 `plugin install`이 `constructor` 같은 marketplace 이름으로 인해 internal error가 발생하는 문제를 수정했습니다. `add`는 이제 그러한 이름을 명확하게 거부합니다.
- `constructor` 또는 `prototype`이라는 이름의 plugin secret이 해당 plugin의 option이 다음 저장 시 삭제되는 문제를 수정했습니다.
- cloud session이 feature flag를 로드하지 않았을 때 저장된 permission이 허용하는 Claude in Chrome action에 대해 auto mode의 확인을 건너뛰는 문제를 수정했습니다.
- `CLAUDE_CODE_RESUME_INTERRUPTED_TURN`이 MCP tool result가 turn을 종료한 후 restart 시 완료된 turn을 다시 실행하는 문제를 수정했습니다.
- Bash permission check가 `BASH_ARGV0` shell variable을 할당한 후 이를 사용하는 일부 command를 자동으로 승인하는 문제를 수정했습니다. 이제 승인을 요청합니다.
- Edit 및 NotebookEdit이 유효한 UTF-8이 아닌 파일(Windows-1252, Shift-JIS, GBK)의 모든 non-ASCII 문자를 대체하는 문제를 수정했습니다. 이제 그러한 edit은 거부됩니다.
- `←` 실행 직후 전송된 prompt가 background service의 응답이 느릴 때 foreground에서 한 번, 보이지 않게 한 번 두 번 실행되는 문제를 수정했습니다.
- SessionStart hook이 여전히 실행 중일 때 전송된 prompt가 `←`로 session을 background로 이동할 때 사라지는 문제를 수정했습니다. 아직 전송되지 않지만, 이제 `↑`이 이를 되돌립니다.
- 늦게 로드되는 plugin의 SessionStart hook output이 headless session에서 `/clear` 후 새 대화에 도달하는 문제를 수정했습니다.
- PowerShell command가 hook이 CLAUDE_ENV_FILE에 작성하는 variable을 보지 못하는 문제를 수정했습니다(파일이 plain assignment만 포함할 때).
- Claude가 cloud session을 non-interactive로 호출하고 MCP server가 authentication이 필요할 때 `/mcp` 또는 `claude mcp`를 제안하는 문제를 수정했습니다.
- `/code-review`가 cloud session, Agent SDK 및 IDE integration에서 raw JSON array로 끝나는 문제를 수정했습니다. 이제 findings가 numbered list로 출력됩니다.
- auto mode가 artifact sharing이 변경되지 않았는데도 변경되었다고 말하면서 당신의 artifact에 대한 한 번의 update를 거부하는 문제를 수정했습니다.
- claude.ai에서 동기화된 skill이 선언하는 marketplace dependency도 claude.ai에서 동기화되었을 때 설치를 완료하지 못하고 모든 동기화 시 다시 다운로드되는 문제를 수정했습니다.
- Linux machine에서 복사된 plugin path가 /home 아래를 가리킬 때 macOS에서 startup hang이 발생하는 문제를 수정했습니다.
- Workflow tool이 Windows에서 checked out한 파일 같은 CRLF line ending을 가진 script 파일을 거부하는 문제를 수정했습니다.
- OpenTelemetry `tool_result` event가 `git commit -q` 또는 `git -C <dir> commit` 후 `git_commit_id`를 누락하는 문제를 수정했습니다.
- `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC`가 text에 Unicode line 또는 paragraph separator(U+2028, U+2029)를 포함할 때 저장된 transcript에서 message를 삭제하는 문제를 수정했습니다.
- `claude purge`가 text에 Unicode line 또는 paragraph separator(U+2028, U+2029)를 포함할 때 history file에 prompt를 남기는 문제를 수정했습니다.
- Windows: PowerShell command가 약 1 KB보다 길면 항상 permission을 요청하는 문제를 수정했습니다. 이제 allow rule과 read-only detection이 32 KB까지 적용됩니다.
- Windows: stdio MCP server가 shutdown 시 force-kill되는 문제를 수정했습니다. 이제 stdin이 먼저 닫히고 server가 300ms 후에도 실행 중일 때만 process tree가 kill됩니다.
- Windows: GitHub SSH key가 없는 machine에서 GitHub `owner/repo` plugin source에 대해 `claude plugin install`이 실패하는 문제를 수정했습니다. 이제 clone이 HTTPS를 통해 재시도됩니다.
- Windows: Git Bash에서 `/rm -rf /c/Users/<name>`이 bypass permission mode에서 요청하지 않는 문제를 수정했습니다.
- fullscreen mode를 개선했습니다. 마우스 포인터 아래의 link가 이제 열 수 있음을 나타내도록 underline됩니다.
- code-heavy conversation에서 syntax-highlighted code block을 캐싱해 transcript toggle(ctrl+o) responsiveness를 개선했습니다.
- Claude apps gateway 뒤의 Claude Desktop's Code tab를 개선했습니다. session을 시작할 수 없을 때(gateway의 `code` 설정을 위해 설정되지 않은 machine 포함), 이유가 reply로 표시됩니다.
- refused cloud session의 오류를 개선했습니다. 이제 조직의 policy를 로드할 수 없는 이유를 설명하고 claude.ai 로그인을 override하는 API key 또는 auth token의 이름을 지정합니다.
- `--debug` output을 개선해 custom agent file의 인식되지 않은 frontmatter field 이름을 지정하고, 가능성 있는 typo에 대한 hint를 제공합니다.
- auto mode를 개선했습니다. auto mode의 check에 사용할 수 있는 답이 없어 실행되지 않은 tool call은 이제 빨간 error 대신 dim "Not run" row로 표시됩니다.
- `--debug` output을 hook에 대해 개선했습니다. tool call, prompt, SessionStart 및 Stop의 command hook은 이제 완료 시 command, plugin, outcome 및 duration을 로그하므로 느린 hook을 식별할 수 있습니다.
- `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC`를 개선했습니다. 큰 transcript file은 10% 이상을 해제할 경우에만 더 이상 다시 작성되지 않습니다.
- `/cost`, status line, `--max-budget-usd` 및 SDK의 cost 수치를 업데이트해 Sonnet 5.5 cache read를 million token당 $0.10으로 가격을 책정했습니다(이전: $0.20).
